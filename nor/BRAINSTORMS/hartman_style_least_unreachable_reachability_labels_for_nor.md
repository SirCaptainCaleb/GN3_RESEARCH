# Hartman-style least-unreachable reachability labels for NOR

Adapt Hartman's Sperner-to-Connector proof trick: label each state by the least boundary/threshold target unreachable inside its monochromatic repair component, so adjacency of same-color states forces equal labels and a fully labeled simplex becomes contradictory.

## Motivation

NOR already has the right reachability language but does not currently use Hartman's decisive labeling trick.

Existing §110 defines, at threshold rank q and polarity s, forward monochromatic reachability sets P_q^s and backward reachability sets Q_q^s, with NOR equivalent to P_q^s ∩ Q_q^s ≠ ∅ for some q,s. Existing Sperner carriers instead label faces by witnessed roots, change defects, or block-local degree data (§§146,155). The missing idea is to make **failure of monochromatic reachability itself** the Sperner label.

Hartman's connector proof suggests the following schema.

## Candidate NOR labeling

Work in a simplicial/cellular state complex whose vertices are compatible ternary memory states or full permutation chambers, and whose adjacency is an actual legal local move preserving a chosen color/repair type.

Choose an ordered list of boundary targets T_0,...,T_d. Depending on the chosen complex these might be:

- threshold faces q=0,...,m;
- simplex facets / ordered-partition boundary faces;
- canonical left/right reachability shores in the threshold prism;
- protected-root exit classes at the boundary.

For a state z, let R(z) be the set of target labels reachable from z by a path entirely inside its own monochromatic / same-repair-type component.

Assuming no NOR connector exists, define

    L(z) = least j such that T_j is not reachable from z.

This is the exact Hartman move.

## Why it could be powerful

If adjacent states z,z' have the same underlying color/repair type, then they lie in the same monochromatic component, hence

    R(z)=R(z')  and therefore  L(z)=L(z').

Thus a Sperner-full cell whose vertices use only two actual colors/repair types cannot have all distinct reachability labels: among d+1 vertices, two share the same underlying color/type, are adjacent inside the simplex, and must have the same least-unreachable label.

So if L is a proper Sperner labeling, Sperner gives a completely labeled cell, while component invariance forbids one. This proves existence of the desired connector.

The attraction is that **no gluing of unrelated local witnesses is required after the topological step**. Reachability has already encoded gluing globally.

## Main proof obligations

1. **Choose the right state complex.**
   The memory-state/Freudenthal refinement is preferable to support-only subset vertices, because legal paths must correspond to actual compatible window moves.

2. **Choose boundary targets so L is Sperner-proper.**
   For a vertex lying on a boundary face F, every forbidden label must correspond to a target that is automatically reachable inside F, exactly as in Hartman's boundary argument. This is the central technical point.

3. **Choose the component relation.**
   Same ternary color alone may be too coarse. A promising option is:
   - fixed polarity s;
   - legal local moves preserving s-monochromatic threshold compatibility;
   - or the repair graph generated by audited flat/square moves before a protected-root exit.

4. **Handle the two-step memory.**
   Adjacency in one simplex must guarantee that same-type vertices are connected by an allowed edge, or at least lie in the same allowed component. The barycentric memory-state complex may make this automatic.

5. **Exploit antipodality.**
   Reversal sends forward s-reachability to backward -s reachability. A least-unreachable labeling may therefore admit a symmetric/Tucker version on the threshold prism if ordinary Sperner boundary conditions are awkward.

## Concrete first test

Start from §110's threshold-prism formulation.

For fixed s, treat each memory state z as carrying the interval/set of threshold ranks q for which z is reachable from the s-source side through an s-monochromatic prefix. Dually track backward -s reachability.

Try labeling z by the smallest threshold/facet index that cannot be reached within its s-component. Prove:

- same-s adjacent states have identical labels;
- on the j-th boundary face, label j is excluded;
- hence the labeling is Sperner proper.

If successful, a fully labeled simplex is impossible because a simplex has d+1 vertices but only the underlying two ternary colors / bounded repair types, forcing a repeated component label among adjacent same-type vertices.

## Strategic significance

This is closely related to the existing Connector and reachability ideas (§§68,110), but materially stronger: instead of using reachability sets only to formulate a separator, it converts the **least missing reachability target** into the actual Sperner label.

That may be exactly the abstraction needed to bypass the current witness-supported square-lift / relative-splicing bottleneck. The topological contradiction would certify a connected legal repair component directly, rather than first producing an algebraic root relation and then asking how to realize it.

## Pursuit update: the directed prism is the wrong component space

The first test fails in its literal directed form. In the prefix automaton, if z→z' is a legal edge, the set of targets reachable forward from z' is only a subset of the set reachable from z. Same-color adjacency does not imply equal reachability sets. Thus Hartman's key component-invariance step is unavailable on the acyclic prefix prism (§300).

There is nevertheless an exact conserved two-color quantity on legal one-change states. For state (S;a,b,c,t), with c the current last-window color and t∈{0,1} the used-switch count,
[
sigma=coplus t
]
is the initial phase color and is preserved by every legal append move (§307). This is the natural Hartman color once a reversible repair complex is found.

## Better candidate: synchronized endpoint-flexible repair states

The surviving two-sided shortcut failure now has a much stronger structure (§§305,308,309).

Fix a distinguished coordinate x. A state of type
[
P(x;y)
]
consists of one common middle order M on V\{x,y} such that both xM and Mx are NOR-good deletion witnesses omitting y. The arbitrary-scan replacement dynamics can be run synchronously on these two endpoint rotations: every successful replacement sends P(x;y) to another P(x;y') while keeping x literally available at both global endpoints.

If one forgets the algorithmic direction and declares two such witness states adjacent whenever an audited synchronized replacement connects them, one obtains an honest undirected repair graph. On each connected component, boundary/exit reachability is automatically constant. This is precisely the component invariance Hartman's least-unreachable labels require.

The remaining topological task is now concrete: realize this endpoint-flexible repair graph, together with its A2/square recurrence cells and protected-root exit cells, as a simplicial or regular cell complex with identifiable boundary target classes satisfying a Sperner condition.

## Binary ladder model

For the opposite-scan residue, define
[
X_i=alpha(x,w_i,w_{i+1}),qquad
Z_i=alpha(z,w_i,w_{i+1}),qquad
R_i=alpha(x,z,w_i).
]
Then
[
R_{i+1}oplus R_i=X_ioplus Z_i,
]
with crossed rail boundary data and R_1=R_m=0 (§310). Pair insertion at position i uses exactly the four-window packet
[
X_{i-1},R_i,R_{i+1},Z_{i+1}.
]

Thus the residual obstruction is an exact two-row binary ladder built from reversible tetrahedral parity squares. Together with the forbidden scan patterns of §290 and the full K_{2,2} endpoint barriers of §305, this is currently the most concrete place to attempt a Hartman/Hex connector theorem.

The revised priority is therefore:

1. do not apply least-unreachable labels to the directed prefix prism;
2. build them on the reversible synchronized-repair / K_{2,2} ladder complex;
3. use protected-root exits as boundary targets;
4. prove the boundary labeling condition there.

This route now has a genuine component invariant and exact local cell structure; its remaining gap is topological realization rather than witness compatibility.

## Second pursuit update: the ladder shortcut itself closes locally

Further analysis sharpens the ladder substantially.

For any rail-disagreement index i,
[
X_i
e Z_i,
]
the four-coordinate order
[
(x,w_i,w_{i+1},z)
]
is automatically a genuine transition carrier with physical root (x	o z), because its consecutive statuses are exactly (X_i,Z_i).

Its curvature is controlled by the rung alignment:
[
X_i=R_i Longleftrightarrow 	ext{fully curved},
]
while
[
X_i
e R_i Longleftrightarrow 	ext{flat}.
]

In the crossed endpoint residue of §304, the first rail disagreement always satisfies
[
X_1=R_1.
]
Therefore
[
(x,w_1,w_2,z)
]
is already a fully-curved protected carrier of the desired shortcut (x	o z) (§326). The crossed shortcut branch consequently closes locally; neither threshold transport nor a Hartman connector is needed to obtain the root.

This also corrects §322's curvature assignment: misaligned disagreement gives a flat shortcut carrier; aligned disagreement gives the protected fully-curved one.

## Revised Hartman target

The genuinely unresolved problem is now one level higher.

The physical shortcut exists. What is missing is **carrier compatibility**: can the shortcut carrier be moved, through reversible audited repairs, into the same outside-order/provenance component as the two endpoint witnesses it is meant to replace?

This is now a natural Hartman problem. Build a reversible complex whose vertices are witnessed shortcut carriers for a fixed ordered pair (x,z), with edges given by:
- flat endpoint-repair squares;
- synchronized deletion replacements;
- A2/braid cells;
- same-cut fully-curved K22 exchange cells.

Boundary target classes should encode the relevant endpoint collars / outside-order classes of the original two witnesses.

For a carrier state q, define the least target class not reachable inside its reversible repair component. Hartman's argument would become applicable if:
1. the repair complex admits a simplex/regular-cell realization with a Sperner boundary condition;
2. adjacent states of the same repair color lie in the same component;
3. every boundary face forces reachability of the corresponding target class.

This formulation attacks exactly the remaining gap identified in §324:
[
	ext{physical shortcut} longrightarrow 	ext{provenance-compatible shortcut/splice}.
]

The original intuition therefore remains valuable, but its role has shifted from producing the shortcut to forcing compatibility among already-realized shortcut carriers.
