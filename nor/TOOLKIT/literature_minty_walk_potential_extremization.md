# Minty's walk-potential proof: paths emerge by extremality

**Summary:** Optimize over walks, not paths. If every closed excursion has nonpositive potential, loop erasure never hurts, so an extremizer is automatically simple. For NOR, seek a defect potential whose extremizers also cannot profitably repeat cube dimensions.

## Statement

Minty's proof maximizes an additive forward-minus-penalized-backward score over all rooted walks. Every closed excursion has nonpositive score, so deleting repeated-vertex excursions never worsens the objective; an extremizing walk is automatically a path. This is a reusable template for optimizing over locally convenient walks while recovering simplicity only at extremality.

# Minty's walk-potential proof: local moves first, paths by extremality

Sources: George J. Minty, "A Theorem on n-Coloring the Points of a Linear Graph", American Mathematical Monthly 69 (1962), 623-624, DOI 10.1080/00029890.1962.11989938. A transparent modern presentation appears in the proof of West's Exercise 5.1.44.

Fix an acyclic orientation D and let r=max_C ceil(a(C)/b(C)), where a(C),b(C) count forward/backward edges around a cycle. Fix x. For any walk W from x define
g(W)=a(W)-r b(W).
Forward steps score +1; backward steps score -r. For y put
g(y)=max{g(W): W is an x-y walk}.

The crucial step is why maximizing over all walks is safe. Every cycle C satisfies a(C)<=r b(C), hence g(C)<=0. Every closed walk decomposes into cycles, so every closed excursion Z also has g(Z)<=0.

If an x-y walk W repeats a vertex, delete the closed subwalk Z between two occurrences. The shortened walk W' satisfies
g(W')=g(W)-g(Z)>=g(W).
Iterating deletes every repetition and produces an x-y path P with g(P)>=g(W). Hence
max over walks g = max over paths g.
There are finitely many paths, so the maximum is finite and attained.

Thus Minty's reusable device is:
1. quantify over a locally convenient large class (walks);
2. use an additive potential;
3. prove every closed excursion is nonprofitable;
4. extremality then removes repetitions automatically.

The coloring step is secondary for toolkit use. If u->v, appending uv gives g(v)>=g(u)+1, while appending vu backwards gives g(u)>=g(v)-r. Thus 1<=g(v)-g(u)<=r, so g mod (r+1) properly colors G.

## NOR analogy

For NOR, enlarge from cube geodesics/permutations to local-move walks where dimensions may repeat. Seek an additive or telescoping potential Phi such that defect-improving moves improve Phi, while every excursion generated by reusing a cube dimension has nonpositive total gain.

Then optimization may be performed over unrestricted walks, making local repair quantifiers easy, and repeated-dimension excursions can be erased afterward without worsening Phi. An extremizer would simultaneously have optimal defect behavior and use no cube dimension twice.

A warning: a path in an auxiliary state graph is not automatically a cube geodesic, because distinct states may reuse the same cube dimension. The erasable object must therefore be a dimension-repetition excursion, or the state must remember enough data that dimension reuse produces a closed excursion in the relevant quotient.

A useful target lemma is: assign each local NOR move a local increment Delta Phi and prove that every closed move sequence restoring the relevant state/provenance data has total increment <=0. The strongest version would make repeated dimensions nonprofitable as a consequence of the same inequalities controlling defects, rather than by an artificial repetition penalty.

Questions for candidate potentials:
- What state data must be restored for loop erasure to be legal?
- Does dimension repetition create a deletable closed excursion?
- Is Phi additive or telescoping under concatenation?
- Can local defect repairs be scored without global-history checks?
- What plays the role of Minty's cycle-ratio inequality?
- Can zero-score excursions be erased while preserving protected-root or threshold-band provenance?
