## Development

If all cut defects vanish for rho_i=e_{x_{i+1}}-e_{x_i}, then L_i=L_{i-1}-{x_i}+{x_{i+1}}. Each cycle coordinate x_j is inserted at step j-1 and removed at step j, and no other step changes it. Every coordinate outside the physical cycle is unchanged. Therefore there is a fixed (p-1)-set K disjoint from the cycle vertices such that L_i=K union {x_{i+1}} for every i. Thus a perfectly compatible protected root cycle lies in one Johnson clique: the cut state is a single token rotating around the physical root cycle over a common core K. This is the normal form of the Delta=0 extraction target.
