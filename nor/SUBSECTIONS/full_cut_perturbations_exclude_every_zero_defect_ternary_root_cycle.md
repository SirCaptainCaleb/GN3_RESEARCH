## Development

Assume a protected physical root cycle has zero cut defect, so its cuts have the one-token form C_i=K union {x_{i+1}} for one fixed (p-1)-core K. In the quadratic full-cut perturbation, the physical roots already sum to zero, so persistence of this cycle as a perturbed zero requires sum_i s_i z_{C_i}=0, with side signs s_i in {+1,-1}. For p>=2 choose a coordinate of K. Its equation, compared with any coordinate outside the common core, forces S=sum_i s_i=0. Then z_{C_i}=1_K+e_{x_{i+1}}-(p/n)1 reduces the zero equation to sum_i s_i e_{x_{i+1}}=0. The cycle coordinates are distinct, so every s_i would have to vanish, impossible. If p=1, the same argument using a coordinate outside the physical cycle works unless the cycle spans all n coordinates; the spanning exception would require all s_i equal. But ternary minimum-first-phase theory already rules out p=1 in a counterexample. Therefore no zero-defect protected root cycle from the ternary deletion state space survives the full-cut quadratic perturbation. Any perturbed protected-root zero must have positive cut defect Delta and hence carries a nontrivial secondary cut-defect circulation.
