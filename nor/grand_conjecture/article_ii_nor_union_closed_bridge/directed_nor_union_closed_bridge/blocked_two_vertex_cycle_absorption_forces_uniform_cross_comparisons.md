# Blocked two-vertex cycle absorption forces uniform cross comparisons

In a locally transitive ternary coloring, let C be a color-0 tight cycle and E contain at least three exterior vertices. If no monochromatic path spans C with any two distinct vertices of E, all exterior vertices are before both cycle neighbors at every cycle center, or all are after both neighbors. The propagation proof uses the endpoint path (x,s(c),...,c,y): an H-position y at c forces every other exterior vertex into H at s(c), and cyclic propagation makes H either empty everywhere or full everywhere. In the before case, every cycle vertex precedes every other exterior vertex at each exterior center; in the after case, the order is reversed. Either configuration joins C with a monochromatic spanning path on E into a one-change order. A one-change exterior path alone does not supply that conclusion.
