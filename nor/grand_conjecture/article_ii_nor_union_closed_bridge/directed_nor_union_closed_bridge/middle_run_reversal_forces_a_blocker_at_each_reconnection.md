# Middle run reversal forces a blocker at each reconnection

For any spanning ternary order with word sigma^a tau^b sigma^c and a,c at least two, reversing exactly the vertex interval supporting the middle tau-run makes every nonboundary status sigma. Only two reconnection pairs can differ. Since every cyclic order in a counterexample has variation at least four, each reconnection zone must contribute two changes; equivalently, each pair contains at least one tau blocker.
