# The ordered-tuple one-change conjecture

N_k indexes k consecutive cube vertices; the translation-invariant coordinate label has arity r=k−1 and belongs to N_{r+1}. The directed ternary coordinate problem is N_4. In the edge-order subclass h(a,b,c)=0 iff λ(ab)<λ(bc), a spanning one-change order yields two monotone paths covering all vertices, overlapping in the switching edge, and hence one path with at least ceil(n/2) ordinary edges. This is the supplied historical motivation; the general reversal-odd coordinate model permits more labels than global edge comparisons.
