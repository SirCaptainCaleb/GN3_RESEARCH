# The perfect-blocker tube contains a six-coordinate holonomy-flip interface

In the same special perfect-blocker tube, the residual holonomies h_i of consecutive double-full packets begin with h_1=1 and end with h_{p-1}=0 by the minimum-phase holonomy-zero lemma. Therefore some adjacent pair satisfies h_j=1,h_{j+1}=0.

On the resulting six-coordinate interface (x,a,b,c,d,e), the old-coordinate data force abc=bcd=cde=0, abd=acd=1, bce=bde=0, with only one remaining old five-set bit. In particular (a,d,b,c,e) is 0-monochromatic. Thus the special branch contains a concrete holonomy-flip interface rather than an arbitrary full barrier.

The result is local and special-scan. Boundary reconnection remains to be handled; it does not imply an old-boundary-preserving splice.
