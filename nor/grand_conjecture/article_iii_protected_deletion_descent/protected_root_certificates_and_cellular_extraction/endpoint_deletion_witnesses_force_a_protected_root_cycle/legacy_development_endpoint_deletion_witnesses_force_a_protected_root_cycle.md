# Endpoint deletion witnesses force a protected-root cycle — preserved pre-item development

## Development

In a minimum counterexample, prepend each coordinate x to a good order of its deletion subinstance. The resulting full order has exactly two changes and its new initial transition is the only extra transition. If that initial tetrahedron were flat, the standard endpoint repair would make the new initial pair monochromatic with the deletion prefix and give a spanning one-change order. Hence the initial tetrahedron is fully curved and yields a protected root with source x. Thus every physical coordinate has positive outdegree in the actual protected-root digraph. Finiteness gives a directed cycle of actual protected roots.
