## A face-bijective balanced lifted A3 four-cycle forces full curvature

Consider a side-balanced honest lifted zero whose physical roots form one directed simple four-cycle on an exact ternary A3 block Q={0,1,2,3}. Assume its four carrying windows occupy the four distinct triangular facets of Q, one label per facet.

Normalize the switch target so pre-switch violations have window color 1 and post-switch violations have window color 0. Side balance gives exactly two labels of each side, hence exactly two carrying windows of color 1 and two of color 0.

Because the physical roots form the cyclic edge set

0->1->2->3->0,

each root has exactly two possible carrying facets. Requiring the four carrying facets to be distinct gives a perfect matching in the edge-versus-omitted-vertex bipartite graph. That graph is an 8-cycle, so there are exactly two matchings: every edge uses one cyclic choice of middle coordinate, or every edge uses the opposite cyclic choice.

In either matching, passing from the actual ordered window value to the canonical unordered face bit f(F) applies the SAME parity flip on all four selected windows. Concretely, with canonical vertex order 0<1<2<3, every selected window ordering is odd relative to its facet's increasing order.

Therefore the multiset of four canonical face bits also contains exactly two zeros and two ones.

By the tetrahedral curvature classification in the coboundary-flat alternating sector, an even face pattern with a 2-2 split is fully curved (up to relabeling it has A=C != B=D).

Hence:

### Theorem

Every side-balanced lifted A3 four-cycle whose carrying windows use all four tetrahedral facets forces the underlying four-set to be fully curved.

In particular, the alternating side pattern +,-,+,- necessarily has this form, because face repetition would force equal signs on adjacent physical-cycle edges.

### Consequence

A support-minimal balanced four-cycle in the honest lifted switch-prism carrier cannot remain a generic A3 circulation. In the face-bijective branch it lands exactly on the fully-curved tetrahedral geometry already used by the protected barrier theory.

This does not yet prove a full-support repair: one must still connect the fully-curved block to the actual exterior boundary data of the carrier state.
