All network edges are outermost roots of canonical proper-subinstance witnesses and are strictly increasing in one chamber order.

### Why this strengthens the one-root return theorem

Applying §278 separately to the four barrier roots gives four potentially unrelated flags. The midpoint construction couples the whole barrier square to a single flag and preserves the two-shore balance.

Consequently the remaining realization problem can be posed as one cellular object:

- one realized backward (K_{2,2}) barrier square;
- one forward acyclic canonical return network on a common flag;
- equal boundary mass on the two shores.

Any branching/merging in the return network is now the only obstruction to decomposing the object into two compatible monotone closing cycles. This is a narrower target than arbitrary endpoint square lifting or arbitrary protected-root circulation.
