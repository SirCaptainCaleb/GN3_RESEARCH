## Scope correction for the ordered-shortcut theorem

The proof of §320 has two different output classes and they must not be conflated.

### Crossed branch

In either crossed endpoint type, the construction in §320 produces an explicit four-coordinate fully-curved transition carrier whose physical root is the desired ordered shortcut
[
x	o z.
]
This is a genuine protected transition root.

### Easier three-block branch

In the direct case of §295, the order
[
xOz
]
may have several changes, and its outermost root is
[
e_x-e_z.
]
This is a genuine witnessed macro-root with endpoints (x,z), but it need not be a single fully-curved four-coordinate transition.

Likewise, if the opposite orientation produces (z	o x), reversal gives a witnessed macro-root (x	o z); full curvature is not automatic.

### Correct global statement

For every ordered pair of distinct coordinates (x,z), minimum-counterexample induction plus the complete three-block analysis gives either:

1. a spanning NOR-good order; or
2. a genuine witnessed physical root (x	o z).

Moreover, in the formerly unresolved crossed branch, the root can be chosen to be an actual fully-curved transition root.

Thus §320 completely resolves the crossed physical-shortcut realization problem, but does not by itself put every ordered pair into the protected-transition class.

Any cycle-shortening argument must therefore state explicitly whether its minimization class contains witnessed outermost macro-roots as well as protected transition roots.
