# Odd order cube carriers force a radial terminal root packet — preserved pre-item development

Let Q=[-1/2,1/2]^n be the centered Boolean cube and identify its boundary radially with the sphere S^{n-1}. For every proper cut C the cube vertex is
u_C=1_C-(1/2)1,
with ||u_C||^2=n/4.

A terminal barrier occurrence with central cut C and root rho=e_a-e_d, a in C and d outside C, satisfies
<u_C,rho>=1.
Under complement-reversal,
(u_C,rho)->(-u_C,-rho).

Suppose K is an antipodally invariant triangulation/refinement of the cube boundary carrying a continuous odd physical-root field
G:|K|->W,
G(-x)=-G(x),
whose values on terminal-state vertices are their actual roots and whose values on each simplex lie in the convex hull of the actual terminal roots carried by that simplex. No assertion is made here that Article III already supplies such a full carrier.

Radially identify |K| with S^{n-1}. Define the tangential projection
T(x)=G(x)-(<G(x),x>/<x,x>)x.
This is a continuous tangent vector field and is odd.

If n is odd, the sphere S^{n-1} has even dimension. Hairy ball forces T(x)=0 somewhere. Therefore
G(x)=lambda x
for some scalar lambda.

If additionally the carrier retains positive radial crossing on the simplex containing x—for example <G(x),x>>0—then lambda>0. Thus some carrier simplex has a convex combination of ACTUAL terminal roots equal to a positive radial vector.

At a terminal cube vertex the canonical tangent vector is explicitly
tau_C=rho-(4/n)u_C.
It is tangent because <u_C,tau_C>=0 and antipodally odd. For n>=3 it is nonzero at every terminal vertex: equality rho=(4/n)u_C is impossible because rho has only two nonzero coordinates whereas u_C has all coordinates equal to plus or minus 1/2.

Hence any obstruction to extending these vertex tangent labels as a nowhere-zero tangent field must occur inside a carrier simplex. The forced singular packet is precisely a place where positive combinations of actual terminal roots align with the radial cut geometry.

This is the odd-n parity complement of the even-n permutahedral hairy-ball theorem. The two results live on different domains:
- even n: the centered permutahedron boundary S^{n-2} forces physical descent-root flow;
- odd n: a faithful centered-cube boundary carrier S^{n-1}, if constructed, forces a radial terminal-root packet.

The missing theorem is domain construction, not the fixed-point step: one must extend terminal barrier labels over an antipodal cut-complex using only realized/provenance-valid barrier states. Bare interpolation over unrealized cube vertices is not licensed.
