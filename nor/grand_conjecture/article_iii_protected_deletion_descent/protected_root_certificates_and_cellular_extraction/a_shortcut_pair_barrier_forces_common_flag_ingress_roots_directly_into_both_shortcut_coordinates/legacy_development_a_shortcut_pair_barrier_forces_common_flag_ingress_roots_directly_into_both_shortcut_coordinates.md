## A shortcut-pair barrier forces common-flag ingress roots directly into both shortcut coordinates

Assume the exceptional source-shore outcome of §319. Thus a fully-curved barrier realizes
\[
\{x,z\}\longrightarrow\{u,v\},
\]
i.e.
\[
x\to u,\quad x\to v,\quad z\to u,\quad z\to v.
\]

Apply the common-flag return theorem §§284,292. There is one nested proper-face flag whose canonical outermost-root digraph carries a positive acyclic return flow from
\[
\{u,v\}
\]
to
\[
\{x,z\},
\]
and at least one complete pairing is realized by actual directed monotone paths.

### Cut by the literal pair \(\{x,z\}\)

Let
\[
P=\{x,z\}.
\]
Every return path begins outside \(P\) and ends in \(P\).

For each path, take its first edge entering \(P\). Since \(P\) has only two vertices, that edge has the form
\[
a\to x
\qquad\text{or}\qquad
a\to z
\]
with
\[
a\notin\{x,z\}.
\]

Because a complete return pairing sends one unit of path-flow to each source-shore sink, the realized pairing contains:

- one canonical flag-compatible ingress root
  \[
  \boxed{a\to x},
  \]
- one canonical flag-compatible ingress root
  \[
  \boxed{b\to z},
  \]

for some \(a,b\notin\{x,z\}\), possibly \(a=b\).

Moreover, the initial segments from \(u\) or \(v\) to \(a,b\) lie entirely in the proper outside set
\[
V\setminus\{x,z\}.
\]

### Relative local object

Thus the exceptional crossed-shortcut branch carries, on one compatible return flag,
\[
\boxed{
\{x,z\}\to\{u,v\}
\quad\text{and}\quad
a\to x,\ b\to z.
}
\]

If \(a\in\{u,v\}\) or \(b\in\{u,v\}\), one barrier edge and one ingress edge already form an opposite-root or cross-return packet on at most the barrier support plus one coordinate.

If both ingress predecessors are farther away, all extra return transport before the final ingress lies completely inside the proper subinstance \(V\setminus\{x,z\}\).

Hence the remaining realization problem separates cleanly into:
1. a bounded local case when a return path re-enters the pair immediately; or
2. a proper-subinstance outside transport followed by one canonical ingress edge into each of \(x,z\).

This is a stricter interface than an arbitrary protected-root cycle: every nonlocal part is confined away from the desired shortcut pair, and the final return steps hit the pair itself.
