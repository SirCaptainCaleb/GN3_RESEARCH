# Cut-moment perturbations encode side provenance without increasing target dimension

Protected side provenance can be encoded inside the physical root space rather than by adjoining a new coordinate. For a protected state (rho=e_a-e_c,C,s), set z_C=1_C-(|C|/n)1 and M(C,rho)=Pi_W(z_C odot rho), then perturb to Psi_epsilon=rho+epsilon s M(C,rho). The cut moment is antipodally even, so Psi_epsilon is odd. Same-side opposite roots cannot form a positive two-cycle. More strongly, for a common minimum first phase p, any side-balanced physical cycle satisfying the perturbed zero equations obeys s_i(1-p/n)+s_{i-1}p/n=0 at each cycle vertex. Hence an opposite-root two-cycle survives only at p=n/2, and a balanced four-cycle survives only at p=n/2 with alternating left/right side labels. Thus the side-sensitive obstruction can be retained in W, preserving the ambient dimension needed by the even-order fixed-point construction, while reducing primitive small circuits to a rigid middle-cut case.
