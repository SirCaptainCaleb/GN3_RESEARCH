# The forced endpoint protected cycle has rank-two incomparable cuts at every junction — preserved pre-item development

## Development

The protected cycle from the endpoint-deletion construction can be chosen with every edge an endpoint-barrier root. Write consecutive edges as x->y and y->z. Their certified cuts are C={x,a} and D={y,c}, because the central cut of an endpoint barrier lies after its first two coordinates. Both cuts have size two. Since y is not in C and y is in D, C and D are distinct; equal cardinality then makes them incomparable. Thus every junction of this endpoint protected cycle is already a consecutive incomparable-cut junction.

The general shortcut-or-alternating-cut dichotomy therefore specializes at every cycle vertex. If c=x, the complete barrier square for the second edge directly realizes the protected shortcut x->z. If a=z, the complete barrier square for the first edge realizes z->y, opposite to the second cycle edge y->z, producing an actual protected two-cycle. The only genuinely unresolved endpoint junction has a different from z and c different from x; in that case C itself certifies the shortcut pair x,z, and physical realization of that certified shortcut is the sole missing operation.

Hence the global protected-circulation problem reduces to the endpoint certified-shortcut theorem at a rank-two junction.
