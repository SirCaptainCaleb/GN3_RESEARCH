# In the first ternary cancellation block every root is an endpoint edge

In the first possible ternary cancellation block, an A3 block of four consecutive tied coordinates, every internal physical window-slide root joins the first and last positions of the block, because ternary slide endpoints are exactly three ranks apart. Thus every internal root is e_first-e_last; the two middle coordinates only mediate chamber motion.

Any support-minimal positive dependence therefore becomes a directed simple endpoint cycle on the four physical coordinates, of length 2, 3, or 4. Opposite endpoint roots require wall distance at least five, matching the short-path coorientation bounds.

This reduces the first genuine ternary protected-root extraction problem to a finite structural family: understand how the two middle coordinates mediate endpoint reversal along a shortest carrier and turn the resulting endpoint cycle into a protected threshold surgery.
