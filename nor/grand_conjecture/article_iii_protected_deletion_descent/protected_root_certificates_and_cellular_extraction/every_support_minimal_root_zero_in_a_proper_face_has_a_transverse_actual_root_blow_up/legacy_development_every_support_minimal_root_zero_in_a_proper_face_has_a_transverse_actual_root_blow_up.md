AUDIT CORRECTION. The transverse-blow-up argument is valid only under an additional same-direction hypothesis: each face block must admit a chosen good order with no internal 10 descent. Minimum-counterexamplehood alone does not provide this. A proper block may have only a 1^*0^* one-change order, and reversal preserves that transition direction. Therefore the concatenation of arbitrary good block orders can contain internal 10 descents, so a crossing actual root sigma is not forced. The geometric coning argument remains valid IF such a transverse actual root is independently supplied, but the unconditional proper-face theorem is withdrawn. Use the symmetric consecutive-change/Sperner carrier instead of this 10-only argument until the orientation gap is repaired.
