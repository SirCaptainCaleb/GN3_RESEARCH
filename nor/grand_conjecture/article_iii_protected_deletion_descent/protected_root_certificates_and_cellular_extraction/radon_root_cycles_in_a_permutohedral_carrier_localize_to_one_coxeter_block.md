# Radon root cycles in a permutohedral carrier localize to one Coxeter block

For protected roots carried by chambers refining one ordered-partition permutohedron face, any positive root dependence is a physical circulation. Along its directed root edges block index is nonincreasing, so every directed cycle of the circulation lies entirely inside one Coxeter block. Since a root joins positions r apart, that block contains the whole r+1-coordinate window union supporting each cycle edge. Outside coordinates are therefore fixed for the local extraction problem.
