# Unrestricted endpoint defects compress to two windows — preserved pre-item development

For an arbitrary reversal-odd ternary label, a minimum-counterexample endpoint word 1,0^p,1^q can be block-reversed on the coordinates supporting 0^p. All internal reversed windows and all untouched suffix windows become/remain 1. For q>=2 the exact new word is L,1^p,gamma,delta,1^(q-2); for q=1 it is L,1^p,gamma. Thus failure is confined to at most two right reconnection windows, with L only an endpoint bit. This uses only h(c,b,a)=1-h(a,b,c), not full alternation or coboundary flatness.
