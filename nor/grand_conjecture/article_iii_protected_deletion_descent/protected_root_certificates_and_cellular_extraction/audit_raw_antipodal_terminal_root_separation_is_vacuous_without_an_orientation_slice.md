# Audit: raw antipodal terminal-root separation is vacuous without an orientation slice

The graded central-cut model fixes provenance but not antipodal cancellation. In the full reversal-closed terminal family, rho occurs with -rho, so raw Gordan separation is vacuous: the positive dependence rho+(-rho)=0 is automatic and no functional can be positive on all roots. A meaningful global argument must use an independently justified orientation slice, an odd lift, or—preferably—odd topology followed by a reversal-even quotient observable such as the cut-root tensor.
