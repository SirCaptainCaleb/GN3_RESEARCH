## Monochromatic-band combing has the same strict potential as threshold-band combing

Work in the coboundary-flat alternating ternary sector. Fix a color \(\eta\in\{0,1\}\) and let \(I=[L,R]\) be a contiguous interval of window ranks on which every status equals \(\eta\).

Suppose the nearest outside window on the left exists and is wrong:
\[
c_{L-1}=1-\eta,\qquad c_L=\eta.
\]
If the supporting transition tetrahedron is flat, apply the same audited left endpoint repair used in §151. Its proof is entirely local to the constant-color side: it changes the boundary pair
\[
(1-\eta,\eta)\longmapsto(\eta,\eta)
\]
and affects only windows farther to the left. Hence every old rank in \(I\) stays monochromatic and rank \(L-1\) joins the band.

Therefore the monochromatic band length strictly increases. The right endpoint is symmetric.

Consequently repeated outward flat repairs from a protected monochromatic interval terminate after finitely many moves in exactly one of two ways:

1. the interval reaches both global endpoints, giving a monochromatic spanning order and hence NOR;
2. an unresolved endpoint is fully curved, yielding the protected physical root attached to that barrier by the terminal-threshold theorem.

No switch cut is needed. The monotonicity proof of §151 uses only the constant target color on the repaired side.

### Corollary

Any full-order surgery that creates a nonempty monochromatic seed while confining all uncontrolled windows outside that seed automatically admits the finite handoff
\[
\boxed{\text{spanning NOR}\quad\text{or}\quad\text{protected fully-curved root}.}
\]

This applies in particular to central monochromatic bridges produced by whole-band reversal.
