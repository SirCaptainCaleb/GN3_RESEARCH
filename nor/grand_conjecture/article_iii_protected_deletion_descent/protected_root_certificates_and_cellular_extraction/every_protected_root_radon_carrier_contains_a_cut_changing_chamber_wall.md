## Every protected-root Radon carrier contains a cut-changing chamber wall

Consider a connected permutohedral carrier cell whose chambers carry canonical protected roots from normalized one-change deletion states with a fixed first-phase length p. For a chamber C, let L(C) be the physical set occupying the first p positions of its deletion carrier.

The common-cut coorientation theorem says that no positive protected-root dependence can be supported on chambers with one common set L. Hence any carrier cell supporting a protected-root Radon zero contains two labeled chambers C0,C1 with
L(C0) != L(C1).

The chamber graph of a permutohedral face is connected by adjacent transpositions inside its Coxeter blocks. Choose a chamber path
C0=C^(0), C^(1), ..., C^(m)=C1.
Along an adjacent transposition, the first-p physical set is unchanged unless the swapped coordinates occupy positions p and p+1. Therefore, since L changes between the endpoints, some path edge C^(i)C^(i+1) swaps exactly across the protected cut.

Thus every connected carrier supporting a positive protected-root zero contains a codimension-one chamber wall at which one physical coordinate leaves the first phase and another enters it.

By Coxeter-block localization, if the positive root dependence has first been restricted to a shortest physical root cycle in one block, this cut-changing wall lies in that same block; all exterior coordinates remain fixed.

### Extraction consequence

The global root problem can therefore be sharpened. It is unnecessary to extract a bridge from an arbitrary signed cycle in one shot. A genuine Radon carrier must first expose a cut-changing adjacent wall. The remaining local theorem may be posed on that wall:

> Given two adjacent carrier chambers differing by the transposition across positions p,p+1, with the protected-root provenance inherited from the Radon cell, show that the cut exchange yields a monotone replacement bridge, enlarges the threshold-compatible band, or passes to a smaller carrier still supporting a positive root dependence.

This is a necessary-locus theorem, not yet the bridge theorem. It does, however, eliminate all common-cut recurrences (including the cooriented A2 recurrence) from the positive-zero extraction frontier.
