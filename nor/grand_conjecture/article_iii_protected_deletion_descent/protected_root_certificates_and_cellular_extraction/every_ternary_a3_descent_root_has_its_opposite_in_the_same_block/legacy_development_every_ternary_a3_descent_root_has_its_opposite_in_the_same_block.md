## Every ternary A3 descent root has its opposite in the same block

Work in a four-coordinate A3 Coxeter block B={a,b,c,d}. Suppose the chamber order

pi=(a,b,c,d)

carries a ternary 10 descent:

alpha(a,b,c)=1,
alpha(b,c,d)=0.

Its physical window-slide root is

rho=e_a-e_d.

Reverse the four-coordinate block:

pi^rev=(d,c,b,a).

Because reversal of an ordered triple is odd,

alpha(d,c,b)=1-alpha(b,c,d)=1,

alpha(c,b,a)=1-alpha(a,b,c)=0.

Thus pi^rev also carries a 10 descent, with physical root

-rho=e_d-e_a.

### Consequence

Every nonzero ternary descent root supported internally in an A3 block comes with its exact opposite in another chamber of the same A3 face. Hence the chamber-root set of any A3 face containing a descent already contains a positive two-root cancellation

rho+(-rho)=0.

So the length-2 endpoint cycle from the A3 endpoint-digraph reduction is not an exceptional obstruction; it is the automatic local-reversal pair attached to every transition tetrahedron.

In particular, if one minimizes positive dependence over all available chamber labels in a fixed A3 face, a two-cycle is always available as soon as any internal descent exists. Directed triangles and four-cycles can only become relevant after these local reversal pairs have been quotiented, blown up, or otherwise declared removable by additional carrier structure.

### Strategic correction

The raw A3 root-circuit problem should therefore not be phrased as 'classify support-minimal cycles of length 2,3,4'. The genuine extraction problem begins after removing the ubiquitous reversal two-cycles. This parallels the earlier inert antipodal-pair phenomenon: an opposite root pair is a local zero, but not by itself a monotone replacement bridge.

The next root theorem should identify a zero-free equivariant local replacement for the A3 reversal pair, or pass to a quotient/state label in which opposite local reversal chambers no longer cancel trivially. Only then do longer endpoint cycles carry new information.
