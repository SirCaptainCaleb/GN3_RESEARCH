# A single fully ported deletion path closes the whole shore without packet repair

If a deletion A\{a} possesses a fully ported monochromatic-zero Hamiltonian path P, then P,x,z,a is a spanning compatible zero connector, and the homogeneous-cut insertion theorem closes NOR. The crossing labels use only the forward terminal edge of P and h(p,x,z)=h(x,z,a)=0. More strongly, if a ported two-path cover of A\{a} contains a singleton path (q), orient {a,q} as a forward length-two zero path; with the other ported deletion path it gives a spanning two-path shore cover and closure. Therefore every ported two-path deletion cover in a minimal whole-shore obstruction has two paths each of length at least two. Local cyclic-packet surgery for three coherent one-path deletion witnesses is unnecessary for global closure; a seven-coordinate fixed-boundary obstruction remains a valid local statement.
