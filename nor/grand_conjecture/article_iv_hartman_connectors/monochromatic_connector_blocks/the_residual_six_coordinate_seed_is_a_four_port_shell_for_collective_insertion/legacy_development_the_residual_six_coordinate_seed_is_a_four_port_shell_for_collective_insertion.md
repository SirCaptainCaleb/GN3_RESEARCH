# The residual six-coordinate seed is a four-port shell for collective insertion — preserved pre-item development

## Development

Assume the residual endpoint type gives the compatible zero seed (l2,l1,x,z,r1,r2), with l2->l1 and r1->r2 in the shore tournament. Let P=(p1,...,ps) be a disjoint zero path of shore vertices with s at least 2. Then (l2,l1,x,P,z,r1,r2) is monochromatic zero exactly when p1 dominates l1, the first edge of P is forward, the last edge of P is forward, and r1 dominates the last vertex of P. All other windows are inherited from the seed or P. Thus the six-coordinate residual seed is a four-port shell: collective insertion of an arbitrarily long zero path depends only on its first two and last two coordinates. This uses the freedom to separate x and z. A single inserted shore vertex behaves differently because the window (x,p,z) has the opposite color, so the block formulation genuinely starts at length two.
