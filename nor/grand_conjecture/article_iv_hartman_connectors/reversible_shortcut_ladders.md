# Reversible shortcut ladders and local shortcut realization

For exterior coordinates x,z and a fixed middle order W=(w_1,…,w_m), put X_i=α(x,w_i,w_(i+1)), Z_i=α(z,w_i,w_(i+1)) and R_i=α(x,z,w_i). The parity identity for the four-coordinate set {x,z,w_i,w_(i+1)} yields R_(i+1)⊕R_i=X_i⊕Z_i. Thus the difference between the two insertion scans is exactly the change in the rung signature: a disagreement X_i≠Z_i flips R.

The four-coordinate order (x,w_i,w_(i+1),z) carries the actual shortcut from x to z whenever the rails disagree. Its complementary faces are curved precisely when X_i=R_i, as follows by the same tetrahedral face identities. The crossed endpoint residue that survived the earlier three-block analysis has its first disagreement already satisfying that equality. Accordingly its very first four-coordinate carrier is a protected shortcut. This closes that local branch directly; a separate long-range topological transport within the binary ladder would add no existence theorem there.

Local protected-shortcut realization, however, is not identical with the global NOR conclusion: to use the shortcut within the original witness order, a proof must preserve or reconstruct the necessary outside collars. The subsequent connector arguments therefore target spanning compatible orders rather than the mere existence of one four-coordinate shortcut.
