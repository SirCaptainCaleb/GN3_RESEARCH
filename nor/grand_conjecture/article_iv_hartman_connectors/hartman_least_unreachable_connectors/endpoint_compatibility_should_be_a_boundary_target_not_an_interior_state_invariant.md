# Endpoint compatibility should be a boundary target, not an interior state invariant

In a connector-repair approach, a state can consist of a monochromatic order containing x,z without being required to have forward endpoint pairs at every intermediate step. This enlarged state space admits reversible interior adjustments that may temporarily change the ports. The final extraction condition is nevertheless exact: one reachable order must both cover the whole shore and have compatible endpoint pairs. Thus endpoint compatibility belongs to the designated successful boundary set, not necessarily to the invariant defining each intermediate component. Allowing x and z to move independently is legitimate only when every purported move preserves the actual ternary monochromaticity and all affected exterior windows; a formal local A2 rotation does not by itself establish global admissibility.
