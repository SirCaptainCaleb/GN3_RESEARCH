# E8998: Three-spoke Boolean-cube classifier

## Theorem

Let `H` be a smallest finite Strong Level-(1) boundary-tournament counterexample to the two-path-cover theorem, and assume

`|H| > 10`.

Thus `pc(H)=3`, while every proper induced subsystem has path-cover number at most two. Then there are distinct vertices `a,c,p,q,r`, with

`P={p,q,r}`

and

`W=V(H)-({a,c}∪P)`,

such that:

1. `(a,s,c)` is tight for every `s∈P`;
2. for every `J⊆P`, the induced subsystem
   
   `G_J=H[W∪J]`
   
   has path-cover number exactly two;
3. the top fiber `G_P=H-{a,c}` has an exact two-cover in which `p,q,r` are all internal; and
4. a finite comparison of the eight exact-two-cover fibers returns one selected certificate of one of the following five types:
   - a literal three-or-more to two component drop on one common cube residue;
   - two exact covers of one residue with different support bipartitions;
   - two exact covers with the same supports but different literal rail orders, yielding a reversed state, a reverse tight trimer, or a proper tight cycle;
   - two exact top-fiber covers in which a spoke is internal in one and an endpoint in the other; or
   - a synchronized singleton star: an exact core cover `F=(v)|B`, singleton rows `(v,s)|B`, and for every pair `{s,t}⊆P` a rank-two row `J_{st}|B`, where `J_{st}` is a tight trimer on `{s,v,t}`. In this last case `X={v,p,q,r}` has no Hamilton tight `P4`.

The four nonsynchronized certificates are born from the retained phase-one cube source packet and each contains an actual proper tight path or cycle before any payment or replay. Equivalently, each satisfies the source-relative prepayment interface used by the downstream first-source descent theorem.

The synchronized star instead carries an ancestry-bearing opposite-sign dimer pair of total support four on an actual rank-two trimer crossing. This pair is certificate data only. Its existence alone does not imply phase descent.

A *literal* cover remembers the ordered vertices on each rail, up to exchanging the two rails. We use throughout the defining boundary antisymmetry axiom: for distinct `x,y,z`, the turn `(x,y,z)` is tight exactly when its complete reversal `(z,y,x)` is bad.

## 1. Pair-deletion rigidity

### Lemma 1

For any distinct `x,y∈V(H)`,

`pc(H-{x,y})=2`,

and every exact two-cover of `H-{x,y}` has two nontrivial rails.

### Proof

Minimality gives `pc(H-{x,y})≤2`. Suppose first that `H-{x,y}` has a Hamilton path

`Q=(q_0,q_1,...)`.

Boundary antisymmetry on `x,q_0,y` gives a tight trimer on `{x,q_0,y}` in one of the two reversed orders. Together with the suffix `(q_1,...)`, this is a spanning two-cover of `H`, a contradiction. Hence the pair-deleted subsystem is exactly two-covered.

Now suppose one rail of an exact two-cover is the singleton `(u)`. Boundary antisymmetry on `x,u,y` gives a tight trimer on `{x,u,y}`. Together with the other rail, this again two-covers `H`, a contradiction. Thus both rails are nontrivial. ∎

## 2. The three-spoke support

Choose distinct anchors `a,c` and an exact two-cover

`H-{a,c}=U|V`.

By Lemma 1 both rails are nontrivial. Their four endpoints account for at most four of the `|H|-2` vertices, so at least

`|H|-6≥5`

vertices are internal. For every internal vertex `x`, exactly one of `(a,x,c)` and `(c,x,a)` is tight. Hence three internal vertices `p,q,r` have the same orientation. After interchanging `a,c` if necessary,

`(a,p,c), (a,q,c), (a,r,c)`

are all tight. In particular, the chosen top cover retains `p,q,r` as internal vertices.

We next need one elementary five-point fact.

### Lemma 2: Five-point support lemma

If

`(a,p,c), (a,q,c), (a,r,c)`

are tight, then

`K={a,c,p,q,r}`

has a Hamilton tight `P5`.

### Proof

For distinct spokes `x,y∈{p,q,r}`, write

`x→_a y`

when `(x,a,y)` is tight, and write

`x→_c y`

when `(x,c,y)` is tight. Boundary antisymmetry makes each relation a tournament on `{p,q,r}`.

If distinct `x,y,z` satisfy

`x→_a y→_c z`,

then `(x,a,y,c,z)` is already a Hamilton `P5`. Assume no such mixed chain exists.

The tournament `→_a` cannot be transitive. Indeed, if

`x→_a y→_a z`

and `x→_a z`, then avoidance of `(x,a,y,c,z)` forces `z→_c y`, while avoidance of `(x,a,z,c,y)` forces `y→_c z`, a contradiction. Thus, after relabelling,

`p→_a q→_a r→_a p`.

Absence of a mixed chain then forces the opposite `c`-cycle

`r→_c q,  p→_c r,  q→_c p`.

Suppose none of the following six words is a Hamilton path:

`a p c r q`, `a q c p r`, `a r c q p`,

`p q a r c`, `q r a p c`, `r p a q c`.

Their only uncertified final turns force, respectively,

`qrc, rpc, pqc, aqp, arq, apr`

to be tight. Applying the same argument to

`a p r c q`, `a q p c r`, `a r q c p`,

`p a q r c`, `q a r p c`, `r a p q c`

forces

`crp, cpq, cqr, rqa, pra, qpa`

to be tight.

Only the three reversal choices on the spoke triple remain. Put

`u=[qpr]`, `v=[pqr]`, `w=[prq]`,

where a bracket is `1` when the displayed triple is tight. For the eight possible values of `(u,v,w)`, consider the indicated pair of candidate words:

```text
000: a c q r p   |   r p q c a
100: c a r q p   |   q p r a c
010: a c p q r   |   q r p c a
110: a c p q r   |   q r p c a
001: c a p r q   |   r q p a c
101: c a p r q   |   r q p a c
011: a c r p q   |   p q r c a
111: c a q p r   |   p r q a c
```

In each row, every turn has already been certified except one turn in each candidate, and those two remaining turns are complete reversals. Boundary antisymmetry therefore makes exactly one of them tight. One of the two candidates is consequently a Hamilton `P5`, contradicting our assumption. ∎

Every smaller complementary anchor/spoke support is Hamiltonian as well. A two-vertex support is a dimer, and a one-spoke support is `(a,s,c)`. For distinct spokes `s,t`, if `(s,c,t)` is tight then use `(a,s,c,t)`; otherwise `(t,c,s)` is tight and `(a,t,c,s)` is a tight `P4`.

## 3. The Boolean cube and block conservation

Put

`P={p,q,r}`, `K={a,c,p,q,r}`, `W=V(H)-K`,

and for every `J⊆P` define

`G_J=H[W∪J]`.

The complementary support

`K-J={a,c}∪(P-J)`

has a Hamilton path by Lemma 2 and the smaller-support observations above. If some `G_J` were Hamiltonian, that Hamilton path together with the complementary path would give a spanning two-cover of `H`. Hence every `G_J` is non-Hamiltonian. Since each `G_J` is a proper induced subsystem, minimality gives

`pc(G_J)=2`                                                    (1)

for all eight fibers. For `J=P`, the original cover `U|V` is such an exact cover and all three spokes are internal.

Fix a nonempty `J⊆P` and an exact two-cover `T_J` of `G_J`. Delete the vertices of `J` from its two rails and split at the deletions. Call the surviving maximal nonempty `W`-segments the *W-blocks*.

There are at least two `W`-blocks. If there were only one, it would be a Hamilton path of `W`; together with the Hamilton path on all of `K`, it would two-cover `H`.

If at least three `W`-blocks remain, they form a literal cover of `W` by at least three inherited tight paths, while (1) supplies an exact two-cover of `W`. This is the first output, the **component-drop certificate**.

Assume henceforth that exactly two `W`-blocks remain. Contract each block to one vertex while leaving the roots in `J` uncontracted. The resulting graph is a forest on `|J|+2` vertices with exactly two components and therefore exactly `|J|` selected edges. No selected edge joins the two contracted `W`-vertices, because the original `W`-blocks were maximal. Thus every contracted edge is either root-root or root-`W`.

Let `p_J` be the number of selected root-root states and let `τ_J` be the number of root-`W` transitions. Then

`p_J+τ_J=|J|`.                                                 (2)

For a singleton fiber `J={s}`, one has `p_J=0`, hence `τ_J=1`. Thus `s` is a literal endpoint attachment to one `W`-block: if it were internal, two root-`W` transitions would be present. Removing `s` therefore leaves an exact two-cover `F_s` of `W`.

Compare the three literal covers `F_p,F_q,F_r`. If two induce different unordered bipartitions of `W` into rail supports, we obtain the second output, the **same-residue support-disagreement certificate**. If their support bipartitions agree but one common support carries different literal Hamilton orders, we obtain the third output, the **same-support order-disagreement certificate**.

Outside these two branches, after exchanging whole rails where necessary, the three trims coincide as one literal exact cover

`F=A|B`,                                                       (3)

and each spoke `s` has a definite physical endpoint `e_s` of `F` such that its retained singleton row is obtained from `F` by the single attachment edge `s e_s`.

## 4. Rank-two coherence and the top fiber

Fix distinct `s,t∈P` and an exact two-cover `T_{st}` of `W∪{s,t}`.

If one root, say `s`, is internal on its rail, deleting `s` splits that rail into two nonempty tight pieces while leaving the other rail unchanged. Thus `T_{st}-s` is a literal three-path cover of the singleton fiber `W∪{t}`, which by (1) also has an exact two-cover. This is again the component-drop output. Outside that branch, both roots are endpoints.

Neither endpoint root can be an entire singleton rail. If, for example, `s` were a singleton rail, deleting it would leave a Hamilton path on `W∪{t}`, contradicting (1). Consequently `T_{st}-s` and `T_{st}-t` are exact two-covers of `W∪{t}` and `W∪{s}`, respectively.

Compare these one-root trims with the retained singleton rows. Any support disagreement or literal-order disagreement is already one of the declared side outputs. Outside those branches,

`T_{st}-s = F_t`,   `T_{st}-t = F_s`                          (4)

literally, up to exchanging the two rails.

Equation (4) identifies the root attachments themselves: the edge incident with `s` is exactly `s e_s`, and the edge incident with `t` is exactly `t e_t`. Trimming both roots gives `F`. Since a two-path forest on `|W|+2` vertices has exactly two more selected edges than a two-path forest on `|W|` vertices, there is no additional root-root state or hidden splice. Therefore

`E(T_{st}) = E(F) ∪ {s e_s, t e_t}`.                           (5)

If `e_s=e_t=v` and `v` is an endpoint of a nontrivial rail of `F`, then `v` has its inherited rail edge and the two root attachments, so its selected degree in `T_{st}` is three. This is impossible in a union of paths. Hence two roots may share a port only when that port is an isolated singleton rail `(v)` of `F`. In that case their component in `T_{st}` is exactly the physical tight trimer on `{s,v,t}`.

We now install all three certified singleton attachments simultaneously. Define

`T_P := F ∪ {p e_p,q e_q,r e_r}`.                             (6)

A nontrivial endpoint of `F` receives at most one root by the rank-two argument. If no two roots share a port, (6) simply extends three distinct rail endpoints and is a literal two-path forest. If exactly two roots share a port, that port is an isolated singleton `v`; their rank-two row supplies the actual tight trimer through `v`, while the third root extends an endpoint of the other `F`-rail. Again (6) is a literal exact two-cover of the top fiber. Every new turn is certified by the corresponding singleton or rank-two row.

Therefore, unless all three roots attach to one and the same isolated singleton `v`, the top fiber has an exact cover `T_P` in which at least one spoke, indeed every newly attached spoke, is a rail endpoint. The retained top source cover `U|V` has `p,q,r` all internal. The two covers are nonidentical and give the fourth output, the **top endpoint/internal discrepancy certificate**.

The only branch with no preceding output is consequently

`F=(v)|B`.                                                     (7)

All three singleton rows are dimer-plus-`B` covers on `{v,s}`, and every rank-two row is a tight trimer on `{s,v,t}` plus `B`.

Put

`X={v,p,q,r}`.

If `X` had a Hamilton tight `P4`, that path together with `B` would be an exact top-fiber two-cover having a spoke endpoint, producing the preceding discrepancy. Hence

`X` has no Hamilton tight `P4`.                               (8)

Equations (7) and (8) are the **synchronized singleton-star certificate**.

## 5. Proper-path and cycle births on the nonsynchronized branches

We now verify the extra ancestry retained by the first four outputs. Any exact two-cover of a cube fiber `G_J`, together with the Hamilton path on the complementary support `K-J`, is a spanning three-path cover of `H`. Since `pc(H)=3`, these are source checkpoints of the original three-spoke packet. The constructions below occur directly among those retained covers, before any later payment or replay.

We use one path-comparison observation.

### Lemma 3: Reverse-ear comparison

Let

`P=(v_0,...,v_k)`

and `Q` be vertex-simple tight paths on the same vertex set. If their literal orders differ, then one finds at least one of the following:

1. a selected state of `Q` reversing a consecutive state of `P`;
2. a tight reverse trimer at a comparison seam; or
3. a vertex-simple proper tight cycle.

### Proof

Read the `P`-vertices in their order of occurrence along `Q`. Since the literal orders differ, choose consecutive `Q`-contacts `v_i,v_j` with `i>j`, and let `E` be the `Q`-subpath from `v_i` to `v_j`; its internal vertices contain no `P`-vertex.

If `E` is the single state `v_i v_j` with `i=j+1`, then it is the desired selected reversal. Otherwise let `x` be the successor of `v_i` on `E` and `y` the predecessor of `v_j`. Test the two seams

`(v_{i-1},v_i,x)`,  `(y,v_j,v_{j+1})`.

If either seam is bad, boundary antisymmetry gives the corresponding reverse tight trimer. If both are tight, traverse `E` from `v_i` to `v_j`, then the old `P`-segment from `v_j` through `v_{i-1}`, and close through the first tested seam. Every turn is inherited from `E` or `P`, or is one of the two tested seams. The choice of consecutive contacts makes the resulting tight cycle vertex-simple. ∎

We now inspect the four nonsynchronized outputs.

### Component drop

Let `R` be the inherited three-or-more path cover of the relevant residue and let `T` be an exact two-cover of the same residue. Some selected state of `T` joins two distinct `R`-components; otherwise the two connected `T`-rails would refine the `R`-partition, impossible when `R` has at least three nonempty components.

Choose an endpoint `x` of such a crossing and an inherited neighbor `h` of `x` in its parent cube cover. If the crossed `R`-component is nontrivial, take `h` inside it. If both crossed components are singleton blocks, at least one has a root neighbor in the parent cover: two singleton blocks with no such neighbor would already be the two whole rails, leaving no third block. The same argument applies when the three-cover arose by deleting an internal rank-two root.

Let `y` be the other crossing endpoint. Boundary antisymmetry on `{h,x,y}` gives one of `(h,x,y)` and `(y,x,h)` tight. Thus the component drop contains a proper source-born trimer.

### Support disagreement

Let `R,T` be exact covers of one residue with different support bipartitions. Some selected state `xy` of one crosses the two components of the other. The crossed components cannot both be singleton, because every cube residue contains `W` and

`|W|=|H|-5≥6`.

Choose an inherited neighbor `h` at an endpoint lying in a nontrivial crossed component. Boundary antisymmetry again gives a proper tight trimer on `{h,x,y}`.

### Literal-order disagreement

On a common rail support, apply Lemma 3 to the two tight rail orders. The resulting reversed dimer, reverse trimer, or proper tight cycle is already a proper path/cycle certificate born inside the retained source packet.

### Top endpoint/internal discrepancy

The retained source cover and the recombined endpoint-exposing cover are nonidentical exact covers of the same top fiber. If their support bipartitions differ, use the support-disagreement argument. Otherwise some common rail support has different literal order, and Lemma 3 applies.

Thus every nonsynchronized output contains an actual certificate-retaining proper tight path or cycle born from a finite packet of the original phase-one cube checkpoints. This is the one-time source-relative prepayment interface. It does not license a fresh application after a later phase-zero replay, and strict phased-rank descent is not being identified with global closure.

## 6. A rank-two trimer must cross a punctured source cover

It remains to prove the additional certificate carried by the synchronized singleton star. Retain the old top source cover `U|V`, in which `p,q,r` are internal, and the synchronized rows from (7).

For `s∈P`, write

`{t,u}=P-{s}`.

Deleting `s` from its source rail splits that rail into two nonempty old-order intervals while leaving the other source rail unchanged. Hence

`R_s := (U|V)-s`

is a literal three-path cover of `W∪{t,u}`. The synchronized rank-two row on the same support is `J_{tu}|B`, where `J_{tu}` is the physical tight trimer on `{t,u,v}`.

### Lemma 4

For some `s∈P`, a selected edge of `J_{tu}` joins two different components of `R_s`.

### Proof

Suppose not. Since `J_{tu}` is connected, the three vertices `{t,u,v}` would lie in a single component of `R_s` for every `s`.

Taking `s=p` shows that `q,r` lie on one old source rail. Taking `s=q` shows that `p,r` lie on one old source rail. Hence `p,q,r` all lie on the same source rail, and the common-component conditions place `v` on that rail as well.

Choose the middle one of `p,q,r` in the literal order of this source rail and call it `s`. Deleting `s` separates the other two spokes into the two opposite nonempty intervals of the rail. They therefore lie in distinct components of `R_s`, contradicting the conclusion that `{t,u,v}` lies in a single component. ∎

Fix such an `s` and a selected crossing edge `xy` of `J_{tu}`. At least one endpoint is a surviving source spoke, since at most one endpoint can be `v`; call such an endpoint

`x∈{t,u}`.

Because `x` was internal in `U|V` and `s≠x`, deleting `s` removes at most one of the two old source neighbors of `x`. Thus an old source neighbor `h` of `x` survives in the `R_s`-component containing `x`. The other endpoint `y` lies in a different `R_s`-component, so `h,x,y` are distinct.

Boundary antisymmetry gives exactly one of

`(h,x,y)`,  `(y,x,h)`

tight. This signs a local dimer from the old source cover. The construction retains the deleted spoke `s`, the source turn `(a,s,c)`, the actual rank-two trimer `J_{tu}`, its crossing edge `xy`, the two crossed components of `R_s`, the surviving spoke endpoint `x`, its old source neighbor `h`, and the witness `y`.

## 7. The synchronized mass-four certificate

For this section, call an ordered dimer `(d_0,d_1)` *tail-signed* by `z` when

`(d_0,d_1,z)`

is tight, and *head-signed* by `z` when

`(z,d_0,d_1)`

is tight. A *balanced dimer pair* is a pair of vertex-disjoint signed dimers of opposite polarity. Its support mass is the number of vertices in the two dimer supports.

If `(h,x,y)` is tight, take the old source dimer

`D=(h,x)`,

which is tail-signed by `y`. If `(y,x,h)` is tight, take instead

`D=(x,h)`,

which is head-signed by `y`.

The deleted source turn `(a,s,c)` supplies both terminal polarities:

- `(a,s)` is tail-signed by `c`;
- `(s,c)` is head-signed by `a`.

The support of `D` lies in

`W∪{t,u}=V(H)-{a,c,s}`,

so it is disjoint from either source dimer. Pair `D` with the opposite polarity: use `(s,c)` when `D` is tail-signed, and use `(a,s)` when `D` is head-signed. The two dimer supports are disjoint and contain exactly four vertices.

Therefore the synchronized singleton star carries an opposite-sign balanced dimer pair of total support mass four, together with all source and crossing ancestry listed above.

This conclusion is deliberately only a certificate statement. The existence of a graph-intrinsic balanced pair does not itself place the current state at a paid or phase-zero checkpoint. In particular, no strict phased-rank descent follows without a separate lawful currentization, payment, and reentry theorem.

This proves the theorem. ∎

## 8. Classifier interface

The proof gives a decision procedure. Test, in order:

1. component drop;
2. exact-cover support disagreement;
3. same-support literal-order disagreement;
4. top endpoint/internal discrepancy.

If none occurs, return the synchronized singleton star.

Thus the classifier returns exactly one *selected* output, even though distinct side certificates need not be mutually exclusive as graph-intrinsic phenomena.

On each of the first four outputs, the retained data include a finite phase-one source packet and a proper tight path or cycle born directly from that packet. Any downstream theorem whose input is such a certificate-retaining first-source prepayment birth can therefore be applied without reconstructing the Boolean cube.

On the fifth output the retained data are

`H-{a,c}=U|V`,  `F=(v)|B`,  `X={v,p,q,r}`,

with `p,q,r` internal in `U|V`, `(a,s,c)` tight for all `s∈P`, `X` non-Hamiltonian, every singleton row dimer-plus-`B`, every rank-two row trimer-plus-`B`, and the source-anchored mass-four balanced pair on an actual rank-two crossing. The mass-four pair carries no automatic phase-progress assertion.

This is the full conclusion of the three-spoke Boolean-cube classifier. Further consumption of either the first-source birth interface or the synchronized singleton star is downstream mathematics.
