# R107 — Hub kernel radius-one-or-singleton-star compression

**Record status:** `UNUSABLE/QUARANTINED`

## Statement
Assume alternative (ii) of R98. Let X=U∪V and let W={w∈X : S∪{w,r}∈F for some r∈R}. Then W is nonempty and |W|≤3. Exactly one of the following hub-generated outcomes holds. (a) There exist a hub H=S∪{w,r}∈F, a support D∈F omitting some s∈S, and P∈{A,B} such that H=P-{p}+{x} and D=P-{q}+{y} for distinct p,q∈P and distinct x,y∉P. Thus the hub kernel itself contains an actual radius-one replacement configuration. (b) No such hub-generated pair exists; after possibly exchanging U and V, write U={w,u} with W={w}. Then every support in F omitting s∈S is the single set D_s=(S\\{s})∪{w}∪V, and for every r∈R the hub H_r=S∪{w,r} belongs to F. Equivalently, all S-omitting supports form the B-star B-{s}+{w}, while all R-touching supports form the A-star A-{u}+{r}.

## Hypotheses
Standing order-ten smallest-counterexample case; A,B are a globally minimum-overlap pair with |A∩B|=3, and the hub alternative (ii) of R98 holds.

## Scope
Pure support-incidence compression inside the R98 hub branch.

## Applicability
Use before reopening representative-dependent return or seam machinery. Outcome (a) feeds the existing radius-one common-frame machinery; outcome (b) is the only support-level hub kernel not already forcing such a configuration.

## Persistence
The conclusion is graph-intrinsic because it concerns only memberships of the global longest-five support family F.

## Exclusions / nonclaims
Does not claim that the singleton-star kernel is impossible, nor that the radius-one outcome alone closes the order-ten case.

## Proof
Assume the hub alternative (ii) of R98. Put X=U∪V and define W as in R107. By R13, union F=V(H), so some support meets R; hence W is nonempty. Also intersection F is empty, so for each s∈S there exists at least one D∈F with s∉D. By R98 every such D is R-free, contains exactly S\\{s}, and has a three-element wing set T(D)⊆X meeting both U and V and containing every element of W. Therefore |W|≤3.

Suppose outcome (a) does not occur. Fix w∈W∩U, if this set is nonempty, and write U={w,u}. Choose a hub H=S∪{w,r}∈F witnessing w∈W. If some S-omitting support D has u∈T(D), then because |T(D)|=3 and T(D) meets V, necessarily T(D)={w,u,v} for some v∈V. Thus
H=A-{u}+{r},
D=A-{s}+{v}.
Here u and s are distinct vertices of A, while r and v are distinct vertices outside A. Hence H and D are exactly the hub-generated radius-one pair in outcome (a), contradiction. Consequently, under failure of (a), every S-omitting D excludes u. In particular W∩U cannot contain both vertices of U, because every D contains W. By symmetry |W∩V|≤1.

If |W|=2, it therefore has one element w_U∈U and one element w_V∈V. Take any S-omitting D. Its wing triple T(D) contains w_U,w_V and one further wing z. If z is the other U-vertex, the preceding argument with w_U gives outcome (a); if z is the other V-vertex, the symmetric argument with w_V gives outcome (a). Both are impossible. Hence |W|≠2. Since W is nonempty and the two-per-side cases already exclude |W|=3, we get |W|=1.

After exchanging U and V if necessary, write W={w} with U={w,u}. For every S-omitting D, the preceding no-(a) argument forces u∉T(D). Since T(D) has size three, contains w, and lies in the four-element wing set X=U∪V, it follows that T(D)={w}∪V. Thus every support omitting a given s is the same set
D_s=(S\\{s})∪{w}∪V=B-{s}+{w}.
Such a support exists for each s by intersection F=empty, so these are exactly the S-omitting supports.

Finally fix r∈R. By union F=V(H), some support C∈F contains r. In the hub alternative every R-touching support is S∪{w',r'} with w'∈W and r'∈R. Since W={w} and C contains r, C=S∪{w,r}=A-{u}+{r}. Hence H_r belongs to F for every r∈R, and every R-touching support has this form. This is outcome (b). Outcomes (a) and (b) are mutually exclusive by the opening clause of (b), completing the proof.
