# R5 — Universal small-deletion exactness through four vertices

**Record status:** `UNUSABLE/QUARANTINED`

## Statement
Deleting any set of one, two, three, or four vertices from a smallest counterexample leaves a graph of path-cover number exactly two.

## Scope
Smallest counterexample.

## Applicability
Deletion set size 1 through 4.

## Proof
Let H be a smallest Strong Level-(1) counterexample and let D be a nonempty vertex set with 1<=|D|<=4. By R4, H-D has path-cover number at most two. We prove it cannot be Hamiltonian. Suppose H-D has a Hamilton tight path K. If |D|=1, the unique deleted vertex is a singleton tight path, so K together with it is a spanning two-cover of H, contradiction. If |D|=2, the two deleted vertices form a tight dimer, so again they together with K give a spanning two-cover. If |D|=3, R3 guarantees a tight ordering of the three deleted vertices, hence a tight trimer on D; this trimer together with K is a spanning two-cover, contradiction. It remains that |D|=4. Choose z in D and put T=D-{z}. By R3, T supports a tight trimer. Then K sqcup T is a two-path cover of H-z. This cover is exact: H-z cannot be Hamiltonian, because a Hamilton path of H-z together with singleton z would be a spanning two-cover of H. Thus K sqcup T is an exact one-vertex-deletion two-cover containing the three-vertex rail T. This contradicts R24, which says every rail in every exact one-vertex-deletion two-cover of a smallest counterexample has order at least four. Therefore H-D is not Hamiltonian in all four cases. Since R4 gives pc(H-D)<=2 and H-D is nonempty, pc(H-D)=2. This proves R5 for every deletion set of size one through four. No four-vertex orientation classification is used in the R5 proof itself; all of the hard four-vertex work is isolated in the independently audited singleton rail floor R24.
