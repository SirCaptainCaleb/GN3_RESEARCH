# R169 — Proper Tight-Path Exterior Order-Five Floor

**Record status:** `UNUSABLE/QUARANTINED`

## Statement
Every proper tight path K in a smallest Strong Level-(1) counterexample H leaves at least five exterior vertices: |V(H)-V(K)|>=5. Equivalently the maximum order L(H) of a proper tight path satisfies L(H)<=|H|-5.

## Hypotheses
H is a smallest Strong Level-(1) counterexample and K is a proper graph-intrinsic tight path of H.

## Scope
Universal smallest-counterexample path-size theorem, independent of how K was produced or currentized.

## Applicability
Immediately upgrades any proper tight path with five exterior vertices to global-longest status and rules out oversized proper path packets. It is the clean parent behind many later five-exterior equality and order-ten longest-path normalizations.

## Persistence
Graph-intrinsic size constraint on K. It survives arbitrary representative changes because it refers only to the vertex set of the tight path.

## Exclusions / nonclaims
Does not itself supply endpoint reverse-star orientations, selected roles, exact complement rails, source maximinity, marker ancestry, or transfer coordinates. Those require separate theorems.

## Proof
Let D=V(H)-V(K). Since K is proper, D is nonempty. If |D|<=4, R5 gives pc(H-D)=2. But H-D is exactly the tight path K, so pc(H-D)=1. Contradiction. Hence |D|>=5, equivalently |K|<=|H|-5.
