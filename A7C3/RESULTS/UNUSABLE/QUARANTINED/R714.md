# R714 — Every first-inward X-complement four-set is Hamiltonian in the synchronized transitive frame

**Record status:** `UNUSABLE/QUARANTINED`

## Statement
Retain the accepted R594 synchronized transitive frame with transitive P4-free four-cell X and Q=(q_0,...,q_m), m>=4. Put u=q_1 and s=q_{m-1}. Then for every x in X, both four-sets {u} union (X\{x}) and {s} union (X\{x}) support tight Hamilton P4s. Proof for u: first X union {u} is P5-free, because a Hamilton P5 on X union {u} together with the untouched tight suffix Q[2,m] would be a spanning two-cover of H. Fix x in X and choose any tight trimer C on X\{x}; such a trimer exists on every three-set by boundary antisymmetry. Since X itself is P4-free, C union {x}=X has no Hamilton P4. If C union {u} also had no Hamilton P4, accepted R522 applied to the fixed trimer C with outside vertices x,u would force a Hamilton P5 on C union {x,u}=X union {u}, contradiction. Hence C union {u} supports a Hamilton P4. The right statement is dual: X union {s} is P5-free because any P5 there together with Q[0,m-2] two-covers H, and the same R522 argument applies. Therefore all eight first-inward X-complement four-sets are graph-intrinsically Hamiltonian. In particular a LOCAL four-cell output of pending R713 is baseline Hamiltonicity already forced by R594+R522; only the DEEP selected-cut branch of R713 is new physical progress.

## Proof
Let u=q_1. If X union {u} had a tight Hamilton P5, its support would be disjoint from the tight path Q[2,m] and the two supports partition V(H), contradicting pc(H)>2. Thus X+u is P5-free. Fix x in X and orient the three-set X-{x} as a tight trimer C, possible by R3 as included in the R594 frame. R594 says X has no Hamilton P4, so C+x has no Hamilton P4. Suppose C+u had no Hamilton P4. Accepted R522, applied to C with distinct outside vertices x,u, would then force a Hamilton P5 on C+{x,u}=X+u, contradiction. Thus C+u, equivalently {u} union (X-{x}), has a Hamilton P4. For s=q_{m-1}, a P5 on X+s together with Q[0,m-2] would two-cover H, so X+s is P5-free and the same argument gives the four right supports.
