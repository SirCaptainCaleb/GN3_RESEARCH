# R2031 — INVALID: two-seam six-vertex completion

**Status:** FAIL PENDING
**Source:** Slack workspace R2031 re-audit

## Original false statement

The original R2031 claimed that distinct `A,C,s,r,t,v` with

`(A,s,C)`, `(A,r,C)`, `(s,C,t)`, `(r,A,s)`

tight must induce a tight Hamilton `P6`.

This is false.

## Error

The original proof repeatedly treated cyclic rotations of a tight ordered turn as automatically tight. R3 supplies only complete-reversal antisymmetry. Under the accepted R887 comparison model, `(x,m,y)` is an orientation of the pair of incident ordinary edges `xm,my`; cyclic rotation changes the middle vertex and is a different comparison.

## Counterexample

On vertex set `{A,C,s,t,r,v}`, globally order the ordinary edges increasingly by

`Cv < Ar < st < tv < AC < rs < rt < sv < At < Av < As < Cr < rv < Cs < Ct`.

As in R887, declare `(x,m,y)` tight exactly when edge `xm` precedes edge `my`.
This is a globally edge-ordered Strong Level-(1) boundary tournament.
The four original hypotheses hold because

`As < Cs`, `Ar < Cr`, `Cs < Ct`, `Ar < As`.

Nevertheless there is no Hamilton `P6`. The complete list of tight Hamilton `P5` orders is

- `v,t,r,C,s` (missing `A`),
- `s,t,A,v,r` (missing `C`),
- `s,r,t,A,v` (missing `C`),
- `C,v,t,A,s` (missing `r`),
- `t,v,A,s,C` (missing `r`),
- `v,A,s,C,t` (missing `r`),
- `v,t,A,s,C` (missing `r`),
- `A,r,s,C,t` (missing `v`),
- `r,A,s,C,t` (missing `v`),
- `r,t,A,s,C` (missing `v`).

For each listed `P5`, insertion of the missing vertex at either endpoint fails its newly created endpoint turn. Any Hamilton `P6` would yield a Hamilton `P5` by deleting an endpoint, so this exhausts all possible Hamilton `P6`s.
