# R2033 — INVALID: three-cap six-vertex completion

**Status:** FAIL PENDING
**Source:** Slack workspace R2033 re-audit

## Original false statement

The original R2033 claimed that distinct `A,C,s,t,r,v` with source turns

`(A,s,C)`, `(A,t,C)`, `(A,r,C)`

and additional tight turns

`(s,A,v)`, `(v,C,s)`, `(t,A,r)`

must induce a tight Hamilton `P6`.

This is false.

## Error

The proof treated cyclic rotations of tight ordered turns as automatic. R3 provides only complete-reversal antisymmetry. Under R887, changing the middle vertex changes the line-graph comparison and is not licensed by R3.

## Counterexample

On `{A,C,s,t,r,v}`, globally order the ordinary edges increasingly as

`rs < Cv < tv < rv < AC < rt < As < Cs < At < Ar < sv < Cr < st < Ct < Av`.

Declare `(x,m,y)` tight iff edge `xm` precedes edge `my` as in R887. This is a globally edge-ordered Strong Level-(1) boundary tournament. The six original hypotheses hold because

`As<Cs`, `At<Ct`, `Ar<Cr`, `As<Av`, `Cv<Cs`, `At<Ar`.

Nevertheless there is no Hamilton `P6`. The complete list of tight Hamilton `P5` orders is

- `C,v,r,t,s` (missing `A`),
- `r,v,s,t,C` (missing `A`),
- `s,r,t,A,v` (missing `C`),
- `C,v,t,A,r` (missing `s`),
- `C,v,t,r,A` (missing `s`),
- `C,v,r,t,A` (missing `s`),
- `v,t,A,r,C` (missing `s`),
- `v,C,A,s,t` (missing `r`),
- `v,C,A,t,s` (missing `r`),
- `s,A,r,C,t` (missing `v`),
- `r,s,A,t,C` (missing `v`).

For every listed `P5`, the missing vertex fails the newly created turn at either possible endpoint. Hence no `P5` extends to a Hamilton `P6`; every Hamilton `P6` would give such a `P5` after endpoint deletion.
