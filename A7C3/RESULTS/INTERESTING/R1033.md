# R1033 — First-flip obstruction for failed one-vertex insertion

## Statement
Let

    B=(b_1,...,b_m),  m>=2,

be a tight path in a Strong Level-(1) boundary tournament, let `x` be outside `B`, and write

    e_i={b_i,b_{i+1}}  (1<=i<=m-1),
    f_i={x,b_i}        (1<=i<=m).

Assume that inserting `x` into every one of the `m+1` slots of the displayed order of `B` fails to produce a tight path. Equivalently, `I_B(x)=empty`.

Then there is an index `1<=t<=m-1` with one of the following certificates in the R887 comparison orientation `Gamma`.

### Star-triangle
For some `2<=t<=m-1`,

    f_t -> e_{t-1} -> e_t -> f_t.

### Reverse-spoke hook

    e_t -> f_t,
    f_{t+1} -> f_t,

and additionally

    e_{t-1} -> f_t          if t>1,
    f_{t+1} -> e_{t+1}      if t<m-1,

while at `t=m-1` the failed final insertion gives

    f_m -> e_{m-1}.

Thus total failure of displayed-order one-vertex insertion always has a local obstruction on `x` and at most three consecutive vertices of `B`.

## Scope
The result uses only R3, the comparison interpretation R887, and tightness of the displayed path `B`. It does not use minimality, source-frame data, R24/R5, or D17 ancestry.

## Proof
Failure of the left endpoint insertion

    x,b_1,b_2,...,b_m

means `f_1 -> e_1` is false, so R3 gives

    e_1 -> f_1.

Failure of the right endpoint insertion means `e_{m-1} -> f_m` is false, so

    f_m -> e_{m-1}.

If some `t<=m-2` satisfies

    f_{t+1} -> e_{t+1},

choose the least such `t`; otherwise set `t=m-1`.

For `t=1`, the left endpoint failure already gives `e_t -> f_t`. For `t>1`, minimality says `f_t -> e_t` does not hold, so R3 gives

    e_t -> f_t.

Suppose first that `t>1` and

    f_t -> e_{t-1}.

Because `B` is tight,

    e_{t-1} -> e_t.

Together with `e_t -> f_t`, this gives the star-triangle

    f_t -> e_{t-1} -> e_t -> f_t.

Otherwise, whenever `t>1`, R3 gives

    e_{t-1} -> f_t.

Assume now that `t<m-1`. By the choice of `t`,

    f_{t+1} -> e_{t+1}.

If also `f_t -> f_{t+1}`, then insertion of `x` between `b_t` and `b_{t+1}` has all required comparisons forward:

    e_{t-1} -> f_t -> f_{t+1} -> e_{t+1},

with the predecessor comparison omitted when `t=1`. That would make the insertion tight, contrary to `I_B(x)=empty`. Hence

    f_{t+1} -> f_t,

and the reverse-spoke hook is obtained.

It remains to treat `t=m-1`. We already have

    e_{m-1} -> f_{m-1},
    f_m -> e_{m-1}.

If `m>2` and `f_{m-1} -> e_{m-2}`, then tightness of `B` gives the star-triangle

    f_{m-1} -> e_{m-2} -> e_{m-1} -> f_{m-1}.

Otherwise `e_{m-2} -> f_{m-1}` when that predecessor exists. Failure of insertion between `b_{m-1}` and `b_m` then forces

    f_m -> f_{m-1},

because the opposite orientation would make all required comparisons forward. For `m=2` there is no predecessor, and failed middle insertion directly gives `f_2 -> f_1`. Thus the reverse-spoke hook also holds in the terminal case. QED.

## Live source-frame consequence
By R1031, in the retained source frame a hypothetical counterexample has `H[B union {v}]` nonHamiltonian. In particular `I_B(v)=empty`, so R1033 supplies a local star-triangle or reverse-spoke-hook obstruction on `v` and a short consecutive interval of the spectator path `B`.
