# R789 — The inward P5 forces a first-inward old-state reversal or strict endpoint cut movement

**Record status:** `USABLE/LEGACY`

## Statement
Retain the accepted crossed beyond-order-ten frame with m>=6 and the accepted R775 P5 branch. Write L=q_0, u=q_1, v=q_2, d=q_{m-2}, s=q_{m-1}, R=q_m, and let J=(v,u,x,s,d) be the tight inward P5 supplied by R775 for some x in X. Test the two cross-depth turns A=(u,v,d) and B=(v,d,s). Then the following exhaustive implication holds. (REV-L) If A is bad, boundary antisymmetry forces (d,v,u) tight, so K_L=(d,v,u,x) is a literal tight P4; in particular its middle state (v,u) is the exact reversal of the old Q-state (u,v). (REV-R) If B is bad, boundary antisymmetry forces (s,d,v) tight, so K_R=(x,s,d,v) is a literal tight P4; in particular its middle state (s,d) is the exact reversal of the old Q-state (d,s). Both REV-L and REV-R may occur simultaneously. (SHORTCUT-CUT) If neither A nor B is bad, then both are tight. Hence K=(u,v,d,s) is a tight P4 and J^#=(L,u,v,d,s,R) is a tight endpoint-preserving P6. Put D^#={u,v,d,s}. In a hypothetical smallest counterexample accepted R4 supplies an exact two-cover T^# of H-D^#. Accepted R508 applied with recompletion J^# and endpoint block {L,R} forces T^# to select a state crossing {L,R} | (X union Q[3,m-3]). Since u and s are deleted, this crossing cannot be either old terminal Q-state {L,u} or {s,R}; it is strict physical endpoint-cut movement into X or the deep middle interval. Consequently every R775 inward P5 yields either one of the two explicitly oriented first-inward old-state-reversal P4s (possibly both) or strict endpoint cut movement.

## Proof
Let J=(v,u,x,s,d) be the accepted R775 P5, so in particular (v,u,x), (u,x,s), and (x,s,d) are tight. Test A=(u,v,d). If A is bad, accepted boundary antisymmetry R3 on the same three vertices forces its reversal (d,v,u) tight. Together with (v,u,x), this gives the literal tight P4 K_L=(d,v,u,x). Its consecutive state (v,u) is literally the reverse of the old Q-state (u,v). This proves REV-L. Independently test B=(v,d,s). If B is bad, R3 forces its reversal (s,d,v) tight. Together with (x,s,d), this gives the literal tight P4 K_R=(x,s,d,v), whose consecutive state (s,d) is literally the reverse of the old Q-state (d,s). This proves REV-R. If neither A nor B is bad, both are tight. The two turns A=(u,v,d) and B=(v,d,s) concatenate to the tight P4 K=(u,v,d,s). The original long rail Q supplies (L,u,v) and (d,s,R), so the four consecutive turns (L,u,v),(u,v,d),(v,d,s),(d,s,R) certify the vertex-simple tight P6 J^#=(L,u,v,d,s,R). Put D^#=V(K)={u,v,d,s}. K is a proper graph-intrinsic tight path, so in a hypothetical smallest counterexample accepted R4 supplies a literal exact two-cover T^# of H-D^#. In W^#=V(H)-D^#, put S^#={L,R}. The recompletion path J^# has vertex set exactly D^# union S^#, and S^# is nonempty proper because X is nonempty. Accepted R508 therefore forces T^# to select a state crossing S^# | (W^#-S^#). Here W^#-S^#=X union Q[3,m-3]. Since u and s are deleted, neither old terminal state {L,u} nor {s,R} belongs to T^#. Thus the selected crossing strictly moves one physical endpoint cut into the surviving deep subsystem. These cases are exhaustive because each of A,B is either tight or bad.
