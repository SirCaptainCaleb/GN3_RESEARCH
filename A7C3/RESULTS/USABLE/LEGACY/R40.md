# R40 — Support-family actualization

**Record status:** `USABLE/LEGACY`

## Statement

Let several graph-intrinsic supports have the same polarity and same witness. One disjoint nontrivial marker path can be tested once to create a single common opposite-polarity support. Every original support then forms a balanced pair with that same opposite support. The head/tail dual is exact.

## Scope
This is a joint pre-payment certificate. Payments from the several pairs remain separate descendants.

## Proof
Let S_1,...,S_r be the graph-intrinsic signed supports, all with the same polarity and the same sign witness w, and let M=(m_0,...,m_k), k>=1, be a tight marker path disjoint from the union of all V(S_i) and from w. Assume first that the family supports are head-signed by w. Perform the single terminal marker test from fully reconstructed R526: test (m_{k-1},m_k,w). If it is tight, the whole marker M is tail-signed by w, so set Q=M. If it is bad, R526/R3 gives (w,m_k,m_{k-1}) tight, so set Q=(w,m_k), tail-signed by witness m_{k-1}. This construction uses only M,w and the common family polarity; it does not depend on i. Hence the same physical signed support Q is produced for every S_i. Because M and w are disjoint from every S_i, Q is physically disjoint from every S_i in either branch. Each S_i has polarity opposite Q, so fully reconstructible direct balanced-pair theorem R514 gives a balanced opposite-sign pair (S_i,Q) for every i. All these pair births share the same Q certificate, but their later payment descendants are separate historical lineages. The tail-signed family case is the exact head/tail dual using R526's initial marker-end test at m_0. This proves the full support-family actualization theorem: one marker test creates one common opposite support and every original family member pairs with it.
