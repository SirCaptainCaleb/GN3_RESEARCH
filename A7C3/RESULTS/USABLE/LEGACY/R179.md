# R179 — Anchored-Capacity Unsigned-End Reverse-Star Saturation

**Record status:** `USABLE/LEGACY`

## Statement
Let (alpha;P),(T;beta) be a balanced opposite-sign pair and fix the signed head h of P, the signed tail t of T, and witnesses alpha,beta. Among all vertex-disjoint tight path pairs (P',T') with head(P')=h and (alpha,P') tight, tail(T')=t and (T',beta) tight, choose one maximizing |P'|+|T'|. Write this anchored-capacity realization again as (P,T), and put X=V(H)\(V(P) union V(T) union {alpha,beta}). Then every x in X has the following forced reverse-star signs. If P=(...,c,d) is nontrivial, x d c is tight; if P=(p) is singleton, x p alpha is tight. Dually, if T=(a,b,...) is nontrivial, b a x is tight; if T=(t) is singleton, beta t x is tight.

## Hypotheses
H is a finite Strong Level-(1) boundary tournament. (alpha;P) is a head-signed tight path and (T;beta) is a tail-signed tight path; P,T are vertex-disjoint and the witnesses lie outside their own supports. The four anchored data (alpha,h;t,beta) are fixed while maximizing |P'|+|T'| over disjoint realizations satisfying the same signed head/tail conditions.

## Scope
Graph-intrinsic, Strong Level-(1)-safe, and representative-relative. The conclusion concerns every ordinary reservoir vertex outside the chosen capacity supports and their two fixed witnesses. It applies equally to nontrivial and singleton supports through the displayed formulas.

## Applicability
Use to turn a static anchored-capacity maximum into full same-polarity witness families on the reverse dimer at each unsigned support end. It is the input for reservoir collision, balanced-cut visibility, and later fixed-frame capacity collisions.

## Persistence
The tight reverse-star turns are graph-intrinsic once proved. The anchored-capacity realization itself is only an auxiliary extremal representative. Historical supports, birth frame, pivots, theta ports/shadows, payment/capture ancestry, and other labels are not replaced by the capacity representative and must be retained separately when needed.

## Exclusions / nonclaims
No claim that anchored capacity is a global monotone, remains maximal after support truncation/refund, or is preserved by recompletion. No claim that the reverse-star trimers are selected in one current cover before a separate currentization. No CW-freeness, state-DAG, scalarization, or cycle-contradiction inference is used.

## Proof
Fix an anchored-capacity realization (P,T) with the four anchored data held fixed. Let x lie in the ordinary reservoir X, so x is outside P,T,alpha,beta. Suppose first that the head-signed support P=(p_0,...,c,d) is nontrivial. If the turn (c,d,x) were tight, then P^+=(p_0,...,c,d,x) would be a tight path with the same head h=p_0 and the same head-sign witness alpha, because (alpha,P) remains a tight prefix of (alpha,P^+). It remains vertex-disjoint from T, and its size is one larger, contradicting maximality of |P|+|T|. Thus (c,d,x) is bad. Boundary antisymmetry R3 on the distinct triple {c,d,x} forces (x,d,c) tight. If P=(p) is singleton, tightness of (alpha,p,x) would similarly extend the head-signed support while preserving h=p, witness alpha, and disjointness, so (alpha,p,x) is bad and R3 forces (x,p,alpha) tight.

The tail side is dual. If T=(a,b,...,t) is nontrivial and (x,a,b) were tight, then (x,T) would be a larger tight path with the same tail t and the same tail-sign witness beta, remaining disjoint from P, contradicting capacity maximality. Hence (x,a,b) is bad and R3 gives (b,a,x) tight. If T=(t) is singleton, an extension (x,t,beta) would contradict maximality, so its reverse (beta,t,x) is tight. These are exactly the four R179 reverse-star formulas. The conclusions are graph-intrinsic tight turns; only the maximizing realization is representative-relative. No further dependency is used.
