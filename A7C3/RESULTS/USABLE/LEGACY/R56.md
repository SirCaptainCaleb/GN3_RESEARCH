## Statement

Fix one adjacent dimer of the root five-path and consider any exact cover of its complement. The remaining vertices split into the old exterior marker, the surviving three vertices of the old five-path, and the fixed trimer.

## Scope
Every such return has a precise physical-marker role:

- if the old marker state is selected, it is either a terminal or internal dimer block of one current rail;
- if the marker state is absent, both marker vertices are current rail endpoints or at least one is internal in a literal current turn crossing from the marker class to the rest.

In all cases a current turn crosses the marker cut. This is the order-ten specialization of the accepted two-singleton marker-role classification parent.
