# R605 — Cross-end rotated endpoint return localizes to anchor contact, terminal collision, or exact state reversal

**Record status:** `USABLE/LEGACY`

## Statement
Retain the surviving exact-two-bad R24 cell with L=q_0, R=q_m, m>=6, and tight cross-end trimer J_*=(L,b,R). Let H-{L,R}=U sqcup V be any exact two-cover in which b is an endpoint of one rail. If b is the head and that rail begins (b,u,v,...) (with v omitted when the rail has order two), then either H has a spanning two-cover, or: (A) a proper tight dimer through the old R-anchor is produced whose physical support differs from {R,q_{m-1}}, so R436 gives an explicit non-replay anchor-contact/growth/cycle/reversal output; or (C_R) u=q_{m-1}, v exists, and v q_{m-1} R is tight. In the latter case, comparing with the old Q-turn q_{m-2} q_{m-1} R, either v!=q_{m-2} and R523 gives a same-head two-witness collision on the identical tested dimer (q_{m-1},R), or v=q_{m-2} and the exact cover literally begins with the reversed old Q-state q_{m-1} q_{m-2}. The tail-end case is dual: unless a new non-replay L-anchor contact occurs, the rail ends (...,q_2,q_1,b), and either the predecessor differs from q_2 giving a same-tail two-witness collision on (L,q_1), or the cover literally selects the reversed old state q_2 q_1. Thus every endpoint-b return of H-{L,R} is role-localized at one terminal end of Q; no anonymous endpoint mate residue remains.

## Proof
Assume b is the head of its rail. Write P=(b,u) if |P|=2 and P=(b,u,v,...) otherwise. Replace b by the tight segment L,b,R. If |P|=2 the only new turn is bRu; if |P|>=3 the only new turns are bRu and Ruv. If all present turns are tight, the modified rail plus the untouched second rail spans H, contradiction. Hence some present hole is bad. If bRu is bad, R3 gives uRb tight. The dimer (R,b) is a proper path containing the signed anchor R of the old head-signed long-rail terminal support H_R=(R,q_{m-1}) (witness b); its support is different, so R436 gives the claimed non-replay R-anchor output. Suppose instead Ruv is bad. R3 gives vuR tight, so the proper dimer (R,u) meets H_R at R. If u!=q_{m-1}, the physical support differs from H_R and R436 again gives a non-replay output. Thus the only remaining case is u=q_{m-1}. But then bRu=bRq_{m-1} is tight by the endpoint star, so the second hole must indeed be the bad one and R3 yields v q_{m-1} R tight. The old Q-turn q_{m-2} q_{m-1} R is tight. If v!=q_{m-2}, these are same-head certificates on the identical tested oriented dimer (q_{m-1},R) with distinct witnesses, so R523 gives the stated collision. If v=q_{m-2}, P literally begins (b,q_{m-1},q_{m-2}), so it selects the exact reversal q_{m-1}q_{m-2} of the old Q-state q_{m-2}q_{m-1}. The order-two aligned case u=q_{m-1} cannot survive because its sole hole bRq_{m-1} is tight and would close. The tail case is exact dual. Write P=(...,v,u,b), try (...,v,u,L,b,R), and test vuL and uLb. A bad uLb gives bLu and hence a new L-anchor dimer unless u=q_1; a bad vuL gives Luv and hence a new L-anchor dimer unless u=q_1. When u=q_1, q_1Lb is tight by the endpoint star, so only vuL can be bad; its reverse Lq_1v is tight. Compare with the old Q-turn Lq_1q_2. If v!=q_2, these are same-tail certificates on tested dimer (L,q_1); if v=q_2, the cover literally ends with the reversed old state q_2q_1. This proves the normal form.
