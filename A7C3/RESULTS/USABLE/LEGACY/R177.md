# R177 — Crossed-Deletion Port-Preservation Regression

**Record status:** `USABLE/LEGACY`

## Statement
There exists a seven-vertex Level-(3) boundary tournament on vertices x,c,d,z,a,b,e satisfying the crossed deletion-window conditions xcd tight, abe tight, cdz bad, zab bad, and dza bad, for which no spanning two-path cover simultaneously preserves the literal exterior ports x,c at the beginning of one path and b,e at the end of the other. Nevertheless the same system has a Hamilton tight path. Hence crossed local deletion data alone does not force a bounded port-preserving two-path reroute.

## Hypotheses
Explicit Level-(3) edge-order witness: ab < xa < be < zb < db < ae < za < cz < xz < cb < xd < dz < da < ze < xc < ce < xe < cd < de < ca < xb. Tightness is interpreted by the standard Level-(3) increasing-edge-order representation.

## Scope
Strong Level-(1) negative result. It refutes only a purely local port-preserving reroute theorem under the displayed crossed-window hypotheses. It is not a counterexample to the Strong Two-Cover Conjecture.

## Applicability
Guardrail against arguments that insist a crossed five-vertex deletion core must reconnect to both original exterior rails without additional global retention/extremality hypotheses.

## Persistence
The counterexample is a fixed graph-intrinsic finite witness. Its Hamilton tight path a,b,z,x,c,d,e shows that the obstruction is port preservation rather than path-coverability.

## Exclusions / nonclaims
Does not say port preservation is impossible under stronger global smallest-counterexample or extremal hypotheses. Does not invalidate explicit retention/restoration theorems. Does not contradict Universal Prescribed-Path Completion, which deliberately allows the complement rails to change.

## Proof
Use the displayed total edge order ab<xa<be<zb<db<ae<za<cz<xz<cb<xd<dz<da<ze<xc<ce<xe<cd<de<ca<xb. Define a turn u v w to be tight exactly when edge uv precedes edge vw in this total order. For every distinct u,v,w exactly one of uv<vw and vw<uv holds, so exactly one of u v w and w v u is tight; hence this is a Strong Level-(1) boundary tournament, indeed the stated Level-(3) edge-order representation.

Direct lookup gives xcd and abe tight, while cdz, zab, and dza are bad, exactly realizing the crossed deletion-window hypotheses.

Now test the literal port-preserving conclusion exhaustively. A candidate spanning ordered two-path partition with one path beginning exactly (x,c) and the other ending exactly (b,e) is determined by choosing the remaining vertices and their internal orders subject to disjointness and spanning. There are 24 such literal candidates. For each, test every consecutive triple using the edge-order rule above. None has both paths tight. Therefore no spanning two-path cover preserves the two prescribed literal ports simultaneously.

Finally the seven-vertex order (a,b,z,x,c,d,e) is tight: its five consecutive turns all satisfy the required adjacent-edge inequalities in the displayed edge order. Thus the system is Hamiltonian even though the prescribed-port reroute fails. The obstruction is therefore exactly port preservation, as claimed. The verification uses only the retained edge order and exhaustive finite testing.
