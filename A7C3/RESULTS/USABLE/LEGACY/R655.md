# R655 — Dual terminal collision branch makes both Q endpoints universal preserved floor coordinates

**Record status:** `USABLE/LEGACY`

## Statement
Retain the accepted crossed R24 frame of R621 and branch (A) of accepted R633. Thus the terminal physical dimer S_L=(L,u) is tail-signed and S_R=(s,R) is head-signed, with L=q_0,u=q_1,s=q_{m-1},R=q_m and m>=4. Then, without generic pair payment, the same fixed Q geometry yields an ancestry-bearing both-singleton floor exactly {L,R}: cut the contiguous middle interval Q[1,m-1]=(u,...,s) through the two historical signed dimers. Signed-Interval Rebirth leaves the tail-signed singleton (L) from S_L and the head-signed singleton (R) from S_R, retaining the R633 terminal-collision witnesses and the named Q cut. Consequently each Q endpoint is a universal preserved floor coordinate in this branch. For every prescribed x distinct from L there is a finite chosen ancestry-retaining continuation yielding either a spanning two-cover or the exact floor {L,x}, with L preserved during the final one-coordinate steering step; dually, for every x distinct from R there is closure or the exact floor {R,x}, with R preserved.

## Proof
Assume branch (A) of accepted R633. By definition, the fixed tested terminal dimer S_L=(L,u) carries tail polarity, while S_R=(s,R) carries head polarity. Their supports are disjoint because m>=4, and both occur as the two terminal dimers of the same retained tight rail Q=(L,u,q_2,...,q_{m-2},s,R). Keep all original R633 witness data.

Let C=Q[1,m-1]=(u,q_2,...,q_{m-2},s). This is a contiguous tight interval of Q. It meets S_L exactly in u and S_R exactly in s. Apply accepted Signed-Interval Rebirth / Tight-Path Cut Memory R425 separately to the two historical signed supports with the vertices met by C deleted. For the tail-signed path S_L=(L,u), the last surviving interval is the singleton (L); since u is the deleted right cut-neighbor, R425 certifies (L) with the same tail polarity, now with the physical cut boundary u available as the rebirth witness. For the head-signed path S_R=(s,R), the first surviving interval is the singleton (R); since s is the deleted left cut-neighbor, R425 certifies (R) with the same head polarity, with cut boundary s as the rebirth witness. Thus the two surviving singleton supports are disjoint and have opposite polarities. They form an ancestry-bearing mass-two balanced-pair floor exactly {L,R}. No generic pair-payment excursion is required: the floor is obtained directly from the one fixed Q interval cut, while the original R633 collision witnesses remain historical ancestry.

Now fix any x distinct from L. If x=R the displayed floor already has target {L,R}. Otherwise apply accepted R432 to the active floor S={L,R} with target T={L,x}. Since S and T share the coordinate L, use the one-replacement case in the proof of R432: retain L as the common singleton and replace only R by x. The chosen continuation yields either a spanning two-cover or the exact floor {L,x}, with L preserved through that replacement. This proves universal preserved-coordinate capability for L. The argument for R is the exact dual, applying R432 to target {R,x} and preserving R. Hence both Q endpoints are universal preserved floor coordinates throughout branch (A).
