# R158 — Carrier-Crossing Splice-or-Full-Breach Lemma

**Record status:** `USABLE/LEGACY`

## Statement
Let C be a retained tight path in a finite Strong Level-(1) boundary tournament, and let S be a literal current path cover containing V(C). If S selects a state crossing V(C) | (V(S)-V(C)) at a carrier vertex v, then either S also selects an historical carrier state of C incident with v, in which case that state and the crossing are consecutive selected states and form a literal current tight splice turn in S, or S selects no historical carrier state of C incident with v. Hence in the no-splice branch an internal crossing vertex loses both historical carrier incidences, while a terminal crossing vertex loses its unique historical carrier incidence.

## Hypotheses
C is a graph-intrinsic retained tight path; S is one displayed literal path cover on a vertex set containing V(C); a current selected state of S crosses the physical cut V(C) | outside at v in V(C).

## Scope
Universal Strong Level-(1) local path-cover statement; no smallest-counterexample or extremality hypothesis is required.

## Applicability
Diagnoses any current carrier/exterior crossing as same-representative splice alignment or complete local historical breach. Useful before invoking assembly or fragmentation machinery.

## Persistence
The splice/breach conclusion is current only in the displayed representative S. Historical carrier identities remain graph-intrinsic after later representative changes, but selection does not.

## Exclusions / nonclaims
Does not identify the splice with a final-candidate assembly coordinate; does not transfer selected states across representatives; does not assert endpoint exposure; does not create a two-cover.

## Proof
Let e be the selected crossing state incident with v. If a historical carrier state f of C incident with v is also selected in S, path-forest incidence forces e and f to be the two consecutive selected incidences at v on one current path component (with the obvious endpoint simplification). Since S is a tight path cover, their ordered triple is tight, so e and f form a literal current carrier/exterior splice turn. Therefore if no such splice turn occurs at the crossing vertex, no historical carrier state incident with v can be selected. If v is internal in C this excludes both old adjacent states; if v is terminal it excludes the unique old adjacent state.
