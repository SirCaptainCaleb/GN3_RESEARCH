# R165 — Arbitrary Prescribed-Head Two-Cover Is False

**Record status:** `USABLE/LEGACY`

## Statement
There exists an eight-vertex Strong Level-(1) boundary tournament H and a vertex r such that H has a spanning cover by two tight paths, but no spanning two-path cover has r as the head of either path. In fact the archived example is CW-free, has r=0, every tight path beginning at 0 has order at most three, and H contains a tight path of order seven.

## Hypotheses
None; this is an explicit existential counterexample. The vertex set is {0,1,2,3,4,5,6,7}. Tightness is defined by local tournaments T_v via u v w tight iff u beats w in T_v.

## Scope
Negative result for Strong Level-(1), already inside the CW-free subclass. Therefore no Strong proof may invoke arbitrary prescribed-head two-cover completion or arbitrary prescribed-head Hamilton/two-path induction.

## Applicability
Regression barrier for rooted variants and proof designs that try to keep an arbitrarily chosen vertex as a current path head through minimum two-cover completion.

## Persistence
Graph-intrinsic explicit counterexample. Independent of representatives in the current A7C3 proof.

## Exclusions / nonclaims
Does not refute the unrooted Strong Level-(1) Two-Cover Conjecture. Does not say every root can fail; in the archived example only root 0 fails and an unrooted two-cover exists.

## Proof
Use the seven transitive local orders and the cyclic-top T_2 written in the accepted P164 certificate. For every middle vertex v, define u v w tight iff u beats w in T_v. Each T_v is a tournament, so for every distinct u,v,w exactly one of u v w and w v u is tight; hence this is a Strong Level-(1) boundary tournament.

The advertised unrooted cover is literal: (2,4,3,7,0,5,6) is tight by direct lookup in T_4,T_3,T_7,T_0,T_5, and singleton (1) is a tight path, so these two paths span V.

Now enumerate tight simple paths beginning at 0 from the retained local tournaments. There are exactly ten such paths in total and their maximum order is three. The only order-three rooted paths are (0,5,6) and (0,6,5). For every tight rooted path P beginning at 0, enumerate all permutations of its complement V\V(P) and test consecutive triples by the same local-tournament rule. No complement has a Hamilton tight ordering. Therefore no spanning two-path cover can have 0 as the head of either path. This is exhaustive because any such rooted two-cover consists of one tight simple path beginning at 0 together with a Hamilton tight path on its complement.

The claimed long path is also literal: (2,4,3,7,0,5,6) is a tight path of order seven.

Finally verify CW-freeness directly without the lost historical rank table. Form the ordered-state digraph on the 56 states (u,v), u!=v, with an arc (u,v)->(v,w) exactly when u v w is tight. Kahn topological elimination removes all 56 states, so this state digraph is acyclic. A closed tight walk would give a directed cycle in this state digraph, therefore none exists. Thus the explicit example is CW-free. All checks use only the local tournaments retained in the accepted certificate; no external historical dependency is required.
