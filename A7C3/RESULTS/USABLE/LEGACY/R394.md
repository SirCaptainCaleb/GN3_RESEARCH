# R394 — One-hole mate finish

**Record status:** `USABLE/LEGACY`

## Statement
Let C be a fixed displayed spanning two-component path-forest candidate in a Strong Level-(1) boundary tournament whose complete uncertified turn set consists of one ordered turn h. If h is tight, C is already a spanning two-cover. If h is bad, boundary antisymmetry gives the exact reverse mate bar(h) tight, and the candidate retains the identity of h and its exact mate as candidate-aware local data. This one-hole mate packet does not by itself produce a spanning two-cover or contradiction; any further assembly conclusion requires an additional theorem consuming the same candidate identity, orientation, endpoint/seam roles, or ancestry.

## Hypotheses
A fixed displayed spanning two-component candidate with exactly one uncertified turn h; Strong Level-(1) boundary antisymmetry.

## Scope
Correction/modernization of legacy R64. It records only the source-supported one-hole mate output and explicitly removes the misleading automatic-finish reading.

## Applicability
Use whenever a final candidate has exactly one hole. It licenses the exact mate of that hole as graph-intrinsic candidate-aware data, but no more.

## Persistence
The displayed candidate identity, physical hole h, and exact reverse mate are retained as graph-intrinsic/candidate-relative data. No current representative containing both candidate seam and mate is asserted.

## Exclusions / nonclaims
Does not assert the mate closes the conjecture, restores the missing turn, currentizes compatibly with the candidate, or supplies capture/protection. Same-end mate/splice incompatibility remains a fence.

## Proof
The candidate has one uncertified turn h. If h is tight the displayed two-path forest is a spanning two-cover. Otherwise h is bad and Strong boundary antisymmetry makes the exact reverse turn bar(h) tight. Historical source review explicitly corrects the old finish language: the one-hole theorem supplies the exact mate/canonicality information but not automatic closure.
