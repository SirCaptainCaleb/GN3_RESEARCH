# R151 — Five-vertex Hamilton-4 Reverse-Wrap root fan

**Record status:** `USABLE/LEGACY`

## Statement
In the order-ten minimum-three-cover counterexample setting, let X be a tight five-path and let its five-vertex exterior be S={y_0,y_1,y_2,y_3,a}. If (y_0,y_1,y_2,y_3) is a tight Hamilton four-path on S\\{a}, then the five exterior trimers (y_1,y_0,a), (y_0,y_1,y_2), (y_1,y_2,y_3), (a,y_3,y_2), and (y_3,a,y_0) are simultaneously graph-intrinsically tight. More strongly, they occur as five literal minimum 5+3+2 covers with the same fixed five-path X: X⊔(y_1,y_0,a)⊔(y_2,y_3); X⊔(y_0,y_1,y_2)⊔(y_3,a); X⊔(y_1,y_2,y_3)⊔(a,y_0); X⊔(a,y_3,y_2)⊔(y_0,y_1); and X⊔(y_3,a,y_0)⊔(y_1,y_2). Equivalently, deleting the displayed marker dimer in each cover gives an exact 5+3 pair-deletion root with X retained literally.

## Hypotheses
Order-ten standing counterexample with minimum path-cover number three; X is a tight five-path on five vertices; its exterior has exactly five vertices S={y_0,y_1,y_2,y_3,a}; (y_0,y_1,y_2,y_3) is tight in the displayed orientation. Historical sources call this the audited Five-Vertex Hamilton-4 Reverse-Wrap / five-root compiler.

## Scope
Generic order-ten five-exterior compiler. It applies whenever a globally-longest five-path has a five-vertex exterior containing a tight Hamilton four-path. Later A7C2 work repeatedly used the generic fan and concrete theta specialization as accepted shared input.

## Applicability
Use when one needs several exact pair-deletion roots on the same physical exterior five-set while retaining the same five-path X literally. The five roots expose all five cycle marker supports {y_0,y_1},{y_1,y_2},{y_2,y_3},{y_3,a},{a,y_0} together with the corresponding complementary fixed trimer.

## Persistence
The same five-path X is literal in all five displayed minimum covers. Each trimer and marker dimer is literal only in its displayed root. The five trimer tightness statements are graph-intrinsic and may be reused across representatives. Marker-dimer orientation is not globally fixed by this contract.

## Exclusions / nonclaims
Does not assert that one chosen orientation of every marker dimer persists around the entire physical five-root cell; later producer-local orientation-holonomy/coherent-dimer claims are not imported here. Does not transport arbitrary selected states between roots, does not imply capture/protection, and does not imply a spanning two-cover. The physical-support fan is stronger than bare five-exterior reverse-star equality because it retains one common X and five exact pair-deletion roots.
