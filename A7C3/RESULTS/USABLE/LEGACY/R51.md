## Statement

For each marker vertex, boundary antisymmetry chooses one of two fold types. ## Scope

If both marker vertices have the same fold type, that terminal system is saturated by all five exterior vertices. If their fold types differ, both terminal systems exist, each with four common witnesses.

These are graph-intrinsic systems. The fold paths and four square corners are not asserted current together.
