# R182 — Fixed-Fiber Selected-Wrap Old-Boundary Alignment

**Record status:** `USABLE/LEGACY`

## Statement
Work on H-T_q with literal old residual cover O=A* disjoint_union R_H disjoint_union R_T. Let h=head(R_T), t=tail(R_H), and let T=C_A disjoint_union C_R be a quiet overlap-maximal exact two-cover in the fixed straight-pairing fiber, with C_R=(h,x_1,...,x_{r-1},t), r>=2, and with the inherited role labels R_H head-lost and R_T tail-lost. Put w=th. If the head-side wrap seam t h x_1 is tight, the explicit rotation T_H=T-{x_{r-1}t}+{th} is an exact two-cover selecting th, preserves every other selected state, and has zero cycle debt. In the surviving quiet/no-R12-exit branch, x_{r-1}t is exactly the literal old last boundary r t of R_H. Dually, if x_{r-1} t h is tight, T_T=T-{h x_1}+{th} is an exact two-cover selecting th with zero cycle debt and, in the surviving quiet/no-R12-exit branch, h x_1 is exactly the literal old first boundary h s of R_T. Thus a successful one-boundary residual-wrap selection consumes a named old residual boundary, not an anonymous target boundary.

## Hypotheses
The synchronized hard fixed-fiber package is in force: old residual cover O=A* disjoint_union R_H disjoint_union R_T of H-T_q; a quiet overlap-maximal exact two-cover T with fixed endpoint sets and straight pairing; completion-independent role labels R_H=head-lost and R_T=tail-lost; and the historical Cross-Completion Opposite-Role Collision package is available. The stated old-boundary conclusion is conditional on remaining in the quiet branch and excluding that package's already-productive outputs.

## Scope
Strong Level-(1)-safe, representative-relative exact-two-cover theorem in the synchronized fixed-endpoint fiber. It identifies the literal selected state removed by the successful wrap rotation and preserves all other selected states of that exact target.

## Applicability
Use when a residual splice th is selected by an intracomponent wrap in the quiet fixed fiber and downstream assembly needs the exact old boundary sacrificed rather than merely existence of a selected th. The head and tail versions are exact duals.

## Persistence
In the rotated exact target, th is literally selected, the identified old residual boundary is literally absent, and every other selected state of T survives. The original target T, its literal C_R order, and any previously certified same-cover internal A* excursion remain simultaneously known as historical/current-frame certificates. However the rotated target is not guaranteed to retain both original A* ingress/egress states if one coincides with the deleted terminal boundary.

## Proof
Write C_R=(h,x_1,...,x_{r-1},t). If t h x_1 is tight, then (t,h,x_1,...,x_{r-1}) is a tight path, so T_H=T-{x_{r-1}t}+{th} is an exact two-cover of H-T_q. It changes one selected state, preserves every other selected state, and has zero cycle debt. The inserted state th is not old because it joins the two distinct old residual components R_H and R_T. Suppose the deleted state d=x_{r-1}t were also not old. Then |T_H cap O|=|T cap O|, so T_H is overlap-maximal. If T_H is nonquiet, the branch has already reached an accepted physical output and no alignment conclusion is required. If T_H is quiet, moving t from target-tail position to target-head position reverses the endpoint-loss polarity assigned to the same old residual component R_H. The accepted Cross-Completion Opposite-Role Collision theorem then gives one of its productive outputs, contrary to the surviving branch hypothesis. Therefore d is old. Since t lies only on old R_H and the only old selected state entering t is its last boundary r t, x_{r-1}t=r t. The tail-side proof is exact dual: if x_{r-1} t h is tight, T_T=T-{h x_1}+{th}; if h x_1 were non-old, the same overlap/role-flip argument applies, so h x_1 is old, and uniqueness of the old state leaving h identifies h x_1=h s, the first boundary of R_T.
