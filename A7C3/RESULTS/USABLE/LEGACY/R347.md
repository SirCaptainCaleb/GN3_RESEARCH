# R347 — Mantel-near-equality fixed-trimer bad graph need not force P6

**Record status:** `USABLE/LEGACY`

## Statement
There exists a seven-vertex Strong Level-(1) boundary tournament with a fixed tight trimer support P={0,1,2} such that the bad-extension graph G_bad on X={3,4,5,6}, where xy is an edge iff P∪{x,y} has no tight P5, is exactly the three-edge star K_{1,3} with center 3, while the whole seven-vertex system has maximum tight-path order exactly five. Concretely P∪{3,4}, P∪{3,5}, P∪{3,6} are non-Hamiltonian five-supports, whereas P∪{4,5}, P∪{4,6}, P∪{5,6} all support tight P5s. No six-vertex support carries a tight P6. Thus R328's Mantel extremal threshold is structurally sharp at m=4: being only one bad edge below the extremal K_{2,2} pattern does not imply path growth.

## Scope
Pure seven-vertex local regression fence for structural-density-to-path-growth arguments.

## Applicability
Use against attempts to infer a P6 from near-Mantel fixed-trimer bad-graph structure. It shows exact extremality, not merely high density, is the first plausible local threshold at four outside vertices.

## Persistence

## Exclusions / nonclaims

## Proof
Use exactly the seven middle-vertex comparison rows written in R347. For each middle b, the row contains one orientation of every unordered pair {a,c} disjoint from b, hence 15 comparisons; taking the reverse orientation false fills all 30 ordered triples with middle b. Across the seven middles this assigns all 210 ordered triples of distinct vertices and, pair by pair, exactly one of (a,b,c),(c,b,a) is tight. Thus the table is a Strong Level-(1) boundary tournament. The row for middle 1 contains 0>2, so (0,1,2) is tight.

Now verify the fixed-trimer extension claims by literal enumeration. For a five-vertex support S, enumerate all 5!=120 orders q=(q1,...,q5) and accept q exactly when its three consecutive turns q1q2q3, q2q3q4, q3q4q5 are all tight according to the table. On P={0,1,2}, the supports P∪{3,4}, P∪{3,5}, P∪{3,6} have zero accepted orders, whereas P∪{4,5}, P∪{4,6}, P∪{5,6} have respectively 2, 5, and 4 accepted orders. Concrete witnesses include (5,0,1,2,4), (1,0,6,2,4), and (0,2,1,5,6). Hence G_bad is exactly the star with center 3.

Finally enumerate every ordered six-tuple of distinct vertices. There are 7P6=5040. A six-tuple is tight exactly when its four consecutive turns are tight. Direct lookup in the same table gives zero tight six-tuples. Since the good five-supports above exhibit tight P5s, the maximum tight-path order is exactly five. This finite check is completely reconstructible from the comparison table in R347: it requires only iterating the stated 120- and 5040-element order sets and testing consecutive triples; no external theorem or hidden certificate is used.
