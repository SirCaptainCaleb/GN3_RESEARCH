If D={a,c}, the tested R649 support is head-signed by both L,R. Use R527 with witness L, orienting marker (e,q_i) so q_i is the captured terminal anchor. ## Proof
Let {e,q_i} be the selected inward state from R702. First D={a,c}. R649 fixes head polarity on either tested orientation of D, with both L and R as valid same-polarity witnesses for the X-complementary packet containing e. The state {e,q_i} avoids L. Apply R527 with witness L and orient the two-vertex marker M=(e,q_i) so q_i=m_1 is the captured anchor. By the explicit head-signed R526 actualization used inside R527, either the terminal test (e,q_i,L) is tight, or it is bad and boundary antisymmetry gives (L,q_i,e) tight. In the first case K=(e,q_i,L) has consecutive Q-contacts q_i,L in reverse Q-order because i>0. Apply R435 to P=Q and K. In the second case put K=(L,q_i,e) and apply R518 with fourth vertex R. If R518 gives a Hamilton P4, retain it. Otherwise its no-P4 reverse contacts include (R,e,q_i), which is a tight path with consecutive Q-contacts R,q_i in reverse order because m>i. Apply R435. Now D={b,z}. R649 fixes tail polarity on either tested orientation, with witness R available. Orient the marker M=(q_i,e) so q_i=m_0 is the captured head anchor in the exact tail-signed dual of R526. Either the dual terminal test (R,q_i,e) is tight or its reverse (e,q_i,R) is tight. In the first case the Q contacts R,q_i occur in reverse order, so R435 applies. In the second apply R518 to K=(e,q_i,R) with fourth vertex L. A P4 ends the branch; otherwise the forced reverse contact (q_i,e,L) is tight and has Q contacts q_i,L in reverse order, so R435 applies. These cases exhaust the R702 INWARD branch, while its END branch is exactly MATE.
