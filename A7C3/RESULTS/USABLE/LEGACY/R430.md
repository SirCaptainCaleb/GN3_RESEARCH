# R430 — Marker Endpoint Anchor Capture

**Record status:** `USABLE/LEGACY`

## Statement
Let M=(m_0,...,m_r), r>=1, be a tight marker path disjoint from a graph-intrinsic signed support. In head-to-tail Signed-Support Marker Actualization of a head-signed support (a;P) using M, the produced opposite-polarity tail-signed support has signed tail anchor exactly m_r. Dually, in tail-to-head actualization of a tail-signed support (P;b) using M, the produced head-signed support has signed head anchor exactly m_0. In the head-to-tail case, if m_{r-1}m_ra is tight the whole marker M is tail-signed by a; if it is bad, boundary antisymmetry gives a m_r m_{r-1} tight and the short support (a,m_r) is tail-signed with tail anchor m_r. The dual endpoint statement is exact.

## Hypotheses
A graph-intrinsic signed support and a disjoint nontrivial tight marker M are given, and the accepted Signed-Support Marker Actualization test is performed in the indicated polarity direction.

## Scope
Strong Level-(1), arbitrary marker length. This identifies the physical endpoint captured by marker actualization; it is stronger than merely asserting that an opposite support exists.

## Applicability
Use when later arguments need the identity of the signed/captured physical anchor supplied by an actualizing marker, especially orientation-selective dimer capture and fixed-turn endpoint budgets.

## Persistence
The captured marker endpoint is a graph-intrinsic signed anchor in the produced support and remains historical ancestry after representative changes. Current protection or selected status requires a separate theorem.

## Exclusions / nonclaims
Capture is not protection. Does not assert the marker orientation was selected in the source cover; does not preserve the entire marker as current in the bad-test branch; does not localize later first contact without a protected continuation.

## Proof
Let (alpha;P) be head-signed and let M=(m_0,...,m_r), r>=1, be a disjoint tight marker used in the head-to-tail actualization direction. Test the terminal turn m_{r-1} m_r alpha. If it is tight, then (M;alpha) is a tail-signed support and its signed tail anchor is exactly m_r. If it is bad, Boundary Antisymmetry R3 gives alpha m_r m_{r-1} tight. Hence the two-vertex support (alpha,m_r) is tail-signed by witness m_{r-1}, again with signed tail anchor exactly m_r. Thus either actualization outcome records the physical endpoint m_r as the new signed anchor. The exact tail-to-head dual tests alpha m_0 m_1 and records m_0 as the head anchor. This is precisely the historical Marker Endpoint Anchor Capture calculation; no generic actualization theorem is needed once the terminal marker turn is displayed.
