# R565 — Trimer pure-rail both-bad CS cell at j=3 has a three-splice hole menu

**Record status:** `USABLE/LEGACY`

## Statement

Retain a full R513 both-bad CS packet with (j,s)=(3,2). Thus K=(c_0,c_1,c_2), the seam four-set is F={a,b,c,d} with a=q_1, b=q_2, c=c_0, d=c_1, both seam holes (a,b,c) and (b,c,d) are bad, and g=(b_r,q_3,q_4) exists because j=3<=m-1 forces m>=4. R3 supplies (c,b,a) and (d,c,b) tight, so K*=(d,c,b,a)=(c_1,c_0,q_2,q_1) is tight. Write lambda*=(q_0,c_1,c_0), rho=(q_2,q_1,c_2), lambda=(q_0,q_2,q_1), and sigma=(c_1,c_0,c_2).

(1) The R513 reverse-four-segment proposal
U*=(q_0,c_1,c_0,q_2,q_1,c_2),\nV=(b_0,...,b_r,q_3,...,q_m)
has complete uncertified-turn set {g,lambda*,rho}. If both lambda* and rho are tight, this is a literal one-hole proposal with sole hole g. If exactly one of lambda*,rho is tight, it is a literal two-hole proposal.

(2) The unique Hamilton P4 on F retaining suffix (c_0,c_1) is P_R=(q_2,q_1,c_0,c_1). If P_R is tight, the proposal
U_R=(q_0,q_2,q_1,c_0,c_1,c_2),\nV as above
has complete uncertified-turn set {g,lambda}, since (c_0,c_1,c_2) is a K-turn. If additionally lambda is tight, this is a one-hole proposal with sole hole g.

(3) The unique Hamilton P4 on F retaining prefix (q_1,q_2) is P_L=(q_1,q_2,c_1,c_0). If P_L is tight, the proposal
U_L=(q_0,q_1,q_2,c_1,c_0,c_2),\nV as above
has complete uncertified-turn set {g,sigma}, since (q_0,q_1,q_2) is a Q-turn.

(4) If any displayed outer turn is bad, R3 supplies its reverse. In particular if lambda* is bad then (c_0,c_1,q_0) is tight; if rho is bad then (c_2,q_1,q_2) is tight; if lambda is bad then (q_1,q_2,q_0) is tight; if sigma is bad then (c_2,c_0,c_1) is tight.

Thus the cell is a one-hole proposal with unchanged V and sole hole g whenever any one of the three splices has all of its listed outer turns tight. Otherwise it is a two-hole proposal from that splice, or an irreducible cell whose missing outer turns are among {lambda*,rho,lambda,sigma}, each with its displayed reverse. No D/S membership of q_1,q_2 is used.

## Hypotheses

H is finite Strong Level-(1) with pc(H)>2. The full accepted R513 both-bad CS packet is retained with (j,s)=(3,2). Tight/bad are complementary by R3.

## Scope

Order-free coordinate-preserving refinement of the R513 CS residue at the unique cell where the Q-seam prefix has length three and the pure C-rail is a trimer. It does not treat j>=4 or s>=3.

## Applicability

In an R513 both-bad CS cell with (j,s)=(3,2), test the outer turns of U*, U_R, and U_L in that order. Stop at the first splice whose listed outer turns are all tight and keep that one-/two-hole proposal. If none succeeds, retain the four named missing turns and their R3 reverses.

## Persistence

Retain D,S,Q,T,K,B,A, crossing orientation, cut index j=3, both bad seam holes, g, the four named outer turns with tight/bad status, and the chosen proposal when certified. Forced reverses are graph-intrinsic; proposal coordinates are representative-relative.

## Exclusions / nonclaims

Does not enumerate anonymous P4 orders beyond K*, P_R, and P_L. Does not treat the SC side. Does not use R435, balanced-pair birth, or an unlabeled reverse trimer as an output.

## Proof

Work in the retained R513 both-bad CS packet with j=3 and s=2. Then a=q_1, b=q_2, K=(c_0,c_1,c_2), F={q_1,q_2,c_0,c_1}, the turns (q_1,q_2,c_0) and (q_2,c_0,c_1) are bad, and R3 gives (c_0,q_2,q_1) and (c_1,c_0,q_2) tight. Hence K*=(c_1,c_0,q_2,q_1) is tight. The range j<=m-1 forces m>=4, so g=(b_r,q_3,q_4) is a defined mixed attachment on the unchanged rail V=(B followed by Q[3,m]).

(1) The R513 substitution is U*=(q_0,c_1,c_0,q_2,q_1,c_2). Its consecutive triples are lambda*=(q_0,c_1,c_0), the two K* turns, and rho=(q_2,q_1,c_2). Every consecutive triple of V is a B-turn, a Q-turn, or g. Thus the complete uncertified-turn set is {g,lambda*,rho}. If both lambda* and rho are tight the set reduces to {g}, so g is bad by pc(H)>2 and reverse(g) is tight. If exactly one of lambda*,rho is tight the set has size two.

(2) The only Hamilton P4 on F with suffix (c_0,c_1) other than the forbidden natural order is P_R=(q_2,q_1,c_0,c_1). If it is tight, U_R=(q_0,q_2,q_1,c_0,c_1,c_2) has consecutive triples lambda=(q_0,q_2,q_1), the two P_R turns, and the K-turn (c_0,c_1,c_2). With V unchanged the uncertified set is {g,lambda}. If lambda is also tight this is a one-hole proposal with sole hole g.

(3) The only Hamilton P4 on F with prefix (q_1,q_2) other than the forbidden natural order is P_L=(q_1,q_2,c_1,c_0). If it is tight, U_L=(q_0,q_1,q_2,c_1,c_0,c_2) has consecutive triples the Q-turn (q_0,q_1,q_2), the two P_L turns, and sigma=(c_1,c_0,c_2). The uncertified set is {g,sigma}.

(4) Each bad outer turn has its R3 reverse as displayed. No vertex of T is moved.
