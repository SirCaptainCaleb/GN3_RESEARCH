# R1011 — Minimum complement rail size alone cannot drive extreme-edge representative descent

## Statement
There exists a two-coverable edge-ordered K10 with globally minimum edge 89 such that H=G-{8,9} has exact two-cover number two and minimum possible rail size exactly two, yet no spanning two-cover of G selects 89. Concretely let H be the n=8 R823 matching-layer construction with A={0,1,2,3}, B={4,5,6,7}, internal order 01<45<12<56<23<67<02<03<13<46<47<57, and cross matching blocks (04,15,26,37)<(05,16,27,34)<(06,17,24,35)<(07,14,25,36), with the displayed within-block order. Then H has longest increasing path order at most six, and it has the exact 2+6 cover (0,1)|(5,6,7,3,4,2). Hence no exact two-cover of H has a singleton rail, so the minimum rail size is exactly two. Add 8,9 with 89 below every H-edge and every 8H,9H spoke above every H-edge. Then G is two-coverable but no two-cover selects 89, as in R1010. Therefore a representative descent theorem whose only strictly decreasing coordinate is the minimum complement rail size is false.

## Hypotheses
Explicit R823-based K8 complement H and the two-vertex extreme extension G described in the statement.

## Scope
Exact finite fence against using minimum complement rail cardinality as the sole termination potential in the minimum-edge activation program. Not a counterexample to R888.

## Applicability
Use when designing representative-descent signatures after the failure of the universal minimum-edge root theorem. Any viable potential must include additional physical obstruction data beyond minimum rail size.

## Persistence
Retain the explicit H edge order, the 2+6 cover, the R823 longest-path bound six, the absence of any singleton+Hamilton cover, and the extreme extension order 89 < E(H) < all new spokes.

## Exclusions / nonclaims
Does not rule out lexicographic potentials beginning with rail size and then using barrier widths, extension-Hall type, or other coordinates. Does not refute R888.

## Proof
Take H on vertices 0,...,7 with A={0,1,2,3}, B={4,5,6,7}. Order the twelve internal edges by 01<45<12<56<23<67<02<03<13<46<47<57. Order the sixteen cross edges in the four perfect-matching blocks M1=(04,15,26,37), M2=(05,16,27,34), M3=(06,17,24,35), M4=(07,14,25,36), with all of M1 before M2 before M3 before M4 and with the displayed strict order within each block. This is an instance of accepted R823 at n=8,m=4, so every increasing path has order at most 4+ceil(4/2)=6.\n\nThe paths (0,1) and (5,6,7,3,4,2) form an exact two-cover: the long path uses edges 56<67<37<34<24, which lie respectively at ranks 3,5,15,19,22 in the displayed order. Thus the minimum rail size among exact two-covers is at most two. It cannot be one, because a singleton rail would require the other seven vertices to form an increasing Hamilton path of order seven, contradicting the R823 bound six. Hence the minimum rail size is exactly two.\n\nNow add vertices 8,9, place 89 below every H-edge, and place every edge from {8,9} to H above every H-edge. By R1010, the resulting K10 is two-coverable but no spanning two-cover selects 89. In particular, starting from any complement representative of minimum rail size two, there is no representative with strictly smaller minimum rail size, while the desired minimum-edge-rooted cover still does not exist. Thus minimum rail cardinality alone cannot be the strict descent coordinate.
