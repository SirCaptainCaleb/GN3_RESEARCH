# R452 — Directed-state rigidity modulo same-support collision

## Statement
Let H be a Strong Level-(1) boundary tournament and let e=(u,v) be a directed physical state. Among vertex-simple tight paths containing e in this orientation, either the same physical dimer (u,v) carries a same-polarity two-witness interaction of R38, or the immediate successor of e is unique whenever it exists and the immediate predecessor of e is unique whenever it exists. Consequently, if two vertex-simple tight paths P,Q contain the same directed state (u,v) in the same orientation and have the same ordered head and tail endpoints, then either an R38 same-support interaction occurs on (u,v) or P=Q as literal ordered paths. More generally, outside R38 interaction, a directed state together with any one reachable terminal endpoint determines the corresponding one-sided continuation uniquely.

## Hypotheses
Strong Level-(1); P,Q and all compared paths are vertex-simple tight paths; the shared state (u,v) is used in the same orientation. R38 is available.

## Scope
Order-free graph-intrinsic stationary-state rigidity. This is a new canonical rederivation of the useful mathematical content associated with the legacy stationary-state/end-window gap; it does not claim to reconstruct every stronger historical first-divergence variant recorded in M12.

## Applicability
Use when several current or historical path representatives share one directed state. It converts ambiguity of predecessor/successor into an explicit same-support sign interaction, and outside that output lets endpoints plus one state freeze a rail.

## Persistence
The shared directed state and any R38 sign certificates are graph-intrinsic. Equality P=Q is literal for the two compared ordered paths under the no-interaction alternative; no statement is made about unrelated representatives not containing the state.

## Exclusions / nonclaims
Does not assert two paths sharing only an unordered edge coincide. Does not compare opposite orientations of the state. Does not exclude productive R38 collision. Does not reconstruct the unavailable historical stationary end-window theorem beyond the stated uniqueness consequence.

## Proof
Suppose two tight paths contain the directed state (u,v) and have distinct immediate successors a and b. Then (u,v,a) and (u,v,b) are both tight, so the same physical dimer (u,v) is tail-signed by the distinct witnesses a,b with the same polarity. R38 gives the same-support two-witness interaction. Therefore outside R38 interaction the successor is unique. Dually, if distinct immediate predecessors a,b occur then (a,u,v) and (b,u,v) are tight, so (u,v) is head-signed by two distinct witnesses and R38 applies; hence the predecessor is unique outside interaction. Now let P,Q contain (u,v) in the same orientation and have the same ordered head and tail. If no R38 interaction occurs, repeatedly apply successor uniqueness from (u,v): the next vertex agrees, then the next directed state agrees, so induction forces the entire suffix through the common tail to agree. Vertex-simplicity prevents one path from passing the common tail and later returning to it. Applying predecessor uniqueness backward forces the prefixes through the common head to agree. Hence P=Q literally. The one-sided endpoint version is the same induction in one direction.
