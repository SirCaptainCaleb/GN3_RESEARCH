# R540 — Hamilton-rail plus singleton partner endpoint-cut recompletion

## Statement
Let H be a finite Strong Level-(1) boundary tournament with pc(H)>2. Let D be a nonempty proper set and suppose H-D has the literal exact two-cover R=(r_0,...,r_t) sqcup (x), with t>=2. Let K=(k_0,...,k_m) be a tight path whose support is exactly D union {r_0,r_t}. Fix an occurrence r_0=k_i. Put R^o=(r_1,...,r_{t-1}). Then U=K[0,i] followed by R^o and V=(x) followed by K[i+1,m], omitting empty pieces, form a spanning two-path proposal whose complete uncertified-turn set is { (k_{i-1},r_0,r_1) if i>=1 } union { (x,k_{i+1},k_{i+2}) if i<=m-2 }. Dually, if r_t=k_j, then U2=K[0,j-1] followed by (x) and V2=R^o followed by K[j,m] have complete uncertified-turn set { (k_{j-2},k_{j-1},x) if j>=2 } union { (r_{t-1},r_t,k_{j+1}) if j<=m-1 }. Each displayed hole set is nonempty and not all its members are tight; if it has one member that member is bad, and if it has two members at least one is bad, so R3 certifies the corresponding reverse mate clause.

## Hypotheses
H finite Strong Level-(1), pc(H)>2; H-D=R sqcup (x) literal two-cover; R has at least three vertices; K tight on exactly D plus the two physical endpoints of R.

## Scope
Order-free singleton-partner recompletion compiler.

## Applicability
Use when an R508/R509-style recompletion has exactly one nontrivial Hamilton C-rail and a singleton partner. It replaces the missing selected partner incidence by one explicit singleton seam hole and keeps the hole count at two.

## Persistence
Retain D,R,x,K, the chosen physical endpoint and its K-index, the displayed proposal, and complete hole set. Reverse mates are graph-intrinsic.

## Exclusions / nonclaims
Does not assert either endpoint occupies a favorable K-position, and does not by itself improve the deletion cover.

## Proof
For the left-end construction, the supports of K[0,i], K[i+1,m], R^o, and {x} are pairwise disjoint except that r_0=k_i belongs only to the first K piece, and together they partition V(H): K spans D union {r_0,r_t}, while R^o supplies every vertex of R except its endpoints and x is the singleton rail. Thus U and V are vertex-disjoint and spanning. Inside K-pieces and inside R^o every turn is tight. At the U splice, the turn (r_0,r_1,r_2) is inherited from R whenever it exists; the only possible preceding splice turn is (k_{i-1},r_0,r_1). At the V splice from singleton x into the K-suffix, the only possible turn is (x,k_{i+1},k_{i+2}). Hence the displayed set is complete. The right-end construction is dual: K[0,j-1] followed by x has sole possible splice turn (k_{j-2},k_{j-1},x), while R^o followed by r_t=k_j and the K-suffix inherits (r_{t-2},r_{t-1},r_t) from R and has sole new turn (r_{t-1},r_t,k_{j+1}). Since pc(H)>2, neither proposal can have all displayed holes tight, and a zero-hole proposal is impossible. Therefore each nonempty hole set contains a bad turn; R3 makes its complete reverse tight, giving the stated one- or two-hole mate clause.
