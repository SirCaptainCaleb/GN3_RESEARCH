# R2039 — Consecutive-source anchor P4 packet

**Status:** PASS_ADJUSTED
**Source:** Slack workspace R2039 re-audit

## Repaired statement

Let a literal exact two-cover rail contain consecutive internal retained source spokes

`(...,x,t,r,y,...)`.

Then the anchor/source four-set `{A,C,t,r}` has a literal tight Hamilton P4. More precisely:

- if `(t,A,r)` is tight, use `(t,A,r,C)`;
- otherwise R3 gives `(r,A,t)` tight, and use `(r,A,t,C)`.

No direct insertion of this P4 into the original rail, and no boundary reverse-cap conclusion, follows without additional seam hypotheses.

## Proof

The retained source turns `(A,t,C)` and `(A,r,C)` are tight.

If `(t,A,r)` is tight, the consecutive turns of `(t,A,r,C)` are exactly `(t,A,r)` and `(A,r,C)`, so this is a tight P4.

If `(t,A,r)` is bad, complete-reversal R3 gives `(r,A,t)` tight. The consecutive turns of `(r,A,t,C)` are then exactly `(r,A,t)` and `(A,t,C)`, so this is a tight P4.

## Removed overclaim

The former proof inserted the detour `t->C->A->r` by treating `(t,C,A)` and `(C,A,r)` as cyclic rotations of retained source turns. R3 provides no such rotation. It also rotated the complete-reversal caps obtained from failed boundary seams. Those steps are invalid, so the insertion and cap conclusions are withdrawn.

## Dependencies

Trusted dependencies: retained source turns at `t,r` and R3.

Provisional dependencies: none.

This is the orientation-correct anchor interface used in the exceptional normal forms of R2034: the source pair can be absorbed as a P4 once the complementary residual paths are legally recompleted.
