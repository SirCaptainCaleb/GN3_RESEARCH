# R879 — Every nontrivial spanning three-cover carries a six-clause physical splice fan

## Statement
Let H be a finite Strong Level-(1) boundary tournament with pc(H)>2, and let H=A sqcup B sqcup C be a literal spanning three-cover in which A,B,C are nontrivial tight paths. For every ordered pair of distinct components, say A=(a_0,...,a_p) and B=(b_0,...,b_q) with p,q>=1, the literal spanning two-path proposal (a_0,...,a_p,b_0,...,b_q) sqcup C has complete uncertified-turn set exactly h_1=(a_{p-1},a_p,b_0) and h_2=(a_p,b_0,b_1). Hence at least one of h_1,h_2 is bad, and boundary antisymmetry forces the physical mate clause (b_0,a_p,a_{p-1}) tight OR (b_1,b_0,a_p) tight. Repeating this for all six ordered pairs among A,B,C gives six explicit two-hole physical mate clauses attached to the same literal three-cover.

## Hypotheses
H is finite Strong Level-(1) with pc(H)>2. H=A sqcup B sqcup C is a literal spanning three-cover and all three component paths have order at least two. Only boundary antisymmetry R3 is used.

## Scope
Order-free generic physical seam compiler. This is the R3-only core extracted from retired R453, with its optional smallest-counterexample/R168 specialization deliberately removed.

## Applicability
Use whenever a literal nontrivial spanning three-cover is already present and a complete physical two-hole splice clause is needed. In particular this is the intended reconstructible parent for the R834 signed-dimer three-cover seam theorem.

## Persistence
Retain the three literal component paths, each ordered component pair, the exact concatenated spanning proposal, and its complete two-hole set. The six proposals are alternative certificates built from the same graph-intrinsic component paths.

## Exclusions / nonclaims
Does not assert that the six clauses contain a Mate-Cycle/Mate-Fork pair, that any two holes are complementary, or that one clause closes H. Does not currentize an arbitrary prescribed path and makes no smallest-counterexample rail-size claim.

## Proof
Fix an ordered pair A,B and leave C unchanged. Write A=(a_0,...,a_p), B=(b_0,...,b_q) with p,q>=1. In the concatenated path A*B=(a_0,...,a_p,b_0,...,b_q), every consecutive triple lying wholly in A or wholly in B is tight. The only new consecutive triples are h_1=(a_{p-1},a_p,b_0) and h_2=(a_p,b_0,b_1). Therefore (A*B) sqcup C is a spanning two-path proposal with complete hole set {h_1,h_2}. If both were tight, H would have a spanning two-cover, contradicting pc(H)>2. So at least one h_i is bad. By R3 the complete reversal of a bad ordered triple is tight, giving (b_0,a_p,a_{p-1}) OR (b_1,b_0,a_p). The same argument applies independently to each of the six ordered pairs A,B; A,C; B,A; B,C; C,A; C,B.
