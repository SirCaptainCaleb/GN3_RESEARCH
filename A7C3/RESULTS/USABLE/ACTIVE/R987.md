# R987 — A four-by-four singleton three-cover can require leaving every selected-edge-preserving threshold box

## Statement
Retain the exact K9 edge order of R981:
07<24<45<03<01<28<68<36<12<27<37<14<16<38<58<78<17<47<57<26<48<15<23<56<04<34<13<05<46<02<35<18<25<06<67<08.
In addition to the R981 threshold-box fence and explicit two-cover, this same edge order admits the following nine increasing 4+4+singleton covers F_z, one isolating each z:
F_0=(4,5,1,3)|(8,2,7,6)|{0};
F_1=(6,5,0,8)|(4,2,7,3)|{1};
F_2=(0,3,7,1)|(8,5,6,4)|{2};
F_3=(2,1,4,0)|(6,8,7,5)|{3};
F_4=(3,8,5,0)|(1,2,6,7)|{4};
F_5=(0,1,4,3)|(8,2,7,6)|{5};
F_6=(4,1,8,0)|(3,7,5,2)|{6};
F_7=(4,0,5,2)|(8,6,1,3)|{7};
F_8=(3,0,1,5)|(2,4,6,7)|{8}.
For every unordered pair F_x,F_y, exhaustive symmetric-difference component flipping shows that no locally increasing recombination has more than six selected edges; equivalently no pair has a positive R980 upper-set recombination.
Nevertheless F_0 and F_2 have a legal neutral recombination obtained by flipping the zero-weight alternating 4-cycle
{7->6,5->1} <-> {7->1,5->6}.
The resulting three-cover is
H={0}|(4,5,6)|(8,2,7,1,3).
Comparing H with F_1, the component flip using the zero components
{8->2,4->5}<->{4->2,6->5},
{5->6}<->{5->0},
and the +1 component empty<->{0->8}, while retaining the -1 component {1->3,7->1}<->{7->3}, gives the size-seven increasing matching corresponding to
(4,2,7,1,3)|(6,5,0,8).
Thus an initially pairwise nonimproving singleton seed family can escape after one neutral recombination, and that escape necessarily leaves the original 4+4+singleton seed class. This is an exact finite proof-of-mechanism for neutral collision recombination; it is not a universal escape theorem.

## Hypotheses
Pure finite edge-ordered K9 example. R980 terminology is used only for interpretation; the finite verification enumerates all symmetric-difference component flips and checks the matching and local increasing inequalities directly.

## Scope
Exact finite strengthening of the R981 fence. It tests the neutral-recombination mechanism on the same K9 edge order and exhibits pairwise nonimproving seeds whose neutral closure immediately unlocks a two-cover.

## Applicability
Use as a regression test for any proposed neutral-recombination escape theorem. A theorem must allow intermediate three-covers with arbitrary component sizes; restricting every iterate to the original 4+4+singleton seed class misses the displayed escape.

## Persistence
Retain the full R981 edge order, all nine listed singleton seeds, the pairwise nonimprovement certificate, the neutral F0/F2 4-cycle flip, H, and the positive H/F1 recombination producing the explicit two-cover.

## Exclusions / nonclaims
Does not prove that every pairwise nonimproving seed family escapes. Does not prove termination of neutral closure. Does not show that a trapped neutral family is impossible. Does not refute R888 or R980.

## Proof
Represent each unordered edge by its zero-based rank in the displayed 36-edge order. For a directed matching M, let in[v] and out[v] be the selected predecessor/successor when present. Call M increasing iff every vertex with both selected sides satisfies rank(in[v],v)<rank(v,out[v]). Such a directed matching cannot contain a directed cycle, because labels would strictly increase around the cycle; hence it is exactly an increasing path cover.

1. Seed verification. For each listed F_z, compute the three consecutive edge ranks on each four-vertex rail. They are strictly increasing, so each F_z is an increasing 4+4+singleton cover and its matching has six edges.

2. Exhaustive pairwise recombination check. For a pair M0,M1, form the connected components of the bipartite symmetric difference on copies v_out,v_in. Each component C stores its M0-edge set E0(C) and M1-edge set E1(C). Enumerate all 2^c subsets W of the c components. Form M_W from common edges, M1 component edges on W, and M0 component edges off W. Reject M_W unless it is a bipartite matching and satisfies the physical local increasing test above. For all 36 unordered pairs among F_0,...,F_8, every accepted M_W has at most six edges.

3. Neutral escape. The F0 matching is {4->5,5->1,1->3,8->2,2->7,7->6}. The F2 matching is {0->3,3->7,7->1,8->5,5->6,6->4}. Their symmetric difference contains the zero-weight alternating 4-cycle {7->6,5->1} versus {7->1,5->6}. Flipping only this component in F0 gives H={4->5,5->6,8->2,2->7,7->1,1->3}, namely {0}|(4,5,6)|(8,2,7,1,3). Its edge ranks are 2<23 and 5<9<16<26, so H is increasing and still has six selected edges.

4. Positive comparison with F1. The F1 matching is {6->5,5->0,0->8,4->2,2->7,7->3}. Relative to H, the symmetric-difference components are: C0: {1->3,7->1} versus {7->3}, weight -1; C1: {8->2,4->5} versus {4->2,6->5}, weight 0; C2: {5->6} versus {5->0}, weight 0; C3: empty versus {0->8}, weight +1; plus common edge 2->7. Choose C1,C2,C3 from F1 and C0 from H. The resulting matching is {4->2,2->7,7->1,1->3,6->5,5->0,0->8}. Its two directed paths are (4,2,7,1,3) and (6,5,0,8), with edge ranks 1<9<16<26 and 23<27<35. Hence it is an increasing spanning two-cover.

Thus the initial nine singleton seeds are pairwise nonimproving under every componentwise recombination, but one legal neutral recombination outside the 4+4+singleton seed class unlocks a positive comparison with a third seed.
