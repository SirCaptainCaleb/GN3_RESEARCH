# R21 — Puncture Crossing Parent

**Status:** USABLE / ACTIVE
**Type:** theorem

## Statement

If a retained path is punctured and its surviving part is nonempty, every exact two-cover of the punctured graph selects a state crossing from the surviving carrier to the exterior. More strongly, the number of such crossings is at least the intrinsic path-cover number of the surviving carrier. A non-Hamiltonian survivor therefore forces at least two simultaneous crossings of the same cut.

## Preferred proof

Partition the punctured graph into surviving carrier S and original exterior E. Since the retained carrier K is a proper tight path in a counterexample, E cannot be Hamiltonian, so pc(E)>=2. Apply R7 to any exact two-cover T: the number of S|E transitions is pc(S)+pc(E)-2+sigma >= pc(S). The historical-run addendum is R20 with two current rails. Restoring the prescribed removed tight path beside the exact complement two-cover gives a minimum three-cover in which the counted crossings remain current.
