# R1014 — A one-sided blocked component join transports its endpoint defects monotonically

## Statement
Let G be a finite edge-ordered complete graph and F a spanning increasing three-cover. For an ordered pair of distinct components with terminal t and source s, put a=L_F(t), b=U_F(s), e=lambda(ts). Define LOW when e<a and e<b: remove the last edge p->t of the terminal component and add t->s, producing the inherited prefix ending at p and the path t followed by the source component. Define HIGH when a<e and b<e: remove the first edge s->q of the source component and add t->s, producing the terminal component followed by s and the inherited suffix beginning at q. Both operations are legal increasing three-cover surgeries. Number the ordinary edges 0,...,M-1 by increasing rank and define Psi(F) to be the sum of the ranks of all selected edges of F. Every LOW move strictly decreases Psi, because it removes edge p t of rank a and adds t s of rank e<a. Every HIGH move strictly increases Psi, because it removes edge s q of rank b and adds t s of rank e>b. Hence every all-LOW or all-HIGH sequence terminates. If pc_inc(G)>2, LOW exhaustion yields a SOURCE-SHIELD normal form satisfying U(s)<lambda(ts) for every ordered cross-component terminal-to-source pair, while HIGH exhaustion yields a TERMINAL-SHIELD normal form satisfying lambda(ts)<L(t) for every such pair. A cover satisfying both forms has U(s)<lambda(ts)<L(t) on all six ordered cross-component joins.

## Hypotheses
Finite edge-ordered complete graph and a literal spanning increasing three-cover. For the shield-normal-form conclusions assume pc_inc(G)>2.

## Scope
Pure edge-order finite-termination theorem for physical fresh-edge transports. No R980, minimum-counterexample, threshold matching, or longest-path hypothesis.

## Applicability
Use to replace arbitrary one-sided blocker chains by two concrete extremal normal forms. The remaining local obstruction is the middle-band double block; comparing source-shield and terminal-shield forms is the next completeness-specific augmentation target.

## Persistence
Retain the initial cover, each explicit LOW/HIGH surgery if needed, the selected-edge rank-sum potential Psi, and the source/terminal shield inequalities in the terminal normal forms.

## Exclusions / nonclaims
Does not prove source- and terminal-shield normal forms coincide, that the fully double-blocked form is impossible, or that a mixed LOW/HIGH sequence has a monotone potential. No endpoint-boundary-sum potential is asserted.

## Proof
Let F=A|B|C be a spanning increasing three-cover. Fix an ordered pair of distinct components A,B with terminal t of A and source s of B, and put a=L_F(t), b=U_F(s), e=lambda(ts), with the usual infinite endpoint conventions only for deciding whether a comparison is vacuous.

LOW. Assume e<a and e<b. Then A is nontrivial, so write its last selected edge as p->t, whose rank is exactly a. Delete p->t and add t->s. The prefix A^- ending at p is inherited. The new path obtained by placing t before B is increasing because its first selected edge has rank e and, if B is nontrivial, the next selected edge has rank b>e; every later comparison is inherited from B. Thus the result is another spanning increasing three-cover. It has the same number of selected edges as F, and differs in selected-edge rank sum only by replacing a with e. Hence Psi decreases strictly.

HIGH. Assume a<e and b<e. Then B is nontrivial, so write its first selected edge as s->q, whose rank is b. Delete s->q and add t->s. The path A followed by s is increasing because the old terminal incoming rank is a<e. The suffix B^+ beginning at q is inherited. Again the result is a spanning increasing three-cover with the same number of selected edges, and Psi changes only by replacing b with e. Hence Psi increases strictly.

Because a spanning three-cover on a fixed finite graph has exactly |V|-3 selected edges, Psi is an integer in a finite bounded set. Therefore an all-LOW sequence cannot continue indefinitely, since Psi strictly decreases at every move; likewise an all-HIGH sequence terminates because Psi strictly increases.

Assume now pc_inc(G)>2, so no direct concatenation of two components is legal. At a LOW-terminal cover, fix any ordered pair with values a,b,e. If e<b, then direct legality a<e<b is impossible, so distinctness of labels forces e<a. That is exactly the LOW condition e<a and e<b, contradicting terminality. Hence b<e for every ordered pair, giving the SOURCE-SHIELD normal form. Dually, at a HIGH-terminal cover, if a<e then direct legality a<e<b is impossible, so b<e, which is exactly HIGH; contradiction. Hence e<a for every ordered pair, giving the TERMINAL-SHIELD normal form. If a cover satisfies both, then b<e<a on all six ordered cross-component joins. This proves every clause.
