# R567 — Multi-absorber transition-pressure inequality

## Statement
Let H be any finite tight-path system with p=pc(H). Let D be a proper vertex set, put W=V(H)\D, and partition W into r>=2 nonempty classes Pi={C_1,...,C_r}. Let T be a literal k-path cover of H-D, and let t_Pi(T) be the total number of selected adjacent states of T whose endpoints lie in different Pi-classes. For each i suppose H[D union (W\C_i)] has a literal path cover by a_i rails. Then t_Pi(T) >= r p - (a_1+...+a_r) - k. More precisely, pc(H[C_i])>=p-a_i for every i, and if b_i(T) is the number of maximal contiguous C_i-blocks in T then b_i(T)>=pc(H[C_i]); since sum_i b_i(T)=k+t_Pi(T), the stated inequality follows. In the two-class case W=S sqcup C, if both D union S and D union C are Hamiltonian, then every k-cover T of H-D satisfies t(T)>=2p-2-k. In particular, in a smallest two-cover counterexample p=3, every exact two-cover of such a residue has at least two S|C transitions. More generally, in the same p=3,k=2 regime, a three-class partition for which each D plus the other two classes is Hamiltonian forces at least four cross-class selected states.

## Hypotheses
Only finite tight-path combinatorics. D is proper; C_i are nonempty and partition H-D; T is a k-path cover of H-D; for each i there is an a_i-path cover of D together with all classes except C_i.

## Scope
Order-free, deletion-size-free, arbitrary path-cover threshold p, arbitrary residue cover size k, and arbitrary partition size r. No Strong Level-(1), antisymmetry, or small-order hypothesis is needed.

## Applicability
Use to rule out low-transition exact deletion covers by manufacturing cheap complementary absorbers through one common deletion set D. It converts multiple absorber certificates into a quantitative lower bound on selected cross-class states in every deletion cover.

## Persistence
Retains the common deletion D, partition Pi, each complementary absorber cover size a_i, and the literal transition count of the chosen T.

## Exclusions / nonclaims
Does not produce the complementary absorber covers. Does not prescribe which class pairs realize the forced transitions. Does not by itself convert the forced transitions into balanced pairs, captures, or closure; those require downstream consumers.

## Proof
Fix i. Let c_i=pc(H[C_i]). By hypothesis H[D union (W\C_i)] has an a_i-path cover. Taking this cover together with a c_i-path cover of H[C_i] gives a literal spanning path cover of H with a_i+c_i rails. Therefore p=pc(H)<=a_i+c_i, so c_i>=p-a_i. Now split every rail of T at every selected transition between distinct Pi-classes. Let b_i be the number of resulting nonempty blocks whose vertices lie in C_i. These b_i blocks form a path cover of H[C_i], so b_i>=c_i>=p-a_i. If one T-rail contains m_j monochromatic blocks, it contains exactly m_j-1 cross-class selected states. Summing over the k rails gives sum_i b_i=sum_j m_j=k+t_Pi(T). Hence k+t_Pi(T)>=sum_i(p-a_i)=rp-sum_i a_i, which rearranges to t_Pi(T)>=rp-sum_i a_i-k. The stated two- and three-class corollaries are immediate substitutions.
