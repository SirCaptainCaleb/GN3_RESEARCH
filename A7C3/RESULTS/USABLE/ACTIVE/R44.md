# R44 — Global-longest two-path endpoint gap parent

## Statement

Let a globally longest tight path be disjoint from another tight path. At either end, the outer attachment of the shorter path to the longer path is bad. If the inner attachment is tight, transferring that endpoint gives the exact size bound forced by global longestness; if it is bad, boundary antisymmetry gives a reverse four-vertex path.

## Hypotheses


## Scope
Applying the two end tests together gives:

- equal orders: both reverse four-paths occur;
- order gap one: at least one reverse four-path occurs;
- order gap two: either a reverse four-path occurs or the endpoint transfers produce a second globally longest path.

When the two paths are the exact complement of a marker, the transfers are literal reversible exact-cover exchanges, preserve the marker, and have zero cycle debt. In the gap-two double-tight face, the two endpoint moves commute, forming a four-cover square.

This is a global-longest parent, not the older lexicographically maximal cover theorem. It subsumes the older gap-zero, gap-one, and gap-two turn geometry for the two largest components, but the lexicographic theorem remains available when selected-cover ownership or boundary ancestry is needed.

## Proof
Let A=(a_0,...,a_{m-1}) be a globally longest tight path and B=(b_0,...,b_{n-1}) a disjoint tight path, with m>=n and n>=2 in the nontrivial endpoint-test case. At the left end of A, the outer attachment (b_{n-1},a_0,a_1) is bad: if it were tight, (b_{n-1},a_0,...,a_{m-1}) would be a tight path of order m+1, contradicting global longestness. Hence R3 gives the reverse turn (a_1,a_0,b_{n-1}) tight. Test the inner attachment I_L=(b_{n-2},b_{n-1},a_0). If I_L is tight, then B_L=(b_0,...,b_{n-1},a_0) is a tight path of order n+1, obtained by transferring the endpoint a_0 from A to B; global longestness gives n+1<=m. If I_L is bad, R3 gives (a_0,b_{n-1},b_{n-2}) tight, and together with (a_1,a_0,b_{n-1}) this makes the literal reverse four-path (a_1,a_0,b_{n-1},b_{n-2}).

The right end is dual. The outer attachment (a_{m-2},a_{m-1},b_0) is bad, so R3 gives (b_0,a_{m-1},a_{m-2}) tight. Test I_R=(a_{m-1},b_0,b_1). If I_R is tight, then B_R=(a_{m-1},b_0,...,b_{n-1}) is a tight path of order n+1 and global longestness again gives n+1<=m. If I_R is bad, R3 gives (b_1,b_0,a_{m-1}) tight, producing the reverse four-path (b_1,b_0,a_{m-1},a_{m-2}).

Now compare the orders. If m=n, either inner attachment would create a path of order m+1, so both are bad and both reverse P4s occur. If m=n+1 and both inner attachments were tight, then the combined path (a_{m-1},b_0,...,b_{n-1},a_0) would have order n+2=m+1, contradicting global longestness; hence at least one inner attachment is bad and at least one reverse P4 occurs. If m=n+2, then either one inner attachment is bad and gives a reverse P4, or both are tight; in the latter case the combined path (a_{m-1},b_0,...,b_{n-1},a_0) has order n+2=m and is therefore a second globally longest path.

When A and B are the two rails of the exact complement of a fixed marker, a tight I_L gives the literal cover exchange A|B -> (a_1,...,a_{m-1}) | (b_0,...,b_{n-1},a_0), and a tight I_R gives A|B -> (a_0,...,a_{m-2}) | (a_{m-1},b_0,...,b_{n-1}). These are state-for-state endpoint transfers inside the same vertex set and preserve the external marker. If both apply, performing both yields (a_1,...,a_{m-2}) | (a_{m-1},b_0,...,b_{n-1},a_0) regardless of order, so the two moves commute and form the four-cover square. All four displayed objects are literal path covers; no cycle is created or consumed, hence the cycle-debt contribution is zero. This proves the complete R44 parent.
