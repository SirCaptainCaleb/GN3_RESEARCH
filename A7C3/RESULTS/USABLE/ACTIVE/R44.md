# R44 — Global-longest two-path endpoint gap parent

**Status:** USABLE / ACTIVE
**Type:** theorem

## Statement

Let a globally longest tight path be disjoint from another tight path. At either end, the outer attachment of the shorter path to the longer path is bad. If the inner attachment is tight, transferring that endpoint gives the exact size bound forced by global longestness; if it is bad, boundary antisymmetry gives a reverse four-vertex path.

## Scope

Together the end tests imply: equal orders give both reverse four-paths; gap one gives at least one; gap two gives a reverse four-path or endpoint transfers yielding a second globally longest path. For exact complements of a marker the transfers are reversible exact-cover exchanges and preserve the marker.

## Preferred proof

At each end, a tight outer attachment would extend the globally longest path, so it is bad and reverses by R3. Test the inner attachment. If tight it transfers one endpoint to the shorter path, constraining sizes by maximality; if bad its reversal together with the reversed outer turn forms the displayed P4. Comparing the two end tests gives the gap-zero, gap-one, and gap-two cases. In a fixed exact-complement frame the tight inner attachments are literal endpoint transfers with zero cycle debt and commute in the double-tight gap-two case.
