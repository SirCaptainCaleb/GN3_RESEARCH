# R995 — An isolated dimer gain is blocked only by the two physical endpoint windows

## Statement
Assume accepted R980 and let G be a minimum-order counterexample to R888. Let F be a spanning increasing three-cover, let t be a terminal of one F-component and s the source of a different F-component, and put e=lambda(ts). By accepted R999 choose a spanning three-cover D containing the dimer rail (t,s). In the symmetric difference M_F triangle M_D, E={t_out s_in} is a singleton component of weight +1. Let a=L_F(t), with a=-infinity if t is a singleton, and b=U_F(s), with b=+infinity if s is a singleton. Then every generating R980 collision implication having E as its lower/source component occurs at one of the two physical vertices t,s, and exactly the following are possible: (T-BLOCK) if a>=e, then E<=C_t, where C_t is the symmetric-difference component containing the F-selected incoming edge at t; (S-BLOCK) if e>=b, then E<=C_s, where C_s is the component containing the F-selected outgoing edge at s. No T-BLOCK exists when t has no incoming edge and no S-BLOCK exists when s has no outgoing edge. There are no other outgoing generating implications from E. Moreover every existing first blocker C_t or C_s has weight 0 or -1, never +1. Hence if a<e<b, E has no successors, {E} is a positive upper set, and flipping E is exactly the direct component merge through t->s. In a counterexample at least one of a>=e or e>=b must therefore hold; the upper closure of the fresh gain begins by transporting precisely the failed endpoint window(s).

## Hypotheses
Accepted R980 collision-preorder theorem; minimum R888 counterexample G; spanning increasing three-cover F; t terminal and s source on different F-components; dimer cover D supplied by accepted R999.

## Scope
Completeness-specific physical edge-activation lemma. It localizes the obstruction to a fresh terminal-to-source edge to the actual incoming threshold at its terminal and outgoing threshold at its source.

## Applicability
Use after selecting a desired joining edge t->s. If it is not immediately legal, retain the exact blocker component(s) C_t,C_s and their witnessing inequalities. Neutral exchange may then be used only to transport those endpoint defects; no abstract gain-loss graph without the physical inequalities is sufficient.

## Persistence
Retain F,D,t,s,e,a,b,E and every existing blocker C_t,C_s, including the selected F edge at the blocked physical copy and the inequality a>=e or e>=b.

## Exclusions / nonclaims
Does not prove the blocker upper closure has weight zero, that transporting one blocker activates e, or that repeated transport terminates. Does not assert coherence across different dimer comparisons.

## Proof
Let F be cover 0 and D be cover 1 in the notation of R980. By accepted R999, E={t_out s_in} is a singleton symmetric-difference component with delta(E)=+1. Because E contains only t_out and s_in, a physical collision constraint involving E can occur only at t or s. At t, F has no outgoing selected edge, so U_0(t)=+infinity, while D has outgoing edge ts of label e and no incoming dimer edge, so U_1(t)=e and L_1(t)=-infinity. The incoming choice at t is changed exactly when t has an F-predecessor; let its symmetric-difference component be C_t and write L_0(t)=a. The only mixed state in which E=1 and C_t=0 uses the F incoming edge and D outgoing edge, and is increasing exactly when a<e. If a>=e, R980 imposes C_out(t)<=C_in(t), namely E<=C_t. The opposite possible implication would require L_1(t)>=U_0(t), i.e. -infinity>=+infinity, impossible. If t has no F incoming edge then a=-infinity and no t-blocker exists. At s, F has no incoming selected edge, so L_0(s)=-infinity, while D has incoming edge ts of label e and no outgoing dimer edge, so L_1(s)=e and U_1(s)=+infinity. If s has F-successor, let C_s be the component containing that outgoing edge and put U_0(s)=b. The mixed state E=1,C_s=0 uses the D incoming edge and F outgoing edge and is increasing exactly when e<b. If e>=b, R980 imposes C_in(s)<=C_out(s), namely E<=C_s. The opposite possible implication would require L_0(s)>=U_1(s), impossible. If s has no F outgoing edge then b=+infinity and no s-blocker exists. There is no third physical vertex at which E participates, so these are all generating outgoing implications from E. Finally, C_t, when it exists, contains the F-only selected edge incident with t_in, while t_in is unmatched in D. Therefore its alternating path has an F-only endpoint, so its D-minus-F weight is either 0 or -1, never +1. The same argument at s_out shows delta(C_s) is 0 or -1. If a<e<b neither outgoing implication exists, so E has no successor in the generated preorder. Hence {E} is an upper set of weight +1. R980 then gives a cover with one fewer component; concretely flipping E simply joins the F-path ending at t to the F-path starting at s, and the inequalities a<e<b are exactly the two new seam conditions. In a counterexample this cannot occur, so at least one endpoint inequality fails.
