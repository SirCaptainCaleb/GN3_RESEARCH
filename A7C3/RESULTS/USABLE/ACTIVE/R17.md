# R17 — Gain minus cycle debt

**Status:** USABLE / ACTIVE
**Type:** theorem

## Statement

For any compatible inserted family, actual path-cover improvement is raw exchange gain minus the number of physical tight-cycle components created. A physical tight cycle is constructive, not contradictory; open one selected state on each cycle.

## Preferred proof

For a spanning path cover on n vertices, the number of selected path states is n minus the number of path components. A compatible exchange with raw gain g changes the selected-state count by g. If the resulting selected-state system has c physical tight-cycle components, remove one selected state from each cycle, turning each into a path. The final selected-state gain is g-c, hence the reduction in path-component count is exactly g-c.
