# R1049 — Endpoint-truncated spectator rail at the OUT-v first-positive pivot

**Status:** PASS_ADJUSTED

## Statement
In the sharpened D17.408 bad-hole construction, the canonical three-forest `J` with `tau(J)=1` may be chosen so that its selected `B-B` edges are exactly the displayed spectator path `B=(c_0=L,c_1,...,c_n=R)` with one endpoint adjacency omitted. Thus `J[B]` is either the prefix `(c_0,...,c_{n-1})` or the suffix `(c_1,...,c_n)`.

In the non-loop OUT-`v` first-positive branch, whenever the literal first-loss switch exists, write the installed pivot edge as `e_r=v->c_j`. Then the deleted edge is the oriented spectator adjacency

    f_r=c_{j-1}->c_j.

If the OUT copy of `c_j` is still on the unflipped augmenter suffix **and `c_j` is nonterminal on the endpoint-truncated `J[B]` rail**, the prefix switch creates the literal next-slot turn

    (v,c_j,c_{j+1}),

so its physicality is governed by exactly the same spoke/forward-spectator comparison variable `{v,c_j}` versus `{c_j,c_{j+1}}` that occurs in the R1033 one-vertex insertion scan. This does not identify `j` with the eventual R1033 certificate index. Terminal pivots are separate endpoint cells and do not carry this next-slot conclusion.

## Proof
R1047 audits the five D17.408 endpoint patterns and the sharpened admissible cuts. Inspecting those same five choices gives more than `E(J[B]) subset E(B)`:

- `(0,1)`: the selected B-only rail is `(c_0,...,c_{n-1})`;
- `(4,0)`: it is `(c_1,...,c_n)`;
- `(2,1)`: cutting the allowed bad-hole chord `RL` leaves `(c_1,...,c_n)`;
- `(3,2)`: cutting `RL` leaves `(c_0,...,c_{n-1})`;
- `(3,4)`: the selected B-only rail is `(c_1,...,c_n)`.

Hence every spectator adjacency is selected except exactly one of `c_0c_1` and `c_{n-1}c_n`, with no nonconsecutive `B-B` edge.

R1048 gives the audited OUT-`v` form of the first-positive literal switch: `e_r=v->c_j`, while `f_r` is a selected `B-B` edge of `J` sharing physical endpoint `c_j`. Since the chosen `J[B]` is an oriented subpath of the displayed spectator order, necessarily `f_r=c_{j-1}->c_j`.

If `c_j,out` remains on the unflipped suffix, its J-successor incidence remains in the J state. **When `c_j` is nonterminal on that truncated rail**, this successor is `c_j->c_{j+1}`. Replacing `f_r` by `e_r` therefore creates the turn `(v,c_j,c_{j+1})`. In R887 comparison notation this is exactly the comparison between the v-spoke `{v,c_j}` and the forward spectator edge `{c_j,c_{j+1}}`, one of the variables scanned in the proof of R1033. If the OUT copy has already passed behind the zipper frontier, this conclusion is not asserted; the prefix state is no longer the unflipped J successor state. If `c_j` is terminal on `J[B]`, no spectator successor exists, so the next-slot turn is likewise absent.

## Audit adjustment
The original workspace wording described the shared variable as “the R1033 first-flip comparison.” The mathematics proves equality of the comparison variable used by the two coordinate systems, but not equality of the canonical zipper pivot index with R1033's eventual certificate index.

A second scope repair is necessary at terminal pivots: being on the unflipped suffix does not create a nonexistent spectator successor. The next-slot statement therefore also requires `c_j` to be nonterminal on the endpoint-truncated `J[B]` rail. This condition was already present in the proof but was missing from the first canonical statement.
