# R167 — Cut-Deficit Splice-or-Full-Breach Principle

## Statement
Let G be a finite Strong Level-(1) boundary tournament, C a retained tight path, Y=G-V(C), and S an exact k-cover of G. For the fixed physical partition {V(C),Y}, t_{C|Y}(S)=1+pc(G[Y])-k+rho_{C|Y}(S). Hence if k<=pc(G[Y]), S has a current C|Y crossing. At every carrier vertex used by such a crossing, either an incident historical carrier state of C is also current and together with the crossing forms a literal current tight splice turn, or no historical carrier state of C incident with that vertex is current. Thus if S has no carrier/exterior splice turn at any current C|Y crossing, every carrier vertex used by a crossing is fully breached in historical carrier incidence. In a smallest counterexample H, every proper retained tight path C has pc(H-V(C))=2, so every hypothetical spanning exact two-cover satisfies this splice-or-full-breach alternative relative to every proper retained tight path.

## Hypotheses
For the general identity: C is a retained tight path in G and S is an exact k-cover of G. For the forced-crossing conclusion assume k<=pc(G[Y]). For the final specialization H is a smallest Strong Level-(1) counterexample and C is proper.

## Scope
General fixed-partition structural theorem plus smallest-counterexample specialization. Longestness is not required. The current splice/breach conclusion concerns one displayed exact cover S.

## Applicability
Use above longest-path specializations whenever a proof has a retained proper path and needs to know that an exact low-component cover must either align a carrier/exterior splice or physically breach every crossing vertex. It combines transition deficit with the local carrier-crossing lemma.

## Persistence
The partition classes and historical carrier identity are graph-intrinsic. Transition selection and splice/full-breach status are current only in S. A fully breached vertex in one representative need not remain breached after recompletion.

## Exclusions / nonclaims
Does not identify a current splice with the exact same-final-candidate coordinate used by static assembly; does not force endpoint exposure; does not assert a global monotone; does not transfer current crossings across representatives.

## Proof
For Pi={V(C),Y}, R7 gives t_{C|Y}(S)=pc(G[C])+pc(G[Y])-k+rho. Since C is tight, pc(G[C])=1, proving t=1+pc(G[Y])-k+rho. If k<=pc(G[Y]), then t>=1, so a selected C|Y crossing exists. Fix such a crossing at v in C. If an historical carrier state incident with v is also selected, it and the crossing are the consecutive selected incidences at v on the current tight path component, hence form a literal current tight splice turn. If no such splice exists, no historical carrier state incident with v can be selected, so the crossing vertex is fully breached relative to C. For a smallest counterexample and proper C, R18 gives an exact two-cover of H-C and therefore pc(H-C)=2. Setting k=2 yields the asserted universal hypothetical-two-cover specialization.
