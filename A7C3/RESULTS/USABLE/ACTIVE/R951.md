# R951 — A minimum counterexample to the existential longest-complement property has a hierarchical three-rail cover

## Statement
Define property E for a finite edge-ordered complete graph G: some globally longest increasing path P has an induced complement G-V(P) with an increasing Hamilton path, allowing the empty complement. Suppose E is false for some graph and choose a counterexample G of minimum order.

Then for EVERY globally longest increasing path P of G, the complement H=G-V(P) is non-Hamiltonian and has increasing path-cover number exactly two. More precisely, because H has smaller order, H satisfies E. Hence H has a globally longest increasing path A such that H-V(A) has an increasing Hamilton path B. Since H is non-Hamiltonian, B is nonempty. Thus
  V(G)=V(P) disjoint-union V(A) disjoint-union V(B)
is a literal partition into three nonempty increasing paths, with P globally longest in G, A globally longest in H, and B Hamilton on H-A. Consequently
  |P| >= |A| >= |B| >= 1.

Therefore the existential longest-complement property reduces, by minimum-counterexample induction, to excluding this hierarchical three-rail configuration for every choice of globally longest P in the minimum counterexample.

## Hypotheses
Pure finite edge-ordered complete-graph setting. Property E is as defined in the statement. G is chosen of minimum order among counterexamples to E.

## Scope
Independent-safe extremal reduction for the proposed existential longest-path-complement theorem. No ordered-1-factorization or boundary-tournament shared strategy is used.

## Applicability
Use as the parent entrance for the existential longest-complement direction. In a hypothetical minimum counterexample, retain an arbitrary globally longest P, then choose A globally longest in its complement with Hamilton complementary rail B. Any exchange theorem need only contradict or improve this hierarchical P|A|B configuration. R947 shows why one must quantify over all globally longest P rather than fix an arbitrary bad support.

## Persistence
Retain the minimum counterexample G, the arbitrary globally longest path P, H=G-P, a globally longest A in H, the Hamilton complement B=H-A, and the inequalities |P|>=|A|>=|B|>=1. Preserve literal edge orders and path orders.

## Exclusions / nonclaims
Does not prove property E or R888. Does not say every longest path in an arbitrary graph has path-cover-two complement. Does not assert A or B is globally longest in G. Does not imply a one-vertex exchange exists.

## Proof
Let G be a minimum-order counterexample to property E, and let P be any globally longest increasing path of G. Put H=G-V(P).

Because G fails E, H cannot have an increasing Hamilton path: if it did, this particular globally longest P would witness E in G. Thus H is non-Hamiltonian.

The graph H has strictly fewer vertices than G because P is nonempty. By minimality of G, H satisfies property E. Therefore there exists a globally longest increasing path A of H such that the induced complement H-V(A) has an increasing Hamilton path; call that path B, with the convention that it could initially be empty.

It cannot be empty. If H-V(A) were empty, then A would be a Hamilton increasing path of H, contradicting that H is non-Hamiltonian. Thus A and B are both nonempty and form an exact two-path cover of H. Since H itself is not Hamiltonian, its increasing path-cover number is exactly two.

Combining with P gives the literal disjoint partition
  V(G)=V(P) union V(A) union V(B)
into three nonempty increasing paths. Since P is globally longest in G and A is itself an increasing path in the induced subgraph H, |P|>=|A|. Since A is globally longest in H and B is an increasing path in H, |A|>=|B|. Therefore |P|>=|A|>=|B|>=1.

The choice of P was arbitrary among globally longest paths of G, so the same conclusion holds for every such P. This proves R951.
