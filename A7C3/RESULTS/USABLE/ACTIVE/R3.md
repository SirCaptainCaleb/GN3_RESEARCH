# R3 — Boundary antisymmetry

**Status:** USABLE / ACTIVE
**Type:** axiom
**Source:** A7C2 active-spine migration S2; controlling compressed sources M1/M6/M10

## Statement

For three distinct vertices, an ordered triple is tight exactly when its complete reversal is bad.

## Scope

Strong Level-(1) boundary tournaments.
