# R3 — Boundary antisymmetry

## Statement
For three distinct vertices, an ordered triple is tight exactly when its complete reversal is bad.

## Proof
R3 is an axiom, so there is no noncircular proof from earlier project results to construct. The correct proof object is therefore a foundational certificate.

Let x,y,z be three distinct vertices. The Strong Level-(1) boundary antisymmetry axiom asserted by this revision is precisely

    (x,y,z) is tight  iff  (z,y,x) is bad.

Thus the conclusion is available directly by the ambient axiom schema, with no hypotheses beyond distinctness of the three vertices. Treating this as a derived lemma would merely restate the axiom under another name and would create a false dependency. Hence R3 is certified as a primitive project axiom, not as a theorem derived from other R-results.
