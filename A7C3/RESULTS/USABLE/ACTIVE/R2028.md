# R2028 — Three-vertex isolated-X normal form

**Status:** PASS
**Source:** Slack workspace R2028

## Statement

In the retained R2024/R2025 source frame, suppose a low-transition exact two-cover `T` has an isolated three-vertex X-rail `P`, and choose a source endpoint `s` of `P`. Then `P` cannot consist of the three source spokes. Hence `P` contains `v` and exactly one further source spoke `t`.

Deleting `s` leaves the oriented two-vertex rail `R=(u_0,u_1)`. If `R=(v,t)`, then `(v,C,s)` is tight. If `R=(t,v)`, then `(s,A,v)` is tight. Thus every surviving isolated three-vertex X-rail is `v`-pinned with a forced anchor cap.

## Proof

Delete the exposed endpoint `s` and apply the audited R2025 lift:

`N=(A,s,C) | (u_0,u_1) | Q`.

Cut the sole edge `u_0->u_1` and add `u_1->A` and `C->u_0`. The non-`Q` path is

`u_1,A,s,C,u_0`.

It is acyclic and has exact two-cover cardinality. Its only new seam trimers are

`L=(s,C,u_0)` and `R_s=(u_1,A,s)`.

If both were tight, this path together with `Q` would be a spanning exact two-cover of `H`, impossible. Therefore at least one of `L,R_s` is bad. By R3, a bad `L` yields `(u_0,C,s)` tight, while a bad `R_s` yields `(s,A,u_1)` tight.

### Excluding the three-source rail

Suppose all three vertices of `P` are source spokes. Then `u_0,u_1` are source spokes.

If `L` is bad, R3 gives `(u_0,C,s)` tight. The path

`(u_1,s,u_0,C,A)`

is tight: `(u_1,s,u_0)` is a cyclic presentation of the original tight trimer `P`, `(s,u_0,C)` is a cyclic presentation of `(u_0,C,s)`, and `(u_0,C,A)` is a cyclic presentation of the retained source trimer `(A,u_0,C)`. Together with `Q` this spans `H` by two tight paths, contradiction.

If `R_s` is bad, R3 gives `(s,A,u_1)` tight. Then

`(C,A,u_1,s,u_0)`

is tight using the source trimer at `u_1`, the cap `(s,A,u_1)`, and the original rail trimer. Again `Q` supplies the complementary path, contradiction.

Thus `P` is not the three-source rail. Since `P` is a three-vertex subset of `X={v,p,q,r}` containing source endpoint `s`, it must contain `v` and exactly one additional source spoke `t`.

### Forcing the v-anchor cap

If `R=(v,t)`, suppose `R_s=(t,A,s)` were bad. R3 gives `(s,A,t)` tight. Then

`(C,A,t,s,v)`

is tight: `(C,A,t)` is the retained source trimer at `t`, `(A,t,s)` is a cyclic presentation of `(s,A,t)`, and `(t,s,v)` is a cyclic presentation of the original tight rail trimer `P`. Together with `Q` this would be a spanning exact two-cover. Therefore `R_s` is tight, so `L` must be bad; R3 gives `(v,C,s)` tight.

If `R=(t,v)`, the symmetric argument applies. If `L=(s,C,t)` were bad, R3 gives `(t,C,s)` tight, and

`(v,s,t,C,A)`

would be a tight five-vertex path complementary to `Q`. Therefore `L` is tight, so `R_s` is bad and R3 gives `(s,A,v)` tight.

This proves the stated normal form.

## Dependencies and scope

Trusted dependencies: `R2025`, R3, the retained source trimers, the original tight three-vertex rail `P`, and the smallest-counterexample assertion that `H` has no spanning exact two-cover.

Provisional dependencies: none.

The proof rederives the needed one-cut/two-join `k=1` surgery directly and does not depend on R2026.
