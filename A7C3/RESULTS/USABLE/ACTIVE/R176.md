# R176 — Spare-Vertex Cross-State Pair Upgrade

## Statement
Let H be a Strong Level-(1) boundary tournament, let W be a proper vertex subset, and let R,T be literal path covers of W. Suppose T selects a state xy whose endpoints lie in two distinct components of R. Then H contains a graph-intrinsic balanced opposite-sign pair.

## Hypotheses
Arbitrary Level-(1); W is a proper subset of V(H), so at least one spare vertex d exists outside W; R and T are literal path covers of W; T contains a selected cross state xy between distinct R-components. The accepted Cross-State Sign-or-Reverse-Trimer theorem is available for xy.

## Scope
Strong-safe generic parent. No smallest-counterexample minimality, endpoint role, component-count drop, deleted marker, extremality, or CW assumption is required. Punctured Component-Drop Pair is the specialization where r<c guarantees such a cross state.

## Applicability
Use whenever two covers of a proper induced subsystem exhibit one current cross-state. It eliminates the bounded reverse-trimer as a sign-free branch by using any spare ambient vertex as an opposite singleton support.

## Persistence
The resulting balanced pair is graph-intrinsic in H. In the good/good seam case retain the original cross-witness provenance. In a bad-seam case retain the explicit reverse-trimer orientation and the chosen spare vertex d; the singleton support uses d and the reverse trimer supplies the opposite nontrivial signed support.

## Exclusions / nonclaims
Without a spare vertex outside W, the reverse-trimer branch does not automatically carry an opposite singleton sign by this proof. The theorem does not preserve current selection of the pair supports in a common cover and does not itself pay the pair or close the conjecture. No endpoint, minimality, or component-drop conclusion is part of the parent statement.

## Proof
Let xy be the selected directed state of T, with x and y in distinct components of R, and choose any spare vertex d in V(H)-W. Let R_x be the R-component containing x. First suppose R_x has at least two vertices. Choose a vertex p adjacent to x along the literal path R_x. Since y lies in a different R-component, p,x,y are distinct. Apply boundary antisymmetry R3 with middle x to the triple {p,x,y}. Exactly one of (y,x,p) and (p,x,y) is tight. If (y,x,p) is tight, then the tested oriented dimer (x,p) is head-signed by witness y. By the standard singleton signed-support convention made explicit in R444, the automatic ordered two-vertex path (d,y) makes singleton (d) tail-signed by the same witness y. The supports {x,p} and {d} are disjoint because {x,p} is contained in W and d is outside W; y lies in a different R-component and is outside both supports. Hence these two supports form a graph-intrinsic balanced opposite-sign pair. If instead (p,x,y) is tight, then oriented dimer (p,x) is tail-signed by witness y. The automatic two-vertex path (y,d) makes singleton (d) head-signed by y, again giving a disjoint balanced opposite-sign pair. Now suppose R_x is the singleton path (x). The selected state xy is itself an ordered two-vertex path and therefore makes singleton (x) tail-signed by witness y. The automatic path (y,d) makes singleton (d) head-signed by the same witness y. Since d lies outside W, the two singleton supports are disjoint, and again we obtain a balanced opposite-sign pair. These cases exhaust the R-component containing x. In every case the pair birth retains the selected cross-state endpoint y as the common witness, the crossed R-component containing x, and, when nontrivial, the exact old R-neighbor p used in the signed dimer. Thus the conclusion and cross-state provenance of R176 follow without the lost historical Cross-State Sign-or-Reverse-Trimer lemma.
