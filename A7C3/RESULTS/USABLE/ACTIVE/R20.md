# R20 — Cover-puncture fragmentation identity

**Status:** USABLE / ACTIVE
**Type:** identity

## Statement

Delete any proper set from a historical spanning cover and split what remains into maximal historical runs. In an exact cover of the deletion, the number of selected states joining different runs equals the number of run-color blocks in the current rails minus the number of current rails. It is at least the number of historical runs minus the number of current rails. Equality means each historical run occurs in one contiguous block.

## Scope

Controls crossing count, not which crossings, orientations, endpoint roles, or ancestry.

## Preferred proof

Color each surviving vertex by its maximal historical run. Along each current rail, selected states joining different runs are exactly color changes, equal to the number of color blocks minus one. Summing gives total run-color blocks minus the number of rails. Every nonempty historical run appears in at least one block, giving the lower bound; equality means exactly one block per historical run.
