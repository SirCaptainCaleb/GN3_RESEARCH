# R1056 — Canonical IN-v closure diagonal is endpoint-anchored in spectator order

## Statement
Assume the sharpened D17.408 canonical forest and a non-loop IN-`v` literal first-loss switch with both adjacent closures defined. Write the displayed spectator path as

    B=(L=c_0,c_1,...,c_n=R).

If

    g_{r-1}=a_{r-1}->b_m

is the same-side closure diagonal at the first-positive pivot, then

    b_m in {L,c_1,R}.

Thus the genuine `B-B` closure diagonal is anchored at a displayed spectator endpoint or at the first spectator vertex after `L`. This does not assert that `g_{r-1}` itself is a consecutive spectator edge.

## Proof
Orient the unique F-heavy alternating component as

    e_1,f_1,e_2,f_2,...,f_{m-1},e_m,

with each `e_i in F\J` and `f_i in J\F`. Its terminal matching copy is `b_m,in`. Because the component begins and ends with F-only edges, this terminal copy is unmatched by `M_J`. Hence the physical vertex `b_m` has no selected J-incoming edge and is the initial vertex of one directed component of the three-forest `J`.

In the IN-`v` first-positive branch, `b_r=v`; because `e_r=a_{r-1}->v` crosses `X|B`, its other endpoint `a_{r-1}` lies in `B`. In the literal first-loss switch, R1036 gives the adjacent same-side closure `g_{r-1}=a_{r-1}->b_m`. In the non-loop case this is a genuine edge. Same-sidedness therefore forces `b_m in B` as well. Thus `b_m` must be a B-vertex that starts one of the canonical D17.408 J-components.

The five D17.408 bad-hole words, with the admissible sharpened cuts audited in R1047, have exactly the following B-starts:

- `(0,1)`: `(L,...,c_{n-1}) | (s) | (R,x,y,z)`, giving B-starts `L,R`;
- `(4,0)`: `(s) | (c_1,...,R) | (x,y,z,L)`, giving B-start `c_1`;
- `(2,1)`: `(x,s) | (c_1,...,R) | (L,y,z)`, giving B-starts `c_1,L`;
- `(3,2)`: `(x,y,R) | (L,...,c_{n-1}) | (s,z)`, giving B-start `L`;
- `(3,4)`: `(x,y,z,L) | (s) | (c_1,...,R)`, giving B-start `c_1`.

Their union is exactly `{L,c_1,R}`, so `b_m` lies in that set.

## Audit adjustment
The original root described this as the non-loop IN-`v` first-loss branch without explicitly inheriting R1036's closure-existence condition. The audited result requires the literal switch to exist, i.e. both adjacent closures are defined. It also states the exact set `{L,c_1,R}` rather than relying on the phrase “first interior spectator vertex,” which can be misleading in very short spectator paths.

## Dependencies and scope
Uses audited R1047 for the five admissible canonical D17.408 forests and audited R1036 for the literal first-loss closure scope. The fact that `b_m,in` is J-unmatched is reconstructed directly from the endpoint of the F-heavy alternating path, so no separate unaudited D17.410/D17.415 dependency is needed. R24/R5 are unused. This is a coordinate localization only, not a spectator-adjacency theorem, cover, or descent.
