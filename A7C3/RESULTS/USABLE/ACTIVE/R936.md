# R936 — Threshold matching duality and exact one-sided rotations for increasing path covers

## Statement
Let G=K_V be a complete graph with a strict total edge order represented by distinct real labels lambda(uv), and let n=|V|. For any real threshold vector tau=(tau_v), form a balanced bipartite graph B_tau with copies V_out,V_in and edge u_out v_in exactly when tau_u<lambda(uv)<tau_v. Then
  pc_inc(G)=n-max_tau nu(B_tau)
           =min_tau max_{X subseteq V} (|X|-|N_{B_tau}(X)|).

Moreover fix any spanning increasing k-path cover F and orient its components increasingly. Let L(v) be the label of the incoming F-edge, with L(v)=-infinity at a source, and U(v) the outgoing label, with U(v)=+infinity at a terminal. Define
  u_out v_in in B^- iff L(u)<lambda(uv)<=L(v),
  u_out v_in in B^+ iff U(u)<=lambda(uv)<U(v).
Then the F-edges form a matching of size n-k in both graphs. Every size-(n-k) matching in B^- compiles to a spanning increasing k-path cover with exactly the same source set as F; every size-(n-k) matching in B^+ compiles to one with exactly the same terminal set. Thus B^- and B^+ are exact collision-free one-sided rotation systems.

ORDERED-1-FACTORIZATION BRIDGE. Suppose in addition that the edge order is by perfect-matching rounds M_1<...<M_{n-1}; write c(uv)=t for uv in M_t, and use the discrete conventions L(source)=0, U(terminal)=n. Call an oriented round-t edge u->v interval-compatible when L(u)<t<U(v). Every interval-compatible oriented edge lies in exactly one of the following PRIORITY classes:
(LOWER) t<=L(v), so u_out v_in belongs to B^-;
(UPPER) t>L(v) and U(u)<=t, so u_out v_in belongs to B^+;
(ACTIVE-ACTIVE) L(v)<t<U(u), so both u and v are active at round t, meaning L(w)<t<U(w), and they lie on distinct current path components.
Thus the wider interval-compatible edge reservoir decomposes into two safe one-sided rotation classes plus a genuinely two-sided cross-component remainder. Combined with any round-abundance count, this classification is only a localization of where the compulsory compatible edges live; it is not itself an augmentation theorem.

## Hypotheses
General threshold statements: finite complete graph with distinct edge labels and a spanning increasing k-path cover F where used. Ordered-factorization bridge: n even, edges partitioned into perfect matching rounds with all M_i before M_j for i<j; L,U are round indices with source/terminal conventions 0,n.

## Scope
Pure edge-ordered graph parent combining movable-threshold Hall duality, exact one-sided rotations, and the Independent-safe lower/upper/active-active classification for ordered 1-factorizations.

## Applicability
Use the threshold identity for R888/Hall reformulations. Use B^- or B^+ for legitimate one-sided rotations. In ordered 1-factorizations, classify every interval-compatible round edge by the priority split before combining compatible-edge abundance with rotation arguments: only LOWER/UPPER are automatically safe matching moves; ACTIVE-ACTIVE is the genuinely two-sided cross-component residue.

## Persistence
Retain the threshold vector and matched arcs. For rotations retain F, source/terminal sets, L,U, and which one-sided graph is used. For the ordered-factorization bridge retain round t, orientation u->v, its priority class, and if active-active the two distinct current components containing u,v.

## Exclusions / nonclaims
Does not prove deficiency <=2, R888, or the ordered-1-factorization two-cover theorem. Does not say all interval-compatible edges lie in one safe matching graph. ACTIVE-ACTIVE edges are not automatically legal simultaneous rotations. Does not preserve both source and terminal sets or all endpoint labels simultaneously.

## Proof
The general threshold-matching identity and the exact B^-/B^+ source-/terminal-preserving rotation conclusions are precisely the accepted theorem R932. It remains only to prove the ordered-1-factorization bridge.

Assume E(K_n)=M_1 disjoint-union ... disjoint-union M_{n-1}, ordered by rounds, and let F be a spanning increasing path cover. Write c(uv)=t when uv lies in M_t. Use L(source)=0 and U(terminal)=n. Let u->v be interval-compatible at round t, so
  L(u)<t<U(v).                                      (1)

Apply the following priority rule.

If t<=L(v), then together with (1) we have
  L(u)<t<=L(v),
which is exactly the discrete lower-cut condition for u_out v_in to belong to B^-.

Otherwise t>L(v). If U(u)<=t, then together with (1) we have
  U(u)<=t<U(v),
which is exactly the upper-cut condition for u_out v_in to belong to B^+.

Finally suppose neither of the preceding cases holds. Then t>L(v) and t<U(u). Combining these inequalities with (1) gives
  L(u)<t<U(u),
  L(v)<t<U(v).
Thus both u and v are active at round t.

It remains to show that active u and v cannot lie on the same current path component. Along any oriented increasing path of F, the selected edge colors strictly increase. Relative to a fixed round t, there is at most one vertex w whose incoming selected color is below t and whose outgoing selected color is above t: it is the unique vertex lying between the last selected edge color below t and the first selected edge color above t, with the source/terminal conventions covering the ends. If the component itself uses an edge of color t, then no vertex of that component is active because the tail has U=t and the head has L=t. Therefore every current component contains at most one active vertex at round t. Since u and v are distinct endpoints of an ordinary edge, if both are active they lie on distinct components.

The three priority classes are exhaustive and disjoint by construction: LOWER is tested first; among the remaining edges UPPER is tested second; if both tests fail the displayed active-active inequalities hold. LOWER and UPPER inherit the safe one-sided matching interpretation from R932. The ACTIVE-ACTIVE class is only a cross-component location statement; no simultaneous splice legality follows. This proves the strengthening R936.
