# R2033 — Three-cap six-vertex completion

**Status:** PASS PENDING (audit complete; chronological frontier only)
**Source:** Slack workspace R2033

## Statement

Let `A,C,s,t,r,v` be distinct vertices with source turns

`(A,s,C)`, `(A,t,C)`, `(A,r,C)`

tight, and additionally

`(s,A,v)`, `(v,C,s)`, `(t,A,r)`

tight. Then the induced six-set has a tight Hamilton `P6`.

## Proof

We use four successive R3 tests.

If `(r,t,v)` is tight, then

`(s,C,A,r,t,v)`

is tight: `(s,C,A)` and `(C,A,r)` are cyclic source turns, `(A,r,t)` is cyclic from `(t,A,r)`, and the last trimer is `(r,t,v)`.

Otherwise R3 gives the reverse class, represented by `(v,t,r)` tight. Test `(r,C,s)`. If it is tight, then

`(t,A,r,C,s,v)`

is tight, using `(t,A,r)`, the source turn `(A,r,C)`, `(r,C,s)`, and `(C,s,v)`, the cyclic form of `(v,C,s)`.

Otherwise R3 gives the reverse class, cyclically `(r,s,C)` tight. Test `(A,t,v)`. If it is tight, then

`(r,s,C,A,t,v)`

is tight, using `(r,s,C)`, the cyclic source turns `(s,C,A)` and `(C,A,t)`, and `(A,t,v)`.

Otherwise R3 gives the reverse class, cyclically `(t,A,v)` tight. Test `(C,r,t)`. If it is tight, then

`(C,r,t,A,v,s)`

is tight: `(r,t,A)` is cyclic from `(t,A,r)`, `(t,A,v)` is the current branch, and `(A,v,s)` is cyclic from `(s,A,v)`.

Finally, if `(C,r,t)` is bad, R3 gives `(t,r,C)` tight. Together with the already retained `(v,t,r)`, the order

`(v,t,r,C,A,s)`

is tight, with final turns `(r,C,A)` and `(C,A,s)` supplied cyclically by the source turns at `r` and `s`.

Thus every orientation branch yields a tight Hamilton path on the six vertices.

Trusted dependencies: R3 and the six displayed tight trimers.
