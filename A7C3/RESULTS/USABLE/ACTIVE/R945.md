# R945 — Role-correct endpoint-return Hall cycles reduce to R435 geometry or a directed triangle

## Statement
Let Omega be a finite boundary tournament with |Omega|>=4 such that Omega is non-Hamiltonian but every one-vertex deletion Omega-y is Hamiltonian. Build the complete endpoint-core incidence graph with left vertices y in Omega and right vertices Omega-{y,r}; join y to Omega-{y,r} when some actual Hamilton path on Omega-y has r as a physical endpoint.

(1) This bipartite graph satisfies Hall, so there exists a matching saturating all left labels. Writing the matched right core as Omega-{y,f(y)} gives a functional digraph y->f(y). Matched 2-cycles are impossible, so every directed cycle has length at least three.

(2) Choose, among all left-saturating endpoint-core matchings, one whose shortest directed cycle has minimum possible length, and choose one such shortest cycle C=(y_0,...,y_{t-1}). For each matched edge choose an ACTUAL Hamilton path P_i on Omega-y_i realizing endpoint y_{i+1}=f(y_i), and retain whether that endpoint is the HEAD or TAIL of the certified path. Compare each consecutive pair P_i,P_{i+1} by accepted R435.

Then either some adjacent comparison yields an explicit R435 reversal, reverse-trimer, or proper tight cycle, OR t=3. In particular, outside explicit R435 geometry an extremal endpoint-return matching has a directed triangle as its shortest cycle.

More precisely, for t>=4 and R435-quiet adjacent comparisons, any change of endpoint role HEAD<->TAIL would make P_i have endpoints {y_{i+1},y_{i+2}}, yielding an unused skip-one endpoint core Omega-{y_i,y_{i+2}} and a rematching that shortens C. Hence all matched roles around C are equal. In the all-HEAD case P_i begins y_{i+1},y_{i+2},y_{i+3}; non-Hamiltonicity says (y_{i+1},y_{i+2},y_{i+3}) is bad, contradiction. The all-TAIL case is the exact certified-direction dual. No reversal of a tight path is used.

## Hypotheses
Finite Strong Level-(1) boundary tournament Omega, |Omega|>=4, Omega non-Hamiltonian, and Omega-y Hamiltonian for every y. R435 is used only in its contact-monotonicity alternative after retaining explicit path orientations.

## Scope
Role-correct repair of the endpoint-return matching argument in D17/DR17.42. Pure hypohamiltonian-block theorem; no smallest-counterexample or source-recurrence hypotheses are needed.

## Applicability
Use inside a saturated deletion-Hamiltonian block. First choose an extremal left-saturating endpoint-core matching and preserve actual HEAD/TAIL roles of matched endpoints. Then either retain explicit R435 geometry or a shortest directed triangle. Do not orient an arbitrary puncture path from a matched endpoint and do not infer that every cycle of an arbitrary matching is triangular.

## Persistence
Retain the matched right cores, functional map f, shortest cycle, actual Hamilton puncture paths P_i, each matched endpoint role HEAD/TAIL, and any rematched skip-one core used in the shortening argument. Triangle output is unoriented beyond the actual recorded roles unless further certified.

## Exclusions / nonclaims
Does not say every endpoint-return cycle is a triangle. Does not say a matched endpoint can be chosen as a path head. Does not make the three forward cyclic turns uniformly bad in a triangle with mixed roles. Does not consume R435 output or the triangle into a spanning two-cover.

## Proof
Build the endpoint-core incidence graph B. For each y in Omega, any Hamilton path on Omega-y has two distinct physical endpoints r,s, so y has at least two distinct right neighbors Omega-{y,r} and Omega-{y,s}. A right core R=Omega-{a,b} can be adjacent only to left labels a or b, because an incidence y-R means R=Omega-{y,r} for some endpoint r. Hence every right vertex has degree at most two. For every left subset S,
  2|S| <= e(S,N(S)) <= 2|N(S)|,
so Hall holds and a matching saturating all left labels exists.

Write the matched core of y as Omega-{y,f(y)}. Then f(y)!=y. If y->r and r->y were both matched, both left labels would be matched to the same right core Omega-{y,r}, impossible. Thus the functional digraph f has no directed 2-cycle; every directed cycle has length at least three.

Among all left-saturating matchings choose one for which the length of a shortest directed cycle is minimum. Let
  C: y_0 -> y_1 -> ... -> y_{t-1} -> y_0
be such a shortest cycle. For each i choose an actual Hamilton path P_i on Omega-y_i which exposes the matched endpoint y_{i+1}. Record epsilon_i=H if y_{i+1} is the first vertex of P_i and epsilon_i=T if it is the last vertex. No path is reversed.

Compare P_i with P_{i+1}. Their common vertex set is Omega-{y_i,y_{i+1}}. If R435 produces a reversal, reverse trimer, or proper tight cycle, retain that output and the theorem is proved. Hence assume every adjacent comparison is R435-quiet, so the common vertices occur in increasing P_i-order along P_{i+1}.

We first determine the position of y_{i+2} in P_i. It is a common vertex. If epsilon_{i+1}=H, then y_{i+2} is the first vertex of P_{i+1}, hence the first common contact along P_{i+1}; monotonicity makes it the first common vertex of P_i. If epsilon_i=H, the only initial noncommon vertex of P_i is its head y_{i+1}, so P_i begins (y_{i+1},y_{i+2},...). If epsilon_i=T, its terminal noncommon vertex is y_{i+1}, so the first common vertex is the actual head and P_i begins (y_{i+2},...). Dually, if epsilon_{i+1}=T, then y_{i+2} is the last common contact along P_{i+1}; monotonicity makes it the last common vertex of P_i. Thus if epsilon_i=H, P_i ends (...,y_{i+2}), while if epsilon_i=T, P_i ends (...,y_{i+2},y_{i+1}).

Consequently, whenever epsilon_i != epsilon_{i+1}, the actual path P_i has endpoint set exactly {y_{i+1},y_{i+2}}. Therefore y_i is incident to the additional endpoint core
  R'=Omega-{y_i,y_{i+2}}.
Assume t>=4. The right core R' is unused by the chosen matching. Indeed only left labels y_i and y_{i+2} can be adjacent to R'. The first is currently matched to Omega-{y_i,y_{i+1}}. The second is currently matched to Omega-{y_{i+2},y_{i+3}}, which is different because t>=4 gives y_{i+3}!=y_i. No other left label can use R'. Rematch y_i from its old core to R'. All other matched cores stay unchanged, so this is again a left-saturating matching. Its functional digraph has the directed cycle
  y_i -> y_{i+2} -> y_{i+3} -> ... -> y_{i-1} -> y_i,
of length t-1. This contradicts the extremal choice of the original matching. Hence for t>=4 all epsilon_i are equal around C.

Suppose first every epsilon_i=H. From the positional argument above, P_i begins y_{i+1},y_{i+2}. Since P_i spans Omega-y_i and Omega is non-Hamiltonian, prepending the omitted y_i cannot be tight. Therefore
  (y_i,y_{i+1},y_{i+2})
is bad, and R3 gives its complete reversal tight.

Now t>=4 implies y_{i+3} is distinct from y_i,y_{i+1}. The next path P_{i+1} begins y_{i+2},y_{i+3}. These are consecutive common contacts with P_i. R435-quiet monotonicity therefore makes them consecutive in P_i as well: after the initial noncommon head y_{i+1}, every remaining P_i vertex is common with P_{i+1}, so no third common vertex can lie between y_{i+2} and y_{i+3} in P_i without also occurring between those consecutive contacts in P_{i+1}. Hence P_i begins
  y_{i+1},y_{i+2},y_{i+3},
so (y_{i+1},y_{i+2},y_{i+3}) is tight. But applying the preceding non-Hamiltonicity statement with index i+1 says the same turn is bad. Contradiction.

The all-TAIL case is symmetric without reversing any path. The positional argument gives
  P_i=(...,y_{i+2},y_{i+1}).
Appending omitted y_i would Hamiltonize Omega, so (y_{i+2},y_{i+1},y_i) is bad. Since P_{i+1} ends (...,y_{i+3},y_{i+2}), the last two common contacts y_{i+3},y_{i+2} are consecutive; monotonicity forces P_i to end
  (...,y_{i+3},y_{i+2},y_{i+1}).
Thus (y_{i+3},y_{i+2},y_{i+1}) is tight, while the same turn is bad by the append obstruction for P_{i+1}. Contradiction.

Therefore an R435-quiet extremal shortest cycle cannot have t>=4. Since matched 2-cycles are impossible, t=3. This proves the role-correct theorem. Note that a triangle may have mixed HEAD/TAIL roles, so no uniform cyclic bad/tight orientation class is asserted.
