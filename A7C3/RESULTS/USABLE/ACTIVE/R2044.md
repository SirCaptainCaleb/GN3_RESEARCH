## Statement

The repaired `E_X` packet does not force the R2034 residual recompletion even with the retained static source frame. There is a globally edge-ordered order-11 Strong Level-(1) realization with:

- tight spectator `B`;
- a tight old source two-cover `F` with `tau(F)=3` and all three sources internal;
- nonHamiltonian `X`;
- a literal `tau=2` `E_X` two-cover;
- the repaired R2032 four-set obstruction;
- all four R2042 endpoint caps;

Thus closing `E_X` requires information absent from this full static packet, such as genuine smallest-counterexample consequences or dynamic ancestry.

`{A,C,v,s,t,r,b1,b2,b3,l,y}`,

with `X={v,s,t,r}` and displayed spectator order `B=(b1,b2,b3,l,y)`.

`rs < Cl < b2r < Ay < Cv < b2v < ls < b2y < tv < lv < b1b3 < b3y < b1r < b2l < Cb2 < b1y < lt < b1t < b1l < Al < ry < Ab1 < rv < lr < Ab2 < vy < b2s < ty < b3t < b3v < As < b3s < Ar < sy < Cs < b1b2 < b1v < Ab3 < b1s < b2b3 < Cy < st < Av < Cb3 < Cr < At < Ct < Cb1 < AC < sv < b2t < rt < b3r < b3l < ly`.

Edge names are unordered, and `(x,m,z)` is tight exactly when `xm<mz`.

The retained source turns are `As<Cs`, `At<Ct`, `Ar<Cr`.

The old source cover

`F=(b1,s,t,b2) | (v,r,b3,l,y)`

is tight because `b1s<st<b2t` and `rv<b3r<b3l<ly`. Its block words are `B-X-X-B` and `X-X-B-B-B`, so `tau(F)=3`; `s,t,r` are internal. The spectator path `B=(b1,b2,b3,l,y)` is tight because `b1b2<b2b3<b3l<ly`. Direct enumeration gives no Hamilton `P4` on `X`.

Take the literal top-fiber cover

`T=(s,v) | (b1,b2,t,r,b3,l,y)`.

Its long rail is tight because

`b1b2 < b2t < rt < b3r < b3l < ly`,

and its block word is `B-X-X-B`; together with the isolated X rail `{s,v}`, this is exactly `E_X` with `tau(T)=2`.

The repaired short-rail four-set `{A,C,s,v}` is P4-free. Its repaired R2032 turns `(s,A,v)`, `(v,C,s)`, `(C,v,A)` are tight from `As<Av`, `Cv<Cs`, `Cv<Av`.

`(s,A,v)`, `(v,C,s)`, `(b2,b1,v)`, `(v,y,l)`

`(s,v) | (b1,b2) | (b3,l,y)`.

Exhaustive check of all `7!=5040` vertex orders on
