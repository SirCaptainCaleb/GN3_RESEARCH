# R425 — Signed-Interval Rebirth and Tight-Path Cut Memory

## Statement
Let P=(v_0,...,v_k) be a graph-intrinsic tight path. Head form: if P is head-signed by w, meaning (w,v_0,...,v_k) is tight, and S is any vertex set with P-S nonempty, then the first surviving interval I=(v_i,...,v_j) of P-S in the old path order is head-signed. If i=0 the witness remains w; if i>0 then v_{i-1} is deleted and (v_{i-1},I) is tight, so v_{i-1} is a new witness. Tail form is dual: if (v_0,...,v_k,z) is tight, the last surviving interval J=(v_i,...,v_j) after deleting S is tail-signed by z when j=k and otherwise by the immediately following deleted vertex v_{j+1}. More generally every surviving interval remembers both cut neighbors: when i>0, (v_{i-1},I) is tight, and when j<k, (I,v_{j+1}) is tight.

## Hypotheses
P is a tight path; the relevant historical head/tail sign is graph-intrinsic when using the signed forms; S is any vertex set; at least one vertex of P survives.

## Scope
Strong-safe and in fact purely path-order theoretic. No smallest-counterexample, cover, CW, exchange, or bounded-marker hypothesis is required.

## Applicability
Use whenever a physical marker/delete-set meets a historical signed support but does not swallow it. It gives a nested signed descendant and exact cut-side witness information without requiring any later cover to select the descendant states.

## Persistence
The surviving interval is a literal ordered subpath of the old support. The sign is graph-intrinsic. The witness may migrate to the immediately deleted old-path neighbor. Repeated contacts yield a nested support ancestry chain with explicit cut witnesses.

## Exclusions / nonclaims
Does not preserve the original signed endpoint anchor when that endpoint is deleted; does not assert selected-state persistence in later covers; does not make deleted marker vertices current; does not by itself imply a cover or component-count improvement.

## Proof
Write P=(v_0,...,v_k). For a head sign (w;P), let I=(v_i,...,v_j) be the first surviving interval after deleting S. If i=0, (w,I) is a prefix of the certified tight path (w,P). If i>0, first-survival implies v_{i-1} in S, and (v_{i-1},v_i,...,v_j) is a contiguous subpath of P, hence tight. Therefore I is head-signed by v_{i-1}. For a tail sign, take the last surviving interval J=(v_i,...,v_j). If j=k retain z; if j<k, then v_{j+1} is deleted and (v_i,...,v_j,v_{j+1}) is a contiguous subpath of P. The same observations on both ends of an arbitrary surviving interval give Tight-Path Cut Memory. This is the exact historical R11 proof. R12 subsequently audited the head form, tail form, cut memory, and marker-contact descent positively.
