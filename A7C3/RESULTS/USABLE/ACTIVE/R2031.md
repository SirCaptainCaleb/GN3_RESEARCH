# R2031 — Two-seam six-vertex completion

**Status:** PASS
**Source:** Slack workspace R2031

## Statement

Let `A,C,s,r,t,v` be distinct vertices with

`(A,s,C)`, `(A,r,C)`, `(s,C,t)`, and `(r,A,s)`

tight. Then the induced six-set has a tight Hamilton `P6`.

More explicitly:

- if `(A,r,v)` is tight, use `(t,s,C,A,r,v)`;
- if `(A,r,v)` is bad, R3 gives `(v,r,A)` tight, and use `(v,r,A,s,C,t)`.

## Proof

If `(A,r,v)` is tight, the consecutive trimers of

`(t,s,C,A,r,v)`

are:

- `(t,s,C)`, the cyclic presentation of `(s,C,t)`;
- `(s,C,A)`, the cyclic presentation of `(A,s,C)`;
- `(C,A,r)`, the cyclic presentation of `(A,r,C)`;
- `(A,r,v)`, tight by assumption.

Hence this order is a tight Hamilton path on the six vertices.

If `(A,r,v)` is bad, boundary antisymmetry R3 gives its complete reverse orientation tight, with cyclic presentation `(v,r,A)`. The consecutive trimers of

`(v,r,A,s,C,t)`

are then

`(v,r,A)`, `(r,A,s)`, `(A,s,C)`, `(s,C,t)`,

all tight by the hypotheses and R3. This is again a tight Hamilton path on the six-set.

## Dependencies and scope

Trusted dependencies: R3 and the four displayed tight trimers.

Provisional dependencies: none.

The result is a reusable local absorber. In particular, any live configuration supplying the four displayed turns may replace that six-vertex support by one Hamilton rail.
