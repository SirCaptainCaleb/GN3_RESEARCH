# R19 — Universal internal-vertex graft

**Status:** USABLE / ACTIVE
**Type:** theorem

## Statement

If a retained tight path contains a vertex internally and a current cover contains that vertex while covering everything outside the rest of the path, insert the two missing path states at the vertex. The complete blocker set is exactly the currently selected states incident with the vertex. If its selected incidence degree is zero, one, or two, the gain is respectively two, one, or zero, with no cycle debt. The resulting representative contains the whole retained path and every component of the old cover after removing that vertex.

## Scope

Parent of older fixed-vertex graft and local four-vertex surgery theorems; specializations matter only when they retain boundary role, side, or ancestry absent here.

## Preferred proof

Let x be the internal retained-path vertex. The two inserted retained-path states are its predecessor and successor adjacencies. Since every other retained-path vertex is absent from the current cover, the only selected states that conflict are the d currently selected states incident with x. Remove those d states, delete x from its old component, and insert the whole retained path. The old cover minus x and the retained path are vertex-disjoint, so no cycle is created. Raw gain and actual gain are 2-d by R17.
