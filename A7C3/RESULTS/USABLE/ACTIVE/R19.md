# R19 — Universal internal-vertex graft

## Statement

If a retained tight path contains a vertex internally and a current cover contains that vertex while covering everything outside the rest of the path, insert the two missing path states at the vertex. The complete blocker set is exactly the currently selected states incident with the vertex. If its selected incidence degree is zero, one, or two, the gain is respectively two, one, or zero, with no cycle debt. The resulting representative contains the whole retained path and every component of the old cover after removing that vertex.

## Proof
Let K=(...,a,x,b,...) be the retained tight path, with x internal, and let T be the current path cover in the R19 setup: T contains x and covers every vertex outside V(K)\\{x}, while the other vertices of K are not present in T. The graft inserts the two retained-path selected states ax and xb through x and restores all of K as one tight path component. Because every vertex of K\\{x} is absent from T, neither inserted state can conflict with any old selected state away from x. The only possible blockers are therefore exactly the old selected states of T incident with x. Since T is a path cover, the selected incidence degree d_T(x) is 0,1,or 2. Remove precisely these d_T(x) blocker states and remove x from its old T-component; keep every resulting component of T-x unchanged. Then add the entire retained path K. The resulting selected-state system is the disjoint union of K with the components of T-x, because those old components use only vertices outside K. Hence it is already a path cover and creates no physical tight-cycle component: cycle debt is zero. The exchange inserts two selected states and removes d_T(x) blockers, so its raw gain is 2-d_T(x). By reconstructed gain-minus-cycle-debt identity R17, the actual path-cover improvement is also 2-d_T(x). Therefore incidence degree zero gives gain two, incidence degree one gives gain one, and incidence degree two gives gain zero. The final representative contains all of K and every component of the old cover after deleting x, exactly as stated. No other blocker or cycle correction exists because the vertex sets are disjoint after x is removed.
