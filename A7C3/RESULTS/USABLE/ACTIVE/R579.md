# R579 — Wrap tetrachotomy for a Hamiltonian path of order at least three

## Statement
Let H be a Strong Level-(1) boundary tournament and let Q=(q_0,q_1,...,q_r) be a vertex-simple tight path with r>=2. Write alpha=(q_r,q_0,q_1) and beta=(q_{r-1},q_r,q_0) for the two wrap-seam turns, rot1=(q_r,q_0,q_1,...,q_{r-1}) and rot2=(q_1,...,q_r,q_0) for the two cyclic rotations, and w=(q_r,q_0) for the wrap state. Then exactly one of the following four exclusive branches holds.

(DW) Double wrap: alpha and beta are both tight. Equivalently both rotations are tight paths, equivalently (q_0,q_1,...,q_r,q_0) is a vertex-simple tight Hamilton cycle on V(Q).

(SW1) Single wrap, rot1: alpha is tight and beta is bad. Then rot1 is a tight Hamilton path of V(Q) starting at q_r and ending at q_{r-1}, while rot2 is not tight, and R3 supplies the reversed seam (q_0,q_r,q_{r-1}).

(SW2) Single wrap, rot2: beta is tight and alpha is bad. Then rot2 is a tight Hamilton path of V(Q) starting at q_1 and ending at q_0, while rot1 is not tight, and R3 supplies the reversed seam (q_1,q_0,q_r).

(DF) Double fail: alpha and beta are both bad. Then neither rotation is a tight path, R3 supplies both reversed seams (q_1,q_0,q_r) and (q_0,q_r,q_{r-1}), and if r>=3 those opposite-polarity certificates on the tested dimer (q_0,q_r) concatenate by R523 to the tight reverse P4 (q_1,q_0,q_r,q_{r-1}).

A single successful rotation is therefore a cyclically shifted Hamilton path, not by itself a Hamilton cycle. A Hamilton cycle on V(Q) occurs if and only if the double-wrap branch holds.

## Hypotheses
Strong Level-(1) boundary antisymmetry R3. Q is a vertex-simple tight path of order at least three. No smallest-counterexample, deletion, cover, or transition hypothesis.

## Scope
Order-free refinement of R548. Applies to any tight path component of order at least three in a Strong Level-(1) boundary tournament, whether or not it is an absorber in a deletion frame.

## Applicability
Use whenever a named Hamilton path must be classified before converting wrap data into a cycle, a second Hamilton order, an R561 reversed dimer, or an R566 boundary fan. Downstream arguments that need a Hamilton cycle on the support must invoke the double-wrap branch, not mere wrap success.

## Persistence
The four-way branch, the listed tight or bad seams, the successful rotation if any, the Hamilton cycle in DW, and the reverse P4 in DF with r>=3 are graph-intrinsic. Selected-state language is used only when Q is viewed as a cover component.

## Exclusions / nonclaims
Does not assert that any branch is contradictory. Does not assert that a single successful rotation makes every vertex of V(Q) Hamilton-accessible as an endpoint. Does not produce an R561 reversed Hamilton dimer from DF or SW alone. Does not itself close a tau=1 cell.

## Proof
Let Q=(q_0,...,q_r) with r>=2 be a vertex-simple tight path in a Strong Level-(1) boundary tournament. The internal turns of Q are tight by hypothesis. The two cyclic rotations differ from Q only at a wrap seam: rot1 is tight if and only if alpha=(q_r,q_0,q_1) is tight, and rot2 is tight if and only if beta=(q_{r-1},q_r,q_0) is tight.

R548 applied to Q says that either at least one cyclic rotation is a tight path, or both wrap-seam turns alpha and beta are bad. Because each rotation is tight if and only if its seam is tight, the four truth-combinations of (alpha,beta) are exclusive and exhaustive and match the four displayed branches.

If both seams are tight, then every consecutive triple of the closed walk (q_0,q_1,...,q_r,q_0) is tight: the internal triples are those of Q and the two wrap triples are alpha and beta. The walk is vertex-simple because Q is. This is a tight Hamilton cycle on V(Q), which is (DW). Conversely, any tight Hamilton cycle through the ordered support of Q uses both wrap seams, so both rotations are tight.

If alpha is tight and beta is bad, rot1 is a tight Hamilton path and rot2 is not. R3 converts the bad seam beta into the tight reverse (q_0,q_r,q_{r-1}). This is (SW1). The symmetric argument gives (SW2).

If both seams are bad, neither rotation is tight and R3 supplies both reversed seams (q_1,q_0,q_r) and (q_0,q_r,q_{r-1}). The first is a head certificate on the tested dimer (q_0,q_r) with witness q_1; the second is a tail certificate on the same tested dimer with witness q_{r-1}. For r>=3 the four vertices q_1,q_0,q_r,q_{r-1} are distinct, so R523 opposite-polarity interaction yields the tight P4 (q_1,q_0,q_r,q_{r-1}), which is the reverse P4 already recorded by R548. This is (DF).

In particular the success language of R548 splits into (DW), (SW1), and (SW2). Only (DW) produces a Hamilton cycle. A single successful rotation changes the endpoints of Q but does not cut a cycle and does not by itself furnish two Hamilton paths with a common endpoint.
