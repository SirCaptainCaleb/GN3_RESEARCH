# R2020 — Same-rail source-closure cycles are X-only

**Status:** PASS
**Source:** workspace root `1789415193.316479`

## Statement

In any physical pre-first-positive prefix covered by R2018/R2019, a nonloop canonical source closure `g_q=a_q->s` can close a same-rail directed cycle only when the base prefix has `tau=1` and `g_q` is same-side. In that case the entire rail from source `s` to terminal `a_q` is transition-free and lies inside `X={v,p,q,r}`.

If the base prefix has `tau=0`, then `g_q` is cross-side and the endpoints must lie on different rails, so the same-rail cycle obstruction is impossible.

## Proof

Let `N` be a physical three-forest at some `q<r`, either a balanced terminal state from R2015/R2018 or an ordinary physical prefix from R2019, and suppose `g_q=a_q->s` is nonloop.

In either setting the neutral contribution has total transition weight zero. The R2018 parity calculation therefore applies: `tau(N)∈{0,1}` and `tau(N+g_q)=1`. Hence

`chi(g_q)=1-tau(N)`.

Thus the closure is cross-side exactly when `tau(N)=0`, and same-side exactly when `tau(N)=1`.

Assume first `tau(N)=0`. Every selected edge of every rail of `N` is then same-side. Since the fixed free IN endpoint `s` is a source spoke in `X`, every vertex on the rail beginning at `s` lies in `X`. If the free OUT endpoint `a_q` lay on that same rail, then `a_q∈X`, so `g_q=a_q->s` would be same-side. This contradicts `chi(g_q)=1`. Hence `a_q` and `s` lie on distinct rails, and adding `g_q` cannot create a directed cycle.

Now suppose a same-rail cycle occurs. The preceding paragraph forces `tau(N)=1`; parity then gives `chi(g_q)=0`, so `a_q` and `s` lie on the same side. Since `s∈X`, also `a_q∈X`. Along their common rail the parity of the number of X|B transitions equals the endpoint-side change, hence is even. But the entire forest `N` contains only one transition edge. Therefore the common rail contains zero transitions. Starting at `s∈X`, every vertex of the rail lies in X.

Since the retained source block is `X={v,p,q,r}`, the entire same-rail cycle support is contained in those four vertices.
