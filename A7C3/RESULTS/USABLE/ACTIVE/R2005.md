# R2005 — First-open local failure is exactly an occupied replacement successor

**Status:** PASS
**Source:** workspace root `1789411321.831759`

## Statement

Let `c=b_{t+1}` be the first R1033-open spectator in a later non-loop OUT-`v` cell, and let `M=hat M_{r-1}` be a literal tight normalized pre-loss three-path forest.

Local interception at c can fail only if c has an occupied selected successor

`c->z`

with

`z!=b_{t+2}`,

and in that case R3 forces the reverse tight trimer

`(z,c,v)`.

Thus every genuine first-open local availability blocker is an occupied replacement successor. If no such bad successor turn occurs, adding or exchanging in `v->c` is physically tight at c; in the occupied-predecessor case this merely transports the free OUT defect to the actual predecessor.

## Proof

By R1060, v is an isolated singleton component of M. Let `c->z` denote the actual selected successor of c when one exists.

If `c,in` is free, add `v->c`. This joins the isolated singleton v to the c-starting component, raises matching cardinality by one, and cannot create a directed cycle. There is no turn at v. If `c,out` is also free, there is no new turn at c. Otherwise the only new turn is `(v,c,z)`.

If `c,in` is occupied by a selected predecessor `y->c`, delete that edge and add `v->c`. Deleting the predecessor cuts one path into a prefix ending at y and a suffix beginning at c; adding `v->c` joins the singleton v to that suffix. The result is again an acyclic three-path forest. There is no new turn at v, and the only possible new turn is again `(v,c,z)`. If that turn is tight, the exchange is physically tight and the free OUT defect has moved from v to y.

Therefore local physical failure at c is possible only when c has a selected successor and `(v,c,z)` is bad. The selected vertices v,c,z are distinct: v is isolated before the exchange, c is a spectator vertex, and a selected successor is not c. R3 then gives the reverse tight trimer `(z,c,v)`.

Finally, if the selected successor is the canonical spectator edge `c->b_{t+2}`, the defining R1033 first-open comparison makes `(v,c,b_{t+2})` tight. Hence a bad successor must satisfy `z!=b_{t+2}`. It is therefore a genuine occupied replacement successor.
