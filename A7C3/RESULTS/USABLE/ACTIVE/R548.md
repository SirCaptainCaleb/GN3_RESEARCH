# R548 — Wrap selection-or-reversal for a path component

## Statement
Let a literal k-path cover contain a component P=(p_0,p_1,...,p_r), r>=1, in a Strong Level-(1) boundary tournament, and put w=(p_r,p_0). If r=1, reversing the two-vertex component gives another literal k-cover selecting w. If r>=2, then either one of the two cyclic rotations (p_r,p_0,p_1,...,p_{r-1}) or (p_1,...,p_r,p_0) is a tight path, hence another literal k-cover on the same support selecting w, or both wrap seam turns (p_r,p_0,p_1) and (p_{r-1},p_r,p_0) are bad. In the latter case R3 forces (p_1,p_0,p_r) and (p_0,p_r,p_{r-1}) tight. Thus the failed-wrap branch carries opposite-polarity signed terminal dimers; when r>=3 these turns concatenate to the tight reverse P4 (p_1,p_0,p_r,p_{r-1}).

## Hypotheses
Strong Level-(1) R3; one literal tight path component of a path cover.

## Scope
Order-free universal path-cover theorem. No smallest-counterexample, minimal-cover, deletion, sign-payment, or R24 assumptions.

## Applicability
Use whenever a named two-vertex state joins the tail of a current path component back to its head. It converts failure to select that wrap by cyclic rotation into an exact pair of reversed endpoint turns.

## Persistence
Retain the path component P, wrap state p_rp_0, which rotation succeeds if any, or in the failed-wrap branch the two exact reversed turns and reverse P4 when r>=3. All are graph-intrinsic except the selected-state role inside the displayed cover.

## Exclusions / nonclaims
Does not assert the wrap-selected cover is distinct when symmetries occur. Does not turn a reverse P4 or signed-dimer packet by itself into a contradiction.

## Proof
For r=1, P=(p_0,p_1) has no triple constraints, so (p_1,p_0) is also a tight two-vertex path and selects the wrap. Assume r>=2. The head rotation P_H=(p_r,p_0,p_1,...,p_{r-1}) inherits every old turn of P except that its only new turn is (p_r,p_0,p_1). Hence if this turn is tight, P_H is tight. The tail rotation P_T=(p_1,...,p_r,p_0) likewise inherits every old turn except the new turn (p_{r-1},p_r,p_0); if that turn is tight, P_T is tight. In either case replacing P by the successful rotation preserves the number of cover components and selects the adjacent wrap state p_rp_0. If neither rotation works, both new turns are bad. R3 gives their complete reversals (p_1,p_0,p_r) and (p_0,p_r,p_{r-1}) tight. These are respectively a tail sign on the reversed head dimer (p_1,p_0) witnessed by p_r and a head sign on the reversed tail dimer (p_r,p_{r-1}) witnessed by p_0. If r>=3 then p_1 and p_{r-1} are distinct and the two turns concatenate to (p_1,p_0,p_r,p_{r-1}), a tight P4. This proves every clause.
