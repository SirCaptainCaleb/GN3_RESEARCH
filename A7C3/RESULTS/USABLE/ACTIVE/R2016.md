# R2016 — The transported endpoint side is determined by the neutral-path transition weight

**Status:** PASS
**Source:** workspace root `1789414783.157869`

## Statement

For the distinguished neutral path `D_v` with transported endpoint `u,in`, one has `u∈X` exactly when `w(D_v)=0`, and `u∈B` exactly when `|w(D_v)|=1`.

Consequently, in the physical terminal branch of R2013 the canonical closure `v->u` has transition count exactly `1` in the zero-weight case and exactly `2` in the nonzero split-neutral case. When `w(D_v)=0`, the endpoint `u` is a source spoke in `{p,q,r}`.

## Proof

Traverse `D_v` in the split bipartite graph from its J-only endpoint `v,in` to its F-only endpoint `u,in`. Label each physical vertex by its side, X or B. Traversing a selected symmetric-difference edge changes the side label exactly when that edge is a transition, and preserves the label for a same-side edge. Hence parity of the total number of transition edges on `D_v` equals whether the physical endpoint changes side from `v` to `u`.

Audited R1039 exhausts the neutral transition placements in the sharp cell. If `w(D_v)=0`, then `D_v` is transition-free or, in the PAIRED NEUTRAL case, carries exactly one F-transition and one J-transition. Thus it contains an even number, zero or two, of transition edges. Since `v∈X`, also `u∈X`.

If `w(D_v)=+1`, the SPLIT NEUTRAL branch of R1039 makes `D_v` the unique neutral component carrying the lone off-`C_*` F-transition and no J-transition. If `w(D_v)=-1`, it carries the lone J-transition and no F-transition. In either case `D_v` contains exactly one transition edge, so `u∈B`. These are the only nonzero neutral weights permitted by R1039.

Now take the physical terminal branch of R2013. The repaired tight three-forest `N` has `tau(N)=1` and free split copies `v,out` and `u,in`; its direct closure is `v->u`. If `w(D_v)=0`, then `u∈X`, so `v->u` is X-X and adds no transition, giving `tau(N+v->u)=1`. Because `u≠v` and `X={v,p,q,r}`, necessarily `u∈{p,q,r}`. If `|w(D_v)|=1`, then `u∈B`, so `v->u` is X-B and adds exactly one transition, giving `tau(N+v->u)=2`.
