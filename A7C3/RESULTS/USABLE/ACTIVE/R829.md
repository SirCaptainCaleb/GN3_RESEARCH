# R829 — Calderbank–Chung–Sturtevant GF(2)^k ordering gives an asymptotic one-half monotone-path fence

## Statement
For n=2^k, identify V(K_n) with GF(2)^k. For each nonzero d, the edges {x,y} with x+y=d form a perfect matching M_d. Totally order the edge set by placing the matching classes M_d in lexicographic order of d, with arbitrary order inside each class. If P=(v_0,...,v_t) is a simple increasing path, then the edge-difference sequence d_i=v_{i-1}+v_i is strictly lexicographically increasing and every nonempty consecutive block has nonzero sum. Hence t is at most f(k), where f(k) is the maximum length of a lexicographically increasing sequence in GF(2)^k having no zero-sum consecutive block. Calderbank, Chung and Sturtevant (Discrete Math. 50 (1984), 15–28) prove f(k) <= (1/2+o(1))2^k. Therefore this edge ordering has no increasing path longer than (1/2+o(1))n. Under the standard translation declaring an ordered triple (u,v,w) tight iff edge {u,v} precedes edge {v,w}, this yields Strong Level-(1) boundary tournaments with no tight path longer than (1/2+o(1))n.

## Hypotheses
n=2^k. The asymptotic f(k) bound is imported from Calderbank–Chung–Sturtevant 1984; the edge-ordering-to-vector-sequence reduction is proved here.

## Scope
Literature fence against spanning or near-spanning tight-path conjectures in arbitrary Strong Level-(1) boundary tournaments. Infinite power-of-two family suffices for the fence.

## Applicability
Use to reject any proposed theorem asserting that boundary antisymmetry alone forces a tight path on more than (1/2+o(1))n vertices. More strategically, remember the mechanism: encode transition classes by an abelian-group difference so path simplicity becomes a no-zero-consecutive-block condition.

## Persistence
Durable fence and construction template.

## Exclusions / nonclaims
Not a claim about smallest counterexamples satisfying the project cover-minimality hypotheses. Not a new proof of the Calderbank–Chung–Sturtevant sequence bound. Does not supersede the elementary 3/4 resource-budget fence R823; the two constructions expose different mechanisms.

## Proof
Let V=GF(2)^k. For each d != 0 put M_d={{x,x+d}:x in V}; after identifying duplicate unordered pairs, M_d is a perfect matching. The M_d partition E(K_n), since every edge {x,y} has unique nonzero difference d=x+y. Order the classes lexicographically by d and order edges arbitrarily inside a class. Let P=(v_0,...,v_t) be an increasing simple path and put d_i=v_{i-1}+v_i. Because each M_d is a matching, P cannot traverse two consecutive edges from the same class. Since all edges of one class form one contiguous block in the global ordering, once an increasing path leaves M_d it cannot return; consequently d_1<...<d_t lexicographically. For any 1<=a<=b<=t, sum_{i=a}^b d_i=(v_{a-1}+v_a)+...+(v_{b-1}+v_b)=v_{a-1}+v_b in characteristic two. The path is vertex-simple, so v_{a-1} != v_b and this sum is nonzero. Thus (d_1,...,d_t) is a lex-increasing sequence with every consecutive block sum nonzero. By Calderbank, Chung and Sturtevant, 'Increasing sequences with nonzero block sums and increasing paths in edge-ordered graphs', Discrete Mathematics 50 (1984), 15–28, the maximum possible length f(k) of such a sequence satisfies f(k)<=(1/2+o(1))2^k. Hence t<=(1/2+o(1))n. Finally, declaring (u,v,w) tight iff {u,v}<{v,w} gives exact reversal antisymmetry because reversing the ordered triple reverses the comparison of the same two distinct edges; increasing graph paths are exactly tight paths in this induced boundary tournament.
