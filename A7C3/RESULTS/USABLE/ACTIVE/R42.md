# R42 — Captured-anchor first-contact control

## Statement

After choosing one actual capture descendant and one designated quiet continuation, the captured anchor remains protected until it reaches the named target role or the first later event touching it is exposed. If a later operation uses a signed support containing that anchor, the operation cannot be a quiet unrelated epoch: an earlier contact was already exposed or the operation itself is the first contact.

## Hypotheses


## Scope
This theorem begins only after an actual protected continuation has been chosen. It does not upgrade every historical capture to current protection, and it does not preserve unrelated current return geometry.

## Proof
Let e be the physical endpoint captured in the chosen actual-capture descendant, and retain the graph-intrinsic signed support S_0 whose signed endpoint is e. Choose the continuation now, at this capture event. Maintain the invariant that before the named target role is reached, either a first contact with e has already been exposed or the continuation retains a historical signed descendant S_i with the same anchor e. Consider the next support/marker path Q used by a quiet macro. If Q is disjoint from S_i, keep S_i. If Q meets S_i but avoids e, apply the first branch of R436: replace S_i by the nonempty signed-side prefix/suffix ending before the first Q-contact. This is a strictly shorter signed support with the same anchor e, so the invariant persists. If Q contains e, the at-anchor branch of R436 gives strict path growth, tight cycle, or a reverse contact/reversal cell, except for exact stationary singleton replay; in every genuine touching operation this is the exposed first-contact event and the protected-quiet branch stops. Exact replay does not erase the anchor and therefore leaves the invariant unchanged. Thus no chosen quiet operation can silently remove e. The captured anchor remains protected along the designated continuation until the continuation reaches its named target role or the first later genuine event touching e is exposed. In particular a later operation using a signed support containing e cannot constitute a new unrelated quiet epoch: either an earlier first contact already stopped the protected branch or that operation is itself the first contact.
