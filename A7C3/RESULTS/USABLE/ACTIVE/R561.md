# R561 — Boundary-reversed Hamilton dimer is a universal one-vertex absorber

## Statement
Let X be a finite induced vertex set in a Strong Level-(1) boundary tournament, or more generally any exact-reversal tight-turn system. Suppose there are distinct u,v in X and two Hamilton tight paths P_start and P_end of X such that P_start begins with the ordered state (u,v) and P_end ends with the ordered state (v,u). Then every exterior vertex d notin X Hamilton-extends X. More precisely, exactly one of the reversal-pair turns (d,u,v) and (v,u,d) is tight. If (d,u,v) is tight, prepending d to P_start gives a Hamilton tight path of X union {d}; if (v,u,d) is tight, appending d to P_end gives one. Thus a single boundary-reversed Hamilton dimer makes X universally one-vertex Hamilton-extendable.

## Hypotheses
Exact complete-reversal antisymmetry on each triple. X has a Hamilton path starting with ordered dimer (u,v) and a Hamilton path ending with the reverse ordered dimer (v,u).

## Scope
Order-free and size-free. No smallest-counterexample, deletion, cover, transitive-cell, or global-longest hypothesis.

## Applicability
Provides a direct structural certificate for the universal-extension hypothesis used in later surgery theorems such as R153. Also abstracts the endpoint-gate logic behind transitive-four-cell arguments.

## Persistence
Graph-intrinsic property of X and the two Hamilton boundary states.

## Exclusions / nonclaims
Does not claim one fixed Hamilton order of X extends every d. The extending Hamilton path may use P_start or P_end according to the antisymmetric turn at d. Does not by itself produce a spanning two-cover of a larger graph.

## Proof
Let d be exterior to X. Apply exact complete-reversal antisymmetry R3 to the ordered triple (d,u,v): exactly one of (d,u,v) and (v,u,d) is tight. If (d,u,v) is tight, prepend d to the Hamilton path P_start of X beginning with (u,v). The only new consecutive triple is (d,u,v), so the resulting path is Hamiltonian on X union {d}. If instead (v,u,d) is tight, append d to the Hamilton path P_end of X ending with (v,u); again the only new consecutive triple is the certified turn (v,u,d). Thus every exterior d Hamilton-extends X, although the extending order may depend on d.
