# R1045 — Companion-independent obstruction certificate for the G39 B-ordered branches

**Status:** PASS
**Source:** G39 workspace certificate root

## Statement

Fix a tight displayed Hamilton path `B` and a common outside vertex `v`. For companion vertices `s`, consider the B-order-preserving extension problems on `B∪{v,s}`.

If `I_B(v)=∅`, then the one-outsider automaton `A(B;v)` has no positive terminal, and its canonical positive-reachability side `R_0` determines a negative cut

`K_0 = δ⁺(R_0)`.

This entire `s`-free cut is inherited identically inside every two-outsider automaton `A(B;v,s)`, so every companion shares the same pre-companion canonical comparison obstruction.

If `I_B(v)≠∅` and each full subsystem `H[B∪{v,s}]` is nonHamiltonian, then every companion insertion set satisfies

`I_B(s) ⊆ W_B(v) := ⋂_{p∈I_B(v)} ({p-1,p,p+1}∩{0,...,m}),`

so all companions are localized to the same window of at most three displayed gaps.

Thus, in every G39 B-ordered branch, the three companion failures are already coupled before source-specific analysis: by a common prefix cut when `I_B(v)=∅`, or by a common at-most-three-gap insertion window when `I_B(v)≠∅`.

## Proof

With only one outside vertex `v`, every B-ordered Hamilton word on `B∪{v}` is exactly the displayed path `B` with `v` inserted into one of its gaps. Hence `I_B(v)=∅` if and only if the one-outsider prefix automaton `A(B;v)` has no positive terminal.

By R1042, the positive-reachability region `R_0` then yields the canonical negative outgoing cut `K_0=δ⁺(R_0)`, and the induced `s`-free automaton inside every `A(B;v,s)` is literally the same `A(B;v)`. Therefore the `s`-free reachable side and outgoing cut are companion-independent.

In the complementary case `I_B(v)≠∅`, R1043 applies to every nonHamiltonian support `H[B∪{v,s}]`: every `q∈I_B(s)` must be within distance one of every `p∈I_B(v)`. This is exactly the displayed common window `W_B(v)`, which is contained in the radius-one neighborhood of any one `p∈I_B(v)` and therefore has at most three gaps.

## Scope

The theorem is a coupling certificate for the displayed-B-order subproblem. It does not itself consume the common cut or common window using the source-frame geometry, and it does not claim that B-ordered failure is equivalent to full nonHamiltonicity.
