# R841 — Crossed m=6 one-hole cap closure forces a twenty-turn outer fan

## Statement
Retain the accepted crossed R621 frame at m=6, Q=(L,u,v,w,d,s,R), X={a,b,c,z}, M_R={ab,cz}>M_S={ac,bz}>M_L={bc,az}. Then the following twenty turns are forced tight by literal one-hole spanning two-path proposals. FIRST LAYER (12): c s R, a s R, L u b, L u z, c R z, c R b, a R z, a R b, c L z, c L b, a L z, a L b. SECOND LAYER (8): c z R, R c b, a b R, R a z, c z L, L c b, a b L, L a z. Each first-layer turn is the exact reversal of the sole uncertified turn in a spanning two-path proposal using a consecutive Q prefix/suffix and a five/six-vertex outer path whose other turns are accepted crossed-gate, endpoint-star, or matching-height turns. Each second-layer turn is obtained by an analogous one-hole proposal using one first-layer turn plus accepted matching-height/gate turns.

## Hypotheses
Accepted crossed R621 frame at m=6, accepted R594 endpoint stars/matching-height four-cell, boundary antisymmetry R3, and pc(H)>2.

## Scope
Finite crossed m=6 R24/O6 cap-saturation lemma. Pure literal one-hole spanning-cover forcing; no R5,R168,R169,R224,R533,R350,generic R358,capture,payment,R436,Reverse Ear,or computation.

## Applicability
Use before resolving the paired R583/R818 terminal-gap clauses. The twenty turns are simultaneous graph-intrinsic cap data and may serve as exact companion literals in Mate-Fork or R833/R834 endpoint arguments.

## Persistence
Retain Q labels, X matching labels, all twenty displayed turns, and for each turn the one-hole spanning proposal listed in the proof.

## Exclusions / nonclaims
Does not by itself close the crossed m=6 frame. Does not claim the twenty turns exhaust all one-hole consequences. Does not infer generic path growth or balanced-pair progress.
