# R1052 — Behind-frontier OUT-v pivots expose an earlier source-gated descent attempt

**Status:** PASS_ADJUSTED
**Source:** workspace root `1789345788.350339`

## Statement

Retain the non-loop OUT-`v` literal first-loss cell. Then the far zipper endpoint is a source spoke `t∈{p,q,r}`.

Write the first-positive pivot as

`e_r=v->b_j`,  `f_r=b_{j-1}->b_j`,

with `b_{j-1}->b_j` a consecutive spectator edge.

There are three relevant local states at `b_j,out`.

1. **Unflipped suffix, nonterminal.** The spectator successor `b_j->b_{j+1}` remains selected, and the pivot tests the R1033 next-slot comparison, as in R1050.
2. **Behind the zipper frontier.** There is a unique earlier index `q<r` with `a_q=b_j`. At that earlier normalized defect position, the canonical closing edge is exactly

   `g_q=b_j->t`.

   The edge `f_r=b_{j-1}->b_j` is still selected on the unflipped suffix, so the near seam of this closing attempt is exactly

   `(b_{j-1},b_j,t)`.

   The shortcut has two-cover matching cardinality and transition count at most two. If the normalized prefix is a literal tight three-forest, its only new physical obligations are the near seam at `b_j`, the far seam at the source spoke `t` when defined, and the possibility that both seams pass but the shortcut closes one rail into a directed cycle. The loop alternative is impossible because `b_j∈B` and `t∈X`.
3. **Unflipped suffix, terminal.** No spectator successor is selected at `b_j`, so neither the next-slot seam of (1) nor the behind-frontier construction of (2) follows merely from this local state. This endpoint-truncation residue remains separate.

Thus every behind-frontier OUT-`v` first loss carries an earlier source-gated matching-level strict-descent attempt whose near seam uses the same consecutive spectator edge later deleted at first loss. The stronger two-way claim covering every OUT-`v` first loss requires the terminal residue to be handled separately.

## Proof

R1051 identifies the exact non-loop OUT-`v` rectangle

`{ b_{j-1}->b_j , v->t } <-> { v->b_j , b_{j-1}->t }`

with `t∈{p,q,r}`. In particular the fixed far unmatched IN-copy of the zipper is `t,in`.

Assume now that `b_j,out` lies behind the first-positive frontier. Along the unique alternating augmenter, the OUT-shore labels `a_0,out,...,a_{m-1},out` are pairwise distinct. Since the physical vertex `b_j` has only one OUT copy, there is a unique earlier index `q<r` with

`a_q=b_j`.

At the normalized prefix at index `q`, the moving unmatched OUT-copy is therefore `b_j,out`, while the fixed far unmatched IN-copy remains `t,in`. Because `q<r`, the later edge

`f_r=b_{j-1}->b_j`

still lies on the unflipped suffix and remains selected. Hence the direct closure of the two free copies is the ordinary edge

`g_q=b_j->t`,

and its near endpoint uses the predecessor `b_{j-1}->b_j`, producing exactly the seam `(b_{j-1},b_j,t)`.

Before the first-positive index, the prefix transition ledger is nonpositive while `tau(J)=1`, so the unnormalized prefix has transition count at most one. Neutral normalization changes only zero-delta components to their `F` states and cannot increase the transition count. Therefore the normalized prefix also has transition count at most one. Since `g_q` crosses `B|X`, adding it raises the count by exactly one, giving transition count at most two. It also increases the matching cardinality by one, from the three-forest cardinality to the two-cover cardinality, because it joins the two free matching copies `b_j,out` and `t,in`.

If this normalized prefix is physically a tight three-path forest, `b_j` is the terminal vertex of one rail and `t` the source vertex of one rail. Adding `b_j->t` creates no new turns except the predecessor seam at `b_j` and, when `t` has a successor, the far seam at `t`. A bad seam gives its R3 complete-reversal trimer. If both seams are tight and the endpoints are on different rails, the shortcut gives a tight two-cover with transition count at most two. If both pass but the endpoints lie on the same rail, the shortcut closes exactly that rail into a directed cycle. Because `b_j∈B` and `t∈X`, `b_j=t` is impossible, so there is no loop case.

The future-suffix nonterminal alternative is exactly R1050. If instead `b_j` is terminal on the endpoint-truncated spectator rail, there is no selected spectator successor and the next-slot conclusion is unavailable. That case is therefore retained explicitly rather than silently folded into the two-way dichotomy.

## Adjustment

The workspace headline correctly identified the behind-frontier source-gated shortcut but concluded that **every** OUT-`v` first loss yields either a live R1033 next-slot comparison or that earlier seam. This omits the unflipped-suffix terminal state already isolated in R1049/R1050. The audited theorem preserves the full behind-frontier mechanism and adds the terminal endpoint residue as a third branch.
