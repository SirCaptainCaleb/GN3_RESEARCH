# R980 — Symmetric-difference path-cover exchanges form a weighted collision poset

## Statement
Let G be a finite edge-ordered graph on vertex set V, with distinct real edge labels lambda, and let F_0,F_1 be two spanning increasing path covers having the same number k of components. Orient every rail increasingly and let M_0,M_1 be the corresponding matchings in the bipartite graph V_out sqcup V_in: u_out v_in is selected exactly when u->v is a consecutive rail edge. Thus |M_0|=|M_1|=|V|-k.

Let C be the set of connected components of the bipartite symmetric difference M_0 triangle M_1. For C in C put delta(C)=|M_1 cap C|-|M_0 cap C|. Every delta(C) lies in {-1,0,1} and sum_C delta(C)=0.

For i=0,1 and v in V, let L_i(v) be the label of the incoming F_i edge, with L_i(v)=-infinity at an F_i source, and let U_i(v) be the label of the outgoing F_i edge, with U_i(v)=+infinity at an F_i terminal. Then L_i(v)<U_i(v).

Whenever v_in and v_out are incident with changed edges belonging to two distinct symmetric-difference components C_in(v),C_out(v), impose the following directed collision constraints on component flip bits 0<1:
(1) if L_1(v)>=U_0(v), impose C_in(v) <= C_out(v);
(2) if L_0(v)>=U_1(v), impose C_out(v) <= C_in(v).
The two inequalities (1),(2) can never both occur at one vertex. Let preceq be the preorder generated by all these constraints.

For any subset W of symmetric-difference components, form M_W by using the M_1 edges on components in W and the M_0 edges on components outside W, while retaining all common edges. Then M_W is the directed matching of a spanning increasing path cover if and only if W is an upper set of the preorder preceq. In that case
  |M_W|=|M_0|+sum_{C in W} delta(C),
so the resulting cover has
  k-sum_{C in W} delta(C)
components.

Consequently, if some upper set W has positive total delta-weight, F_0 and F_1 have a globally cooperative componentwise recombination with strictly fewer than k paths. In particular, for k=3 any positive upper set yields a spanning cover by at most two increasing paths.

Dually, if no upper set has positive total delta-weight, collapse the preorder to its strongly connected component DAG. There exists an integral nonnegative flow on its directed arcs whose net outflow minus inflow at each DAG node equals the total delta-weight of that node. Equivalently every positive gain unit is transported upward through physical collision constraints to negative loss units. Thus failure of every globally cooperative componentwise recombination has an exact collision-transport certificate.

## Hypotheses
Finite edge-ordered graph; F_0,F_1 are spanning increasing path covers with the same number of components. No completeness, smallest-counterexample, boundary-tournament, local-surgery, or fixed-threshold hypothesis is needed.

## Scope
Pure edge-ordered matching/path-cover theorem. It permits simultaneous rewriting on arbitrarily many symmetric-difference components and gives an exact max-closure/min-cut dual obstruction.

## Applicability
Compare two singleton-deletion three-covers of a hypothetical R888 counterexample, after adjoining the deleted vertex as a singleton. Any positive upper set closes R888. Otherwise retain the integral collision flow as a global obstruction certificate. For compatible singleton fibers with a synchronized common rail, the theorem localizes to the exchanged port universe.

## Persistence
Retain F_0,F_1, M_0,M_1, every alternating component and delta-weight, each physical vertex producing a directed collision constraint, the resulting preorder/SCC DAG, and either an explicit positive upper set or the integral collision flow.

## Exclusions / nonclaims
Does not assert that every pair of three-covers has a positive upper set. Does not by itself prove R888. Does not say arbitrary broad-interval alternating paths compile. Does not synchronize Hamilton orders on equal supports unless they are explicitly chosen equal. The flow certificate is a structural obstruction, not a contradiction.

## Proof
Orient every rail of F_i in its increasing direction. For each consecutive rail pair u->v select the bipartite edge u_out v_in. Because every physical vertex has at most one predecessor and one successor, M_i is a matching. A k-path cover on n vertices has exactly n-k selected adjacencies, hence |M_0|=|M_1|=n-k.

1. SYMMETRIC-DIFFERENCE COMPONENTS AND WEIGHTS.
The graph M_0 triangle M_1 has maximum degree two and alternates between M_0 and M_1 edges. Hence each connected component is an alternating cycle or alternating path. On a cycle the two matchings contribute equally many edges. On a path their contributions differ by at most one. Therefore delta(C)=|M_1 cap C|-|M_0 cap C| belongs to {-1,0,1}. Summing over components gives sum delta=|M_1|-|M_0|=0.

For any set W of components, choosing M_1 on W and M_0 off W produces a bipartite matching M_W: distinct symmetric-difference components are vertex-disjoint in the bipartite graph, and common edges are disjoint from every changed edge at their copies. Its cardinality is
  |M_W|=|M_0|+sum_{C in W} delta(C).
The only issue is whether this directed matching is an increasing path cover in the physical graph.

2. THE ONLY POSSIBLE PHYSICAL COLLISIONS.
At a physical vertex v write L_i(v) for its F_i incoming label, with -infinity if absent, and U_i(v) for its F_i outgoing label, with +infinity if absent. Since F_i is increasing, L_i(v)<U_i(v).

If the choice of incoming edge at v is fixed between M_0 and M_1, then L_0(v)=L_1(v) as a selected label/convention and both possible outgoing choices are compatible with it because F_0 and F_1 are individually increasing. The same holds if the outgoing choice is fixed. If both copies change but v_in and v_out lie in the same symmetric-difference component, they receive the same flip bit, so the local pair is exactly the F_0 pair or exactly the F_1 pair and is safe.

Thus a new local condition arises only when v_in and v_out belong to two distinct changed components C_in and C_out. There are four bit choices. The equal choices 00 and 11 are safe because they reproduce F_0 and F_1. The mixed choice 10 (incoming from F_1, outgoing from F_0) is safe exactly when
  L_1(v)<U_0(v).
The mixed choice 01 is safe exactly when
  L_0(v)<U_1(v).
These two mixed inequalities cannot both fail. Indeed failure of both would give
  L_1(v)>=U_0(v)>L_0(v)>=U_1(v)>L_1(v),
a contradiction. Therefore each physical vertex forbids at most one mixed orientation.

If L_1(v)>=U_0(v), the forbidden state is C_in=1,C_out=0, so impose the implication C_in<=C_out. If L_0(v)>=U_1(v), impose C_out<=C_in. The two generating implications cannot both be produced at v. Let preceq be their transitive closure.

3. FEASIBLE FLIPS ARE EXACTLY UPPER SETS.
Suppose W is an upper set for preceq. At every collision vertex, W cannot realize a forbidden mixed state, because every generating implication c<=d has the property c in W => d in W. All other local states were shown safe. Hence every physical vertex with both a selected incoming and outgoing edge in M_W has incoming label strictly below outgoing label.

Conversely, if W is not an upper set, then some generating implication c<=d has c in W and d not in W. At its witnessing physical vertex the corresponding forbidden mixed state occurs, so the selected incoming label is at least the selected outgoing label. Therefore M_W is not an increasing path cover.

It remains only to verify that a locally increasing directed matching gives a path cover rather than directed cycles. Each physical vertex has indegree and outdegree at most one. If a directed cycle existed, writing its selected edge labels in cyclic order would give a strict increase at every vertex and hence
  a_0<a_1<...<a_r<a_0,
impossible. Thus every component is a directed path or singleton. Therefore M_W is exactly the matching of a spanning increasing path cover if and only if W is upper.

Combining this with the cardinality formula, the cover represented by an upper set W has
  n-|M_W|=k-sum_{C in W} delta(C)
components. Any upper set of positive weight therefore strictly improves F_0; for k=3 it gives at most two paths.

4. COLLISION-TRANSPORT DUAL.
Assume no upper set has positive total delta-weight. Collapse strongly connected components of preceq. A flip must be constant on each such class, so this loses no feasible assignments. Give each DAG node D weight
  w(D)=sum_{C in D} delta(C).
The total weight is zero, and every upper set of DAG nodes has weight at most zero.

Build a flow network by adjoining source s and sink t. For each node D with w(D)>0 add s->D of capacity w(D). For w(D)<0 add D->t of capacity -w(D). Give every DAG arc infinite capacity. Let P be the total positive weight, equal to total negative absolute weight.

A finite s-t cut is determined by an upper set U of DAG nodes on the source side: if a DAG arc left U the cut would have infinite capacity. Its finite capacity is
  P - sum_{D in U,w(D)>0} w(D) + sum_{D in U,w(D)<0} (-w(D))
  = P-w(U).
By hypothesis w(U)<=0, so every cut has capacity at least P. The trivial cut has capacity P. Max-flow/min-cut therefore gives a flow of value P saturating every source-supply and sink-demand edge. All capacities are integral, so an integral maximum flow exists.

Discard s,t. At each DAG node D, flow conservation becomes
  outflow(D)-inflow(D)=w(D).
Thus every positive gain unit is transported along directed collision implications to negative loss units. Conversely, existence of such a flow immediately gives w(U)<=0 for every upper set U, since no DAG arc leaves an upper set and summing the divergence over U gives w(U)=-inflow_from_outside(U)<=0.

This proves the exact upper-set/improvement alternative and its collision-transport dual.
