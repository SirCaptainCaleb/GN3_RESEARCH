# R7 — Intrinsic Partition-Cover Deficit Identity

**Status:** USABLE / ACTIVE
**Type:** theorem
**Source:** A7C2 active-spine migration S2; controlling compressed sources M1/M6/M10

## Statement

For a fixed partition into physical classes, the number t_Pi(T) of selected transitions between classes in a current exact cover T equals the sum of the intrinsic path-cover numbers of the classes minus the number of current cover components, plus a nonnegative representative-relative excess sigma. Equality sigma=0 means every class restriction realizes its intrinsic minimum path-cover number.

## Scope

A fixed physical partition and one displayed exact cover.

## Exclusions / nonclaims

The excess is not a global monotone or literal exchange credit.
