# R954 — An ordered XOR 1-factorization of K16 has no longest path with Hamilton complement but has a spanning two-path cover

## Statement
Let V=GF(2)^4 identified with 0,...,15. For every nonzero difference d, let M_d be the perfect matching of edges {x,x xor d}. Order the fifteen matching blocks by 1<7<6<2<4<3<5<10<12<13<14<9<8<11<15, with arbitrary order inside each block. Then every globally longest increasing path has exactly 12 vertices, and the complement of every globally longest increasing path is a four-vertex induced edge order with no increasing Hamilton path. Nevertheless V has a spanning cover by two vertex-disjoint increasing paths. Hence the existential strengthening of R888 asserting that some globally longest increasing path always has Hamiltonian complement is false even inside ordered 1-factorizations.

## Hypotheses
Explicit ordered 1-factorization of K16 by XOR difference classes in the displayed block order. Within-block tie order is irrelevant for vertex-simple increasing paths.

## Scope
Exact finite fence against longest-first strategies for R888 and the ordered-1-factorization theorem.

## Applicability
Use to reject any proof strategy that first insists one rail be globally longest and then Hamilton-covers its complement. The example remains positively two-coverable, so it is also a laboratory for genuinely cooperative two-rail constructions.

## Persistence
Retain the block order; the R823 equality classification; the normalized eight-case omitted-cross table; the base longest path (4,5,7,3,0,10,6,8,1,9,2,13); the base bad complement {11,12,14,15}; and the explicit two-cover (0,1,3,7,4,14,2,13) plus its xor-8 translate.

## Exclusions / nonclaims
Does not refute R888 or the ordinary ordered-1-factorization two-cover theorem. Does not assert that all longest-complement failures have this XOR form. The conclusion concerns the displayed block order only.

## Proof
Write V=GF(2)^4 as the integers 0,...,15 under bitwise xor. For each nonzero d, the edges {x,x xor d} form a perfect matching M_d. The displayed order of the fifteen difference classes is\n\n1<7<6<2<4<3<5<10<12<13<14<9<8<11<15.\n\nConsecutive edges of a vertex-simple path cannot have the same xor difference, so within-block order is irrelevant. Put A={0,...,7} and B={8,...,15}. Differences below 8 are internal to A or B and are exactly the first seven blocks; differences at least 8 are cross edges and are exactly the final eight blocks. Thus accepted R823 applies with m=8 and every increasing path has at most 8+ceil(8/2)=12 vertices.\n\nWe classify the equality case. Let P be an increasing path on 12 vertices. In the notation of the R823 proof, let c be its number of cross edges and let p be the number of vertices in the initial one-part segment, including the endpoint of the first cross edge. Then p+c=12, c<=8, and p+floor(c/2)<=8. Hence c is 7 or 8. If c=8, P uses all eight cross blocks in their displayed order 10,12,13,14,9,8,11,15. Their xor is 0, so the forced consecutive cross walk returns after eight cross edges to its starting vertex, contradicting vertex simplicity. Therefore c=7 and p=5.\n\nThe seven cross edges use seven of the eight cross blocks. XOR translation preserves every difference class, so translate P by its first-cross starting vertex and, if necessary, thereby swap A and B; we may normalize that starting vertex to 0 in A. For each possible omitted cross difference delta, the consecutive cross part is forced because at each used matching block the current vertex has a unique mate. The following table gives the cross-walk states beginning at 0. When the walk is simple, the last column gives the five A-vertices that the initial internal prefix would have to occupy and the number of increasing Hamilton orders of that five-set ending at 0 under the internal block order 1<7<6<2<4<3<5. The latter counts are the direct check of the 4!=24 possible orders before 0.\n\nomit 10: 0,12,1,15,6,14,5,10 ; required {0,2,3,4,7}; count 0.\nomit 12: 0,10,7,9,0,8,3,12 ; repeats 0.\nomit 13: 0,10,6,8,1,9,2,13 ; required {0,3,4,5,7}; count 1, uniquely (4,5,7,3,0), with differences 1,2,4,3.\nomit 14: 0,10,6,11,2,10,1,14 ; repeats 10.\nomit 9: 0,10,6,11,5,13,6,9 ; repeats 6.\nomit 8: 0,10,6,11,5,12,7,8 ; required {0,1,2,3,4}; count 0.\nomit 11: 0,10,6,11,5,12,4,11 ; repeats 11.\nomit 15: 0,10,6,11,5,12,4,15 ; required {0,1,2,3,7}; count 0.\n\nThus every 12-vertex increasing path is an xor translate of\n\nP0=(4,5,7,3,0,10,6,8,1,9,2,13),\n\nwhose difference sequence is\n\n1,2,4,3,10,12,14,9,8,11,15.\n\nIts complement is C0={11,12,14,15}. Hence every globally longest path complement is an xor translate of C0. We show C0 has no increasing Hamilton path. Its three opposite-edge perfect matchings are\n\n{{14,15},{11,12}}, with differences 1,7 and block ranks 1,2;\n{{12,14},{11,15}}, with differences 2,4 and block ranks 4,5;\n{{12,15},{11,14}}, with differences 3,5 and block ranks 6,7.\n\nThus every edge of the first opposite matching precedes every edge of the second, and every edge of the second precedes every edge of the third. In any Hamilton path on four vertices, the first and third edges are disjoint and therefore form one of the three opposite perfect matchings, while the middle edge belongs to another. If the middle edge comes from a higher matching band than the two outer edges, then middle>third; if it comes from a lower band, then first>middle. Either way the three path edges cannot be strictly increasing. Hence C0 is non-Hamiltonian, and the same holds for every xor translate. Therefore no globally longest path has Hamiltonian complement.\n\nNevertheless the graph has a spanning two-path cover. Let\n\nR=(0,1,3,7,4,14,2,13)\nand\nR+8=(8,9,11,15,12,6,10,5).\n\nThese two vertex lists are disjoint and together contain all sixteen vertices. Both have the same consecutive xor-difference sequence\n\n1,2,4,3,10,12,15,\n\nwhose block ranks are 1,4,5,6,8,9,15, strictly increasing. Hence both are increasing paths. This proves all assertions.
