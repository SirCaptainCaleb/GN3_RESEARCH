# R2043 — E_B nucleus-only closure fence

**Status:** PASS
**Source:** Slack workspace root `1789425088.653779`

## Statement

The repaired local seven-vertex packet occurring in the `E_B` orientation with long X-end `v,t,r,...` does not force a Hamilton nucleus.

There exists a globally edge-ordered Strong Level-(1) realization on `{A,C,s,t,r,v,b}` with all three source turns, `{A,C,s,b}` P4-free, the repaired short-rail turns `(s,A,b)`, `(b,C,s)`, `(C,b,A)`, the actual long-rail turn `(v,t,r)`, the R2042 cap `(t,v,b)`, and even the R2026 source-side cap `(v,C,s)` all tight, but with no tight Hamilton P7.

Therefore any closure of this `E_B` branch must use residual-B/far-end geometry or stronger global ancestry, not a nucleus-only absorber.

## Proof

Use the R887 global edge-order model. On the 21 ordinary edges of `{A,C,s,t,r,v,b}`, take the strict order

`tv < As < rt < Cb < At < br < Cv < bs < bv < rs < AC < Ct < Av < rv < bt < Ar < Cs < st < Ab < sv < Cr`.

A turn `(x,m,z)` is tight exactly when the ordinary edge `xm` precedes `mz` in this order.

The required packet follows from the displayed comparisons:

- `As<Cs`, `At<Ct`, `Ar<Cr` give the three source turns;
- `As<Ab`, `Cb<Cs`, `Cb<Ab` give `(s,A,b)`, `(b,C,s)`, `(C,b,A)`;
- `tv<rt` gives `(v,t,r)`;
- `tv<bv` gives `(t,v,b)`;
- `Cv<Cs` gives `(v,C,s)`.

Direct enumeration of the 24 vertex orders of `{A,C,s,b}` shows that no order has its three consecutive ordinary-edge ranks strictly increasing, so this four-set has no tight Hamilton P4.

There is also no Hamilton P7. In fact the only tight Hamilton P6 orders on six of the seven vertices are

- `(v,t,r,b,s,C)`, missing `A`;
- `(A,s,b,v,r,C)`, missing `t`;
- `(s,b,v,A,r,C)`, missing `t`;
- `(r,t,A,C,s,v)`, missing `b`.

For these four P6s, respectively, the missing vertex fails both endpoint extensions because the following required turns are bad:

- `(A,v,t)` and `(s,C,A)`;
- `(t,A,s)` and `(r,C,t)`;
- `(t,s,b)` and `(r,C,t)`;
- `(b,r,t)` and `(s,v,b)`.

Any Hamilton P7 would yield a Hamilton P6 by deleting one endpoint, so no P7 exists.

## Dependencies and scope

Trusted dependency: R887 for the global edge-order interpretation. Provisional dependencies: none.

This is only a fence on the local `E_B` nucleus abstraction. It does not realize the far B-block, the full literal `E_B` rail, or smallest-counterexample ancestry. It therefore does not refute `E_B`; it proves that the omitted far-end or global data are genuinely required for the next closure.
