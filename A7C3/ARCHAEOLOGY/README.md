# A7C3 Archaeology

This directory preserves the pre-Engine result corpus for archaeology, provenance recovery, historical comparison, and repair. It is not the default active theorem interface.

`RESULTS/` is the complete former result tree, including the former `INTERESTING`, usable, invalid, and quarantined collections. Historical trust labels remain historically meaningful, but active research should initialize from Slack and work through current Engines rather than rebuilding arguments by composing archived result files.
