# R150 — Current-trimer endpoint/incidence role trichotomy

**Record status:** `USABLE/LEGACY`

## Statement
Let T be an exact two-cover of an eight-vertex residual set whose component-size profile is 5+3 or 4+4. If a distinguished trimer J=(j_0,j_1,j_2) occurs literally as three consecutive vertices of one selected component of T, then one of the following holds: (i) both outer vertices j_0,j_2 are current component endpoints; (ii) exactly one of j_0,j_2 is a current component endpoint; or (iii) both j_0,j_2 are internal and each has a selected external incidence on that component.

## Hypotheses
T is an exact two-cover of eight vertices with component orders 5+3 or 4+4; J=(j_0,j_1,j_2) is literally selected consecutively in one target component with the stated orientation.

## Scope
Pure path-position consequence for the residual 5+3/4+4 profiles. Historically stated as Corollary 5 of the 4+3+3 residual compiler, and especially used for the canonical candidate mate J_Z.

## Applicability
Use after a named trimer has been currentized in an exact eight-vertex residual two-cover, when downstream consumers need endpoint exposure or current external incidence on the trimer outer vertices.

## Persistence
All endpoint and incidence roles are literal selected roles in the same target T in which J is current. No role is transported to another representative.

## Exclusions / nonclaims
Does not make the parent candidate current; does not identify the external incidences with any prescribed historical edges; does not imply capture, protection, a seam, or final assembly; does not assert simultaneous endpoint exposure and internal incidence.

## Proof
Recovered from A7C2_MATH_EXPLORER_000006.md, Corollary 5. If the target rail containing J has order 3, J is the entire component and both outer vertices are endpoints. If it has order 4, a consecutive trimer occupies positions 1-3 or 2-4, so exactly one outer vertex is an endpoint. If it has order 5, J occupies positions 1-3, 2-4, or 3-5. In the first and last positions one outer vertex is an endpoint; in positions 2-4 both outer vertices are internal and each is incident with the adjacent selected path state outside J. These exhaust the possibilities.
