# R346 — Hamilton-five density equality has an order congruence fence

**Record status:** `USABLE/LEGACY`

## Statement
Assume equality in the accepted R326/R331 Hamilton-five bad-family density ceiling on an r-vertex set W. Then r is congruent to 0 or 5 modulo 15. More precisely, R331 already gives r=5q and a 4-(r,5,q) design on the bad five-sets. In any 4-(r,5,q) design, the number lambda_2 of bad blocks through a fixed physical pair is lambda_2=q*binom(r-2,2)/binom(3,2)=q(r-2)(r-3)/6, hence an integer. If q is congruent to 2 modulo 3, then r=5q is congruent to 1 modulo 3, so q(r-2)(r-3) is congruent to 2*2*1=1 modulo 3, contradiction. Therefore q is congruent to 0 or 1 modulo 3, equivalently r is congruent to 0 or 5 modulo 15. In particular at every order r congruent to 10 modulo 15 the R326 density bound is necessarily strict.

## Hypotheses
Accepted R331 equality normal form for the bad five-set family.

## Scope
Pure design-integrality consequence of the accepted extremal density normal form. No Strong turn geometry beyond R331 is used.

## Applicability
Use when testing whether the R331 extremal bad-family structure can actually occur at a given order. It removes all r=10 mod 15 equality candidates immediately.

## Persistence
Order arithmetic only.

## Exclusions / nonclaims
Does not rule out equality for r congruent to 0 or 5 modulo 15. Does not improve the asymptotic 4/5 density constant by itself and does not force path growth.

## Proof
By R331, equality implies 5 divides r; write r=5q, and the bad family is a 4-(r,5,q) design. Fix a two-subset S of W. Double-count pairs (B,T) where B is a bad block containing S and T is a four-subset with S subset T subset B. On one hand each block B through S contains binom(3,2)=3 such four-subsets T. On the other hand there are binom(r-2,2) four-subsets T containing S and each lies in exactly q bad blocks. Thus 3 lambda_2=q binom(r-2,2), so lambda_2=q(r-2)(r-3)/6 is an integer. Suppose q=2 mod 3. Since r=5q=2q mod 3, r=1 mod 3, hence r-2=2 mod 3 and r-3=1 mod 3. Therefore q(r-2)(r-3)=2*2*1=1 mod 3, impossible because divisibility by 6 in particular requires divisibility by 3. Hence q is not 2 mod 3. Thus q=0 or 1 mod 3 and r=5q is 0 or 5 mod 15. The strictness statement for r=10 mod 15 follows.
