# R738 — Universal first-inward stars directly force labelled P4s at both ends

**Record status:** `USABLE/LEGACY`

## Statement
Retain the accepted crossed R621 frame and accepted R723. Put L=q_0,u=q_1,v=q_2 and d=q_{m-2},s=q_{m-1},R=q_m. Then each physical end independently forces a labelled tight Hamilton P4, without using the first-step zipper dichotomy R725/R727. LEFT: apply accepted R700 to the old Q-trimer K_L=(L,u,v) with any two distinct probes x_1,x_2 in X. If R700 takes its P4 branch, a labelled P4 exists on {L,u,v,x_i} for some i. Otherwise R700 makes the reverse terminal dimer (v,u) head-signed by both x_1,x_2. Accepted R723 already makes the same tested dimer (v,u) tail-signed by every X vertex. Using x_1 for the new head certificate and the distinct x_2 for the old tail certificate, accepted R523 gives the literal P4 (x_1,v,u,x_2). RIGHT dually: apply R700 to K_R=(d,s,R) with x_1,x_2. If no P4 is returned, R700 makes the reverse initial dimer (s,d) tail-signed by both probes, while R723 makes (s,d) head-signed by all X; hence R523 gives, for example, (x_2,s,d,x_1). Thus the crossed frame contains a source-labelled P4 on each side before root advance, outer-matching saturation, five-cell recompletion, or payment.

## Proof
For the left, K_L=(L,u,v) is a tight trimer because it is a consecutive Q segment. Apply R700 with distinct probes x_1,x_2 in X, which are outside K_L. The P4 branch is already the conclusion. In the DUAL-CP branch, R700 makes reverse terminal tested dimer (v,u) head-signed by x_1 and x_2, so (x_i,v,u) is tight. R723 gives (v,u,x) tight for every x in X, hence in particular (v,u,x_2). Choosing the distinct witnesses x_1,x_2, R523 concatenates (x_1,v,u) and (v,u,x_2) to the literal P4 (x_1,v,u,x_2). For the right, K_R=(d,s,R) is tight. R700 DUAL-CP makes reverse initial tested dimer (s,d) tail-signed by both probes, while R723 gives (x,s,d) for every x in X, i.e. head polarity on that same tested dimer. Thus (x_2,s,d,x_1) is tight by R523. The alternatives exhaust R700.
