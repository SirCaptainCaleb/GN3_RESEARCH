## Statement

The repaired `E_B` packet does not force the R2034 residual recompletion even after restoring the entire far B-block and retained static source frame. There is a globally edge-ordered order-11 Strong Level-(1) realization with:

- tight spectator `B`;
- a tight old source two-cover `F` with `tau(F)=3` and all three sources internal;
- nonHamiltonian `X`;
- a literal `tau=2` `E_B` two-cover with long rail `v,t,r,...`;

- but, after deleting the two internal long-rail sources, no Hamilton `P7` on the seven residual vertices.

Thus the full static far-end geometry does not close `E_B`; additional smallest-counterexample or dynamic-ancestry information is required.

## Construction

Use vertices

`{A,C,v,s,t,r,b1,b2,b3,l,y}`,

with `X={v,s,t,r}` and displayed spectator order `B=(b1,b2,b3,l,y)`. Globally order the 55 ordinary edges by

`lr < Cy < b1s < st < b1t < vy < b1l < b3v < AC < ry < rv < Av < ty < Cb1 < b2y < Cl < Ab2 < Ar < rs < b1b3 < At < b1y < b2l < Cr < Ay < Ab3 < Al < Cb3 < b2v < ls < b3s < b1b2 < b3y < b3r < Ct < sy < b2t < Cv < b2s < tv < Cb2 < As < Ab1 < lv < lt < b3t < sv < rt < Cs < b2r < b1v < b2b3 < b1r < b3l < ly`.

Edge names are unordered, and `(x,m,z)` is tight iff `xm<mz`.

The retained source turns are `As<Cs`, `At<Ct`, `Ar<Cr`.

The old source cover

`F=(b1,s,t,b2) | (v,r,b3,l,y)`

is tight because `b1s<st<b2t` and `rv<b3r<b3l<ly`. Its block words are `B-X-X-B` and `X-X-B-B-B`, so `tau(F)=3`; `s,t,r` are all internal. The spectator path `B=(b1,b2,b3,l,y)` is tight because `b1b2<b2b3<b3l<ly`. Exhaustive check gives no Hamilton `P4` on `X`.

Take the literal top-fiber cover

`T=(s,b1) | (v,t,r,b2,b3,l,y)`.

The long rail is tight because

`tv < rt < b2r < b2b3 < b3l < ly`.

Its block word is `X-X-X-B-B-B-B`, while the short rail is `X-B`, so `tau(T)=2`. This is exactly `E_B` with X-side endpoint `v` and internal consecutive sources `t,r`.

The repaired short-rail four-set `{A,C,s,b1}` is P4-free; `(s,A,b1)`, `(b1,C,s)`, `(C,b1,A)` are tight.

For R2042, with `z=b1` and `Q=(v,t,r,b2,b3,l,y)`, the four fixed caps

`(s,A,b1)`, `(b1,C,s)`, `(t,v,b1)`, `(b1,y,l)`

are tight. The R2026 source-side branch is realized by `(v,C,s)`.

Delete `t,r`. The residual paths are

`(s,b1) | (v) | (b2,b3,l,y)`.

Exhaustive check of all `7!=5040` orders on

`{s,b1,v,b2,b3,l,y}`
