# R2018 — Balanced nonloop closures are parity-locked at transition count one

**Status:** PASS
**Source:** workspace root `1789414941.561289`

## Statement

Every nonloop balanced closure produced by R2015 is parity-locked at transition count exactly `1`.

For its terminal index `q<r`, one has `tau(N)=1+S_q` with `S_q∈{-1,0}`. D17.421 zipper parity gives `chi(a_q->s)≡S_q (mod 2)` because `w(C_*)=2`. Hence the closure contributes `0` when `S_q=0` and `1` when `S_q=-1`, so

`tau(N+{a_q->s})=1`

in both cases.

## Proof

Let `N=M(q,S)` be a physically tight terminal state produced by R2015 in the nonloop case `a_q!=s`, with `q<r` and balanced neutral set `S`, so `sum_{D in S} w(D)=0`.

For the F-normalized standard prefix at index `q`, D17.421 gives

`tau(hat M_q)=1+S_q+W_0`,

where `S_q=sum_{i<=q}(chi(e_i)-chi(f_i))` and `W_0` is the total neutral transition weight. Audited R1039 gives `W_0=0`. Passing from `hat M_q` to `N=M(q,S)` toggles exactly the neutral components in `S` from F-state to J-state, changing transition count by `-sum_{D in S} w(D)=0`. Therefore

`tau(N)=1+S_q`.

R2015 gives `tau(N)<=1`, while transition count is nonnegative. Hence `1+S_q∈{0,1}`, so `S_q∈{-1,0}`.

For the closure `g_q=a_q->b_m=a_q->s`, put `gamma_q=chi(g_q)`. D17.421 gives

`gamma_q = (S_q mod 2) xor (w(C_*) mod 2)`.

In the sharp cell `w(C_*)=2`, so the second parity bit is zero. Thus `gamma_q` is exactly the parity of `S_q`: zero for `S_q=0` and one for `S_q=-1`. Therefore

`tau(N+g_q)=1+S_q+gamma_q=1`

in both possibilities.
