# R1000 — Every physical component join is a merge, a monotone one-block transport, or a reverse-P4 rebuild

## Statement
Let G be a minimum-order counterexample to R888 and let F=A|B|C be any spanning increasing three-cover. Let t be the terminal of A and s the source of distinct component B, put e=lambda(ts), a=L_F(t) with a=-infinity when A={t}, and b=U_F(s) with b=+infinity when B={s}. Exactly one of the following strict-order regimes holds. (MERGE) a<e<b, in which case concatenating A followed by B through t->s gives a spanning increasing two-cover, impossible in G. (LOW) e<a and e<b; if A=(...,p,t), deleting p->t and adding t->s gives the increasing three-cover A^- | (t,B) | C, with the affected source and terminal boundary ranks both strictly decreased. (HIGH) a<e and b<e; if B=(s,q,...), deleting s->q and adding t->s gives the increasing three-cover (A,s) | B^+ | C, with both affected boundary ranks strictly increased. (DOUBLE) b<e<a; then A and B are nontrivial, writing A=(...,p,t), B=(s,q,...), the four-vertex path K=(q,s,t,p) is increasing. By R998, G-V(K) has an exact two-cover U|V, so K|U|V is a spanning increasing three-cover. Thus every blocked physical joining edge has an explicit completeness-specific escape operation; only the DOUBLE rebuild is not monotone in the global boundary potential.

## Hypotheses
G is a minimum-order R888 counterexample; F is a literal spanning increasing three-cover; A,B are distinct components with terminal t and source s.

## Scope
Completeness-specific physical edge-activation theorem. Pure edge order plus R888 subclass minimality through R998; no R980, threshold matching, longest-path route, or fixed seed union.

## Applicability
Use as the main fresh-edge augmentation interface. Repeated LOW/HIGH moves admit the finite boundary potential of R997; DOUBLE produces a literal reverse-endpoint P4 and discards the old complement ordering via R998.

## Persistence
Retain F,A,B,C,t,s,e,a,b and the exact regime. In LOW/HIGH retain the removed and added edges and new cover. In DOUBLE retain p,t,s,q, K=(q,s,t,p), and a fresh exact complement cover U|V.

## Exclusions / nonclaims
Does not prove that repeated DOUBLE rebuilds terminate or that one rebuild improves any global potential. Does not assert synchronization between U|V and the discarded portions of A|B|C.

## Proof
Let F=A|B|C, with t the terminal of A and s the source of B. Put e=lambda(ts), a=L_F(t), b=U_F(s), using -infinity and +infinity at singleton boundaries. Because edge labels are distinct, e differs from every finite boundary edge incident with t or s. Therefore exactly one of the four relative-order regimes holds: a<e<b; e<a and e<b; a<e and b<e; or b<e<a. In the first regime, every inherited turn of A and B remains increasing and the only new junction is the edge t->s. At t we have a<e, and at s we have e<b, so A followed by B is increasing; with C this is a spanning two-cover, impossible in a counterexample. In the LOW regime e<a forces A nontrivial; write its last edge p->t, so lambda(pt)=a. Delete p->t and add t->s. The resulting components are the prefix A^- ending at p, the path t followed by all of B, and C. The new path begins with edge ts of label e and then, when B is nontrivial, its old first edge has label b>e; hence it is increasing. The prefix and C are inherited. Thus this is an increasing three-cover. If ordinary edge ranks are used with the singleton sentinel below all edge ranks, the new terminal boundary of A^- is the edge preceding pt, hence has rank strictly below rank(a), while the new source boundary of tB is e, strictly below b. The HIGH regime is dual: b<e forces B nontrivial; write its first edge s->q of label b. Delete s->q and add t->s. The resulting paths are A followed by s, the suffix B^+ beginning at q, and C. Since a<e, the first path is increasing; the new terminal boundary is e>a, and the new source boundary of B^+ is the next B-edge after sq, which has rank strictly above b, with the singleton sentinel above all ranks if the suffix is a singleton. Finally suppose b<e<a. Then both A and B are nontrivial. Write A=(...,p,t) and B=(s,q,...). The ordinary undirected edge labels satisfy lambda(qs)=b<e=lambda(st)<a=lambda(tp). Therefore K=(q,s,t,p) is a vertex-simple increasing P4. It is proper because C is a nonempty third component. Apply R998 to K: the induced complement G-V(K) has exact increasing path-cover number two, so choose an exact two-cover U|V. Then K|U|V is a spanning increasing three-cover containing the reverse-endpoint P4 literally. This proves the trichotomy and all stated constructions.
