# R534 — Transitive four-cell P5-free fifth vertex has alternating full matching gates

## Statement
Let X be a transitive no-P4 Strong Level-(1) four-cell. Write its three opposite-edge perfect matchings as M_R>M_S>M_L so that for distinct u,v,w in X, uvw is tight iff M(uv)>M(vw). Let d be a fifth vertex such that X union {d} has no tight Hamilton P5. Suppose an M_L-edge {t,l} is fully outgoing from d, meaning dtl and dlt are tight, and an M_R-edge {t,r} is fully incoming to d, meaning trd and rtd are tight. Let s be the fourth vertex of X. Then among the two M_S-edges {t,s} and {l,r}, exactly one is fully outgoing from d and the other is fully incoming to d. Equivalently, with A=[dts], B=[dst], C=[drl], D=[dlr], one has A=B, C=D, and A is not equal to C. In particular every P5-free fifth vertex over a transitive four-cell has a full gate in each matching class, with the middle-class gate orientation opposite on its two edges.

## Hypotheses
Strong Level-(1) boundary antisymmetry; X is a transitive matching-height no-P4 four-cell; X union {d} is P5-free; one fully outgoing M_L gate and one fully incoming M_R gate sharing t are fixed.

## Scope
Pure five-vertex local theorem; no smallest-counterexample or deletion hypothesis.

## Applicability
Use when a P5-free fifth vertex is trapped between bottom and top matching gates. It supplies the previously missing M_S full gate and allows a gate to be chosen transverse to any prescribed 2+2 matching partition of X.

## Persistence
All vertices, matching classes, and certified ordered gate turns are graph-intrinsic on X union {d}.

## Exclusions / nonclaims
Does not assert which M_S edge is outgoing without the named M_L/M_R gate choices. Does not itself produce a P5 or a cover; the conclusion is exactly the alternating full-gate structure.

## Proof
Write M_R={{t,r},{l,s}}, M_S={{t,s},{l,r}}, M_L={{t,l},{r,s}}. The matching-height rule makes trl,lrs,tsr,rts,lst,stl,slr,rlt tight. Put A=[dts], B=[dst], C=[drl], D=[dlr]. We use only P5-freeness and R3.\n\nA implies B. Suppose A holds and B fails, so tsd is tight. If sdl were tight then (r,t,s,d,l) would be a P5, since rts is tight; hence lds is tight. If rld were tight then (t,r,l,d,s) would be a P5, since trl and lds are tight; hence D=dlr is tight. If tdl were tight then (t,d,l,r,s) would be a P5, since D and lrs are tight; hence ldt is tight. But then (l,d,t,s,r) is a P5 using ldt, A=dts, and tsr, contradiction. Thus A implies B.\n\nB implies A. Suppose B holds and A fails, so std is tight. If tdr were tight then (l,s,t,d,r) would be a P5 using lst and std; hence rdt is tight. If lrd were tight then (s,l,r,d,t) would be a P5 using slr and rdt; hence C=drl is tight. If sdr were tight then (s,d,r,l,t) would be a P5 using C and rlt; hence rds is tight. But then (r,d,s,t,l) is a P5 using rds, B=dst, and stl, contradiction. Hence A=B.\n\nC implies D. Suppose C holds and D fails, so rld is tight. If sdr were tight then (s,d,r,l,t) would be a P5 using C and rlt; hence rds is tight. If dst were tight then (r,d,s,t,l) would be a P5 using rds and stl; hence tsd is tight. If sdl were tight then (r,t,s,d,l) would be a P5 using rts and tsd; hence lds is tight. But then (t,r,l,d,s) is a P5 using trl, rld, and lds, contradiction. Thus C implies D.\n\nD implies C. Suppose D holds and C fails, so lrd is tight. If tdl were tight then (t,d,l,r,s) would be a P5 using D and lrs; hence ldt is tight. If dts were tight then (l,d,t,s,r) would be a P5 using ldt and tsr; hence std is tight. If tdr were tight then (l,s,t,d,r) would be a P5 using lst and std; hence rdt is tight. But then (s,l,r,d,t) is a P5 using slr, lrd, and rdt, contradiction. Hence C=D.\n\nIt remains to show the two full M_S gates have opposite polarities. If A=C=0, then std and lrd are tight. P5-freeness of (l,s,t,d,r) forces tdr bad and hence rdt tight; then (s,l,r,d,t) is a P5, contradiction. If A=C=1, then B=D=1 by the equalities. P5-freeness of (r,d,s,t,l) forces rds bad and hence sdr tight; then (s,d,r,l,t) is a P5 using C and rlt, contradiction. Therefore A is not equal to C. Since A=B and C=D, exactly one M_S edge is fully outgoing from d and the complementary M_S edge is fully incoming. This proves the conclusion of R534 without using its extra named M_L/M_R gate hypotheses, so in particular the broader final clause is justified.
