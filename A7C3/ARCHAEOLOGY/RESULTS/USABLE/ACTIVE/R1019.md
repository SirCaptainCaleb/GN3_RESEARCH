# R1019 — Every failed four-deletion exactness instance has the fixed R881 eight-core normal form

## Statement
Let H be a hypothetical smallest Strong Level-(1) counterexample and let D be a four-vertex set such that H-D is Hamiltonian. Then D itself is exactly the four-cell X in the clean R594/R881 normal form: after choosing any z in D and a tight trimer P on D-{z}, the exact cover H-z=P sqcup Q triggers R881. Consequently D=X is a no-P4 transitive matching-height four-cell, Q=(q_0,...,q_m) with m>=6 is the Hamilton path on H-D, and with L=q_0,u=q_1,s=q_{m-1},R=q_m,N=Q[2,m-2], the eight-vertex core G_8=H[D union {L,u,s,R}] satisfies pc(G_8)=2 while H=G_8 disjoint-union N and N is a nonempty Hamilton path. Every exact two-cover G_8=A sqcup B therefore gives a literal minimum three-cover H=A sqcup B sqcup N; the aligned/crossed gate split is internal to G_8.

## Hypotheses
H is a hypothetical smallest Strong Level-(1) counterexample; D has order four; H-D has a Hamilton tight path. Use clean R3,R4,R881.

## Scope
R24-free fallback normal form for the sole unresolved |D|=4 case of R5. It does not assert four-deletion exactness; it says any failure is forced into the already-clean bounded-core long-rail geometry with the original deleted set retained exactly as X.

## Applicability
Use whenever an argument would like R5 on a four-set D but can tolerate a structured exceptional branch. Either pc(H-D)=2, or if H-D is Hamiltonian this theorem supplies the exact R881 core decomposition with D preserved as the four-cell.

## Persistence
The original four-set D is retained literally as X. The Hamilton complement path is retained as Q up to choosing its displayed Hamilton order. The four boundary Q vertices, middle rail N, core G_8, pc(G_8)=2, and internal gate phase are retained as in R881.

## Exclusions / nonclaims
Does not prove the exceptional branch impossible. Does not assert uniqueness of the Hamilton order Q or of an exact G_8 two-cover. Does not assume or conclude R24. It only compiles a four-deletion failure into the accepted R881 normal form.

## Proof
Let D be a four-vertex set such that H-D is Hamiltonian, and fix a Hamilton tight path Q on V(H)-D. Choose any z in D. By R3, the three-set D-{z} admits a tight trimer ordering; call the resulting path P. Then P sqcup Q is a literal two-cover of H-z. It is exact: if H-z were Hamiltonian, a Hamilton path on H-z together with singleton z would form a spanning two-cover of H, contradicting that H is a counterexample. Hence H-z=P sqcup Q is an exact singleton-deletion two-cover with |P|=3.\n\nThis is exactly the clean hypothesis of accepted R881. Apply R881 to this displayed failure certificate. Its underlying R594 normalization defines X=V(P) union {z}. But V(P)=D-{z}, so X=D literally. Therefore the original four-deletion set, not merely an isomorphic replacement, is the synchronized no-P4 transitive matching-height four-cell. R881 supplies a Hamilton ordering Q=(q_0,...,q_m) of the complementary rail with m>=6. Write L=q_0, u=q_1, s=q_{m-1}, R=q_m and N=Q[2,m-2]. Then N is nonempty and Hamiltonian, and for G_8=H[D union {L,u,s,R}] one has |V(G_8)|=8, pc(G_8)=2, and V(H)=V(G_8) disjoint-union V(N). Every exact two-cover G_8=A sqcup B consequently yields the literal minimum spanning three-cover H=A sqcup B sqcup N. R881 also states that the aligned/crossed middle-gate split is entirely internal to this same G_8.\n\nNo R24 statement is used. The proof starts from the literal failure of four-deletion exactness and feeds its own physical certificate into the accepted noncircular R881 reduction. The identity X=D is retained because R594 defines X from the three-vertex short rail and its deleted singleton, which here are exactly D-{z} and z. Thus any attempted use of R5 at deletion size four may be replaced by the structured alternative: either H-D has path-cover number two, or its Hamiltonian failure is confined to this fixed eight-core plus nonempty Hamilton middle-rail normal form.
