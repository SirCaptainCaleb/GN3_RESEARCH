# R1047 — Canonical D17.408 forest uses only spectator-consecutive B-B edges

**Status:** PASS
**Source:** workspace root `1789344741.326159`

## Statement

In the canonical D17.408 bad-hole construction, the spanning tight three-path forest `J` with `tau(J)=1` may be chosen so that every selected `B-B` edge of `J` is a consecutive edge of the displayed spectator path `B`.

Consequently, at the D17.411 first-positive prefix pivot

`e_r=a_{r-1,out} b_{r,in} ∈ F\J`,  `f_r=a_{r,out} b_{r,in} ∈ J\F`,

where `chi(e_r)=1` and `chi(f_r)=0`, the deleted same-side edge `f_r` is either an `X-X` edge or a genuine consecutive spectator adjacency. More precisely, if the shared physical endpoint `b_r` lies in `B`, then `f_r` is a consecutive `B`-edge; if `b_r` lies in `X`, then `f_r` is `X-X`.

## Proof

Write the displayed spectator path as

`B=(L=b_0,b_1,...,b_m=R)`.

The original D17.408 construction uses exactly five endpoint-position patterns for its source-five-set word `K_s`. In each bad-hole branch choose the cut as follows.

### Pattern `(0,1)`

Here `K_s=(L,R,x,y,z)`. The D17.408 cut removes `sR`. The selected `B-B` edges that remain are

`L b_1, b_1 b_2, ..., b_{m-2}b_{m-1}`,

all consecutive in `B`, and D17.408 gives a tight three-forest with `tau(J)=1`.

### Pattern `(4,0)`

Here `K_s=(R,x,y,z,L)`. The D17.408 cut removes `Rx`. Its selected `B-B` edges are

`b_1b_2,...,b_{m-1}R`,

again consecutive in `B`, with `tau(J)=1`.

### Pattern `(2,1)`

Here `K_s=(x,R,L,y,z)`. The unique bad hole is

`(b_{m-1},R,L)`.

Original D17.408 explicitly permits cutting either edge of this bad hole. Choose the chord `RL`, rather than the spectator edge `b_{m-1}R`. The resulting three components are

`(x,s) | (b_1,...,b_{m-1},R) | (L,y,z)`.

The sole `X|B` transition is `Ly`, so `tau(J)=1`. Every selected `B-B` edge lies on the displayed spectator rail.

### Pattern `(3,2)`

Here `K_s=(x,y,R,L,z)`. The bad hole is

`(R,L,b_1)`.

Again original D17.408 explicitly allows either hole edge to be cut. Choose the chord `RL`. The three components may be written

`(s,z) | (x,y,R) | (L,b_1,...,b_{m-1})`.

The sole transition is `yR`, hence `tau(J)=1`, and every selected `B-B` edge is spectator-consecutive.

### Pattern `(3,4)`

Here `K_s=(x,y,z,L,R)`. The D17.408 cut removes `Ls`; the `B`-only rail is

`(b_1,...,b_{m-1},R)`.

Thus every selected `B-B` edge is again consecutive in `B`, and D17.408 gives `tau(J)=1`.

These are the five exhaustive D17.408 endpoint patterns, so in all cases

`E(J[B]) ⊆ E(B)`

for the selected path edges. The sharpening introduces no extra vertex-distinctness requirement: in the two modified cases it cuts one of the two edges of the same already-valid three-vertex bad hole used by D17.408.

For the pivot statement, D17.411 proves at the first positive proper prefix that

`chi(e_r)=1`,  `chi(f_r)=0`.

The alternating edges `e_r` and `f_r` share the physical endpoint represented by `b_r`. Since `e_r` crosses `X|B` while `f_r` is same-side, if `b_r∈B` then the other physical endpoint `a_r` of `f_r` also lies in `B`; hence `f_r` is `B-B`, and the sharpening above makes it a consecutive spectator edge. If `b_r∈X`, same-sidedness instead gives `a_r∈X`, so `f_r` is `X-X`. These cases are exhaustive.
