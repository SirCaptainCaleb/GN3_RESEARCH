# R776 — Internal-trimer puncture of a P5 exposes both endpoints or selects the endpoint chord

## Statement
Let H be a finite boundary tournament with pc(H)>2, and let J=(j_0,j_1,j_2,j_3,j_4) be a proper vertex-simple tight P5. Put D={j_1,j_2,j_3}, E=V(H)\\V(J), and let T be any literal exact two-cover of H-D. Then exactly one of the following structural regimes holds. (DUAL-EXTERIOR) The endpoint chord {j_0,j_4} is not selected in T. Then T contains a selected state {j_0,a} with a in E and a selected state {j_4,b} with b in E; thus both P5 endpoints simultaneously have current exterior crossings in the same exact cover T. (ENDPOINT-CHORD) The state {j_0,j_4} is selected in T. Then at least one of j_0,j_4 also participates in a selected state to E. More precisely, the three R508 applications giving this are: apply R508 with deletion D, absorbable singleton S={j_0}, and tight recompletion path J_L=(j_0,j_1,j_2,j_3), forcing a selected state from j_0 to either j_4 or E; apply R508 with S={j_4} and J_R=(j_1,j_2,j_3,j_4), forcing a selected state from j_4 to either j_0 or E; and apply R508 with S={j_0,j_4} and recompletion path J itself, forcing a selected state from the endpoint pair to E. Consequently the only way either endpoint can avoid a true exterior neighbor is for the two P5 endpoints themselves to be selected adjacent, and even then the other R508 obligation forces a true exterior crossing at one endpoint. In a hypothetical smallest counterexample, accepted R4 supplies such an exact two-cover T because the deleted internal trimer D is a proper tight path.

## Hypotheses
Finite boundary tournament H with pc(H)>2; J is a proper vertex-simple tight P5; T is a supplied exact two-cover of H-{j_1,j_2,j_3}. For the unconditional smallest-counterexample corollary, use accepted R4. Uses accepted R508.

## Scope
Order-free generic P5 recompletion theorem. No crossed frame, sign machinery, R5,R168,R169,R224,R533,R350,generic R358,R176,R436,R312,capture,payment,Reverse Ear,or computation.

## Applicability
Use whenever a role-labelled P5 has important physical endpoints. It strengthens pending R769 before any R3 classification: first inspect whether the endpoint chord is selected. If not, both endpoints have simultaneous exterior crossings in one exact middle-trimer-deletion cover. If yes, retain the selected endpoint chord plus the forced exterior crossing. In the R775 depth-two P5 J=(q_2,q_1,x,q_{m-1},q_{m-2}), the ENDPOINT-CHORD branch is the selected long inward state {q_2,q_{m-2}}, while DUAL-EXTERIOR gives simultaneous current crossings at both inward anchors in H-{q_1,x,q_{m-1}}.

## Persistence
Retain J,D,the exact cover T, the endpoint chord selected/not-selected bit, both singleton R508 crossing certificates, and the endpoint-pair R508 exterior crossing certificate. In DUAL-EXTERIOR retain one exterior neighbor at each endpoint. In ENDPOINT-CHORD retain the selected chord and at least one endpoint-exterior selected state. All selected states are T-relative.

## Exclusions / nonclaims
Does not classify the directions or polarities of the selected endpoint crossings. Does not assert both endpoint-exterior crossings are distinct, lie on different rails, or by themselves close H. In the ENDPOINT-CHORD branch it does not assert which endpoint has the additional exterior neighbor. Does not turn the selected endpoint chord into a spanning path. Does not require both rails of T to remain nontrivial after deleting an endpoint.

## Proof
Let W=V(H)\\D. Since J is proper, E=V(H)\\V(J) is nonempty. First apply accepted R508 with deletion D, S={j_0}, and Q=J_L=(j_0,j_1,j_2,j_3). The path Q is tight and has vertex set exactly D union {j_0}; hence T selects a state from j_0 to W\\{j_0}. The only surviving J-vertex besides j_0 is j_4, so this neighbor is either j_4 or a vertex of E. Dually, applying R508 with S={j_4} and Q=J_R=(j_1,j_2,j_3,j_4) forces a selected state from j_4 to either j_0 or E. Third, apply R508 with S={j_0,j_4} and Q=J itself. Since V(J)=D union S and E=W\\S is nonempty, T contains a selected state joining one endpoint in {j_0,j_4} to E. If the endpoint chord {j_0,j_4} is not selected, the first singleton obligation cannot terminate at j_4 and therefore gives j_0-E, while the second cannot terminate at j_0 and gives j_4-E. This is DUAL-EXTERIOR. If the endpoint chord is selected, the third application independently forces an endpoint-E state, giving ENDPOINT-CHORD. The two regimes are exhaustive. In a smallest counterexample, accepted R4 supplies an exact two-cover of H-D because D is a proper tight trimer. This proves the theorem.
