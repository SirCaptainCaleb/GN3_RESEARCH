# R949 — Separated insertion barriers carry an increasing rail corridor and an exact detour inequality

## Statement
Let P=(p_0,...,p_m) be an increasing path in an edge-ordered complete graph and let x,y be vertices outside P that are not insertable into any internal gap of P in the displayed order. If their canonical R895 barriers satisfy beta(x)=i<j=beta(y), then (x,p_{i+1},p_{i+2},...,p_j,y) is an increasing path. Consequently, if an increasing path Q disjoint from P contains x,y consecutively and its adjacent outer path edges (when present) lie respectively below the first corridor edge and above the last corridor edge, replacing xy by this corridor gives an increasing path of order |Q|+(j-i). If P is globally longest, every such valid detour satisfies |Q|+(j-i)<=|P|. In particular, beta(x)=0 and beta(y)=m-1 force (x,p_1,...,p_{m-1},y) to be another path of order |P|.

## Hypotheses
Pure edge-ordered complete graph setting; P increasing; x,y outside P and noninsertable into P; beta is the accepted R895 least-right-feasible barrier.

## Scope
Pure support-exchange lemma for longest-path complement investigations.

## Applicability
Use to turn strict barrier separation into a whole increasing corridor through P, rather than only the one-witness cross turn. The detour form supplies exact obstructions to cooperative exchanges with complementary paths.

## Persistence
Retain the adjacent-barrier case separately from the wider-gap chain, the exact corridor vertex list, and the detour length increment j-i.

## Exclusions / nonclaims
Corridors cannot in general be concatenated through an intermediate exterior vertex: the canonical barrier inequality there is reversed. This lemma does not imply that sorting exterior vertices by beta is itself an increasing path, and does not prove the longest-complement conjecture.

## Proof
Write e_k=p_kp_{k+1}, so e_0<...<e_{m-1}. Put i=beta(x)<j=beta(y).

If j=i+1, accepted R895 says that strict barrier separation is witnessed at p_{i+1} by
x p_{i+1} < p_{i+1} y.
Hence (x,p_{i+1},y) is increasing.

Assume j>=i+2. Right-feasibility at gap i gives
x p_{i+1} < e_{i+1}.
The displayed rail is increasing, so
e_{i+1}<e_{i+2}<...<e_{j-1}.
The R895 propagation argument gives left-feasibility at the canonical gap j of y, hence
e_{j-1}<p_j y.
Combining these inequalities gives
x p_{i+1}<e_{i+1}<...<e_{j-1}<p_j y,
which is exactly the edge-label sequence of
(x,p_{i+1},p_{i+2},...,p_j,y).
Thus the corridor is increasing in all cases.

Now let Q be an increasing path disjoint from P containing the consecutive edge x->y. If x has a predecessor on Q, let a be that preceding Q-edge label; if y has a successor, let b be the following Q-edge label. Suppose every present outer seam is favorable, namely a<x p_{i+1} on the left and p_j y<b on the right. Replace the single edge xy of Q by the corridor. The old Q inequalities, the two assumed outer inequalities, and the corridor inequalities just proved show that the resulting path is increasing. It is vertex-simple because Q is disjoint from P, and it gains exactly j-i vertices of P, so its order is |Q|+(j-i).

If P is globally longest, no increasing path has order exceeding |P|, hence every valid detour satisfies |Q|+(j-i)<=|P|.

Finally, if i=0 and j=m-1, the corridor is
(x,p_1,...,p_{m-1},y),
which has 2+(m-1)=m+1=|P| vertices. It is therefore another path of the same order as P, and if P is globally longest then so is this corridor path.
