# R1042 — Arbitrary insertion oscillation and the common prefix-cut backbone

**Status:** PASS
**Source:** G39 workspace barrier root; durable development `A7C3/WORKSPACE/two-vertex-extension-barrier.md`

## Statement

Let `B=(b_1,...,b_m)` be a tight displayed Hamilton path in the R3 comparison abstraction.

1. For every subset `I⊆{2,...,m-2}` there is an R3-compatible comparison orientation and an outside vertex `x` such that insertion of `x` after `b_i` preserves tightness exactly for `i∈I`. Hence no universal interval, one-crossing, or first-loss/last-gain theorem for one-vertex insertion follows from `R3 + B tight` alone.
2. Fix `B` and an outside vertex `v`, and let `s` vary over companion vertices. In the B-order-preserving prefix automaton on `B∪{v,s}`, the positive-reachability region before `s` has been consumed is independent of `s`. Consequently, whenever `H[B∪{v,s}]` is nonHamiltonian, the canonical B-ordered failure cuts for different companions share exactly the same `s`-free prefix-cut backbone; companion-specific cut behavior can begin only on a transition that consumes `s` or after `s` has already been consumed.

The first item is only an R3-level fence and does not assert realization of the full live source-frame packet. The second item is a certificate for the B-order-preserving Hamilton-word subproblem; full nonHamiltonicity implies this restricted failure, but the converse is not claimed.

## Proof

Write `e_i={b_i,b_{i+1}}`. For every internal `b_j`, prescribe

`e_{j-1} -> {b_j,x} -> e_j`.

Together with the old path comparison `e_{j-1}->e_j`, this is a consistent transitive orientation in the local comparison tournament at `b_j`. For insertion after `b_i`, all old B-turns persist and the two outer new comparisons are already positive, so the inserted word is tight exactly when

`{x,b_i} -> {x,b_{i+1}}`.

These consecutive comparisons lie in the local tournament at `x` and can be oriented independently for the chosen consecutive pairs. Thus any prescribed success set `I⊆{2,...,m-2}` occurs in an R3-compatible comparison orientation.

For the second item, form the acyclic B-ordered prefix automaton whose state records the number of B-vertices consumed, the consumed subset of `{v,s}`, and the last at most two vertices. A transition appending a new vertex is positive exactly when the new turn is tight. Let `R_s` be the positive-reachable state set.

Restrict to states in which `s` has not been consumed and to transitions that do not append `s`. This induced automaton is exactly the one-outside-vertex automaton `A(B;v)`, independent of the identity of `s`. A path ending at an `s`-free state cannot have consumed `s` earlier, because vertices are only added and never removed. Hence

`R_s ∩ A(B;v) = R_0`

for every companion `s`, where `R_0` is the positive-reachability region of `A(B;v)`. Therefore the outgoing cut restricted to transitions between `s`-free states is the same cut `δ⁺(R_0)` for every companion. Any difference must occur when appending `s` or after `s` has been consumed.

If the full induced subsystem `H[B∪{v,s}]` is nonHamiltonian, then in particular no B-ordered Hamilton word exists, so this canonical restricted cut is available.

## Scope

This result forbids using generic ordered-gap monotonicity as a theorem of R3. It replaces that nonexistent structure with an exact shared prefix-cut certificate for the B-ordered subproblem. Any stronger alignment among several companions must come from additional source-frame structure rather than from R3 and the displayed path alone.
