# R17 — Gain minus cycle debt

## Statement

For any compatible inserted family, actual path-cover improvement is raw exchange gain minus the number of physical tight-cycle components created. A physical tight cycle is constructive, not contradictory; open one selected state on each cycle.

## Proof
Let the initial spanning path cover have n fixed vertices and q path components. Each path component on m vertices contains exactly m-1 selected adjacent states, so the whole cover has n-q selected states. Perform any compatible inserted-family exchange in the project sense: add the inserted selected states and remove its complete blocker set, preserving the local degree/compatibility conditions so every connected component of the resulting selected-state system is either a vertex-simple path or a physical tight cycle. Let g be the raw exchange gain, namely the number of inserted selected states minus the number of removed selected states. Before cycle opening the new system therefore has n-q+g selected states. Suppose it contains exactly c cycle components. On each physical tight cycle, remove any one selected state. Removing one state opens that cycle into a vertex-simple tight path and does not alter any other component. After opening all c cycles, the resulting spanning system is a genuine path cover with n-q+g-c selected states. Since a spanning path cover with q' components has exactly n-q' selected states, we have n-q'=n-q+g-c, hence q-q'=g-c. Thus actual path-cover improvement equals raw exchange gain minus the number c of physical tight-cycle components created. In particular a physical tight cycle is constructive bookkeeping debt rather than a contradiction: one selected state pays exactly one unit to open it. This is the full R17 identity.
