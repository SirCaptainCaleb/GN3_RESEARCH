# R1031 — Three parallel source trimers force a Hamilton P5

## Statement
Let `a,c,p,q,r` be five distinct vertices in a Strong Level-(1) boundary tournament. If

    (a,p,c), (a,q,c), (a,r,c)

are tight, then the induced subsystem on `{a,c,p,q,r}` has a tight Hamilton path of order five.

## Scope
This uses only boundary antisymmetry R3 and distinctness. It does not use minimality, R24/R5, the old source two-cover, the spectator path, or any D17 ancestry statement.

## Proof
For distinct `x,y in {p,q,r}`, write

    x ->_a y  iff  (x,a,y) is tight,
    x ->_c y  iff  (x,c,y) is tight.

By R3, each relation is a tournament on `{p,q,r}`.

If distinct `x,y,z` satisfy `x ->_a y ->_c z`, then

    x,a,y,c,z

is a tight Hamilton P5: its middle turn `(a,y,c)` is one of the three hypotheses.

Assume for contradiction that no tight Hamilton P5 exists. Then there is no such mixed chain.

If `T_a` were transitive, relabel its vertices so

    x ->_a y,  y ->_a z,  x ->_a z.

Avoiding `x,a,y,c,z` forces `z ->_c y`, while avoiding `x,a,z,c,y` forces `y ->_c z`, contradicting that `T_c` is a tournament. Hence `T_a` is a directed 3-cycle. Relabel so

    p ->_a q ->_a r ->_a p.

Avoiding the three mixed-chain P5s then forces the opposite `c`-cycle

    r ->_c q,  p ->_c r,  q ->_c p.

Still assuming no Hamilton P5, inspect the six words

    a p c r q,
    a q c p r,
    a r c q p,
    p q a r c,
    q r a p c,
    r p a q c.

In each word the first two required turns are already tight from the source hypotheses and the two displayed cycles. Therefore the last turn must be bad; applying R3 to its complete reversal forces, respectively,

    (q,r,c), (r,p,c), (p,q,c),
    (a,q,p), (a,r,q), (a,p,r).

Now inspect

    a p r c q,
    a q p c r,
    a r q c p,
    p a q r c,
    q a r p c,
    r a p q c.

The same reasoning, using the turns just forced, yields

    (c,r,p), (c,p,q), (c,q,r),
    (r,q,a), (p,r,a), (q,p,a).

At this point only three source-only reversal bits are relevant. Write

    u = [(q,p,r) is tight],
    v = [(p,q,r) is tight],
    w = [(p,r,q) is tight].

For each of the eight values of `(u,v,w)`, the indicated pair of candidate words has every required turn already certified except one pair of complete reversals:

    000:  a c q r p   |   r p q c a
    100:  c a r q p   |   q p r a c
    010:  a c p q r   |   q r p c a
    110:  a c p q r   |   q r p c a
    001:  c a p r q   |   r q p a c
    101:  c a p r q   |   r q p a c
    011:  a c r p q   |   p q r c a
    111:  c a q p r   |   p r q a c.

For example, in the `000` row the only undecided turns are `(a,c,q)` and `(q,c,a)`, which are complete reversals. The same holds row by row. R3 therefore makes exactly one undecided turn tight in each row, so one word in the relevant pair is a tight Hamilton P5. This contradicts the assumption that no Hamilton P5 exists.

Hence `{a,c,p,q,r}` always has a tight Hamilton P5. QED.

## Live source-frame consequence
In the retained source frame, `(A,s,C)` is tight for all `s in {p,q,r}`. Therefore

    S={A,C,p,q,r}

has a Hamilton P5. Since `B union {v}` is disjoint from `S`, any Hamilton path on `H[B union {v}]`, in any order, together with this P5 would be a spanning two-cover of `H`. Thus in a hypothetical counterexample the induced subsystem `H[B union {v}]` must be nonHamiltonian.
