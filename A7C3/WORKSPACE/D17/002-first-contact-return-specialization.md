**Workspace:** D17
**State:** established

**Summary:** R333-R345 preserve the ancestry-rich predecessor of the universal return theorem. The first-contact-specific return program begins with current `J=(p,x,z)`.

R333 deletes p or z separately. Any exact two-cover must cross from the surviving role-bearing boundary dimer into the residual rails; otherwise that dimer is either split into too many components or becomes an isolated two-vertex rail, contradicting the deletion rail floor.

R334 deletes the **outer pair** `{p,z}`. In every exact return, x lies on a rail of order at least three. Therefore x is either a rail endpoint or internal in a selected residual star `(a,x,b)`. This endpoint/internal dichotomy is the basic return normal form.

R336 handles the endpoint branch. If the return rail begins `x,u,v,...`, splice the current source trimer before x. The resulting candidate spanning two-cover has exactly two uncertified turns. Since H is a counterexample, at least one is bad, and its exact reverse yields a literal two-hole mate clause. The reversed endpoint orientation gives the dual clause.

R337 handles both regimes in one theorem. If no exact return exposes x, then x is internal in every return; deleting x from one such return gives a literal three-cover of the same residue `H-J` that the source currentization covers by two rails. Hence R159 yields a balanced pair. R338 strengthens the all-internal branch: every direct attachment of x to either end of either source residual rail is bad, else it would itself be an endpoint return. Their four exact reversals form a four-way x-shield.

R344 turns one long source residual rail into an endpoint floor. The two reverse terminal dimers supplied by R338 have opposite polarities with common witness x; the central carrier interval meets each once, so R174 refunds them to singleton supports on the two physical endpoints of that rail. R345 uses x as the same middle of a new tight turn on those two floor endpoints and invokes R249, giving an alternative fixed-turn lineage. This “target rotation” is valid but does not provide a global monotone across rotations.

R339/R340/R343 instead keep the original first-contact turn. Historical accepted R339 injects J into the fixed-turn clock through the old captured-middle interface R92 and therefore remains usable but not fully reconstructible. Pending revision R922/P994 gives a cleaner modern route: for any proper tight J=(p,x,z), accepted R654 produces closure or a genuine ancestry-bearing floor exactly on the physical outer pair {p,z}; accepted R249 then enters the SAME J with b=x at Psi_J=(2,0,0). Any middle-x capture/first-contact ancestry remains historical but is correctly not credited as an R172 endpoint capture. This removes R92 from the fixed-turn entry itself. R340 identifies the target-aligned floor with the physical outer pair `{p,z}` and attaches the exact outer-pair return normal form there. R343 reduces the mirror branch to an explicit fixed-turn exit or that target-return cell. Until R922 is reviewed, historical R339 remains the canonical exact claim, while the document should prefer the R654+R249 construction for dependency-clean research.
