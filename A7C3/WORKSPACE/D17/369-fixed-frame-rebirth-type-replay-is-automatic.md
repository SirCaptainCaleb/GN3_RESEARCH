# Fixed-frame rebirth types are replayable by construction; certificate novelty is not a bottom rank

**Workspace:** D17
**State:** established
**Key:** `fixed-frame-rebirth-type-replay-is-automatic`

**Summary:** Fix an old endpoint pair E, one prescribed exact H-E frame F, an internal middle r, and one selected incidence e at r. The raw R434 endpoint certificate extracted from (F,r,e) is a graph-intrinsic function of the same physical turn/incidence data. After any hypothetical nonclosing flat payment return to an ancestry-bearing singleton floor, accepted R1022 permits choosing the same physical pair E, the same exact frame F, and the same internal middle r again. Repeating the same incidence e therefore reproduces the identical oriented support, polarity, and sign witness. Any retained fossil paired with that endpoint certificate is likewise re-exhibited as the same PAYABLE-FOUR type. Thus a theorem forbidding a second occurrence of the same support/orientation/witness/frame-slot birth type cannot hold merely from certificate identity: repetition is available by construction whenever the flat returns themselves exist. A finite ledger of first-seen birth types is therefore not a well-founded bottom potential. Bottom extinction must instead use a payment-sensitive datum that cannot be reset by R1022, or compile the entire fixed-frame replay reservoir into a static contradiction. This is a strategy fence, not an existence claim for an infinite flat-return lineage.

### 1. Fixed frame and slot
Fix the old physical endpoint pair E={a,c}, one literal exact pair-deletion frame F=H-E=U|V, an internal frame vertex r, and one chosen selected predecessor or successor incidence e at r. Retain the tight outer turn J_r on E+{r}. Applying accepted R434 to this same literal frame/turn/incidence tests one fixed physical three-set. Hence its raw endpoint output C(F,r,e), including oriented dimer support, polarity, and exact sign witness, is graph-intrinsic. Re-running the same test does not create a different certificate type.

### 2. Flat return can deliberately restore the same test
Suppose some PAYABLE-FOUR birth is paid and, outside TWO-COVER or strict old-E descent, the continuation reaches an ancestry-bearing singleton floor and returns rank-flat to E. Accepted R1022 explicitly permits choosing any physical target pair and an exact pair-deletion cover of that target pair; in particular one may prescribe the same E and the same exact frame F used before the excursion. If r is internal in F, choose the same r again.

This is exactly the controlled reuse already employed in SV81686. After reentry, select the same incidence e. Since H, F, r, e and the relevant tight turn are unchanged physical data, R434 reproduces the same certificate C(F,r,e) with the same support order, polarity, and witness.

### 3. The same PAYABLE-FOUR type can therefore be re-exhibited
Let T be any separately retained historical signed fossil physically disjoint from C(F,r,e) with opposite polarity, so that B=T|C(F,r,e) is a PAYABLE-FOUR certificate. Historical graph-intrinsic facts survive the excursion in the R514/SV57138 sense. On the flat return of Section 2, the same T and the replayed C(F,r,e) re-exhibit the identical physical/witness PAYABLE-FOUR type B.

No simultaneous currentness of paid descendants is asserted. This is only a statement that the source certificate type is statically reproducible from the same prescribed frame slot.

### 4. Consequence for bottom-rank design
Therefore certificate novelty is not a well-founded rank at the flat bottom. In particular, one cannot prove in this generality that a non-source PAYABLE-FOUR type, even when enriched by exact support order, polarity, sign witness, old E, and fixed source-frame slot, occurs at most once in distinct flat generations. Conditional on the existence of those flat returns, R1022+R434 can reproduce that type deliberately.

Likewise, finiteness of the physical certificate alphabet does not by itself force progress when a type repeats: exact replay may simply be a re-reading of the same graph-intrinsic turn. Historical R443 already fenced the same issue by stating that a finite same-frame packet reservoir does not itself imply no replay.

Thus any genuine bottom extinction theorem must do one of two things: (i) use a payment-sensitive coordinate not resettable by choosing the same R1022 frame/slot, or (ii) avoid generational novelty altogether and derive a static contradiction from the finite common-parent reservoir of graph-intrinsic frame certificates.

### 5. Scope fence
This section does not assert that an infinite flat-return lineage exists, nor that a particular R514 branch can always be repeated. It only rules out birth-type novelty itself as the reason such a lineage terminates. A separate consumer may still show that paying B cannot return flat, or that the static reservoir already two-covers H. R24 and R5 are unused.
