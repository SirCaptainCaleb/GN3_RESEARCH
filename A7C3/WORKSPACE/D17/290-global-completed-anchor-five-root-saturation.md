# Completed endpoint anchors are globally spent; every five-root fan saturates one common physical center

**Workspace:** D17
**State:** established
**Key:** `global-completed-anchor-five-root-saturation`

**Summary:** A completed R434 endpoint certificate is attached to the physical vertex, not to its old endpoint pair. If a later R434 incidence at any other pair containing the same vertex produces a new endpoint-anchored dimer, the old signed singleton and new dimer trigger R436 immediately; hence completed anchors are globally spent and every quiet completed endpoint episode anywhere enlarges one finite global ledger A_*. Applying this to SV58280 sharpens its five-root fan: the fully reconstructed R176 proof uses the same selected cross-state and the same xi-anchored signed support for all five spare roots d in K. Each branch can be paid and steered to a common-center floor {d,xi}. From that floor an xi-anchored R434 channel either closes, is explicitly nonquiet if xi was globally completed, or completes xi once and strictly enlarges A_*. Therefore in any reconstruction-closed family at minimal global completed-anchor budget, all five SV58280 root choices are forced into explicit nonquiet geometry at the same physical center xi. This removes endpoint-pair switching as a source of quiet rank-flat recurrence, but does not yet consume the five nonquiet packets.


### 1. Completed endpoint history is pair-independent

Let H be a hypothetical smallest Strong Level-(1) counterexample. Call a physical vertex e GLOBALLY COMPLETED if some earlier selected-incidence episode of accepted R434, at some aligned endpoint pair E containing e and some proper middle, completed its designated R42-protected return to an aligned both-singleton floor with e retained as the historically signed singleton coordinate. Retain the complete R434 certificate, in particular the graph-intrinsic historical signed singleton (e).

Write

  A_* = { e : e has a globally completed certificate }.

No endpoint pair or middle is part of the definition of membership in A_*.

Suppose later we work at ANY aligned endpoint pair E'={e,f} containing the same physical vertex e, with any admissible internal middle b'. Reconstruct the e-channel of accepted R434 in the current exact H-E' frame. Unless H closes during actualization, that channel produces a genuinely later nontrivial signed dimer D_e containing the physical anchor e. The old completed certificate supplies the signed singleton (e). Apply accepted R436 to the old singleton and the later proper path D_e. The exact-singleton stationary-replay fence does not apply because D_e has order two. Hence the new episode is explicitly nonquiet: R436 gives strict path growth, strict growth of the later path, a proper tight cycle, or reverse-contact/reversal geometry.

The old endpoint partner and the old middle never enter this comparison. Therefore

  GLOBAL-SPEND: once e is completed at one endpoint pair, e is spent against every later R434 incidence at every endpoint pair containing e.   (GA.1)

Conversely, if e is not in A_* and an R434 e-channel completes quietly, its protected return ends with the signed singleton (e), so append e to A_*. Thus every completed quiet endpoint episode anywhere in the project strictly enlarges A_*.

Consequently

  epsilon_* = |V(H)|-|A_*|                                      (GA.2)

is a finite global quiet-episode budget. Endpoint-pair switching and middle rebasing cannot reset it. This does not consume the explicit R436 geometry.

### 2. The SV58280 five-root fan has one root-independent R176 support

Retain the exact source frame of SV58280. Thus K is one physical Hamilton P5, W=V(H)-K, R_K is the punctured source cover of H[W] with at least three components, T_K is an at-most-two-path cover of H[W], and T_K selects one fixed cross-state

  xi eta

whose endpoints lie in distinct R_K-components. Fix the endpoint xi and its R_K-component R_xi.

Inspect the fully reconstructed proof of accepted R176 before choosing the spare root d in K.

If R_xi is nontrivial, choose once and for all the literal R_K-neighbor p of xi used by R176. The single R3 test on {p,xi,eta} has one fixed outcome, independent of d:

- if (eta,xi,p) is tight, the oriented dimer S_xi=(xi,p) is head-signed by eta;
- if (p,xi,eta) is tight, the oriented dimer S_xi=(p,xi) is tail-signed by eta.

In either orientation the signed physical anchor of S_xi is xi. For every d in K, using d as the R176 spare vertex pairs this SAME signed dimer S_xi with the opposite-polarity singleton (d).

If R_xi is the singleton component (xi), the same selected cross-state xi eta makes (xi) one fixed signed singleton support, and for every d in K R176 pairs it with the opposite singleton (d).

Therefore all five SV58280 root alternatives share, before any payment is chosen,

  K, R_K, T_K, xi eta,
  and one fixed xi-anchored signed support S_xi of order one or two.       (GA.3)

Only the spare singleton root d varies over K.

### 3. Normalize every root to one common-center floor

Fix d in K. If S_xi is already singleton, the R176 birth is the ancestry-bearing floor {d,xi}. If S_xi is a dimer, apply accepted R428 with the singleton (d) fixed. Outside a spanning two-cover this reaches an ancestry-bearing both-singleton floor while preserving d. Then apply accepted R432 with prescribed target pair {d,xi}; because d is already one target coordinate, use the one-coordinate replacement branch preserving d. Outside closure this yields an ancestry-bearing floor whose physical singleton set is exactly

  {d,xi}.                                                   (GA.4)

Retain the common parent data (GA.3) as historical ancestry. Thus one source pair-deletion frame generates FIVE alternative common-center floors

  {d,xi},   d in K,                                        (GA.5)

all tied to one P5, one punctured source cover, one recompletion, one selected cross-state, and one fixed xi-anchored R176 support. This is stronger than five unrelated paid descendants; no coexistence of alternative current representatives is asserted.

### 4. Every common-center floor either spends xi once or is immediately nonquiet at xi

Fix one normalized floor {d,xi}. Accepted R429 gives an exact pair-deletion frame

  H-{d,xi}=U|V

with both rails nontrivial. Accepted R533 gives n=|V(H)|>10, so if |U|=r and |V|=s then r+s=n-2 and

  (r-2)+(s-2)=n-6>0.

Choose an internal rail vertex b. By R3 one of the two outer orientations on {d,b,xi} is a proper tight turn. In that displayed orientation, xi is one outer endpoint. Because b is internal, both selected predecessor and successor exist, so choose the R434 incidence channel anchored at xi.

There are now only three possibilities.

1. H closes during actualization or the protected continuation.
2. xi is already in A_*. Then GLOBAL-SPEND (GA.1) makes this xi-channel explicitly nonquiet immediately, independently of d and independently of the new middle b.
3. xi is not in A_*. Run the fresh-endpoint protected continuation of R434. Either it exits explicitly nonquiet, or it completes quietly and appends xi to A_*, strictly lowering epsilon_* by one.

Hence for EVERY d in K the corresponding root branch has a finite continuation

  TWO-COVER
  or explicit xi-anchored nonquiet geometry
  or strict global-anchor progress epsilon_* -> epsilon_*-1.             (GA.6)

The same physical center xi is used for all five branches.

### 5. Closed-family consequence: virtual global saturation

Let F be any nonclosing reconstruction family of ancestry-bearing checkpoints which is closed under the five SV58280 root choices, the above payment/steering normalizations, and the displayed xi-channel test. Choose within F a stratum minimizing epsilon_*.

A quiet completion at xi would strictly lower epsilon_* and leave the stratum, contradicting its minimality and closure. Therefore every one of the five common-center root choices available from the SV58280 parent frame must terminate in explicit nonquiet geometry at xi (unless H closes).

Thus literal completion of all physical anchors is unnecessary. At a minimal globally rank-flat stratum the family is VIRTUALLY SATURATED at the common center:

  five rooted return choices sharing one parent
     => five alternative explicit nonquiet xi-anchor packets.             (GA.7)

This handles the G22 fence that recurrence may occur before A_E=E. Endpoint-pair cycling cannot provide an unlimited quiet escape because completed-anchor history is global, not pair-relative.

### 6. Scope and remaining obstruction

This theorem is a family-level compression, not O4 closure. It does not claim the five nonquiet packets coexist as current representatives, and it does not yet absorb their growth/cycle/reversal outputs. Its gain is that a reconstruction-closed flat family can no longer evade saturation by changing the endpoint pair or the middle: after finitely many globally completed anchors, every SV58280 fan is forced into explicit geometry at one common physical center with one common cross-state/R176 ancestry.

The next obstruction is therefore sharper than generic portal recurrence: consume a five-way common-center nonquiet packet, preferably using the shared P5 K, the shared cross-state xi eta, and the fixed pre-payment support S_xi rather than treating the five outputs separately.
