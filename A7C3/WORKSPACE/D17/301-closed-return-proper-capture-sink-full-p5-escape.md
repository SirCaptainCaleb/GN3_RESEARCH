# Every proper all-choice capture sink leaks through the complementary P5 roots

**Workspace:** D17
**State:** established
**Key:** `closed-return-proper-capture-sink-full-p5-escape`

**Summary:** Generalize the two-root escape SV60949 to every proper sink SCC S of the all-choice P5 capture graph. Fix a in S and delete the other S-roots from any exact H-a row. Because every original K-a|E crossing has K-endpoint in S, the surviving path forest on H-S is pure for (K-S)|E. An exact two-cover of H-S exists by smallest-counterexample minimality (splitting a Hamilton cover if necessary), and R508 applied to the original Hamilton P5 K forces that cover to select a crossing ce with c in K-S, e in E. This crossing joins two components of the pure source forest. The proof of R176 run at c with spare a produces singleton a opposite a singleton/dimer signed at c; the order-two R428 descent used in SV58568 then either closes H or reaches exactly the floor {a,c}. Hence any proper sink S, of size 2,3,or4, has a lawful ancestry-bearing return through a root c outside S. Therefore a nonclosing reconstruction-closed G23 root kernel generated by K cannot live on a proper subset of K: all five P5 roots are forced. The only surviving wheel kernel is the full five-root rim together with the common hub/spoke ancestry; this is not yet full wheel extinction.

### 1. Proper sink kernel in the all-choice capture graph
Retain the Hamilton P5 K, exterior E=V(H)-V(K), and all-choice capture digraph C_K of SV60654. Assume no branch closes H. Let

  S subsetneq V(K)

be a sink strongly connected component of C_K. SV60654 gives 2<=|S|<=4. Fix any root a in S. By the sink property, for every exact H-a two-cover T and every selected K-a|E crossing of T, the K-endpoint of that crossing lies in S.                                                     (FS.1)

We show that the full legal reconstruction family necessarily escapes S through a root in K-S.

### 2. Delete the other sink roots: the source forest becomes cut-pure
Choose any exact two-cover

  T=P|Q

of H-a and delete all other sink roots S-{a}. The surviving intervals form a literal path forest

  R := T-(S-{a})

spanning

  W=H-S.                                                   (FS.2)

Put

  C=V(K)-S.

Because S is a proper subset of the five-set K, C is nonempty; E is nonempty in the SV58280/SV60333 application. Thus W=C disjoint_union E with both sides nonempty.

Every component of R is C/E-pure. If one surviving component contained vertices from both C and E, it would contain a selected adjacency ce crossing C|E. That adjacency already occurred in T and avoids S-{a}; hence it was a K-a|E crossing of the original H-a row with K-endpoint c in C=K-S, contradicting FS.1. Therefore

  every component of R lies wholly in C or wholly in E.      (FS.3)

No assumption on how many components R has is needed.

### 3. Recomplete H-S and force an outside-root crossing
By smallest-counterexample minimality R4, H-S has path-cover number at most two. If it is Hamiltonian, split one Hamilton path into two nonempty contiguous subpaths; this is possible because W contains the two nonempty sets C and E and hence has at least two vertices. Thus choose a literal spanning two-path cover

  F=F_1|F_2

of H-S.

Apply accepted R508 with deletion set D=S, absorbable block C=K-S, and carrier path Q_K=K. The hypotheses are exact: D is nonempty, C and E=W-C are nonempty, and K is a vertex-simple tight path whose vertex set is exactly D union C. Consequently F selects a physical crossing

  ce,    c in C=K-S, e in E.                               (FS.4)

By FS.3, c and e belong to distinct components of the source forest R. Therefore FS.4 is a literal current cross-state for the comparison R,F.

### 4. The crossing pays to a floor using the outside root c
Choose the spare vertex a in S, which lies outside W. Run the local P540/R176 seam construction at the C-side endpoint c of the selected adjacency {c,e}. Its direction in F is irrelevant to this endpoint-local seam test: if the R-component containing c is singleton, the automatic two-vertex path through e signs singleton c and the automatic path through spare a gives the opposite singleton sign. If that R-component is nontrivial, choose its literal neighbor p and apply R3 to {p,c,e}; exactly one polarity makes the order-two support on {c,p} signed at physical anchor c, while singleton a receives the opposite polarity from the automatic two-vertex path through e.

Thus the cross-state produces

  singleton (a) + an opposite signed support D_c of order 1 or 2,

with signed physical anchor c in K-S.                         (FS.5)

If |D_c|=1 the ancestry-bearing floor is already {a,c}. If |D_c|=2, use the exact width-two fixed-singleton descent in R428. This is the same order-two endpoint calculation isolated in SV58568: outside closure the unsigned endpoint is clipped while the signed endpoint c survives. Hence

  TWO-COVER, or an ancestry-bearing floor {a,c}, c in K-S.   (FS.6)

The retained ancestry contains T, the deleted sink set S-{a}, the pure source forest R, the exact recompletion F, and the physical outside-root crossing ce.

### 5. Proper-sink extinction
The floor in FS.6 uses one root a in S and one root c outside S. Therefore no nonclosing family closed under the legal capture/component-drop/payment reconstructions can remain supported on a proper sink S of C_K. Every proper all-choice capture sink leaks through the complementary P5 roots.

In particular:

- |S|=2 gives SV60949's third-root escape;
- |S|=3 forces a fourth- or fifth-root paid return;
- |S|=4 forces the unique fifth-root paid return.

Hence the normalized nonclosing root kernel associated with one SV58280 Hamilton P5 cannot be a proper subset of K. It must contain all five physical P5 roots.                    (FS.7)

This is the desired wheel-shortening result in a stronger form: rather than classifying rim cycles of lengths 2,3,4 separately, every proper sink kernel is eliminated by the same full-deletion recompletion argument.

### 6. Remaining full-wheel obstruction
FS.7 does not close the full five-root kernel. When S=K the complementary block K-S is empty, so the R508 escape used above disappears exactly at the full P5. The remaining G23 object is therefore sharply normalized:

  one Hamilton P5 K,
  all five roots unavoidable under reconstruction closure,
  the common SV58568/SV58856 hub-spoke ancestry,
  and pair-deletion current geometry on the rim.

The next extinction step must use the hub x, pair-partition coherence/Phi, or a global five-root gluing contradiction. Generic floor steering alone is not counted as consuming this final full-wheel state.
