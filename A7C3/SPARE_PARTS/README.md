# A7C3 Spare Parts

This directory contains deliberately rescued reusable mathematics from discarded Engines or genuinely useful results that do not belong to a surviving Engine. Spare-part identifiers use `S<N>` beginning at `S9001`.

Do not promote ordinary incremental research here merely because it passed audit. Prefer coherent Engine development. A part belongs here only when the surrounding Engine is being discarded or no coherent Engine applies, and the part is judged independently useful enough to preserve.
