# Interesting results

This directory is the curated shelf for A7C3 mathematics that is both **audited** and judged unusually important, creative, reusable, or conceptually illuminating.

A result belongs here only after a Slack `(INTERESTING)` nomination is endorsed during audit and the result receives `(PASS)` or `(PASS_ADJUSTED)`.

Typical reasons include substantial progress, repeated reuse, a strong structural principle, a creative mechanism, or a non-obvious construction/counterexample that permanently changes how a tempting route should be viewed.

Keep one canonical copy here. Do not mirror the same result under `USABLE/ACTIVE/`. If later invalidated, move it to the appropriate unusable location. If it merely becomes strategically inactive while remaining mathematically interesting, it may remain here.
