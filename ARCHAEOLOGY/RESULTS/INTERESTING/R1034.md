# R1034 — Static spectator-gate packet plus sharp source counts is insufficient

## Statement
There exists a globally edge-ordered Strong Level-(1) boundary tournament on

    {A,C,p,q,r,v,b0,b1,b2,b3}

in which all of the following hold simultaneously:

- `(A,s,C)` is tight for each `s in {p,q,r}`;
- `B=(b0,b1,b2,b3)` is a tight Hamilton spectator path;
- `X={v,p,q,r}` is P4-free and realizes the noncyclic R516 signature `11`;
- both `X union {b0}` and `X union {b3}` are P5-free;
- the universal reverse endpoint stars

      (b1,b0,x), (x,b3,b2)

  are tight for every `x in X`;
- the literal old source two-cover

      F=(b0,p,q,r,b3) | (v,b1,b2)

  is tight, has `tau(F)=3`, and contains the consecutive internal source block `p,q,r`;
- the literal three-forest

      J=(p,q,r) | (v,b3,b2) | (b0,b1)

  is tight and has `tau(J)=1`;
- `H[B union {v}]` is nonHamiltonian;
- `H[{A,C,p,q,r,v}]` is nonHamiltonian.

Therefore the displayed static conclusions of the D17.391 quiet spectator-gate frame, even when combined with the sharp physical source-frame data `tau(F)=3`, `tau(J)=1`, do not by themselves consume the one-vertex obstruction on `v`. Any successful closure must use genuinely additional information, such as dynamic/canonical ancestry that explains how the D17.421 first-loss/source-gate packet is produced, a further retained conclusion not represented here, or a stronger global smallest-counterexample consequence.

This is a fence on an abstraction. The construction is not asserted to be a smallest counterexample and does not realize the provenance assumptions that lead to the D17.391 quiet branch.

## Construction
Declare tight turns by one global strict order on ordinary edges: `(x,m,y)` is tight exactly when edge `xm` occurs before edge `my`. Use the total order

    qv < b3q < b0b1 < b0p < pr < rv < b3p < b2r < b2v < b2p
       < b3v < b2q < b1r < b1p < b1b3 < b1v < b0b2 < b1b2 < b0b3
       < b1q < b0q < b0v < b0r < Ap < pq < qr < pv < b3r < b2b3
       < Cv < Cb3 < Ar < Cr < Cp < Aq < Cq < Cb2 < Cb1 < Cb0
       < Av < Ab3 < Ab2 < Ab1 < Ab0 < AC.

Because this is a global edge order, every complete-reversal pair of turns has exactly one tight orientation, so it is an R3-compatible Strong Level-(1) realization.

## Verification
The source turns follow immediately:

    Ap < Cp,
    Aq < Cq,
    Ar < Cr.

The spectator path is tight because

    b0b1 < b1b2 < b2b3.

For `X`, take the R516 notation `(a,b,c,y)=(v,q,r,p)`. The twelve tight representatives are exactly

    vqr, vrq, qvr,
    vqp, qpv, qvp,
    prv, rpv, rvp,
    prq, rpq, pqr,

which is R516 signature `11`. Hence `X` is the noncyclic P4-free cell used by the quiet D17.391 static frame.

The universal reverse endpoint stars are immediate from

    b0b1 < b0x

and

    b3x < b2b3

for every `x in X`.

The old source rail satisfies

    b0p < pq < qr < b3r,

and the other rail satisfies

    b1v < b1b2.

Thus

    F=(b0,p,q,r,b3) | (v,b1,b2)

is a literal tight two-cover. Its selected `X|B` edges are exactly `b0p`, `b3r`, and `b1v`, so `tau(F)=3`. The source block `p,q,r` is consecutive and internal on the first rail.

Likewise `pq<qr` and `b3v<b2b3`, so

    J=(p,q,r) | (v,b3,b2) | (b0,b1)

is a literal tight three-forest. Its only selected `X|B` edge is `b3v`, so `tau(J)=1`.

Direct exact enumeration of vertex orders gives:

- zero Hamilton P4 orders on `X`;
- zero Hamilton P5 orders on `X union {b0}`;
- zero Hamilton P5 orders on `X union {b3}`;
- zero Hamilton P5 orders on `B union {v}`;
- zero Hamilton P6 orders on `{A,C,p,q,r,v}`.

The source five-set itself is Hamiltonian, for example

    A,p,q,r,C

is tight because `Ap<pq<qr<Cr`.

Hence all claimed static and sharp source-frame features coexist with the stubborn one-vertex obstruction.

## Scope and exclusions
The construction does not claim to satisfy:

- smallest-counterexample minimality;
- the historical provenance by which the D17.391 quiet branch was reached;
- absence or resolution of every R408-derived output that occurs during that derivation;
- the canonical D17.421 first-loss switch or its actual augmenter ancestry;
- the provisional D17.433-D17.439 ancestry conclusions as a generated chain.

Accordingly, the theorem does not refute those stronger dynamic routes. It isolates their necessity: static endpoint-gate geometry and sharp transition counts alone are insufficient.
