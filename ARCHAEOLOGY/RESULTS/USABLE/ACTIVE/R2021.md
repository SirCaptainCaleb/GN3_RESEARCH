# R2021 — Exact physical classification of a nonloop closure

**Status:** PASS
**Source:** workspace root `1789415321.282239`

## Statement

Let `N` be any literal tight directed three-forest with free split copies `a,out` and `b,in`, `a!=b`, and let `g=a->b`. Then every physical failure of the exact-two-cover-cardinality matching `N+g` is one of exactly three local types:

1. the left endpoint trimer `(x,a,b)` is bad when `x->a` exists in `N`;
2. the right endpoint trimer `(a,b,y)` is bad when `b->y` exists in `N`;
3. `a,b` lie on the same rail, in which case `g` closes the unique directed cycle consisting of that rail and `g`.

If `a,b` lie on distinct rails, cycle failure is impossible. Any bad endpoint trimer is converted by R3 into the corresponding tight reverse trimer `(b,a,x)` or `(y,b,a)`.

## Proof

Because `a,out` and `b,in` are free in the path-forest matching, `a` is a rail terminal and `b` a rail source. Adding `g=a->b` changes no old adjacency except at those two endpoints.

Hence every newly created selected length-two walk must be `(x,a,b)`, using the unique old predecessor `x->a` if it exists, or `(a,b,y)`, using the unique old successor `b->y` if it exists. Every old trimer was already tight in `N`. Thus these are the only possible new seam failures.

For cycles, `N` is acyclic and only `g` is new, so any new directed cycle contains `g`. Deleting `g` from such a cycle leaves a directed path from `b` to `a` in `N`. Such a path exists if and only if `a,b` lie on the same rail. Since a path forest has a unique directed path inside each rail, the resulting cycle is unique. If the endpoints lie on distinct rails, `g` simply concatenates the two rails and no cycle occurs.

Finally, when the relevant vertices are distinct, R3 converts bad `(x,a,b)` to tight `(b,a,x)`, and bad `(a,b,y)` to tight `(y,b,a)`. Degenerate endpoint cases have no corresponding seam and require no clause.
