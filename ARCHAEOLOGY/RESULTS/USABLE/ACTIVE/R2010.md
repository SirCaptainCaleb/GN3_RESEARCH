# R2010 — The first-open spectator cannot be terminal in a later OUT-v loss

**Status:** PASS
**Source:** workspace root `1789413886.871229`

## Statement

In a later non-loop OUT-`v` first-loss cell with `j>t+1`, the first-open spectator `c=b_{t+1}` cannot be terminal at `c,out` on the endpoint-truncated rail `J[B]`.

Indeed, terminality would force `c=b_{m-1}`, omission of `b_{m-1}->b_m` from `J[B]`, and `j=m`, while R1051 simultaneously makes the selected first-loss edge `f_r` exactly `b_{m-1}->b_m∈J`, a contradiction.

## Proof

Write `B=(b_1,...,b_m)` and `c=b_{t+1}`. Because the putative first loss is later, `j>t+1`, so `t+1<m` and therefore `c!=b_m`.

Audited R1049 says `J[B]` is exactly the displayed spectator path with one endpoint adjacency deleted. If the deleted edge is the left endpoint edge `b_1->b_2`, then the nontrivial rail is `b_2->...->b_m`; every `b_i` with `2<=i<m` has a selected successor. Since `c=b_{t+1}` has index at least `2` and strictly less than `m`, `c,out` is not terminal.

Thus terminality at `c,out` can only occur when the deleted endpoint adjacency is the right edge `b_{m-1}->b_m`. Then the nontrivial rail is `b_1->...->b_{m-1}`, and among vertices of index `<m` its unique terminal OUT-copy is `b_{m-1},out`. Hence `c=b_{m-1}` and `t=m-2`.

The later-loss inequality now gives `j>m-1`; since `b_j` is a spectator vertex, `j<=m`, so `j=m`.

Apply audited R1051 to the same non-loop OUT-`v` literal first-loss cell. It identifies the selected deleted same-side J-edge as

`f_r=b_{j-1}->b_j`.

With `j=m`, this is exactly `b_{m-1}->b_m`, and R1051 derives it as a selected edge of the canonical `J`. But terminality forced that same right endpoint adjacency to be the unique edge omitted from `J[B]`. Contradiction.

Therefore a putative later first loss `j>t+1` cannot escape first-open interception merely because `c,out` is terminal on the endpoint-truncated spectator rail.
