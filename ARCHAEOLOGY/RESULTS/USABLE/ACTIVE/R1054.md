# R1054 — IN-v first loss exposes a source incidence on the very next augmenter edge

**Status:** PASS
**Source:** workspace root `1789345505.369599`

## Statement

In the IN-`v` first-positive branch, the deleted same-side edge is

`f_r=t->v`

for a source spoke `t∈{p,q,r}`. Since the first-positive index is proper, the next old-`F` edge on the unique augmenter exists and is

`e_{r+1}=t->b_{r+1}`.

Moreover `b_{r+1}≠v`. Hence exactly one of the following holds:

- `b_{r+1}∈B`, so `e_{r+1}` is an immediate source gate across `X|B`;
- `b_{r+1}∈X\{v}`, so `b_{r+1}` is another source spoke and `e_{r+1}` is an immediate source-source `X-X` mate.

Thus the IN-`v` first-loss branch exposes literal source ancestry one zipper edge after the pivot, with no source-anonymous interval between them.

## Proof

R1048 gives the audited IN-`v` form of the v-rooted first-positive pivot. In this orientation

`b_r=v`

and

`f_r=a_r->v`

with `a_r=t` one of the three source spokes. Hence `f_r=t->v`.

The first-positive index `r` is a proper prefix index of the augmenting path, so `r<m`. In zipper coordinates the next old edge is therefore

`e_{r+1}=a_r->b_{r+1}=t->b_{r+1}`.

R1037 gives `d_F(v)=1` in the v-rooted sharp source frame. The old transition

`e_r=a_{r-1}->v`

already uses that unique selected old-`F` incidence at `v`. Therefore the distinct selected edge `e_{r+1}` cannot also be incident with `v`, and

`b_{r+1}≠v`.

The physical partition is `G=B disjoint-union X` with `X={v,p,q,r}`. If `b_{r+1}∈B`, the edge from the source spoke `t` crosses `X|B` and is a source gate. If `b_{r+1}∈X`, then the exclusion of `v` leaves another source spoke, so the edge is source-source `X-X`. These cases are exhaustive.
