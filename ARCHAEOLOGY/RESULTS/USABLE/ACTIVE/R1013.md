# R1013 — A single pair-deletion representative can have an empty Hamilton-extension graph while another representative escapes

## Statement
There exists an edge ordering of K_8 with global minimum edge 01 such that H=G-{0,1} is non-Hamiltonian and has the literal exact two-cover (2,3,4)|(5,6,7), while none of the four supports {0,2,3,4}, {1,2,3,4}, {0,5,6,7}, {1,5,6,7} is Hamiltonian. Nevertheless G has the spanning increasing two-cover (0,1,2)|(4,6,3,5,7). One exact total edge order is 01<07<47<45<46<37<36<25<17<35<27<26<56<67<23<15<16<05<57<14<12<04<34<02<24<06<13<03. Thus the 2x2 Hamilton-extension graph attached to one exact complementary two-cover may be empty even when the complement itself is non-Hamiltonian; representative change is genuinely necessary.

## Hypotheses
Pure exact finite edge-order example on K_8; no minimum-counterexample assumption.

## Scope
Exact finite fence for representative-descent arguments based only on the Hamilton-extension graph of one fixed pair-deletion cover.

## Applicability
Use to rule out any proof claiming that every exact pair-deletion representative has a nonempty Hamilton-extension graph. It shows that progress must range over alternative exact complementary covers.

## Persistence
Retain the exact K_8 edge order, global minimum 01, the displayed dead representative 234|567, the four failed Hamilton extensions, non-Hamiltonicity of H, and the escaping rooted two-cover 012|46357.

## Exclusions / nonclaims
Does not refute R888, the existence of a good representative, or the minimum-rail perfect-extension conjecture. It only falsifies fixed-representative nonemptiness.

## Proof
Number the displayed edges by ranks 0,...,27 in the stated order. The complement rail (2,3,4) is increasing because rank(23)=14<rank(34)=22. The rail (5,6,7) is increasing because rank(56)=12<rank(67)=13, so H=G-{0,1} has an exact two-cover. Exhaustive inspection of all 6!=720 vertex orders on H finds no increasing Hamilton path; for reference an increasing path of order five is (3,7,2,6,5), whose edge ranks are 5<10<11<12, so H is genuinely non-Hamiltonian rather than trivially short. For each of the four supports {0,2,3,4}, {1,2,3,4}, {0,5,6,7}, {1,5,6,7}, inspect all 4!=24 vertex orders; none has strictly increasing consecutive edge ranks. Thus the Hamilton-extension graph of the displayed representative (2,3,4)|(5,6,7) is empty. Finally, (0,1,2) is increasing because rank(01)=0<rank(12)=20, and (4,6,3,5,7) is increasing because rank(46)=4<rank(36)=6<rank(35)=9<rank(57)=18. These paths are vertex-disjoint and spanning, so G is two-coverable. Hence the failure is genuinely representative-specific.
