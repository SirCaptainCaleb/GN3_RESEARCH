**Key:** `historical-cross-generation-cycle-exit`

**Summary:** Valid abandoned R382/R383 show that one all-internal state already carries two incompatible diagonal payment births, so the old Kneser rotation cycle was never a completely featureless terminal residue.

R382 and R383 are valid abandoned interfaces whose useful content is an alternative way to consume the old all-internal target-rotation residue. In an R359 all-internal return state, R373 supplies two diagonal mass-four balanced pairs: one pairs the left terminal dimer of U with the right terminal dimer of V, and the other pairs the left terminal dimer of V with the right terminal dimer of U. Declare one birth historical and form the second before an unrelated reset.

If the four terminal supports are pairwise vertex-disjoint, the historical cross-generation two-pair collision theorem says the two births cannot both be quiet: the second carries a cross-generation pair interaction. If they are not pairwise disjoint, the overlap lies between terminal supports on one source rail, and historical support orthogonalization/contact-rebirth yields strict signed-support decrease or another productive support/contact output before the second birth can be normalized as an unrelated quiet pair. Thus the two diagonal channels are state-locally incompatible.

R383 applied this observation to the then-current O4 reduction R372. Its mate-clause and fixed-turn-exit outputs were already explicit; in the remaining decorated same-middle Kneser cycle, choosing any one cycle state and applying R382 produced a cross-generation interaction/descent output. Hence the cycle was not an information-free obstruction.

These claims were abandoned because later accepted fixed-turn and source-trimer consumers give cleaner and stronger exits, not because the local incompatibility argument was false. The useful residue is an alternative historical method for consuming an all-internal state. It should not be promoted back to a canonical O4 reduction, and it does not by itself prove closure.
