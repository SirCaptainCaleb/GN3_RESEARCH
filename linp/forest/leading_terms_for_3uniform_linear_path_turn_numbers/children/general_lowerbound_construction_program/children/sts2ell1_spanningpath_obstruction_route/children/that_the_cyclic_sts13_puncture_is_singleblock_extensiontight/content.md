# Human proof that the cyclic STS(13) puncture is single-block extension-tight

## Statement

Let S be the cyclic Steiner triple system on Z_13 generated by the translates of {0,1,4} and {0,2,7}. Delete vertex 0 and its six incident blocks. If any one of those six blocks is restored, the resulting 21-edge system contains a spanning 6-edge linear path.

## Body

The six blocks through 0 are
{0,1,4}, {0,2,7}, {0,3,12}, {0,5,11}, {0,6,8}, {0,9,10}.
For each restored block, the following sequence is a 6-edge linear path in the restored system:

{0,1,4}:  {0,1,4}, {1,2,5}, {2,3,6}, {6,7,10}, {7,8,11}, {8,9,12}.
Its consecutive joints are 1,2,6,7,8.

{0,9,10}: {1,2,5}, {2,3,6}, {3,4,7}, {7,8,11}, {8,9,12}, {0,9,10}.
Its consecutive joints are 2,3,7,8,9.

{0,6,8}: {1,2,5}, {5,6,9}, {0,6,8}, {7,8,11}, {3,4,7}, {4,10,12}.
Its consecutive joints are 5,6,8,7,4.

{0,3,12}: {1,2,5}, {1,10,11}, {6,7,10}, {3,4,7}, {0,3,12}, {8,9,12}.
Its consecutive joints are 1,10,7,3,12.

{0,2,7}: {1,2,5}, {0,2,7}, {6,7,10}, {4,6,11}, {3,9,11}, {8,9,12}.
Its consecutive joints are 2,7,6,11,9.

{0,5,11}: {1,2,5}, {0,5,11}, {3,9,11}, {8,9,12}, {4,10,12}, {6,7,10}.
Its consecutive joints are 5,11,9,12,10.

In each displayed sequence, direct inspection shows that every consecutive pair meets in exactly the listed joint and every nonconsecutive pair is disjoint. Thus each is a linear P_6^(3). Since a 6-edge linear 3-uniform path has 13 vertices, each path is spanning. Therefore restoring any single deleted 0-star block destroys P_6-freeness.
