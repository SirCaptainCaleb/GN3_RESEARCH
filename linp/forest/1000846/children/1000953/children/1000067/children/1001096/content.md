# Human proof of the exact six-block deletion threshold in cyclic STS(13)

## Statement

In the cyclic Steiner triple system STS(13) generated by the translates of B_1={0,1,4} and B_2={0,2,7}, at least six blocks must be deleted to destroy every spanning linear P_6, and six deletions suffice.

## Body

Let O_1 and O_2 be the two translation orbits of 13 blocks generated by B_1 and B_2.

First, O_1 contains the spanning linear path
{0,1,4},
{1,2,5},
{2,3,6},
{6,7,10},
{7,8,11},
{8,9,12}.
Its successive intersections are 1,2,6,7,8, and every nonconsecutive pair is disjoint.

Second, O_2 contains the spanning linear path
{0,2,7},
{2,4,9},
{4,6,11},
{1,6,12},
{1,3,8},
{3,5,10}.
Its successive intersections are 2,4,6,1,3. To check nonconsecutive disjointness conceptually, index the B_2-translates by t in Z_13. Two B_2-translates intersect exactly when their index difference lies in
D={2,5,6,7,8,11}.
The displayed path has index sequence
0,2,4,12,1,3.
Its five consecutive differences lie in D, whereas every nonconsecutive difference lies in the complementary nonzero set
{1,3,4,9,10,12}.
Hence it is a linear P_6. Since a 6-edge linear 3-uniform path has 13 vertices, both displayed paths are spanning.

Now let F be a set of blocks whose deletion destroys every spanning P_6. Write
p=|F∩O_1| and q=|F∩O_2|.

Translate the first spanning path by all 13 elements of Z_13. This gives 13 spanning P_6's contained wholly in O_1. Each block of O_1 occurs in exactly six of these translated paths, because the original path has six O_1-blocks and translations act regularly on O_1. Since F must meet every one of the 13 translated paths, counting incidences between F∩O_1 and these paths gives
6p >= 13,
so p>=3.

Applying the same argument to the second all-O_2 spanning path gives
6q >= 13,
so q>=3.

Therefore |F|=p+q>=6.

Conversely, delete the six blocks through any fixed point, say 0. The remaining hypergraph has only 12 vertices, whereas P_6^(3) requires 13 vertices, so it is P_6-free. Thus six deletions suffice.

Hence the exact deletion number is 6.
