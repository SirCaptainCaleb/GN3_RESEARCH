# Three-colored K3,3 copies refute the ascending-incidence rank bound

## Statement

For every t>=2 there is a finite linear 3-graph H_t with A=9t ascending edges on n=6t+3 vertices such that rank_R(N_↑)=5t+2. In particular, for t=3 one has rank_R(N_↑)=17<18=2A/3, so the conjectured bound rank_R(N_↑)>=2A/3 is false. Moreover A/n=9t/(6t+3) tends to 3/2.

## Body

Construction. For s=1,...,t let A_s={a_{s,0},a_{s,1},a_{s,2}} and B_s={b_{s,0},b_{s,1},b_{s,2}}, and add three further vertices c_0,c_1,c_2. For r,i in Z_3 put E_{s,i,r}={c_r,a_{s,i},b_{s,i+r}}. The hypergraph is linear: edges with the same r meet only at c_r, and edges with different r meet in at most one base vertex because the three color classes form the standard proper 3-edge-coloring of each K_{3,3}. There are n=6t+3 vertices and 9t edges.

All edges are ascending for t>=2. In the intersection graph, for each r the 3t edges of color r form a clique C_r, and the three hyperedges incident with each base vertex form a clique. Hence an induced path contains at most two vertices from each C_r, so every induced path has at most six vertices. For the target E_{1,0,0}, using a second component, the sequence E_{2,0,1},E_{2,2,1},E_{2,1,2},E_{1,2,2},E_{1,2,0},E_{1,0,0} is an induced path of length six; symmetries give such a path ending at every edge. Thus phi(E)=6 for every edge. Any induced six-vertex path ending at a color-r edge must use exactly two vertices of each color clique; the other color-r vertex must be consecutive to the last edge, so every longest path enters the target through c_r. Hence every edge is nonspecial with unique entrance c_r. A path ending physically at c_r with last edge of color r can use no other color-r edge, so it has length at most five; the sequence E_{2,0,1},E_{2,2,1},E_{2,1,2},E_{1,1,2},E_{1,0,0} gives length five. Therefore phi(c_r)=5=phi(E)-1 and every edge is ascending.

Rank. Restrict the incidence matrix to the 6t base-vertex rows. This is the unsigned vertex-edge incidence matrix of t disjoint copies of K_{3,3}; each connected bipartite component has real incidence rank 5, so the base rows have rank 5t. The three center rows are the indicator vectors of the three edge colors. Their sum lies in the base-row span because the sum of all base rows equals twice the all-ones edge row, while the sum of the three center rows is the all-ones edge row. Modulo the base-row span, however, the three center rows have dimension exactly two: on one K_{3,3}, a color-constant edge vector (alpha_0,alpha_1,alpha_2) belongs to the unsigned incidence row space only if alpha_0=alpha_1=alpha_2. Indeed alternating sums around the 4-cycles on {a_0,a_1}x{b_0,b_1} and its cyclic shifts give 2alpha_0=alpha_1+alpha_2 and 2alpha_1=alpha_0+alpha_2. Thus rank N_↑=5t+2.
