# Global bound for ascending edges

## Statement

Let H be a finite linear 3-graph and let A be the number of ascending edges. Then A<=3|V(H)|/2.

## Body

This is the global replacement for the refuted pointwise conjecture that every vertex is a last vertex of at most three ascending edges. The local statement is false: 830b0775567f has four ascending edges sharing one last vertex. The global bound remains consistent with all current examples. It is sharp in the three-center one-factorization family, where for large even base size N all 3N/2 hyperedges are ascending while the total number of vertices is N+3, so A/|V(H)| tends to 3/2. If the conjecture holds, then the ascending-edge accounting inequality 3m-A<=sum_v(2φ(v)-1) immediately gives m<=(2ell/3-1/2+o(1))n in the P_ell-free case; using the refined accounting with H_2 only improves this.
