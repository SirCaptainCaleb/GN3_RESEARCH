# Amortized distinct-deletion rotation closure

## Statement

Let H be a finite linear 3-graph and let P be a globally longest p-edge path. Suppose a reachable maximum-path state has a terminal vertex v with d(v)>=p+t. Then, unless the rotation component already contains Omega(t) distinct reachable terminal pairs, there is a sequence of length-preserving one-edge rotations that omits Omega(t) distinct original private vertices of P without immediately restoring more than a bounded fraction of earlier omissions. Each newly omitted private vertex that was used by a double off-v contact destroys one distinct blocker contact, converting that edge into a latent singleton exchange for any later reachable state in which its surviving contact is terminal. In particular, persistent degree excess above p should force rotation-component expansion at p-scale rather than 2p-scale.

## Body

Local accounting motivating the conjecture is exact. Fix a terminal vertex v of a globally longest p-edge path P. For incident edges f!=g_p, let s be the number having exactly one off-v contact with V(P)\\g_p, D the number having two, and U the number of vertices of V(P)\\g_p unused by all such contacts. Linearity makes the off-v contact sets pairwise disjoint, so s+2D+U=2p-2 and d(v)=1+s+D. Therefore 2(d(v)-p)=s-U. Hence degree excess over p is precisely singleton surplus over unused contact capacity. Singleton contacts give legal one-edge rotations, and two pivot vertices belonging to the same path step normally encode the same exposed terminal side, so d(v)>=p+t forces at least t active exchange locations up to boundary bookkeeping. Double-contact edges form a matching on contact vertices. A rotation replaces one old private path vertex b by a new off-path vertex. Suffix reversal alone does not generally make a blocking double exchange-compatible. The robust mechanism is deletion: if a double used b, then relative to the rotated path it loses exactly that contact and becomes a singleton-contact edge. Because the contact pairs are disjoint, deleting distinct blocker endpoints unlocks distinct incident edges. The conjecture asks for an amortized version across the rotation component: either distinct active locations already yield many reachable terminal pairs, or one can choose rotations so that many different original private vertices are omitted before substantial backtracking. Any decisive proof should compare several reachable maximum paths essentially; a one-fixed-path argument risks returning to the old 2p contact-capacity barrier.
