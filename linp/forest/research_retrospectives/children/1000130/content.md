# Major-result retrospective epoch 5

## Statement

The latest lens-free and collision progress reinforces exact-equality and route-salvage methodology, and adds one new general nudge: boundary conventions must not be mistaken for the geometric witnesses required by downstream arguments.

## Body

Evidence from the current theorem-scale wave:

- The lens-free repair matured from local salvage into a supported global chain. a78c5a025340 independently reconstructs the five-eighths switching-mass stability without endpoint lenses, while the corrected certificate-at-either-terminal reduction and class split isolate the genuine local congestion problem. This confirms the existing lesson that a failed auxiliary picture should be separated from the quantitative mechanism the theorem actually consumes.

- The U_11 collision route improved by resolving equality cases rather than merely strengthening a coarse inequality. The certified chain 867efd696575 -> 259bdff45872 -> 1b787a779ada -> 24c5513a3977 -> c9982d3355c8 turns failure of rank-sum surplus into exact half-rank configurations, rotations, source-path overlaps, and finite cut states. The newest proposed 2q-3 and 2q-4 cut results continue this pattern. This affirms the existing advice to preserve exact recurrences/equality structure and to build incompatibility relations among cheap local states.

- The audit wave exposed a recurring failure mode not stated sharply enough in the existing nudges. Several proofs treated a value assigned by definition at a boundary case as if it certified the geometric event used in the next argument. Examples included terminal contact multiplicity one for a host last edge being treated as an actual precursor contact, and internal-edge propagation being applied to a possible last host edge. Similar mistakes also arose from confusing a path's last vertex with the entrance into its last edge. These are not isolated notation errors: they systematically create false splices, false contacts, or unjustified applications of internal-position lemmas.

Promoted general advice:

Treat boundary conventions as bookkeeping, not geometric witnesses. If a definition assigns a value to a last edge, endpoint, degenerate cell, or other exceptional case by convention, split off that case before invoking a theorem whose proof needs a genuine contact, internal position, entrance, or exchange.

This advice has been added to research_nudges.

Theory of change:

Observed failure mode: a conventionally assigned boundary value satisfies the syntax of a downstream hypothesis while failing to provide the geometric witness that the downstream proof actually uses. Because the resulting statement often looks locally plausible, the error can propagate through multiple descendants.

Intervention: whenever a local definition has an exceptional boundary convention, explicitly distinguish the conventional case from the genuine geometric case before applying contact-, entrance-, internal-edge-, or exchange-based machinery.

Expected observable change: fewer audit failures caused by last-edge/internal-edge confusion, fewer descendants built on nonexistent contacts, and shorter repairs because boundary cases are isolated at the first interface.

Reversal/non-regression condition: do not turn this into gratuitous case splitting when the downstream theorem is genuinely formulated to include the boundary convention. The distinction matters only when the proof consumes additional geometry not supplied by the convention.
