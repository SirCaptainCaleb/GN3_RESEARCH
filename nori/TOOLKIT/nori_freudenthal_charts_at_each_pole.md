# Freudenthal charts at arbitrary antipodal starting vertices

## Statement

Freudenthal charts at arbitrary antipodal starting vertices

## Body

For S⊆V set A≤_S B iff A△S⊆B△S. This identifies the cube with a Boolean lattice having least vertex S and greatest vertex bar S. Every antipodal geodesic starting at S is a maximal chain in its Freudenthal triangulation. The chart change A↦A△S is a coordinate description only: it must not modify the value of a NORI coloring on actual four-vertex windows. In particular, fixing one preferred pole is not an innocent reduction for a basepoint-dependent coloring. Adapted from NOR port, freudenthal_charts_based_at_arbitrary_poles.
