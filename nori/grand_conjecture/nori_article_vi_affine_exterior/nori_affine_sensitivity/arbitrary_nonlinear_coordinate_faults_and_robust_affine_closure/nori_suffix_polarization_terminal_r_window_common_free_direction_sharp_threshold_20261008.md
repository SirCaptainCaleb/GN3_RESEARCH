# Three-terminal-window polarization is sharp: four arbitrary nonlinear terminal directions have no common free root bit

# Exact width-three limitation of the one-bit suffix-polarization mechanism

For an ordered-r-face coloring, the color at a geodesic window of r consecutive coordinate directions depends only on the physical ordered r-face, hence is independent of the starting-root bits in its r free directions. Fix a direction order with a prefix D and a terminal set of t exceptional coordinates K=(k1,...,kt). The final t ordered-r-face windows are the windows meeting K.

**THEOREM (sharp suffix-common-free-coordinate threshold).** Assume t>=1, and there are at least r−1 ordinary prefix directions before K. Then the intersection of the FREE-coordinate direction sets of ALL t terminal r-windows contains a coordinate in K IF AND ONLY IF t<=r. More precisely for t<=r it contains the first exceptional direction k1; for t>=r+1 it is EMPTY on K, because the first terminal r-window contains exactly k1 among K, while the final terminal r-window contains only k_{t-r+1},...,k_t, none of which equals k1.

For the ACTIVE ordered-three-face NORI case r=3, the last THREE exceptional windows have common free direction k1, while the last FOUR exceptional windows have NO common free direction in K. Therefore changing ONE exceptional root bit can preserve all three exceptional actual physical windows and simultaneously flip an ordinary full-exterior-parity prefix, but there is NO corresponding choice of exceptional root bit preserving ALL FOUR exceptional windows when four different exceptional directions are appended.

**Proof.** The first exceptional r-window comprises the last r−1 prefix directions followed by k1; its only exceptional free direction is k1. The final exceptional r-window when t>=r is (k_{t-r+1},...,k_t), which contains k1 exactly when t<=r. If t<=r, every one of the t terminal windows contains k1, because the first exceptional coordinate enters at the first exceptional window and cannot leave the sliding r-window until r further shifts. The assertions follow. QED.

**Interpretation.** The recent NORI proof of closure under THREE completely arbitrary nonlinear exceptional coordinate directions hinges on toggling the common free coordinate k1: all three exceptional suffix colors remain fixed as the reference-prefix bit flips, forcing an alternating three-color suffix under hypothetical failure. This is an exact algebraic property of genuine physical ordered faces, not a probabilistic artifact. When FOUR terminal coordinate directions are exceptional, no K-coordinate has this universal physical-face invariance across the four suffix colors. Thus extending the proof from three to four arbitrary exceptional COORDINATE directions requires a new multi-root/multi-coordinate polarization, a different terminal-memory decomposition, or new global topology; a direct application of the one-bit toggle cannot work. The theorem is only a LIMITATION OF THIS PARTICULAR METHOD, not a counterexample to four-fault or unrestricted NORI closure.
