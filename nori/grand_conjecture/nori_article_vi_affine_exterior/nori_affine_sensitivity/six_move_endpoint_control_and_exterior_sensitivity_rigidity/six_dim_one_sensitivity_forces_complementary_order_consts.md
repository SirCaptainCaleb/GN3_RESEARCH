# One active exterior coordinate forces constant complementary ordered faces

Statement:
Let c be an antipodal-reversal-odd binary coloring of ordered three-faces of Q_6, and assume every antipodal geodesic has at least two color changes. Fix distinct a,b,c,d,e,f. If the color C_{abc} of faces with ordered free axes (a,b,c) is sensitive to the fixed exterior bit x_d, then C_{def} and C_{dfe} are constant over all assignments of their exterior bits and have the same constant value h. Their reversal partners C_{fed} and C_{efd} are constant with value 1-h.

Proof:
For the coordinate order (a,b,c,d,e,f), write the four consecutive colors as A(x_d,x_e,x_f), B(x_a,x_e,x_f), C(x_a,x_b,x_f), D(x_a,x_b,x_c). Preceding flips are absorbed into the arguments, without affecting which variables occur. Choose (x_e,x_f)=(e_0,f_0) witnessing sensitivity of A in x_d. For every x_a,x_b,x_c choose x_d so that A=B, possible because A takes both binary values when x_d varies. The full color word is (B,B,C,D). Its assumed at-least-two changes imply B≠C and C≠D, hence B=D=1-C. Therefore D(x_a,x_b,x_c)=B(x_a,e_0,f_0) is independent of x_b and x_c. Antipodal-reversal oddness gives C_{cba}(x_d,x_e,x_f)=1-C_{abc}(1-x_d,1-x_e,1-x_f); hence C_{cba} is also sensitive to x_d. Repeating the argument with order (c,b,a,d,e,f) shows C_{def} depends at most on exterior bit x_c. It already depends at most on x_a, so it is constant. Using order (a,b,c,d,f,e), whose first and second ordered triples have the same colors A,B as before, the same argument shows C_{dfe} equals B(x_a,e_0,f_0) for all x_a; it is constant by the reversed-first-triple argument, so both constants are equal. Finally C_{rev σ}(̅y)=1-C_σ(y) turns any constant h into constant 1-h, proving the statements for (f,e,d) and (e,f,d).
