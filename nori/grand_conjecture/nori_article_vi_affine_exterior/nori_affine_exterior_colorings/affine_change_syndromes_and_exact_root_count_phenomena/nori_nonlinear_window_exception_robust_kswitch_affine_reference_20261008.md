# Robust NORI closure with one fully nonlinear exceptional ordered-face window

# Nonlinear perturbation stability of fully controllable color words: k arbitrary windows cost at most k switches

Let n>=4 and fix a direction permutation pi=(p1,...,pn). Put L=n−2 for the ordered-three-face window color-word length and m=L−1=n−3 for the number of adjacent change positions.

Let c_0 be ANY physical ordered-three-face coloring such that, as the starting cube root x ranges over {0,1}^n along direction order pi, its binary window-color change vector D_0(x)∈F2^m is SURJECTIVE onto F2^m. (The previously proved common exterior-parity affine colorings with at most THREE zeros, distributed in distinct modulo-three position chains, have this property; each target D has exactly EIGHT root witnesses.)

Let c be an arbitrary OTHER binary ordered-three-face coloring, allowed to have **NONLINEAR** dependence on all exterior face bits, with the sole requirement that the actual window color of c and c_0 agree at every root x for all except k specified consecutive-triple positions j∈E⊆{1,...,L}. The contents at those exceptional window positions can be COMPLETELY ARBITRARY Boolean functions of x; the colors need not be affine, need not be related to each other, and can come from arbitrary valid NORI ordered-face colors. The endpoint root-progress and underlying direction order are identical. The assumption is automatically meaningful for an ordered-face coloring that agrees with c_0 on the L−k ordered-triple TYPES of pi, while arbitrarily changing the other types on every exterior face. In the active NORI model one may impose the antipodal-reversal rule on their reversed types independently; the result remains valid.

**Lemma (robust binary-word skeleton).** Fix L positions and any exceptional set E of size k. There exists a binary reference word w∈{0,1}^L with the following UNIVERSAL property: every word w' that agrees with w at all positions outside E, but is arbitrary on E, has at most k adjacent bit changes.

**Proof.** Decompose the nonexceptional positions into contiguous maximal good runs and prescribe w constant within each run. Suppose two successive good runs are separated by a maximal internal exceptional block of length ell>=1. Prescribe the binary colors of the two good runs to differ by ell mod2, i.e. equal if ell even and opposite if ell odd. Along the ell+1 edges joining the last good position before the block to the first good position after the block, the number of bit changes has parity equal to the prescribed endpoint XOR, i.e. ell mod2. If all ell+1 edges changed color, their parity would instead be ell+1 mod2, impossible. Therefore at most ell of these edges can change, for EVERY arbitrary choice of the ell exceptional bits. A maximal exceptional block at the left or right boundary of the word of length ell has only ell adjacency edges touching it, hence automatically contributes at most ell changes. All edges lying completely within good runs contribute zero changes. Summing over disjoint maximal exceptional blocks gives total change count <=sum ell=k. If there are no good positions at all, every length-L word has at most L−1 < k=L changes, so the statement is trivial. QED.

**Theorem (k arbitrary nonlinear window exceptions).** Under the hypotheses, there exists a cube starting root x such that the FULL antipodal pi-geodesic of c has at most k ordered-three-face color changes. In particular, for k=1, the ACTIVE NORI ONE-SWITCH GRAND CONCLUSION HOLDS even when the exceptional ordered-three-face window is an ARBITRARY NONLINEAR function of its exterior bits.

**Proof.** Construct a reference binary word w according to the lemma. Because the baseline change-vector map D_0 is onto F2^m, there exists a cube root x for which c_0's color word equals w or its COMPLEMENT (the difference vector D uniquely determines a binary word up to simultaneous global complementation). In either case, the lemma remains valid for that reference word, since complementing all symbols preserves all differences and the combinatorial argument. At every nonexceptional position the c window color equals the c_0 reference word at this same actual root x; at exceptional positions it is arbitrary. Hence by the robust word lemma the c window word has at most k changes. The path is a full physical antipodal geodesic because pi uses every direction exactly once. QED.

**Quantitative corollary (at least eight good roots).** If every prescribed binary change vector of c_0 has exactly eight roots (as in the common exterior-parity family with at most three zeros), the selected reference pattern D(w) has eight distinct starting roots, and ALL eight yield at most k changes for c, regardless of its nonlinear exceptional window values. Thus for k=1 at least eight one-switch full antipodal pi-geodesics survive an arbitrary nonlinear corruption of one window TYPE; indeed the number of actual valid starting roots is at least eight for the chosen fixed pi.

**Interpretation and scope.** This strengthens the preceding affine perturbation/rank theorem: unlike the linear rank argument, the exceptional window functions here can have arbitrary Boolean degree and need not obey any additive exterior model. The method is a *discrete robust encoding*: a surjective control of reference switch patterns constructs a 'fault-tolerant' word whose k uncontrolled symbols cannot create more than k switches. It is a dimension-independent, explicitly root-certified class of active NORI grand closure. It does not prove the result for TWO arbitrary exceptional window types, because then the lemma gives at most two switches; a further true restriction from the 3-face geometry, antipodal symmetry, or ordering exchanges is required to force at most one.
