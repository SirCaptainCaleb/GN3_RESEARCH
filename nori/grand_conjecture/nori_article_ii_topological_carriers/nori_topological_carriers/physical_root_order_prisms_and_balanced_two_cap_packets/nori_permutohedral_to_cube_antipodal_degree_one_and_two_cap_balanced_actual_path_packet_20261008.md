# Permutohedral antipodal position map forces actual endpoint-balanced full-path packets localized to two-direction endpoint caps

THEOREM (CANONICAL CUBICAL ROOT-POSITION MAP AND REAL TWO-CAP TUCKER PACKET). Fix n>=7, an active NORI binary ordered-three-face coloring, a physical cube root x, and a selected coordinate i. Let P_n be the standard (n−1)-dimensional centrally symmetric permutohedron, whose vertices represent full coordinate orders π, and whose central reversal is π↦rev π. Let B_x be ACTUAL endpoint-balanced full geodesic direction orders π, namely their first and last ordered-three-face colors differ. The previously proved TRUE GEODESIC FACE NERVE K_x has vertex set B_x; simplices are families of actual orders in ONE COMMON PROPER permutohedral face; its free reversal involution has ind_Z2(K_x)>=n−3.
For each actual permutation π, define its projected i-EDGE POSITION in the physical cube by the (n−1)-bit vector
  v_i(π)=x restricted to [n]\{i} XOR χ_{S_i(π)},  where S_i(π)={j≠i:direction j occurs BEFORE i in π}.
This is the literal projected location of the physical i-edge on the full geodesic from root x. Under the actual antipodal reversal at the SAME root, S_i(rev π)=D_i\S_i(π), hence v_i(rev π)=complement(v_i(π)).
CUBICAL MAP. Regard each binary v_i(π) as a vertex of [0,1]^(n-1). For any proper permutohedron face H, there is a nonempty proper subset S⊂[n] occupying the first |S| positions in EVERY permutation vertex of H (the face lies inside a facet of P_n). If i∈S, pick any j∉S: j is ALWAYS after i, so the projected j-bit v_i(π)_j equals x_j throughout H. If i∉S, pick any j∈S: j is ALWAYS before i, so that projected bit equals 1−x_j throughout H. Thus all literal projected positions from permutations in H lie in one FIXED PROPER COORDINATE FACET of the cube, avoiding its interior. Consequently affinely interpolating the vertex map v_i over the simplices of the true-path face nerve K_x defines a continuous equivariant simplicial/PL map
  Φ_i:|K_x|→∂[0,1]^(n−1) ≅ S^(n−2),
with Φ_i(rev z)=1−Φ_i(z) coordinatewise. The same recipe on the face-barycentric subdivision of the FULL permutohedral boundary gives an antipodally equivariant continuous map ∂P_n≅S^(n−2)→∂[0,1]^(n−1)≅S^(n−2). By the elementary odd-degree theorem for maps between antipodal spheres of the SAME dimension, that full-boundary map has ODD topological degree (in particular it is onto).
TUCKER-BALANCED PACKET. Choose ANY set T⊆[n]\{i} of k directions with 1<=k<=n−3. Consider the k real coordinates of Φ_i(z)−(1/2,...,1/2) indexed by T. They define a τ-ODD continuous map |K_x|→R^k. Because w1(K_x/τ)^k≠0 (as k<=n−3), this odd map HAS A ZERO. Choose a supporting simplex σ of K_x at such a zero; its vertices are ACTUAL endpoint-balanced full geodesics, all belonging to one common proper permutohedral face H. By Carathéodory's theorem in R^k, at most k+1 of these vertices π_1,...,π_s suffice, with nonnegative weights α_r totaling1, to satisfy EXACTLY
  for EVERY j∈T: sum_r α_r 1_{j occurs before i in π_r}=1/2.
(The root-bit XOR x_j only complements individual coordinates and leaves centered balance unchanged.) In particular for every j∈T the selected actual path family contains BOTH a path with j before i and a path with i before j.
CRITICAL TWO-CAP LOCALIZATION. Set k=n−3 and write [n]\({i}∪T)={a,b}, the TWO leftover coordinate directions. Choose any nonempty proper common prefix support S from a facet containing their shared proper permutohedron face H. If i∉S, then every j∈S occurs before i on all selected paths, so S∩T=∅ and necessarily S⊆{a,b}, giving 1<=|S|<=2. If i∈S, then every j∉S occurs after i on all selected paths, so T⊆S and consequently [n]\S⊆{a,b}, giving n−2<=|S|<=n−1. Thus the forced ACTUAL endpoint-balanced path packet, of size at most n−2, is located in ONE of TWO RIGID CAP CHARTS:
  (EARLY) the paths have one or two COMMON FIRST coordinate directions AS AN UNORDERED SET, chosen inside {a,b}; OR
  (LATE) the paths have one or two COMMON LAST coordinate directions AS AN UNORDERED SET, chosen inside {a,b}.
All those paths share a genuine physical cube vertex at their common prefix cut, and the selected i-edge positions, being real projected physical cube-edge positions, are simultaneously balanced in all n−3 prescribed coordinates T. The topology has left exactly TWO unprescribed directions a,b, matching the rank-two terminal memory of the exact reversed-tail NORI extraction theorem.
PROOF OF ZERO: If a τ-odd R^k-valued map from K_x had no zero, normalize it to a τ-equivariant map K_x→S^(k−1). The nonzero kth power of w1(K_x/τ) would pull back from the vanishing kth power of the tautological class on RP^(k−1), contradiction. The rest follows from explicit physical prefix supports and Carathéodory.
LIMITATION. The cap memory supplied by a shared proper permutohedron facet is an UNORDERED one- or two-direction prefix/suffix SUPPORT, not yet the REVERSED ORDERED TWO-TAIL label that extracts a full NORI one-switch path. The balancing condition is a convex combination of real path-position BIT labels, not a claim that one path uses the complementary position of another or that the path interior colors align. The necessary new combinatorial theorem is a two-cap orientation/order refinement: turn one such genuinely witnessed balanced packet into either a one-switch full path or two same-root monochromatic branches with complementary supports and reversed ordered tails. Nothing in the statement assumes that missing refinement.
