# Exact middle-belt cube geodesic iff complementary-odd uniform-hypergraph tight path through 2k−1 distinct directions

# Exact middle-belt path ↔ Johnson-geodesic ↔ tight uniform-hypergraph path

Let n=2k >=4 and let L be the collection of k-subsets S of [2k], identified with cube vertices of Hamming rank k. Choose ANY binary vertex label lambda:L→F2 satisfying lambda(S^c)=1+lambda(S), with complement taken inside [2k]. Define a genuine antipodally odd coloring of all the cube EDGES in the three-level central belt (vertex ranks k-1,k,k+1): for every edge joining a rank-k vertex S to a rank-(k-1) or rank-(k+1) vertex, assign it the color lambda(S). This is well defined since each such edge has precisely one rank-k endpoint. Its antipodal edge joins the complementary rank-k vertex S^c to the opposite outer rank, so its color is 1+lambda(S). Extend outside the central belt by assigning arbitrary opposite colors to antipodal physical edge orbits. Such extensions exist and preserve oddness.

THEOREM (THREE EXACT EQUIVALENCES). The following statements are equivalent:
(A) This genuine antipodally odd physical edge coloring has a MONOCHROMATIC FULL antipodal n-edge cube geodesic whose every vertex lies in the central three Hamming levels k-1,k,k+1.
(B) The antipodally odd VERTEX coloring lambda on the Johnson graph J(2k,k) contains a MONOCHROMATIC JOHNSON GEODESIC of k-1 edges joining two k-subsets S,T with Johnson distance d_J(S,T)=k-1 (equivalently |S∩T|=1).
(C) The k-uniform complete hypergraph on ground set [2k], with each k-set S colored lambda(S) and every complementary pair oppositely, has a MONOCHROMATIC TIGHT PATH whose k consecutive k-element windows use 2k-1 DISTINCT ground elements. Explicitly, some permutation (a_1,...,a_(2k-1)) of 2k-1 distinct elements has k equal-colored windows {a_j,...,a_(j+k-1)}, j=1,...,k.

PROOF (A)->(B): Any antipodal full path beginning at middle rank k must end at middle rank k at its complementary vertex. Its first and last physical edges are colored lambda(S) and lambda(S^c), opposite; therefore it CANNOT be monochromatic. Any path satisfying (A) instead begins at rank k-1 or k+1; reverse its direction if needed to assume it begins rank k-1 and ends rank k+1. Its first and last edges must go through middle rank k, and every passage between middle-rank vertices is a TWO-EDGE excursion through an adjacent rank k-1 or k+1 vertex. Since every of the n coordinate directions is used exactly once in the full geodesic, these two steps must consist of one removal and one addition, each of a previously untouched coordinate. Thus the successive middle-rank vertices form a JOHNSON geodesic S_0,...,S_(k-1) of k vertices and k-1 Johnson edges, with distinct coordinates removed and distinct coordinates added. Their endpoints have Johnson distance k-1 (intersection exactly one). Every cube edge in the belt has color lambda at its middle-rank endpoint, so all lambda(S_j) are the same.

(B)->(C): Write S_0={a_1,...,a_(k-1),h}, the k-1 elements deleted along the Johnson geodesic in their deletion order plus its UNIQUE element h retained in S_0∩S_(k-1). Write b_1,...,b_(k-1) for the introduced directions in their corresponding arrival order; the shortest-path hypothesis ensures all 2k-1 symbols a_1,...,a_(k-1),h,b_1,...,b_(k-1) are distinct, and successive k-set windows of this 2k-1 word are EXACTLY S_0,...,S_(k-1). Their lambda colors are equal, proving a monochromatic k-window TIGHT path.

(C)->(A): Let (a_1,...,a_(k-1),h,b_1,...,b_(k-1)) represent the monochromatic tight path. Let g be the ONE ground-set element missing from this 2k-1-word. Start the ACTUAL Q_(2k) cube geodesic at the rank-(k-1) root X={a_1,...,a_(k-1)}. First add h, reaching the rank-k vertex S_0. For j=1,...,k-1, remove a_j and then add b_j. This visits rank k-1 between consecutive rank-k vertices S_(j-1),S_j. Finally add the missing element g. Every coordinate from the full n-set [2k] was toggled EXACTLY once: first h, then each removed a_j and introduced b_j, then g. The final vertex is B∪{h,g}=[2k]\X, the antipode of X. Every intermediate vertex has rank k-1 or k, hence certainly stays in the middle three layers. Every physical path edge is incident to some middle-rank vertex with its lambda color in the fixed monochromatic tight-window sequence, so the FULL n-edge geodesic is monochromatic. QED.

CONSEQUENCES. This is an exact bridge from ORIGINAL antipodally odd EDGE geodesic closure on a natural nonlinear central-vertex-sign subclass to the classical combinatorics of MONOCHROMATIC TIGHT HYPERGRAPH PATHS and the geodesics of the Johnson graph. It justifies using the existing physical tight-path and snake-digraph techniques in a clean edge-model, while respecting the fact that arbitrary ordered-three-face NORI colors are not reducible to vertex labels in this way. The general hypergraph forcing question
 'Does every complementary-odd 2-coloring of the k-subsets of [2k] contain a monochromatic tight path on 2k-1 elements?'
is an OPEN SUFFICIENT SUBPROBLEM. The theorem proves EQUIVALENCE to belt closure FOR THIS SPECIFIC lambda-derived physical EDGE coloring; it does NOT prove universal belt closure, universal hypergraph path existence, or the unrestricted edge conjecture.

If the subproblem has a negative answer in any k, it supplies a GENUINE antipodally odd cube-edge coloring with NO monochromatic central-three-layer antipodal geodesic, but the full edge conjecture might still be true via a geodesic leaving the belt. If the subproblem is positive in all k, this would solve the lambda-derived middle-vertex-sign subclass, not arbitrary edge colors, because general central physical edge colors need not be constant around each rank-k vertex.
