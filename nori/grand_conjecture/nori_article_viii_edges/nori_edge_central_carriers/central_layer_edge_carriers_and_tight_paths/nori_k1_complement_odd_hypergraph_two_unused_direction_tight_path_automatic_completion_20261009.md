# Complement-odd k-hypergraph tight paths automatically extend from 2k−2 to 2k−1 distinct vertices

# Universal antipodal tight-path completion with exactly two unused directions

Let k>=2 and color every k-subset of the 2k-element ground set V with a binary label lambda satisfying lambda(V\S)=1+lambda(S). A TIGHT path on t distinct ground-set vertices (a_1,...,a_t) is the sequence of its t-k+1 consecutive k-subset windows {a_j,...,a_(j+k-1)}. It is monochromatic if all these windows have the same lambda color.

THEOREM (EXACT TWO-UNUSED-VERTEX COMPLETION). EVERY monochromatic tight path P on exactly 2k−2 DISTINCT ground elements can be extended AT ONE OF ITS TWO ENDS by one of the TWO unused ground elements to form a monochromatic tight path on 2k−1 distinct elements. This holds for EVERY complement-odd coloring, no other regularity or induction hypothesis. Consequently, a complement-odd coloring without any monochromatic tight path on 2k−1 distinct elements cannot have even a monochromatic tight path on 2k−2 distinct elements.

PROOF. Let the given path have distinct order (a_1,...,a_(2k−2)), and monochromatic window color q. Its initial (k−1)-direction block A={a_1,...,a_(k−1)} and terminal (k−1)-direction block B={a_k,...,a_(2k−2)} are DISJOINT and together cover precisely its 2k−2 ground elements. Let u and v be its two unused elements. The two candidate NEW extension windows are
  E_left = A ∪ {u}  (prepend u),
  E_right = B ∪ {v} (append v).
These are COMPLEMENTARY k-subsets in the full 2k-element ground set V, because A∩B=empty, u!=v, and A∪B∪{u,v}=V. Hence lambda(E_left)+lambda(E_right)=1. Exactly ONE of these two new candidate windows has color q. Use that one to extend the path. Every OLD window remains color q, the new one also has color q, and the extended direction word uses distinct elements, so it is a valid monochromatic tight path on 2k−1 elements. QED.
