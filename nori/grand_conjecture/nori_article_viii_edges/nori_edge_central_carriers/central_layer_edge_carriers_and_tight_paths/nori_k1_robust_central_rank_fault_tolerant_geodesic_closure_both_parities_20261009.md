# Quantitative middle-rank fault tolerance for prescribed antipodal edge-geodesic colors in both dimension parities

ROBUST CENTRAL-RANK EDGE-GEODESIC FORCING (arbitrary binary physical edge coloring, with odd antipodal law).

Let n be arbitrary and fix desired direction-edge target bits T_i and reference upper-center bits a_i. An i-edge is specified by its n−1 exterior fixed bits. All counts below concern TRUE physical edges and TRUE rooted full antipodal geodesics.

EVEN n=2k. Define U={i:a_i=T_i}, L={i:a_i!=T_i}, u=|U|, l=|L|; u,l have same parity. Define one prescribed central-layer family E_i of edges of direction i as follows. If u,l EVEN: for i∈U take exterior fixed bits with u/2 ones on U excluding i and l/2 ones on L; for i∈L take l/2−1 ones on L excluding i and u/2 ones on U. If u,l ODD: for i∈U take (u−1)/2 ones on U excluding i and (l+1)/2 ones on L; for i∈L take (l−1)/2 ones on L excluding i and (u−1)/2 ones on U. In every case these lie, respectively, in total exterior rank k for i∈U and rank k−1 for i∈L. Let N_i=|E_i| (the product of the two corresponding binomial coefficients). Let d_i be the number of edges in E_i whose actual color DISAGREES with a_i for i∈U or with 1+a_i for i∈L. If sum_i d_i/N_i <1, then an ACTUAL full antipodal geodesic with precisely direction-color vector T exists. This conclusion does not require antipodal oddness, although active oddness motivates the paired central layers.

Proof. Use the central Hamming-weight track construction already established in nori_k1_even_dimension_center_rank_uniformity_oscillating_geodesic_all_targets_20261009. For even u,l take the arbitrary permutations U then L, assign the root bit of each direction to 1 for a descending weight step and 0 for an ascending step, and follow weight paths k↔k+1 on U, k↔k−1 on L. For odd u,l take the same order with U track starting k+1 and finishing k and L track starting k and finishing k−1. These assignments prescribe the correct actual initial vertex weight, so produce true full antipodal cube paths. Each i-edge in this family lies in the stated E_i. Over uniformly random independent permutations of U and L, the law of that physical i-edge is UNIFORM over E_i: the symmetric group of each class acts transitively on E_i and preserves the path construction, and every path visits exactly one i-edge. Hence probability its color is wrong is exactly d_i/N_i. The union bound shows that the expected number of wrong-color directions is sum_i d_i/N_i<1; therefore one actual path has no wrong-color direction. QED.

ODD n=2k+1. Let U0={i:a_i=T_i}, L0={i:a_i!=T_i}; exactly one of |U0|,|L0| is odd. Choose any bridge direction h from that odd-sized set; remove h to give EVEN-sized U,L with u+l=2k. Traverse ALL L directions, then h, then ALL U directions, with prescribed vertex weight track k↔k−1 on L, bridge k→k+1, and weight track k+1↔k+2 on U. Assign initial bits by descending/ascending orientation as in the proved nori_k1_odd_dimension_near_center_rank_uniformity_antipodal_bridge_all_targets_20261009.

For i∈L, define E_i as the actual direction-i physical edges with exterior h-bit0, exactly l/2−1 exterior ones within L excluding i, and u/2 exterior ones within U. For i∈U define E_i with exterior h-bit1, l/2 exterior ones in L, and u/2 exterior ones within U excluding i. They are genuine rank k−1 and k+1 physical edge layers, respectively. Let N_i=|E_i| (products of those binomial coefficients), and d_i the number whose colors differ from the target T_i (=1+a_i for L or a_i for U). If
     sum_(i != h) d_i/N_i < 1/2,
then a genuine full antipodal geodesic with ALL prescribed edge colors exists.

Proof. Among the u!l! permutations of the two even classes, each nonbridge i-edge is uniform in E_i by the same class-permutation transitivity. The physical bridge direction h has exactly l/2 exterior ones in L and u/2 in U. Swap positions (1,2),(3,4),... within EACH of the even-sized class permutations. This maps the physical bridge edge to its antipodal physical edge while remaining within the family, because each pair has complementary bit requirements. No permutation pair is fixed (at least one nonempty even class for n>=3). Antipodal oddness forces opposite bridge colors, so the probability the bridge has its required color is EXACTLY 1/2. For every nonbridge i, probability of wrong-color edge is d_i/N_i. Consequently by the union bound the probability all edges have target colors is at least 1/2−sum_i d_i/N_i>0. QED.

INTERPRETATION. The previous central-layer forcing theorems correspond to all d_i=0. The present two inequalities allow ARBITRARY nonlinear, position-sensitive faults inside the actual USED central rank families; outside these families the coloring can be completely arbitrary, subject to oddness in the odd-dimensional theorem. This is a quantitative physical-edge stability theorem, not an unrestricted solution: adversarial colorings may have large defect fractions, and no universal bound on these is presently known. The opposite-color constraint is required ONLY for the odd-dimensional bridge parity argument, while the even theorem itself is valid for all binary edge colorings.
