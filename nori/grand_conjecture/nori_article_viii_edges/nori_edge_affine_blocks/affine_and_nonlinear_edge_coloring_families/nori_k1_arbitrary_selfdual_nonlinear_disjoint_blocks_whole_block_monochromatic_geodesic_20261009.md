# All self-dual functional-block edge colorings admit block-constant full antipodal geodesics, even with overlapping supports

# Arbitrary self-dual nonlinear block gates admit monochromatic geodesics by whole-block scheduling

**Setup.** Partition the n coordinate directions into m>=2 nonempty groups B_1,...,B_m. For each group j choose a NONEMPTY input support M_j⊆B_(sigma(j)), where sigma(j)!=j. Assume different groups' supports M_j are PAIRWISE DISJOINT. Choose ANY Boolean functions g_j:{0,1}^{M_j}->F2 satisfying the antipodal self-duality
  g_j(bar y)=1+g_j(y)
for every input y∈F2^{M_j}. There is NO linearity, majority, symmetry, or monotonicity hypothesis. These functions automatically attain BOTH Boolean outputs, and may have arbitrarily large support sizes.

For each group B_j, choose one constant block bias b_j∈F2, the SAME for EVERY coordinate direction v∈B_j. Define the actual UNDIRECTED physical edge color by
  c_v(x)=b_j+g_j(x_(M_j)), v∈B_j.
Since M_j∩B_j=empty, the color is independent of the incident edge's toggled direction v. Since g_j is self-dual, c_v(bar x)=1+c_v(x). Hence this is a fully legal original k=1 antipodally odd cube EDGE coloring, with arbitrarily nonlinear driver gates and ANY loopless block-dependency map sigma (branching allowed).

**THEOREM (all BLOCK-CONSTANT color patterns).** For EVERY prescribed collection of m bits T_1,...,T_m∈F2, there exist an ACTUAL root x and a full permutation p of all n directions such that the TRUE antipodal n-geodesic P(x,p) has edge color T_j on EVERY edge whose direction belongs to block B_j. In particular T_j=0 for all j yields a monochromatic FULL antipodal geodesic, and T_j=1 for all j yields one of the other color.

**Proof (one-shot whole-block ordering).** Select ANY strict total order of the m groups, and choose p to concatenate the coordinates of each entire B_j in that group order, in ANY internal order. For group j, every input coordinate in M_j belongs to ANOTHER single group B_(sigma(j)) which is traversed as an entire contiguous block. Therefore at the moment ANY direction v∈B_j is traversed, EITHER all of M_j has already been toggled (if B_(sigma(j)) precedes B_j) OR none of M_j has yet been toggled (if B_(sigma(j)) follows B_j). No M_j coordinate is traversed during B_j itself, so g_j is constant throughout the whole block B_j, regardless of its internal direction order.

Let e_j=1 if the driver group B_(sigma(j)) is earlier than B_j and 0 otherwise. By self-duality of g_j, its gate output while B_j is being traversed is
  g_j(x_(M_j)) + e_j.
To achieve the desired actual physical edge color T_j, it suffices to choose the initial gate values
  g_j(x_(M_j))=T_j+b_j+e_j.
Every g_j is self-dual, hence attains both possible values. Because the supports M_j are PAIRWISE DISJOINT, we can choose initial input bits x_(M_j) satisfying all m displayed equations INDEPENDENTLY; assign the remaining root bits arbitrarily. For the resulting ACTUAL full n-edge cube geodesic P(x,p), every edge in B_j has
  c_v=b_j+g_j(x_(M_j))+e_j=T_j.
The path uses all coordinates exactly once and is antipodal. QED.

**Stronger physical interpretation.** Arbitrarily complex, arbitrarily nonlinear self-dual functions may have NO alternating full input geodesic and still admit globally monochromatic cube geodesics when driver blocks are traversed intact and direction biases are constant within each consumer block. This proof is strictly simpler than the all-target parity-padding/majority simulation approach, but it solves a DIFFERENT complementary class: it permits arbitrary gate truth tables while guaranteeing only BLOCK-CONSTANT target direction words. By contrast the signed-symmetric alternating-gate result nori_k1_nonlinear_disjoint_signed_odd_majority_functional_block_all_pattern_geodesics_20261009 permits independently varying biases b_v and arbitrary independently prescribed target T_v inside each block, but needs the gate's universal alternating-trace property.

**Boundary and next forcing target.** If b_v varies within one B_j, or if the prescribed T_v differs across directions inside one block, processing that block contiguously makes its gate output constant and may not satisfy the multiple local requirements. One must split or interleave its directions across driver-coordinate movements. A natural generalization is a scheduling lemma that handles arbitrary self-dual odd input traces, not merely fully alternating (parity/signed-symmetric) traces, while coordinating the interleavings around functional directed cycles. Overlapping driver supports introduce a separate independent-root-realizability obstacle.


**Exact local TRACE-ONLY NO-GO (why arbitrary per-direction targets do NOT follow automatically).** Consider two blocks X and Y, each with three marked coordinates, and FIX the internal order of all three bits in each block. Suppose their respective driver-gate output traces under those fixed orders are
   f(Y-prefix length j)=(0,0,0,1), j=0,1,2,3,
   g(X-prefix length i)=(0,0,0,1), i=0,1,2,3.
These traces are individually perfectly compatible with antipodal self-duality: starting and ending colors are opposite. Complementing either full initial support bit string complements its trace to (1,1,1,0), so allow both independent global trace complements.

Now interleave the three X and three Y steps arbitrarily, with the color of each X-step prescribed by the current f-output and the color of each Y-step prescribed by the current g-output. There is NO interleaving that produces EXACTLY ONE color-zero step and TWO color-one steps in EACH of the two blocks, for ANY choices of the two trace complements.

Proof. For either trace (0,0,0,1) or (1,1,1,0), achieving a mixed prescribed count of 1 zero and2 one X-steps requires at least one X-step BEFORE the third/final Y-step and at least one X-step AFTER it; the gate output only changes when all 3 Y steps are completed. Consequently the LAST Y-step must occur before the LAST X-step. The same argument applied to Y-steps forces the LAST X-step to occur before the LAST Y-step. Contradiction. This does NOT contradict original edge closure: a genuine Boolean driver gate such as a projection can permit different output traces under a DIFFERENT internal input order, and those alternate orders may repair the scheduling. The point is that mere existence of a self-dual ODD trace for each gate is NOT SUFFICIENT for an arbitrary target vector via a fixed-trace grid interleaving. It clarifies why the signed-symmetric theorem uses universal fully alternating trace realizability, whereas the present arbitrary-gate theorem guarantees only block-constant target patterns.


**STRICTLY STRONGER THEOREM (v3): DISJOINTNESS NOT NEEDED FOR ARBITRARY SELF-DUAL WHOLE-BLOCK GEODESIC CLOSURE.** Drop the requirement that the supports M_j be pairwise disjoint, entirely. Retain ONLY that for each consumer block B_j, the nonempty support M_j belongs to one DIFFERENT driver block B_(sigma(j)) with sigma(j)!=j, and that g_j is ANY antipodally self-dual Boolean function on M_j; each consumer direction v∈B_j has the same block bias b_j. Then, for EVERY block-constant target color vector T_j, there still exists a full antipodal geodesic with color T_j on each direction of B_j. In particular arbitrary overlapping self-dual gates of this functional-block form admit FULL MONOCHROMATIC ANTIPODAL GEODESICS in all dimensions.

**Proof (cycle-root selection followed by a topological sort).**
Choose arbitrary initial root bits x for the moment, and write alpha_j=g_j(x_(M_j)). For each block j let q_j=T_j+b_j, and prescribe the orientation of the functional dependency edge {j,sigma(j)} by
  e_j=q_j+alpha_j,
where e_j=1 means that the driver block B_(sigma(j)) should be processed BEFORE consumer B_j, and e_j=0 means consumer B_j should precede its driver. Traversing each whole block contiguously, the actual color in consumer B_j is
  b_j+alpha_j+1{driver block precedes consumer block}
  =b_j+alpha_j+e_j=T_j
exactly whenever the total block order realizes all prescribed pairwise relations e_j.

A finite loopless functional digraph j->sigma(j) consists of disjoint directed cycles C (each length>=2) with directed in-trees attached. Every undirected cycle in the underlying edge multigraph is one of these functional cycles; the special length-2 directed cycles correspond to two opposite functional arrows on the SAME undirected edge, imposing inverse ordering requirements. A system of pairwise precedence constraints admits a strict total order iff it contains no directed precedence cycle. For any functional cycle C, the prescribed precedence edges are consistently cyclic precisely if ALL its e_j=0 or ALL its e_j=1. For a cycle of length2, the two possible valid patterns are (0,1) and (1,0), which is the same 'not all equal' criterion. Thus the ENTIRE block order exists if for EACH directed cycle C the sequence (e_j)_(j∈C) is NONCONSTANT. Arbitrarily oriented tree edges cannot create a new directed cycle.

We can FORCE this by choosing ONE root x. For a given cycle C, the supports M_j, j∈C, lie inside mutually DISTINCT coordinate blocks B_(sigma(j)), since sigma permutes the vertices of C cyclically. Thus the sets M_j for j∈C are PAIRWISE DISJOINT, regardless of extensive overlap with supports of tree gates. They are also disjoint from supports corresponding to OTHER directed cycles, since different functional components have disjoint block labels. Since each g_j is self-dual, it attains BOTH bit values; therefore assign the initial root bits ON these cycle supports independently so that the desired values alpha_j yield any selected NONCONSTANT e_j pattern (e.g. one1 and all remaining0) on EACH directed cycle. Set all other root bits arbitrarily. Now alpha_j values for the remaining TREE gate vertices become determined automatically, even if their supports overlap any others; define their e_j accordingly. No special conditions are imposed on tree-edge labels because a forest has no cycles.

The resulting full precedence digraph is ACYCLIC. Topologically sort its block labels and concatenate each entire group B_j in that order, with arbitrary internal direction order. For each j its input support M_j lies COMPLETELY in a distinct driver group B_(sigma(j)), so all its inputs have been flipped or none have been flipped when B_j is traversed. By the Boolean self-duality, its output is alpha_j+e_j throughout B_j, and thus every physical edge in B_j has precisely T_j. This is a genuine coordinate-distinct n-edge antipodal cube geodesic. QED.

**Optimal interpretation of the new proof.** The old disjointness hypothesis was merely a sufficient way to prescribe ALL initial gate outputs alpha independently. This is unnecessary: ONLY the gate values ON genuine dependency cycles must be independently prescribed. Their supports are AUTOMATICALLY disjoint by functional cycle geometry. Tree gate outputs may be completely correlated, because they merely determine orientations of forest edges, which never obstruct topological sorting. This gives a precise cycle-local versus tree-global separation and resolves the previously listed overlap obstruction for block-constant target vectors.

**Boundary preserved.** Arbitrary per-direction biases b_v within one consumer block, or arbitrary non-block-constant target T_v, still cannot be handled by a single whole-block traversal. The stronger all-target signed-symmetric theorem requires genuinely alternating gate traces AND disjoint support sets; the removal of disjointness here does NOT automatically extend to that more demanding problem. The fixed 0001 trace-grid example above demonstrates why arbitrary mixed block requirements need additional input-order choices.
