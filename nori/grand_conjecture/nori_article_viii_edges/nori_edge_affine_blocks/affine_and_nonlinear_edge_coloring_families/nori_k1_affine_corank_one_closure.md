# Original k=1 edge coloring: affine corank-one geodesic closure

Original k=1 edge analogue. Let edge color c_i(x)=b_i+sum_j A_ij x_j over F2, with A_ii=0 and every row sum 1 (the antipodal oddness condition). For direction order p and root r, define t_i(p)=sum of A_ij over j earlier than i. The edge color vector indexed by direction is C(r,p)=A r+b+t(p). If rank(A)=n, root solves C=z for every target z and any order. If rank(A)=n-1, choose nonzero left-null vector u. Adjacent swapping i and j changes t by v_ij=A_ij e_i+A_ji e_j. Some pair obeys u dot v_ij=1: otherwise u_i A_ij=u_j A_ji for all pairs, whence 0=(u^T A)_j=sum_i u_i A_ij=u_j sum_i A_ji=u_j, contradiction. Put such a pair adjacent and choose its orientation so u dot (z+b+t)=0. This gives z+b+t in image A and a root solving C=z. Therefore every antipodally odd affine edge coloring with rank at least n-1 has monochromatic antipodal geodesic, in fact all direction-indexed target words are realizable. Moreover pair vectors v_ij span the cokernel: the same left-kernel argument proves no nonzero functional annihilates them all. If k disjoint pairs give a cokernel basis, orient these adjacent blocks independently for complete closure at corank k. Distinct k disjoint pairs are a sufficient hypothesis, not automatically known. Rotation of a geodesic with first direction j maps C to C+e_j, since the moved edge is replaced by its antipodal edge and every other physical edge survives.
