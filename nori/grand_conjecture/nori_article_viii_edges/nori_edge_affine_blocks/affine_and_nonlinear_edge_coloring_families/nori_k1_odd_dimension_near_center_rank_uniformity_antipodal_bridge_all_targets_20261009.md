# Odd-dimensional edge-geodesic closure via two middle-weight tracks and an antipodal physical bridge

THEOREM (odd-dimensional exterior-near-center uniformity, all target edge colors). Let n=2k+1>=3. Color ACTUAL undirected cube edges with bits c, satisfying c(bar e)=1-c(e). Suppose that for each direction i, every i-edge having exactly k+1 of its n−1 fixed exterior coordinates equal to1 has the same color a_i. Antipodal oddness then makes every direction-i edge at exterior rank k−1 have color 1+a_i. The intermediate rank k edge colors may be ENTIRELY ARBITRARY subject only to the antipodal law; likewise all other exterior ranks. Then for EVERY prescribed bit vector T indexed by coordinate directions there exists a true full n-edge antipodal GEODESIC whose direction-i edge has color T_i. In particular a monochromatic antipodal geodesic always exists.

PROOF. Partition directions into U={i:a_i=T_i} (upper-track directions) and L={i:a_i differs from T_i} (lower-track directions). Since n is ODD, exactly one of |U| and |L| is ODD. Select any coordinate h from that odd-sized class as a CENTRAL BRIDGE and remove it from its class. The remaining U and L groups have EVEN sizes u and l, with u+l=n−1=2k. Put all lower-track L directions first, then bridge h, then all upper-track U directions.

For the l lower-track directions, prescribe the vertex total Hamming weights to alternate k,k−1,k,k−1,...,k, beginning at weight k. Then traverse the bridge h as an upward edge from total weight k to k+1, and for the u upper-track directions alternate k+1,k+2,k+1,...,k+1. For each direction in this order define its INITIAL root bit to be1 if the prescribed weight transition is downward, and0 if upward. The lower run has l/2 downward steps, the upper run u/2 downward steps, and the bridge is upward, hence the resulting starting vertex has l/2+u/2=k ones as prescribed. Therefore the actual full cube geodesic rooted at this vertex realizes EXACTLY the prescribed Hamming-weight sequence.

Each lower-track edge traverses a direction-i physical edge with k−1 exterior ones: descending from k toggles an initial 1, or ascending from k−1 toggles an initial 0. Its color is therefore 1+a_i=T_i. Each upper-track edge analogously has k+1 exterior ones and color a_i=T_i. Only the bridge h is not yet controlled: it has exactly k exterior ones, the arbitrary central layer.

The physical bridge i-edge begins at an intermediate cube vertex z with total weight k and z_h=0. Because l,u are BOTH EVEN, as we vary independently the order of the L directions and the U directions, we realize EVERY assignment z to the n−1 exterior coordinates satisfying
   number of 1s on L = l/2,
   number of 1s on U = u/2.
Indeed, following the even-length lower oscillation, the final L-coordinate bits alternate 0,1,... and may be assigned to ANY half-sized subset of L by reordering; the initial U bits for the subsequent upper oscillation likewise alternate 0,1,... and may be assigned to ANY half-sized subset of U. Since these subset sizes are EXACT halves, the family of possible physical bridge edges is closed under antipodal complementation of ALL exterior bits (each subset is sent to its complement within its own group). As c is antipodally odd, each complementary pair of these REAL bridge edges has opposite colors. Thus select an ordering of L and U for which the physical bridge h-edge has the desired target color T_h. This changes only WHICH named coordinates occupy down/up positions within their prescribed tracks, without affecting any lower or upper edge colors. The bridge now has color T_h as well. Every direction is traversed exactly once, so the resulting path is a full antipodal GEODESIC with ALL desired direction colors. QED.

For n=2k+1, antipodal oddness forbids a direction-i color that is constant on the CENTRAL exterior rank k, because antipodality maps that rank to itself. Nonetheless one may choose any per-direction constant values on exterior rank k+1, opposite on rank k−1, and ANY antipodally odd distribution on exterior rank k. The theorem guarantees full-geodesic all-target realization.
