# Even-dimensional odd edge colorings uniform on a single central exterior-rank layer realize every geodesic color vector

THEOREM (even-dimensional middle-layer uniformity implies all-target edge-geodesic closure). Let n=2k>=2 and let c be ANY binary coloring of the undirected physical edges of Q_n satisfying antipodal oddness c(bar e)=1-c(e). Assume that for EACH direction i there is a bit a_i such that every i-edge whose n−1 fixed exterior vertex coordinates contain EXACTLY k ones has color a_i. There is NO restriction whatsoever on the color variation outside this single middle exterior-weight layer, beyond active antipodal oddness. The lower-middle layer (external weight k−1) then automatically consists entirely of color 1+a_i by the antipodal law.

For EVERY target direction-color vector T in F2^n there exist a genuine root x and a permutation p of all n distinct coordinate directions such that the resulting FULL antipodal n-edge GEODESIC has color T_i on its direction-i edge. In particular T=0 yields a monochromatic full antipodal geodesic.

PROOF. Partition the direction coordinates into U={i:a_i=T_i} and L={i:a_i!=T_i}, of sizes u,l with u+l=2k. Thus u and l have the SAME PARITY.

CASE 1: u,l both EVEN. Put all U-directions first in an arbitrary order, then all L-directions. Prescribe the total Hamming weight of the successive path vertices as follows: start at k; during U-steps alternate weights k,k+1,k,k+1,...,k; during L-steps alternate k,k−1,k,k−1,...,k. Along each rising edge, choose the traversed coordinate's INITIAL root bit 0, and along each falling edge choose its initial bit 1. Every coordinate is traversed exactly once. There are u/2+l/2=k falling steps, so exactly k coordinates have initial bit1. Therefore the actual root has the stipulated starting Hamming weight k, and its successive vertex weights follow the prescribed sequence.

CASE 2: u,l both ODD. Again put all U directions first, followed by L. Prescribe initial total weight k+1, alternate k+1,k,k+1,...,k along the u U-steps, and then alternate k,k−1,k,...,k−1 along the l L-steps. Define the actual starting root bits as before (0 for rising edge,1 for falling). There are (u+1)/2+(l+1)/2=k+1 falling steps, exactly the prescribed initial Hamming weight. Hence these are the actual successive vertex weights.

In EITHER case, an upper-track step k↔k+1 always traverses an i-edge with exactly k exterior 1-bits: if it rises from k, the traversed bit is0; if it falls from k+1, the traversed bit is1. Its actual physical edge color is therefore a_i=T_i for i∈U. Similarly a lower-track step k−1↔k always traverses an i-edge with k−1 exterior 1-bits, whose color by antipodal oddness is 1+a_i=T_i for i∈L. Thus EVERY edge has its prescribed direction color. Since all directions are flipped once, the path is full, antipodal and geodesic. QED.

COROLLARY (arbitrary nonlinear symmetric external rank). For n even, choose independently for each direction i ANY Boolean function F_i:{0,...,n−1}->F2 satisfying F_i(n−1−r)=1+F_i(r), and set c_i(x)=F_i(number of 1s outside i). Each such legal antipodally odd coloring realizes EVERY direction-indexed target bit vector on some full antipodal geodesic. These F_i may be wildly nonlinear, nonsmooth and different for every direction. Their input supports overlap maximally: each direction-i color may depend on ALL other n−1 coordinates. Moreover, one may perturb the coloring ARBITRARILY on every exterior-weight layer except the two central ones, respecting oddness, without changing this conclusion.

This is a different global closure mechanism from all prior functional block-driver and affine rank theorems: it uses a common weight-level path oscillation, not disjoint root registers, block-contiguous scheduling, or a finite syndrome square. It is constructive in O(n) from the direction central-layer bits and target T. For odd n, a direction-coloring depending ONLY on exterior Hamming weight cannot be antipodally odd, because exterior length n−1 is even and its middle level is fixed under global complementation; the theorem makes NO odd-n claim. The unrestricted edge conjecture remains open.
