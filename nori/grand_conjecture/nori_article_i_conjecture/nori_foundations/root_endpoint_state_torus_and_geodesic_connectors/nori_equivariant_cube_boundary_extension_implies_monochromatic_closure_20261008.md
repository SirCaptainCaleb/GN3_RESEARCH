# Equivariant extension of the physical cube boundary into honest reachability carrier forces closure

# A precise equivariant cellular-extension criterion for the honest reachability carrier

Let c be an antipodally odd edge coloring of Q_n, n>=3, and let K=union_(z,q) K_q(z) be the honest monochromatic-prefix target complex inside the root-target diagonal cross X_n. Let alpha(r,s)=(1-r,s) exchange opposite physical roots. Theorem: o in K iff a monochromatic antipodal geodesic exists; if o not in K, then K is a finite free alpha-complex of dimension at most n-2. The canonical crossed-edge construction embeds the physical cube graph G=Q_n^(1) alpha-equivariantly into K.

**Conditional topological closure theorem.** Suppose the canonical equivariant embedding G -> K extends to a continuous alpha-equivariant map
f: boundary([0,1]^n) -> K,
where the source alpha action is usual central reflection u->1-u and target alpha is root complementation. Then c possesses a monochromatic antipodal geodesic.

Proof. If not, K is an alpha-free finite polyhedron of dimension <= n-2. The boundary cube is an antipodal sphere S^(n-1) (equivariantly PL-homeomorphic to the standard antipodal sphere). By the Borsuk--Ulam/Dold dimension obstruction there is no equivariant map S^(n-1) into a free Z2 complex of dimension <=n-2. (Equivalently: the source double-cover class has nonzero power w^(n-1), while the target quotient has no cohomology in degree n-1.) Contradiction. QED.

**Exact cellular test.** Such an extension can be assembled inductively over source proper faces H of dimensions 2,...,n-1. Opposite faces H,bar H are distinct and exchanged by the antipodal involution. Once a map has been defined on all (k-1)-skeleton faces equivariantly, choose one k-face from each antipodal pair and extend its prescribed boundary map f|boundary H:S^(k-1)->K over H iff that boundary map is nullhomotopic. Define the extension on bar H using alpha. Therefore if all these facewise obstruction classes vanish (for compatible choices made at each earlier stage), the geodesic conjecture follows.

**Necessary caution.** This is a sufficient condition, not yet proved for arbitrary colorings. A separate exact Q_2 example shows that even when a monochromatic antipodal geodesic exists, the canonical physical square loop can remain non-nullhomologous in the two-dimensional face-restricted reachability carrier. Hence the inductive extension must permit global detours in K, a different 1-skeleton embedding, or a different equivariant source if local obstruction persists. The criterion identifies the actual topological obligation of this strategy, with every target label still an honest realized geodesic prefix.
