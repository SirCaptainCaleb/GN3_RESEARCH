# Valid NORI colorings have disjoint opposite-corner monochromatic terminal basins in every even dimension at least eight

THEOREM (exact fixed-pair KKM/Hex obstruction). Let n>=8 be even. Color every ordered three-dimensional physical face F by the parity of the sum of its n-3 exterior bits, independently of triple order: c(F,pi)=sum_{j notin free(F)} exterior_j(F) mod 2. Because n-3 is odd, complementing the entire cube flips that parity, while reversing pi changes nothing. Therefore c(bar F,reverse pi)=1-c(F,pi), satisfying the ACTIVE NORI axiom.
Fix distinct directions a,b; write D=[n] without {a,b}, d=n-2>=6. Take y=0^n, y^D=1_D, and the common d-dimensional root facet H={x:x_a=x_b=1}. Let b0=1_{a,b} be the natural base corner for terminal basin T_(a,b)(y), and b1=b0 xor 1_D the natural base corner for T_(b,a)(y^D). Identify roots x in H with their D-bits S={i in D:x_i=1} relative to b0.
(i) EXACTLY T_(a,b)(y)={x in H: |S|<=1}. To reach y from x via a directed path ending (a,b), all used directions are decreases 1->0, so every successive ordered-three-face exterior parity alternates: when the window shifts one position, an earlier decreasing coordinate leaves the free triple already flipped to 0 and the new incoming decreasing coordinate formerly contributed 1. Their exterior parity changes by one. Therefore a path of |S|+2 edges has a monochromatic window word iff it has <=1 window, equivalently |S|<=1 (the |S|=0 terminal 2-edge path is vacuously monochromatic).
(ii) EXACTLY T_(b,a)(y^D)={x in H: |D\S|<=3}. A path to y^D using terminal order (b,a) first increases precisely the s=|D\S| coordinates in D where x has 0, then decreases b,a. Between successive ordered-three-face windows with directions p_j,...,p_(j+3), exterior parity changes modulo two by 1-x_(p_j)-x_(p_(j+3)) mod 2, where bits are measured at starting root x. The first s directions are increases (starting bit 0) and the final b,a directions decreases (starting bit 1). Thus the earliest s-3 window transitions, when s>=4, have parity change 1, while the final two transitions have parity change 0. Therefore all colors are equal iff s<=3. Any order of the s increasing coordinates has the same status.
For n>=8, d>=6, a root in BOTH basins would satisfy |S|<=1 and |D\S|<=3, contradicting |S|+|D\S|=d>=6. Hence the two exact color-free monochromatic terminal basins are DISJOINT, even though each is a genuine geodesically corner-rooted reachable subset with the natural radius-one star. This is NOT a counterexample to the full NORI conjecture: it blocks one prescribed (y,J) pair, not every pair simultaneously.
FIXED-POINT IMPLICATION. Any fixed-point/Hex/KKM theorem using only a single pair of opposite-corner terminal basins, their corner stars, coordinatewise downsets and geodesic connectedness cannot universally force intersection. A successful topology must exploit interdependence among multiple target/tail choices, the physical-face coloring constraints, or a higher-order carrier encoding actual window-compatible path witnesses.
