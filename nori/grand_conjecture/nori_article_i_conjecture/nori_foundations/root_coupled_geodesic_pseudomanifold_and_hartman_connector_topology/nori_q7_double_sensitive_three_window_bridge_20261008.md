# Double-sensitive seven-direction bridge has an exact endpoint formula

BRIDGE FORMULA. Fix order (b,c,d,e,a,g,f), all initial bits but x_e, and suppose the first and last ordered-window colors depend sensitively on their exterior e-bit. Its five colors are (A(x_e),L,M,R,B(1-x_e)), where A(t)=a+t and B(t)=b+t in F2, and the three central windows contain e so L,M,R are fixed. Put d=[L!=M]+[M!=R]. Then min_(x_e) changes =d+eta, where eta=0 if a XOR b XOR 1 = L XOR R, else eta=1. Proof: as x_e toggles the two endpoints complement simultaneously, so they can both be matched to the target pair (L,R) exactly when their XOR agrees; otherwise exactly one endpoint mismatch remains. If L=M=R, the minimum is at most 1 regardless of A,B. If d=1, it is 1 exactly when A=B as functions of e, else 2. If d=2, no root has <=1 change. This is a precise connector target for the double-sensitive branch of the Q7 two-row root-transport obstruction. Existence of such a good central connector is still open.
