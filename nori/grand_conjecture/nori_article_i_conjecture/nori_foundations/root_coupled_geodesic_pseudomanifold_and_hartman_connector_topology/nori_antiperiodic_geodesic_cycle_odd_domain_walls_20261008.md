# Odd cyclic seam index and root-slide/square-swap defect transport

In an antipodally odd binary EDGE coloring c(bar e)=1-c(e), a full geodesic P(x,p) followed by its antipodal translate using the same coordinate order makes a simple 2n-cycle. Its colors a_j satisfy a_(j+n)=1-a_j; hence transition bits d_j=a_j XOR a_(j+1) obey d_(j+n)=d_j and XOR_(j=1)^n d_j=1. Thus m(x,p)=sum_(j=1)^n d_j is positive odd, and the complete cycle has exactly 2m color changes. If D(P)=sum_(j=1)^(n-1) d_j, the closing seam is d_n=1-(D mod 2), so m=2 floor(D/2)+1. Consequently m=1 iff D<=1; because antipodal domain walls are n edges apart, this is also equivalent to a monochromatic antipodal geodesic along the same cycle after a root slide. Root slides rotate the cyclic word and preserve m. An adjacent transposition of consecutive directions at fixed root changes exactly two consecutive colors in the n-edge first half, so only three of the n cyclic seam bits can change. Their parity stays fixed (their XOR is determined by the unchanged two neighboring colors); hence every adjacent transposition changes m by -2, 0, or +2. This supplies a discrete odd-valued defect for the all-root chamber graph. A dimension-independent grand-closure tactic is to prove that any m>=3 chamber has a path of zero-cost root slides / adjacent swaps culminating in a -2 swap. That plateau-escape statement is OPEN. Example: for even n, rank-parity edge coloring c(edge between ranks r,r+1)=r mod2 has m=n-1 at root 0^n for every coordinate order; no immediate descending swap exists there. The colored cycle is the one-dimensional antiperiodic sign bundle; m counts antipodal pairs of domain walls. This edge-case periodicity does not directly transfer to NORI ordered-three-face oddness, whose involution reverses the free-coordinate order.
