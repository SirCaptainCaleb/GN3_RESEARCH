# Extremal good-root sheets have constant phase across easy directions and large bad-root cuts

# Root-fiber separator for globally extremal one-switch geodesics

Let n>=6, 4<=k<n, and suppose an arbitrary binary coloring of physical ordered three-faces of Q_n has NO good (k+1)-edge direction-distinct path, where good means at most one change among ordered-three-face window colors. Fix a k-direction order p=(p_1,...,p_k), used set S, and missing set T=[n]\S. Set
 D=T ∪ {p_1,p_2,p_3,p_(k-2),p_(k-1),p_k},
 r=|D|=n-k+min(k,6).
Let H be any D-coordinate subcube of Q_n, obtained by fixing all other coordinates. Put G_p(H)={x∈H:P_x(p) is good}; for x∈G_p(H), let λ(x) denote its last window color. Because every monochromatic k-path could be extended by an unused coordinate, every x∈G_p(H) has EXACTLY ONE switch, so λ(x) is also the terminal phase and its initial phase is 1−λ(x).

**Theorem (actual good-root phase separator).** Along every H-edge xy with x,y∈G_p(H), one has λ(x)=λ(y). Therefore the good-root subgraph H[G_p(H)] has monochromatic connected components for terminal phase. If G_p(H) contains BOTH terminal phases, H\G_p(H) is a vertex separator and
 |H\G_p(H)|>=r.
More precisely, writing G_i={x∈G_p(H):λ(x)=i}, the external vertex neighborhoods N_H(G_0)\G_0 and N_H(G_1)\G_1 are each subsets of H\G_p(H). Thus the bad-root set witnesses literal graph separation rather than merely a difference of abstract labels.

**Proof.** Every edge of H changes one direction d∈D. If d is one of p_1,p_2,p_3, the FIRST ordered three-face of P_x(p) and P_(x+d)(p) is the SAME physical ordered face: d is one of its free directions. Hence the first window bits coincide. Both good paths have exactly one switch, so their final bits coincide. If d lies among the last three directions, the LAST physical ordered three-face is unchanged by the root flip because d is free in that face; hence final bits coincide directly. If d∈T, the two literal appended d caps share one physical ordered three-face F_y({p_(k-1),p_k,d})=F_(y+d)({p_(k-1),p_k,d}), where y is the endpoint of P_x(p). Were the final phases different, the common appended cap would match one final phase and provide a good (k+1)-path, contrary to the hypothesis. This proves edge constancy on G.

The phase classes G_0,G_1 have no joining edges and every neighbor of G_i outside G_i must be a bad root. If both phase classes are nonempty, deleting all bad roots disconnects H. The r-cube Q_r has vertex connectivity r, so at least r vertices must be deleted. For completeness, prove the connectivity inductively: Q_1 remains connected after fewer than one vertex deletions. For r>=2 partition Q_r into the two Q_(r−1) facets. Deleting <=r−1 vertices either leaves <=r−2 deletions in each facet (so each remaining facet is connected by induction, and at least one of the 2^(r−1)>r−1 matching cross-edges survives), or deletes >=r−1 from one facet (so the opposite facet is intact, and every surviving vertex of the first facet has its cross-edge to the intact second facet). Thus fewer than r deletions leave Q_r connected. QED.

**Corollary (quantitative root phase dichotomy).** If |G_p(H)|>2^r-r, all its good roots have one terminal phase. If both phases occur, the good-root density on H is at most 1-r/2^r. This is a necessary condition on any globally extremal geodesic family.

**Antipodal symmetry audit.** Under the NORI antipodal-reversal axiom, the full-cube involution sends a k-path at x, direction word p and missing set T, to the physical path at x+T with direction word reverse(p), whose window-color word is 1−reverse(W_x(p)). For a one-switch word q^s(1−q)^t, this gives q^t(1−q)^s: THE PHASE IS PRESERVED and the run lengths are exchanged. Thus antipodal symmetry couples the p-chart to the reverse(p)-chart with the SAME phase. It does not alone force both phases into one fixed-p root fiber. A global closure argument must certify phase opposition through additional ACTUAL adjacent-order path exchanges, or force a pivotal good-good missing-root edge. This identifies the missing topological gluing premise exactly.

**Use.** The theorem is valid for all physical ordered-three-face colorings; antipodal oddness enters only the final symmetry audit. It places a concrete vertex-cut cost on changing extremal phases across the n-k+min(k,6) easy root coordinates, leaving only the k-6 deep interior used coordinates as potential unblocked root-transport channels.
