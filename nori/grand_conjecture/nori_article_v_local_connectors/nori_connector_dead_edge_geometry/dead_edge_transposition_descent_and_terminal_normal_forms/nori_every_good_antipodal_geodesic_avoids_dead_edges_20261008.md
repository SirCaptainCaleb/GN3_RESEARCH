# Every NORI one-switch antipodal geodesic is entirely dead-edge-free; terminal dead edges force an antipodal two-wall color pattern

THEOREM (DEAD-EDGE EXCLUSION FOR ALL GRAND WITNESSES). Let n>=5, let c be ACTIVE NORI with c(bar F,reverse pi)=1-c(F,pi), and define dead physical edges as those traversed by NO genuinely monochromatic directed 4-edge geodesic. Then EVERY FULL antipodal n-edge geodesic containing a dead physical edge has AT LEAST TWO ordered-three-face color changes. Consequently EVERY genuinely good antipodal geodesic with <=1 color change is PHYSICALLY DEAD-FREE. This is a necessary geometric restriction on ALL grand-conjecture witnesses.
PROOF. Let e_i={z,z xor i} be dead, with its certified local rigidity bit t: at either hub endpoint, all ordered three-faces omitting i have color t, ordered triples containing i in the MIDDLE have t, and triples containing i at an END have 1-t. The antipodal dead partner has hub bit 1-t.
For a full directed antipodal path P(x,p), let k be the position of this dead i-edge. If 2<=k<=n-1, three consecutive color windows around i suffice. If k=2, the first three windows with relative direction words (a,i,b),(i,b,c),(b,c,d) have colors (t,1-t,t), forcing two switches. If k=3, the windows (a,b,i),(b,i,c),(i,c,d) have colors (1-t,t,1-t), forcing two. If 4<=k<=n-3, five consecutive windows have colors (t,1-t,t,1-t,t), forcing four. If k=n-2 or n-1, the symmetric three-window patterns around the dead edge force two changes; these follow by the same physical-face rigidity, not any assumption of same-face reversal symmetry.
If k=n (terminal dead edge), let z=v_(n-1) be the vertex before it, so x is antipodal to z WITHIN the (n-1)-dimensional facet omitting direction i: x=z xor ([n] minus{i}). The vertex x is also the OTHER endpoint of the antipodal partner dead i-edge, hence its local dead bit is 1-t. The FIRST ordered three-face window of P uses directions avoiding i and contains x, so its color is 1-t. The penultimate ordered window avoids i and contains z, so has color t. The LAST ordered window contains i at its END and has color 1-t. Thus the color word has occurrences in order (1-t,...,t,1-t) and at least two changes. If k=1 (initial dead edge), the first window contains i at its beginning and has color 1-t, the second window avoids i and contains the other endpoint z xor i so has t, and the LAST window avoids i and ends at the antipodal dead partner hub bar x with bit 1-t; again (1-t,t,...,1-t) forces >=2 changes.
This proof uses the FULL active NORI antipodal reversal law only at the two boundary positions; the internal dead patterns work for every ordered physical-three-face coloring. A global minimum-switch path may still have a dead edge as its terminal coordinate while D>=2; excluding that last singular defect in favor of a compatible dead-free 1-switch witness is the remaining nontrivial closure problem.
