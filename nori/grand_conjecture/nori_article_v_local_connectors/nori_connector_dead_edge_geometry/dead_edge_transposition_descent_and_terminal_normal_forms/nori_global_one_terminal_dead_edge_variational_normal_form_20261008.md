# Every active NORI geodesic admits a non-increasing-switch root-slide/swap normal form with at most one dead edge, at the last position

THEOREM (GLOBAL VARIATIONAL SINGLE-TERMINAL-DEFECT NORMAL FORM). Let n>=7 and let c be any ACTIVE antipodally reversal-odd binary coloring of ordered physical 3-faces of Q_n. A cube edge is DEAD if it is traversed by no directed monochromatic 4-edge cube geodesic. For EVERY rooted FULL n-edge antipodal geodesic P there exists another rooted FULL n-edge antipodal geodesic Q (its root may differ from P's root) with
   D(Q)<=D(P)
and with EITHER NO DEAD physical edge whatsoever OR EXACTLY ONE DEAD edge, which is Q's LAST (nth) edge. Here D is the number of color changes in the ordered-three-face window word. The procedure is explicit and uses only adjacent coordinate swaps and root slides along the doubled antipodal geodesic belt.
PROOF. INPUT 1: the dead-edge matching/rigidity theorem implies (a) two differently directed dead edges have physical endpoint distance >=3; (b) dead status is invariant under physical antipodality. INPUT 2: the cyclic four-spacing theorem says dead positions on any full antipodal geodesic form a 4-separated subset of the cyclic n-position set. INPUT 3: an adjacent swap moving a dead coordinate one position RIGHT while it is in an interior position 4<=k<=n-3 never increases D, and the newly traversed edge in the OTHER coordinate is certainly live. The dead i-edge either becomes live or moves from position k to k+1; hence the weighted bubble potential decreases until all dead edges are in the first3 or last3 positions.
By 4-spacing there is AT MOST ONE dead edge in the first three positions, and AT MOST ONE in the last three positions. Thus the bubble-normalized path has at most TWO dead physical edges. If it has zero, stop. If it has exactly one dead edge in a last-three position k=n,n-1,n-2, ROOT-SLIDE BACKWARD along the current last coordinate exactly n-k times, to move that dead coordinate to LAST position; every slide does not increase D because the last two 3-face window colors differ whenever a dead edge lies among the last three edges. This is the exact root-slide identity D(backslide)=D-[last-boundary-is-switch]+[new-front-boundary-is-switch], and the local dead-edge pattern forces the subtracted boundary to equal one. Dead-edge counts remain unchanged under root slides because the removed last physical edge is replaced by its ANTIPODAL mate, with the same dead status. If it has exactly one dead in the first-three position k=1,2,3, ROOT-SLIDE FORWARD k times. Each slide does not increase D because the first two windows differ whenever a dead edge lies among the first three edges. The dead coordinate moves one position toward the front under each slide, and on the kth slide the dead first edge is replaced by its antipodal dead mate in the last position; there is now one terminal dead edge.
Finally suppose the bubble-normalized path has TWO dead edges: one in a first-three position k<=3 and one in a last-three position l>=n-2. Cyclic four-spacing rules out all combinations except (k,l)=(2,n-2),(3,n-2),(3,n-1), with the obvious requirement n sufficiently large. Root-slide FORWARD k times, as before. This does not increase D, leaves ONE dead edge at the FINAL nth position, and moves the other dead edge to position l-k. In all allowed configurations l-k lies in the interior range 4,...,n-4. Apply the monotone RIGHT dead-edge bubble operation to the second edge. As soon as it would move into position n-3, the NEW physical i-edge CANNOT still be dead: it would be cyclically only three positions from the already fixed dead nth edge, contradicting four-spacing. Hence the second dead edge disappears before reaching n-3, leaving ONLY the terminal dead edge. No move raises D. This completes the constructive proof.
The theorem is an ALL-DIMENSIONAL structural advance toward grand closure: the search for a globally minimum-switch full NORI geodesic can WLOG be restricted to geodesics without dead edges, or with exactly one dead edge at their final step. It DOES NOT itself show D<=1, because even fully live geodesics may have incompatible local square certificates; the precise remaining variational obstacle is eliminating color-switches along this normal form, not finding local four-window witnesses.
