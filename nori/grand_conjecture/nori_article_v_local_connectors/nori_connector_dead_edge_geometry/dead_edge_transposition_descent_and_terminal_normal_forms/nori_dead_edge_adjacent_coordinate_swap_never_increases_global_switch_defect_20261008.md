# Dead-edge adjacent transpositions monotonically reduce NORI geodesic switch defect, with exact plateau rigidity

THEOREM (FULL-GEODESIC VARIATIONAL DESCENT AT A DEAD EDGE). Let n>=7 and color actual physical ORDERED 3-faces of Q_n arbitrarily with binary colors; antipodal oddness is not required. Let P be ANY full antipodal directed n-edge cube geodesic rooted at x with distinct direction order p_1,...,p_n. Suppose its kth edge is DEAD (it lies on no monochromatic directed four-edge geodesic), and 4<=k<=n-3, so at least three coordinate steps precede and follow it. Let q be the dead-edge local rigidity bit at its two endpoints. Then the five consecutive ordered-three-face window colors w_(k-3),...,w_(k+1), using 1-based start indices, equal (q,1-q,q,1-q,q), giving exactly FOUR successive color transitions.
RIGHT ADJACENT TRANSPOSITION: exchange directions p_k and p_(k+1) while keeping the same original root. The five colors become (q,q,1-q,q,X), with X arbitrary, and all windows outside these five retain their original physical ordered face and color. If the next unchanged color R=w_(k+2) exists, the old local switch count INCLUDING transition to R is 4+[R!=q], whereas the new local count is 2+[X!=q]+[X!=R] <=4. Hence the swap never increases TOTAL switches. If R does not exist (k+3=n), the original local switch count4 falls to at most3, so the swap STRICTLY decreases D. Otherwise equality of old/new D is possible ONLY if R=q and X=1-q.
LEFT ADJACENT TRANSPOSITION: exchange directions p_(k-1) and p_k. The five colors become (Y,q,1-q,q,q), with Y arbitrary, other windows unchanged. If the preceding unchanged color L=w_(k-4) exists, the old local switch count INCLUDING L is [L!=q]+4, whereas the new count is [L!=Y]+[Y!=q]+2<=4. Thus this swap never increases D. If L does not exist (k=4), it STRICTLY decreases D. Otherwise equality is possible ONLY if L=q and Y=1-q.
PROOF OF COLOR PATTERNS. Let z be the vertex BEFORE the kth, i-directed dead edge. Write its preceding directions (...,u,a,b), following (...,c,d,v). Dead-edge rigidity states that at either endpoint of the dead edge, all ordered triple faces avoiding i have color q; those containing i in the middle have q, and those containing i at an end have 1-q. The original five windows (u,a,b),(a,b,i),(b,i,c),(i,c,d),(c,d,v) therefore have (q,1-q,q,1-q,q). Swapping i with c gives (u,a,b),(a,b,c),(b,c,i),(c,i,d),(i,d,v), whose first four physical triple faces contain z and have colors q,q,1-q,q, while the last has unspecified X. Swapping b with i gives (u,a,i),(a,i,b),(i,b,c),(b,c,d),(c,d,v), whose last four physical triple faces contain z or z xor i and have colors q,1-q,q,q, while the first is unspecified Y. All further windows coincide physically because the swap exchanges two commuting cube-coordinate flips, leaving the path unchanged outside its intervening square. The displayed switch-count inequalities are elementary for bits.
COROLLARY (PLATEAU BARRIER FOR A GLOBAL MINIMUM). A globally minimum-switch full NORI geodesic can traverse a dead edge with >=3 steps on each side only if k>=5 and k<=n-4 and its two additional outside window colors both equal q; furthermore the colors X and Y of the two swapped replacement windows must both be 1-q. In particular, for n<=8 no globally minimum-switch full path can have a dead edge at positions 4,...,n-3, because the strict-descent boundary cases exhaust those positions. This is a dimension-independent local descent rule and exact plateau rigidity, NOT grand closure: it does not control swaps of a dead edge near an endpoint, and a swapped path may traverse another dead edge of the same direction.
