## Research note

A full antipodally odd Q4 edge coloring has a red component R={2,3,8,10,11,12,14} which is a tree with edges (2,3),(2,10),(3,11),(8,12),(10,14),(12,14), containing only one antipodal pair (3,12). Their red distance is 4. All red edges of the full cube: (0,1),(0,4),(1,9),(2,3),(2,10),(3,11),(4,5),(4,6),(5,7),(6,7),(7,15),(8,12),(9,13),(10,14),(12,14),(13,15). These form one edge per antipodal edge pair. Degrees at 3 and 12 are both two, so the port-parallel loop bundle has four elements. The component has 7 vertices and rank 6, attaining the endpoint-star bound 2n-1 and 2n-2 for n=4. Neither a second antipodal root pair nor any red circuit is forced by large port-parallel bundles, even in a full cube coloring. This obstructs generic matroid exchange based on multiple roots, not NORI1.
