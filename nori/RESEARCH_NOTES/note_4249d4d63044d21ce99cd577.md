# Affine Q4 obstruction to a rootwise two-sweep closure lemma

Index dimensions by \(0,1,2,3\), and define the edge colors modulo two:
\[
c_0(x)=x_1,\quad
c_1(x)=x_2,\quad
c_2(x)=x_3,\quad
c_3(x)=x_0+x_1+x_2.
\]
Each \(c_i\) is independent of \(x_i\) and contains an odd number of other variables, so it defines a legal antipodally odd coloring on \(Q_4\).

At root \(x=6\) (bits \(x_0,x_1,x_2,x_3=(0,1,1,0)\)), the order \((2,1,3,0)\) gives a color-zero full antipodal geodesic: \(6\to2\to0\to8\to9\). However, no dimension permutation \(\pi\) has \(U_\pi^2(6)=\bar6=9\), where \(U_i(v)\) swaps along a color-zero edge in dimension \(i\) and fixes \(v\) if that edge has color one.

Finite certificate: evaluating all \(24\) permutations of four dimensions yields the set of two-sweep endpoints
\[
\{U_\pi^2(6):\pi\in S_4\}
=\{0,1,2,3,4,5,12,13\}.
\]
It excludes \(9\). The certificate is independently reproducible by enumerating all permutations and applying the displayed Boolean functions.

The coloring itself satisfies the global two-sweep strengthening: for instance \(\pi=(0,1,2,3)\) and root \(x=3\) give \(U_\pi^2(3)=12=\bar3\).

Thus the implication 'root admits a monochromatic full geodesic \(\Longrightarrow\) root admits a successful two-sweep order' is false even for affine antipodally odd \(Q_4\) colorings. The weaker global existential statement in the published paired-direction-involutions Subsection remains open.
