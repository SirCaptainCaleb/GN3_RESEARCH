## Research note

THEOREM (equivariant basis-map classification for partition matroids). Let M be a loopless, coloopless partition matroid with connected component decomposition M=⊕_{(r,m)} U_{r,m}^{⊕ t_{r,m}}, where (r,m) indexes distinct types, 1≤r<m and t≥1. Every map on the bases of M commuting with all matroid automorphisms arises by independently choosing, for each component type with m=2r, either to complement the selected r-subset in every component of that type or to leave all those subsets unchanged. Component types with m≠2r must be fixed. In particular the centralizer of Aut(M) on the basis set is an elementary abelian 2-group with one generator per self-dual component type.

PROOF. Aut(M) acts transitively on bases, so an equivariant map is determined by the image y of a standard basis x, which must be fixed by the stabilizer G_x. Choose the same standard r-subset B inside each of the t identical components of type (r,m). The stabilizer contains (S_r×S_{m-r})^t and S_t permuting the identical components. The only r-subsets invariant under S_r×S_{m-r} are B, and its complement if m=2r. The S_t action forces the same choice for every component of the type. Different component types are independent, giving precisely the stated maps; each map is an involution.

APPLICATION. For ⊕_{i=1}^n U_{1,2}, the unique nonidentity canonical base polarity complements all coordinates. For U_{2,n}, n≥5, there is no nonidentity equivariant basis map; U_{2,4} permits complement as the exceptional self-dual case. Thus any common theorem requiring a matroid-automorphism-canonical free base involution excludes the ordinary boundary-tournament model. Reversal of tournament exchange arrows instead belongs to an oriented exchange-flag category. This classifies candidate base polarizations and rules out a tempting unification, while leaving the color-compatible coherent-rank augmentation problem open.
