# Missing ordered-pair graph: global rigidity and the sharp extremal case

Let c be any legal antipodally odd two-coloring of the n-cube, n >= 2. Define a graph H(c) on the direction set [n]: distinct i,j are adjacent when no red direction-simple two-step path has direction word (i,j). Antipodal oddness makes the same condition equivalent to the absence of blue paths with that word.

**Theorem.** (1) Each nontrivial connected component of H(c) is a complete bipartite graph K_{a,b}. On its vertex set S=A disjoint_union B there is an antipodally odd Boolean function g of the bits indexed by [n] minus S such that c_i=g for all i in A and c_j=1+g for all j in B (all equalities pointwise on the cube). In particular, no component spans all n directions.

(2) For every n >= 2,
  |E(H(c))| <= floor((n-1)^2/4).
The bound is sharp for every n >= 3.

(3) If n >= 5 and equality holds in (2), every such coloring has a red and a blue full antipodal geodesic. Thus maximally many simultaneous two-step failures enforce a full witness.

**Proof of (1).** Fix i != j and consider any square in directions i,j. Write a_0,a_1 for the colors of its two i-edges and b_0,b_1 for those of its two j-edges. Every pair (a_u,b_v), u,v in {0,1}, occurs consecutively along an (i,j)-ordered two-step path in that square. If there is no red such path anywhere, the antipodal image of a blue such path would be red, so there is also no blue such path. Thus a_u != b_v for every u,v, yielding a_0=a_1=1+b_0=1+b_1. Each vertex lies on one such square; consequently c_j(x)=1+c_i(x) for every x.

Conversely, assume this pointwise identity. Since c_j is independent of x_j and c_i=1+c_j, c_i is independent of x_j; similarly c_j is independent of x_i. The two successive colors on any (i,j)-ordered path are therefore c_i(x) and c_j(x+e_i)=1+c_i(x). Hence no monochromatic ordered pair exists.

Now classify the functions {c_i} modulo pointwise complementation. Within any equivalence class choose one representative g. The missing-pair edges within the class are precisely all pairs between the directions whose functions equal g and those whose functions equal 1+g. There are no edges between different classes. This proves the disjoint-complete-bipartite classification. If the component has direction set S, each c_i, i in S, is independent of its own bit by legality; hence g is independent of every bit indexed by S. It remains antipodally odd, so it requires at least one bit outside S. In particular |S| <= n-1.

**Proof of (2).** Let s_t be the sizes of all components, including isolates, so sum_t s_t=n and max_t s_t<=n-1. Each component contributes at most s_t^2/4 edges. If some s_t=n-1, the remaining component is an isolate and the asserted bound follows. Otherwise s_t<=n-2 for all t, whence
  |E(H)| <= (sum_t s_t^2)/4 <= n(n-2)/4 = ((n-1)^2-1)/4.
Integrality yields the same upper bound. For sharpness choose a spectator direction r, divide the other n-1 directions into nonempty parts A,B differing in size by at most one, and fix i_0 in A. Set c_i(x)=x_r for i in A, c_j(x)=1+x_r for j in B, and c_r(x)=x_{i_0}. These rules obey legality and antipodal oddness. The only missing pairs are A cross B, giving floor((n-1)^2/4) edges.

**Proof of (3).** Write M=floor((n-1)^2/4). For odd n>=5, the bound n(n-2)/4 from the second case of the previous proof is strictly less than M. For even n>=6, equality in n(n-2)/4=M would require every component size s_t to equal n-2, since equality in sum s_t^2 <= (n-2)sum s_t requires s_t=n-2 for every positive s_t. Such a partition of n is impossible for n>=5. Consequently equality with M forces one component S of size n-1 and one isolated direction r; the component is balanced between its signs A,B.

By (1), the common rule g of the S-component is an odd function of the single spectator bit x_r, hence g(x)=x_r+b for some bit b. Since c_r is independent of x_r, write c_r(x)=h(x_S), where h is antipodally odd; there is z in {0,1}^S with h(z)=0. Start at x_r=b, x_A=z_A+1 (bitwise), x_B=z_B, traverse all directions in A, then r, then all directions in B. Before the r-step every A-edge has color g=0. Immediately before the r-step the S-bits equal z, so that edge has color h(z)=0. After the r-step all B-edges have color 1+g=0. Thus the path is a red full geodesic. Its antipodal image is a blue full geodesic.

**Interpretation and limit.** The graph H only records failures of specified two-step direction words; its classification uses the known ordered-pair rigidity lemma. The extremal construction has floor((n-1)^2/4) missing pairs and nevertheless has full monochromatic antipodal geodesics. This result makes no claim that a coloring with fewer missing pairs admits a full geodesic by an analogous argument; unrestricted NORI1 remains open.

**Finite check.** Independent enumeration of all 4, 64, and 65536 legal antipodally odd colorings for n=2,3,4 respectively found H-edge counts distributed as n=2: {0:4}; n=3: {0:40, 1:24}; n=4: {0:59824, 1:5280, 2:432}, consistent with the theorem. The mathematical proof is dimension-uniform and independent of enumeration.

## Fixed-root profile shattering inside a missing-pair component

**Theorem.** Let S=A union B be the direction set of a nontrivial connected component of H(c), and put T=[n] minus S. Its color rules have the form c_i(x)=g(x_T) for i in A and c_j(x)=1+g(x_T) for j in B, with g odd under complementation of all T-bits. Fix any root x and any permutation sigma of T. For every prescribed bit pattern w on S there is a full antipodal geodesic from x, whose subsequence of T-directions is sigma and whose direction-indexed colors restricted to S equal w.

**Proof.** Follow sigma on the T-bits from their starting values. Since g is antipodally odd, it changes value somewhere along this traversal. Choose one step k of sigma at which g changes, from a to 1+a. Insert each i in A immediately before k when w_i=a and immediately after k otherwise. Insert each j in B immediately before k when w_j=1+a and immediately after k otherwise. Keep all T-steps in their original relative order. Inserting directions from S leaves g unchanged: its arguments involve only T. Thus g=a on the entire block inserted before k and g=1+a on the block inserted after k. All requested colors on S occur. Every direction is traversed once, and the starting root and external relative order remain fixed. QED.

**Consequences.** From every fixed root, full-path profiles project surjectively onto the S-bits. Even after prescribing the entire relative order of T, there are at least 2^|S| different full profiles from that root. This is a root-compatible and exterior-order-compatible conclusion valid for arbitrary nonlinear rules elsewhere in the coloring.

**Sharp limit.** In Q3 set c_0(x)=x_2, c_1(x)=1+x_2, c_2(x)=x_0. The missing-pair component S={0,1} has the asserted fixed-root shattering property. Nevertheless root x=000 admits no red full geodesic: directions 0 and 1 can both be red only in order (0,2,1), whose middle direction-2 edge is blue. Colors in T cannot be controlled by this shattering construction.

A direct enumeration at random roots in 1000 sampled legal colorings for each of n=3,4,5 verified all detected missing pairs; the counts of checked pairs were 347, 89 and 4. The mathematical proof is dimension-uniform and independent of these finite tests.


## Complementary-gate padding and rootwise profile factorization

**Theorem (unrestricted complementary-gate extension).** Fix m>=2 and a legal antipodally odd coloring c of Q_m. Let g: F_2^m -> F_2 satisfy g(bar x)=1+g(x), and take integers a,b>=1. Add disjoint new direction sets A,B of sizes a,b, respectively, and set
C_i(x,u,v)=c_i(x) for old directions i,
C_j(x,u,v)=g(x) for j in A,
C_k(x,u,v)=1+g(x) for k in B.
Then C is a legal antipodally odd coloring on Q_(m+a+b). Its missing-pair graph contains the complete bipartite graph on A,B.

For a coloring d and starting root t, define P_d(t) as the set of direction-indexed color words attained on full antipodal geodesics from t. For every augmented starting root (x,u,v), the following equality holds:
P_C(x,u,v)=P_c(x) times F_2^(a+b).
In particular, for each monochromatic color separately, x supports a full geodesic of c if and only if every root (x,u,v) supports a full geodesic of C. Moreover C admits any monochromatic full geodesic if and only if c does.

**Proof.** Legality holds because each old rule ignores its own bit and each new rule ignores every new bit. Complementing all vertex bits reverses all rules by antipodal oddness of c and g. For j in A and k in B, C_k=1+C_j at all vertices, so all pairs jk belong to H(C).

Projection of any full path of C onto the old directions retains its starting old root x, traverses every old direction once, and has old direction colors prescribed by c; hence the left profile set is contained in the displayed product.

Conversely, take a full geodesic from x with color profile w, in a fixed old direction order. Along that old path, g changes from g(x) to 1+g(x); choose one step where it changes from q to 1+q. Given an arbitrary desired new-direction word v, insert each j in A just before this step if v_j=q and just after otherwise. Insert each k in B just before when v_k=1+q and just after otherwise. The new steps leave the old bits unchanged, so they alter neither the old path colors nor the values of g on the two insertion blocks. Every new edge has its requested color, and all directions are traversed once. All choices of initial new bits work. This proves the reverse inclusion, the rooted success statement, and the global equivalence.

**Corollary (arbitrarily large missing-pair components are NORI1-complete).** Fix any real 0<epsilon<1. The assertion that every legal antipodally odd coloring of Q_N with a missing-pair component on at least (1-epsilon)N directions has a monochromatic full geodesic, for all N, is logically equivalent to unrestricted NORI1. The same equivalence holds if the promise is |E(H)| >= (1/4-epsilon)N^2, for any 0<epsilon<1/4.

Indeed, given arbitrary base c on Q_m choose balanced a,b with N=m+a+b arbitrarily large. The new component has at least a+b=N-m members, and |E(H(C))|>=ab=floor((N-m)^2/4). As N tends to infinity with m fixed, (N-m)/N tends to 1 and |E(H(C))|/N^2 tends to 1/4. A theorem under either promise therefore applies to some such C, and its monochromatic full path projects to one for c. The reverse implication is immediate.

More quantitatively, the universal upper bound M_N=floor((N-1)^2/4) satisfies M_N-|E(H(C))| <= M_N-floor((N-m)^2/4) = O_m(N). Thus a hypothetical NORI1 counterexample in dimension m would generate counterexamples with a missing-pair graph within O_m(N) edges of its maximum, for arbitrarily large N.

For m>=3 one can choose g with neither g nor 1+g equal to any old c_i, so the newly adjoined K_(a,b) is a component with vertex set A union B. There are 2^(2^(m-1)-1) pointwise-complement classes of odd Boolean functions on m bits, exceeding m for every m>=3, so such a choice exists.

**Relation to older work.** This extends the established Cartesian factorization and projection-only padding observations by proving a rootwise profile-set equality for coupled, non-Cartesian new direction rules. It gives a limitation on missing-pair extremal-stability approaches; it does not prove unrestricted NORI1.

**Independent finite check.** Deterministic-seeded random tests compared both sides of the profile-set equality at every old root and two new-bit assignments, with 100 random legal Q3 bases and one direction of each sign, 40 random legal Q3 bases with two directions of the first sign and one of the second, and 30 random legal Q4 bases with one of each sign. Each case passed; this check is supplementary to the proof.


## Near-extremal missing-pair graphs with exponentially sparse successful roots

**Theorem.** For every 0<epsilon<1/4, arbitrarily large N admit legal antipodally odd colorings of Q_N such that |E(H)| >= (1/4-epsilon)N^2 but the fraction of roots supporting any monochromatic full geodesic is at most 2^(-epsilon*N/8).

**Proof.** Begin with the legal odd coloring F on Q4:
f_0=x_1, f_1=x_0, f_2=1+x_1, f_3=1+x_0.
For a color-t full path starting at x, the 0-edge requires 0 before 1 if x_1=t, and the 1-edge requires 1 before 0 if x_0=t. These constraints conflict when x_0=x_1. For x_0!=x_1, both colors are attainable. When (x_0,x_1)=(1,0), orders (3,0,1,2) and (2,1,0,3) have all edges of colors 0 and 1, respectively; when (x_0,x_1)=(0,1), their colors interchange. Hence F supports both monochromatic colors at precisely half its roots, and none at the other half.

Take the Cartesian product of r independent copies of F, yielding a legal odd coloring c on Q_(4r). A monochromatic full path projects to a monochromatic full path in each factor. Conversely, when every factor root satisfies x_0!=x_1, each factor has full paths in both colors, and concatenating same-color factor paths gives a full path. Hence the successful-root fraction of c is 2^(-r).

Apply the preceding complementary-gate padding theorem, with balanced positive a,b, where N=4r+a+b and 4r/N tends to epsilon. The profile-factorization equality shows the successful-root fraction remains 2^(-r). The missing-pair graph contains K_(a,b), so
|E(H)| >= ab=floor((N-4r)^2/4).
As r tends to infinity, |E(H)|/N^2 has lower limit at least (1-epsilon)^2/4 > 1/4-epsilon, whereas r/N tends to epsilon/4. For all sufficiently large r we obtain both claimed inequalities.

The four-dimensional base and Cartesian root-sparsity amplification occur in earlier research notes; the new conclusion is their combination with the complementary-gate profile-product theorem. This gives an unconditional obstruction to inferring high witness-root density from near-maximal missing-pair density.
