## Research note

**Conjecture (middle-switched tournament).** Let \(V\) be any \(n\)-element set, \(n\ge3\), let \(T(a,c)\in\mathbb F_2\) be an arbitrary tournament orientation, and let \(\varphi:V\to\mathbb F_2\) be arbitrary. Define
\[
b(a,h,c)=T(a,c)\oplus\varphi(h)
\qquad(a,h,c\text{ pairwise distinct}).
\]
Then \(b\) admits a monochromatic Hamilton tight path on all \(n\) original vertices.

The reversal-odd condition is automatic because \(T(c,a)=1-T(a,c)\). The published outer-pair tournament theorem proves the subcase of constant \(\varphi\), with an explicit odd/even interleaving of two directed tournament Hamilton paths.

**Finite evidence.** A bitmask dynamic program with state (used vertex set, final two vertices, final triple color) minimizes switches over all Hamilton paths. For each new vertex it adds the bit \(T(a,c)\oplus\varphi(b)\) and increments the switch count if that bit differs from the previous one. Exhaustively enumerating every \(2^{\binom n2}\) tournament and every \(2^n\) middle-vertex bit map yielded minimum zero in all \(2^{\binom n2+n}\) instances for \(n=5\) (32768 instances) and \(n=6\) (2097152 instances). Additional sampled tests of 1000 random pairs \((T,\varphi)\) in each dimension \(7,8,9,10,11\) also returned minimum zero; deterministic transitive tournaments with various structured \(\varphi\) were checked through dimension eleven. These tests are evidence rather than a universal proof.

**Proof target.** Generalize the insertion proof of Rédei's directed Hamilton-path theorem to the second-order condition \(T(v_i,v_{i+2})=\varphi(v_{i+1})\oplus c\) for some constant \(c\in\mathbb F_2\). Any proof must retain all \(n\) distinct vertices. Unlike a numerical threshold condition, arbitrary \(T\) can contain directed triangles, and \(\varphi\) can vary independently at every middle vertex.

This conjecture is a strict intermediate class between the already proved outer-pair tournament result and arbitrary reversal-odd boundary 3-tournaments, and is proposed for further proof or counterexample search only.
