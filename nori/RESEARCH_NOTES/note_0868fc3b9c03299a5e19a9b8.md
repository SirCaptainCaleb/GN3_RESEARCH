## Research note

Let r>=2 and d=r+2. Use cycle bits y_0,...,y_{r-1} and two additional bits u,v. Color undirected cube edges by
\[
f_i(y,u,v)=y_{i-1}\quad(0\le i<r,\ \text{indices modulo }r),\qquad
f_u=(1-v)(1-\prod_{i=0}^{r-1}y_i),\qquad f_v=1-u.
\]
All formulas are independent of the bit in their own edge direction.

The directed dependency graph consists of the source cycle on the r cycle directions, the terminal two-cycle u<->v, and arrows from every cycle direction into u. The sole branching target is u, of indegree r+1; every other direction has indegree one. Both feedback components are covered by the existing cyclic-core and rooted-tree reductions.

Write A_0 for roots admitting a full 0^*1^* geodesic, A_1 for the opposite orientation, and P=A_0 intersect A_1. Then
\[
\boxed{
A_0=\{(y,u,v):y\ne\mathbf1,\ (u,v)\ne(0,0)\},\qquad
A_1=\{(y,u,v):y\ne\mathbf0,\ (u,v)\ne(1,1)\},
}
\]
and consequently
\[
\boxed{
P=\{(y,u,v):y\notin\{\mathbf0,\mathbf1\},\ u\ne v\},\quad
|A_0|=|A_1|=3(2^r-1),\quad |P|=2^{r+1}-4.
}
\]
The two roots admitting neither orientation are (\mathbf0,0,0) and (\mathbf1,1,1).

Proof of the A_0 upper containment. If y=\mathbf1, the first and last cycle steps have colors one and zero, regardless of their interleaving with u,v; their subsequence prohibits 0^*1^*. Suppose instead u=v=0. If v occurs before u, its edge has color one and the later u edge has color zero. If u occurs before v, the v edge has color zero. Favorability therefore forces the u edge to be zero as well, requiring all cycle bits to equal one at that moment. When y!=\mathbf1, reaching this state has already traversed a one-colored cycle edge: for mixed y, the initial zeros contain a run whose first direction has a predecessor initially equal to one, and that predecessor cannot have been flipped on a path to the all-one state. If y=\mathbf0, the final cycle step before reaching all ones has a predecessor already flipped and is therefore one. In either case this earlier one followed by the zero u step is a descent. Thus no root with u=v=0 lies in A_0.

For the converse, a nonconstant cycle root has a monochromatic zero full cycle geodesic. Indeed, zero colors impose the precedence conditions [i-1 before i]=y_{i-1}. The resulting orientation of the cycle is acyclic unless all its y bits agree, so a total order exists.

For nonconstant y, roots (u,v)=(0,1) can traverse u,v first in color zero and then this cycle path. Roots (1,0) can traverse the zero cycle path first, then u,v in color one; the terminal cycle state is still nonconstant, making f_u=1. Roots (1,1) can traverse u first in color zero, then the zero cycle path, then v in color one. Each word is favorable.

For y=\mathbf0, reverse cyclic direction order gives the cycle word 0^{r-1}1. At (u,v)=(0,1), put u,v before this word, both in color zero. At (1,1), put u before the cycle and v afterward, extending its zero and one blocks. At (1,0), traverse the first r-1 zero cycle steps, then u,v in color one, then the remaining cycle step in color one. At the u step one cycle bit is still zero, so its color is one. This proves the A_0 formula. Path reversal gives A_1(z)=A_0(\bar z), establishing the remaining formulas.

At z=(\mathbf0,0,0), every full path has a rise because its cycle subsequence starts with zero and ends with one. The preceding case analysis gives a descent in every full path as well. Nevertheless reverse cyclic order followed by u,v gives
\[
\boxed{0^{r-1}100,}
\]
with precisely one one-colored edge, strictly internally. Its endpoints are the two empty roots. Changing that one edge to zero gives a monochromatic full path between them.

Thus the hypothesis used to localize restoration defects -- an empty prescribed root together with a single internal exception -- does not force two branching targets in a weakly connected dependency factor. Strong connectivity in Corollary 55 is consequential. The defect can lie in the source cyclic component while the only branching target lies in a different, individually reducible terminal component.

This is a scoped obstruction to root-specific transport. The displayed paired-root formula proves global paired-root existence for the entire family. It does not construct a NORI1 counterexample or assert that these face colorings extend to a critical repair quadrilateral with compatible outside arms.

The root-profile formulas were also verified on every root for cycle lengths two through five by direct enumeration of full dimension orders. The argument above proves them for every r>=2.

Further proved refinement: every one-defect full path from (\mathbf0,0,0) has word 0^{r-1}100, and there are precisely r such dimension orders. Every cycle traversal supplies at least one one-colored edge, so the u and v steps of a one-defect path must be zero. A zero v step requires u before v; at that u step v is still zero, so a zero u step requires all cycle bits already one. Hence all cycle directions occur first, followed by u,v. In the cycle, all directions except the sole exceptional one must precede their predecessor. These precedence relations give the unique reverse cyclic order ending at the exceptional direction, with r possible exceptional directions. Thus the defect rank is always r. No path exchange confined to this face and retaining one defect can bring it to an endpoint.
