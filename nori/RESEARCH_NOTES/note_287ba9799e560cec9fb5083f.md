## Research note

For an arbitrary edge-colored cube c define I_red(c) as the family of direction subsets S for which there exists some red direction-simple path traversing the members of S once each, with unrestricted starting root and order. For independent Cartesian products c box d, these feasible-support families factor as I_red(c box d)={S union T: S in I_red(c), T in I_red(d)}. Projection of a red product path onto each factor proves inclusion one way; concatenating factor paths proves the other. The same formula holds for blue.

IMPORTANT: These feasible-support families need NOT be hereditary and therefore need NOT be matroids. A legal antipodally odd Q3 example has c0=x1, c1=x0, c2=1-x1. From root (x0,x1,x2)=(1,0,0), the direction order (0,1,2) is a red full geodesic. But directions 0 and 2 have complementary rules at every vertex, hence no red two-step path can use both of them without direction 1 in between. Therefore {0,1,2} belongs to I_red but its subset {0,2} does not. This shows the ability to realize a direction set can depend on additional pivot directions.

A separate Q4 seed exhibits a linear rank barrier despite complete pairwise red compatibility: b0=0, b1=x2 XOR x3, b2=x1 XOR x3, b3=x1 XOR x2. Its red-feasible support family consists of the subsets S with |S intersection {1,2,3}|<=2. The three-direction part of its red graph is two disjoint stars, and direction 0 is always red. In this particular coloring I_red is the matroid independent-set system U_(2,3) direct-sum U_(1,1), of rank 3. For blue, direction 0 never occurs and a full blue path using {1,2,3} exists, so I_blue is U_(0,1) direct-sum U_(3,3), also rank 3. Both matroid ranks add under independent products. The h-fold product on Q_(4h) has red and blue feasible-support ranks 3h while all 4h edges at the origin are red. After odd completion and paired balanced lifting this fractional obstruction persists within the frozen original-direction faces.

The comparison with rainbow paths is structural: a graph containing every pairwise red turn may have feasible-support ranks with a linear deficit; simultaneously the general family is not even hereditary because a missing pair can become feasible when a pivot is included. A faithful model must retain ordered path-state compatibility rather than merely a graph or matroid of direction labels.
