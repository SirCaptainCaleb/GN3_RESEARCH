## Research note

THEOREM (sharp Clifford congruence). The signed operators J_i=S_iP of any legal antipodally odd cube coloring pairwise anticommute if and only if all square curvatures kappa_ij=c_i(x)+c_i(x+e_j)+c_j(x)+c_j(x+e_i) equal one. Such a legal coloring exists in dimension n>=2 precisely when n is 0 or 3 mod 4. Proof: use c^0_i=sum_{j<i}x_j, which has unit square curvature. Any other unit-curvature cochain is c^0+delta phi by cube simply-connectedness. With psi(x)=phi(x)+phi(bar x), antipodal oddness requires delta_i psi=1+i mod2 for indices i=0,...,n-1. This linear psi is antipodally invariant if and only if sum_i(1+i)=n+binom(n,2) is even, i.e. n congruent 0 or 3 mod4. Conversely choose phi independently on representatives of antipodal vertex pairs and put phi(bar x)=phi(x)+psi(x). This gives the required legal coloring. Two such colorings differ by delta h with h(x)+h(bar x) constant. Pairwise anticommutation implies J(t)^2=-(sum_i t_i^2)I; so every nonzero combination is invertible and Pf(J(t))=sign*(sum_i t_i^2)^(2^(n-2)). Also each unit-curvature legal coloring has full geodesic color-parity formula (n mod2)*|x|+inv(pi)+K_c, proved by counting increasing pairs in the triangular reference and observing that gradient changes add the antipodal endpoint potential. This is an algebraic classification, not a NORI1 proof.
