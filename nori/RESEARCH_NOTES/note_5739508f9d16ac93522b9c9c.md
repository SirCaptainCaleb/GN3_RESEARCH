# Complete realization and enumeration of directed influence graphs for legal antipodal cube colorings

Let n>=2. For a legal antipodally odd coloring c of Q_n, define the directed influence digraph D(c) on [n] by placing j->i when j!=i and the direction-i rule c_i depends essentially on x_j. Write d_i for the indegree of direction i.

**Theorem (realizability and formula).** A loopless digraph D is the influence graph of some legal antipodally odd coloring if and only if every indegree belongs to {1,3,4,...,n-1}. Let
N(d)=sum_(k=1)^d (-1)^(d-k) binom(d,k) 2^(2^(k-1)) (d>=1).
Then the number of legal colorings realizing a specified digraph D is Prod_i N(d_i). In particular N(1)=2, N(2)=0, N(3)=10, N(4)=208, and N(d)>0 for all d>=3.

**Proof.** Because an undirected direction-i edge is unchanged by toggling x_i, c_i is independent of x_i. On its d_i essential input bits it is antipodally odd. An odd Boolean rule has nonempty essential support. For a two-bit odd rule f, the opposite input pairs give f(00)=a, f(11)=1+a, f(01)=b, f(10)=1+b. Its discrete differences in the two input bits are 1+a+b and a+b, of which one vanishes identically. Hence no such rule depends essentially on two inputs.

For any positive odd d, the rule f(z)=sum_(k=1)^d z_k is antipodally odd and depends on all d inputs. For even d>=4, take
f(z)=z_1+(z_1+z_2)(z_3+z_4)+sum_(k=5)^d z_k,
where the empty sum is zero. The product term is invariant under complementing every input; the other terms change by 1+(d-4)=1 in F2. Every input is essential. Hence for every permitted digraph D, choose these rules on each specified incoming-neighbor set independently across the output directions; legality and oddness hold, and D(c)=D.

For k>=1, there are A(k)=2^(2^(k-1)) odd Boolean functions on k designated inputs, since one output can be prescribed freely on each pair of antipodal inputs. Set A(0)=0. Inclusion-exclusion over omitted essential inputs gives N(d)=sum_(k=0)^d (-1)^(d-k)binom(d,k)A(k). Direction rules are independent choices, so the product formula follows.

**Corollary (single-path profile-uniformity inside every influence class).** Fix any realizable digraph D, a root x, a permutation pi of its n directions, and any target direction-indexed binary profile w. Among the Prod_i N(d_i) legal colorings whose influence graph is D, precisely 2^(-n) Prod_i N(d_i) attain w on the prescribed full path (x,pi). In particular, conditioning a uniformly random legal coloring on its influence digraph leaves the profile of any fixed full geodesic uniform on F2^n.

**Proof.** For each direction i, complementing the output f_i -> 1+f_i preserves oddness and essential input support and pairs all N(d_i) allowed rules. Within each pair, one rule supplies each of the two colors at the single queried vertex on the path. Consequently N(d_i)/2 choices give the required direction-i color, independently for all i. Multiplication yields the result. This is a statement about one prescribed path across the coloring class and does not imply that all profiles occur in one fixed coloring.

**Corollary (almost-sure complete influence).** For n>=4 a uniformly random legal coloring has every possible directed arc j->i, j!=i, with probability at least 1-n(n-1)2^(-2^(n-3)). This follows because the fraction of odd functions on n-1 inputs independent of any particular input is 2^(2^(n-3))/2^(2^(n-2))=2^(-2^(n-3)), followed by the union bound.

**Mathematical limitation.** Every digraph satisfying the necessary indegree restrictions is attained by some legal coloring. Moreover every such influence class contains colorings assigning any desired binary profile to any preselected rooted full geodesic. Thus legality by itself cannot exclude further directed interaction patterns or constrain the profile on one chosen full path. Proving unrestricted NORI1 still requires simultaneous compatibility of direction colors within an individual coloring; the result provides no closure claim.

**Finite audit.** Complete enumeration of antipodally odd Boolean functions for one through four inputs gives their essential-support size distributions: d=1: {1:2}; d=2: {1:4}; d=3: {1:6,3:10}; d=4: {1:8,3:40,4:208}. The stated realizing functions were checked on all inputs for d=1,3,4,5,6,7,8. These checks supplement the dimension-uniform proof.
