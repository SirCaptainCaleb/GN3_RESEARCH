## Research note

The ordered-pair boundary graph B_n has vertices (a,b), a!=b, with edges (a,b)--(b,c) for distinct a,b,c and vertex reversal R(a,b)=(b,a). Its quotient B_n/R is J(n,2), the line graph of K_n. Every reversal-invariant proper height function h(a,b)=h(b,a) therefore needs at least n-1 levels: the quotient has a clique of size n-1 (and chromatic number n-1 for even n, n for odd n). Labeling each forward overlap edge u->v by 1 if h(v)>h(u), and 0 otherwise, obeys chi(R e)=1-chi(e), because R reverses forward arcs and preserves h. Each constant-bit forward run is strictly monotone in h. Accordingly, a height-based logarithmic-run obstruction must use at least n-1 levels on B_n. In the two-sheet parity lift with tau(a,b,s)=(b,a,s), the quotient is bipartite since each overlap step flips s, so it admits a two-level proper height. Note that this distinguishes the boundary model from this obstruction but does not prove any long-path conjecture; the cubical antipodal quotient need not have high chromatic number.
