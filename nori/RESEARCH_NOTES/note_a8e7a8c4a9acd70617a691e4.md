## Research note

AFFINE FOUR-FACE GLUING OBSTRUCTION WITH A COMMON RED STAR. Give Q4 bits x0,x1,x2,x3 and color directions by c0=0, c1=x2 XOR x3, c2=x1 XOR x3, c3=x1 XOR x2. Each function ignores its own bit. At root x=0000, all four incident direction edges are red, so every pair of directions is witnessed as a red 2-step geodesic through the SAME center. However no monochromatic full 4-geodesic exists in Q4: color 1 is impossible because direction 0 is always red. A red full path would project to a red geodesic using all of directions 1,2,3. In the induced Q3 on those directions, the red edges form two disjoint three-edge stars centered at 000 and 111, and no red path can traverse all three directions. Hence no red full path exists.

NOW FORM A LEGAL ODD Q5. Add bit t=x4 and define for i=0,1,2,3: C_i(x,0)=c_i(x), C_i(x,1)=1-c_i(bar x). Color the t-direction by C4(x,t)=x0. Edge consistency and antipodal oddness hold. The frozen t=0 face is the foregoing Q4 and has no red full four-face geodesic. In the t=1 face, direction 0 has color one throughout, so it also has no red full four-face geodesic. Yet all pairs among directions 0,1,2,3 have a common red incident witness at x=0000,t=0. Thus not even a root where FOUR distinct directions are simultaneously red is enough to guarantee a red geodesic using all those directions; making all pairwise comparisons in a K4 compatible does not solve the chained-root consistency problem.

The example is a negative test for transfers from increasing paths in edge-ordered K_n, from Hamilton paths in the pairwise direction graph, or from rainbow pair packings: they must encode the changing cube state through successive direction moves. It is not a counterexample to NORI1, because the full Q5 path may use the t-direction and does have a monochromatic full geodesic.
