## Research note

For a legal antipodally odd cube coloring, let v_ij(u)=(partial_j c_i(u))e_i+(partial_i c_j(u))e_j, and let V be the span of these square-exchange vectors. Build a graph H on direction labels with an edge ij whenever some v_ij=e_i+e_j, and mark i whenever some v_ij=e_i. In each marked connected component C, V contains all vectors supported in C; in each unmarked component C, V contains precisely the even-parity vectors supported in C. Proof: connected weight-two edge generators span the even subspace; a singleton generator at a marked vertex completes it to the full subspace. Every unmarked component is even sized: reversing a full geodesic order at the same root complements every profile bit, so the all-ones vector belongs to V. No unmarked component is a singleton because every direction function is odd and independent of its own bit, hence reads some other bit and occurs in a nonzero generator. Thus V-perp has basis the disjoint indicators of the unmarked even components.

Every unmarked component C is an autonomous zero-curvature block. Indeed if c_i for i in C read an outside bit j, v_ij would mark i or connect i to j, impossible. Similarly inside C, partial_j c_i=partial_i c_j or a singleton generator would mark a vertex. Therefore c_i for i in C depends only on bits in C, and the edge cochain there is a gradient c_i(x)=phi_C(x_C)+phi_C(x_C+e_i). Antipodal oddness gives phi_C(x_C)+phi_C(bar x_C)=sum_(i in C)x_i+kappa_C. Consequently, every full profile w from root x satisfies sum_(i in C) w_i=sum_(i in C)x_i+kappa_C for each unmarked component C. By the previously proved rootwise affine-hull identity, these are all affine-linear constraints on rooted profiles. There are no cross-block affine constraints. The number of blocks is at most floor(n/2), sharply attained by independent paired directions.
