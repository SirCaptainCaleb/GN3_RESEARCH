## Research note

THEOREM. Let b0 be any reversal-odd coloring of ordered distinct triples on n vertices. Independently flip each reversal pair's color with probability rho, 0<rho<=1/2, producing b. Fix any initial ordered pair (v1,v2), any target color c, and any 0<delta<1. Put r=ceil(log(n/delta)/rho). When r<n-2, with probability at least 1-delta there is a vertex-simple c-monochromatic tight path starting with (v1,v2), visiting at least n-r original vertices. PROOF: Starting at the pair, greedily test all unused candidate vertices w for extension with b(v_(t-1),v_t,w)=c and select any that succeeds. The center v_t of the current triple has not been a center of any previously queried triple, because path vertices are fresh. Consequently all color trials at the current step are unexposed independent Bernoulli variables, each with probability of the required color at least rho regardless of the baseline coloring. With k unused vertices, probability every candidate fails conditional on the full earlier history is <=(1-rho)^k <=exp(-rho k). Before n-r vertices have been visited, k>=r; there are fewer than n stages, so the union bound gives failure probability <=n exp(-rho r)<=delta. CONSEQUENCE: For rho n/log n -> infinity, arbitrary initial reversal-odd coloring subjected to independent rho-noise almost surely has a monochromatic tight path on n-o(n) vertices (even for any predetermined initial pair/color). This complements the existing research note titled 'Random sparse comparison conflicts limit purification density', which proves that with the same independent-noise construction comparison-faithful subgraphs may have only O(n log n/rho) edges for rho>=8log n/n. Thus globally purifying every comparison loses nearly all edges while a local monochromatic path remains near-spanning. It does not prove deterministic robustness for arbitrary o(n^3) adversarial errors; the stochastic independence of freshly exposed center comparisons is decisive.
