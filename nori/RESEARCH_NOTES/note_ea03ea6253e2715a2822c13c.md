## Research note

# Global exceptional-direction dependence defeats fixed-root blockwise phase bounds

For each even m≥6, take the singleton partition \(\mathcal P=\{\{1\},\ldots,\{m\}\}\) of the cube coordinates, and the constant-zero reference coloring \(d_i^0(x)=0\) for every i. Recolor each direction i by
\[
d_i(x)=\bigoplus_{j\ne i}x_j.
\]
Each singleton block has only one exceptional direction, so this is a one-direction-per-block perturbation if exceptional edge colors may depend on *other blocks*. Every spanning geodesic rooted at \(0^m\) has kth edge color \(k-1\bmod2\), whatever coordinate order it follows. Thus every such path has \(m-1\) switches.

For even m, \(d\) is itself antipodally odd: complementing every vertex changes the parity of the m−1 coordinates other than the traversed direction. The example therefore also occurs within the antipodally odd coloring class.

**Consequence.** The fixed-common-root \(O(t)\) estimates of the blockwise phase-interleaving theorem fail for t=1 if every block is allowed one globally dependent exceptional direction; the rooted switch count can grow linearly with the dimension. This does not rule out low-switch geodesics at a different root, nor the endpoint intersection \(E_2(d)\cap E_3(e)\) for two arbitrary colorings. It identifies the dependency assumption needed for the interleaving method. The adjacent two-direction theorem avoids it by arranging only two arbitrary exceptional edges into one short color word.
