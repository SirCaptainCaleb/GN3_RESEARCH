## Research note

For any n>=3 define legal odd cube coloring c_i(z)=z_(i+1 mod n). For a root x and full direction order pi, the direction-indexed color word satisfies w_i=x_(i+1) xor [i+1 occurs before i]. A requested word w induces precedence constraints on the n-cycle. Such constraints admit a topological ordering if and only if the cycle is not consistently directed in one of the two senses. Thus the attainable full rooted profiles are ALL 2^n binary words except the two antipodal words b(x) and complement(b(x)), where b_i(x)=x_(i+1). In particular at x=0, every nonconstant profile occurs but neither monochromatic word does. For every proper subset of directions, EVERY prescribed color pattern occurs from that same root, because it extends to a nonconstant full word. For each desired full word t, all roots except two antipodal roots realize t. This dimension-uniform extremal obstruction demonstrates that arbitrary simultaneous consistency on every proper subset of direction colors fails to force a monochromatic full path from a specified root. The coloring does satisfy NORI1 globally.
FUNCTIONAL READER CLASSIFICATION. For any function rho without fixed points and constants a_i, define legal odd coloring c_i(z)=a_i xor z_(rho(i)). At root x, a requested profile t requires rho(i) to occur before i precisely when t_i xor a_i xor x_(rho(i))=1. These precedence conditions are feasible if and only if, on every directed cycle C in the functional graph i->rho(i), the listed bits are not all zero and not all one. Indeed each weak component of a functional digraph has one directed cycle and trees; only consistently oriented cycles create directed precedence contradictions. For a two-cycle the two parallel requirements are contradictory precisely for the two constant patterns. If the cycles have lengths ell_1,...,ell_r and q=sum ell_j, the rooted profile support size is 2^(n-q) product_j (2^ell_j-2), independent of x. A witnessing order follows by topological sorting. For Q3, each legal odd direction rule reads one other bit with optional complement. Sixteen of the 64 colorings have a directed three-cycle and six rooted profiles; the other 48 have a two-cycle and a tail, producing four rooted profiles. This classifies the first nonlinear rooted profile obstruction, without claiming NORI1 closure.
ROOT-PROFILE INCIDENCE DUALITY. In the functional-reader coloring c_i(z)=a_i xor z_(rho(i)), fix any desired full color word t. For each dependency cycle C, the bits x_(rho(i)) with i in C permute all vertex bits x_i on C. The target t is blocked at a root only when its restriction to C gives one of the two constant precedence orientations. Precisely two of the 2^|C| assignments of x_C are forbidden. All root bits outside cycles are unrestricted. Hence the number of roots realizing t equals 2^(n-q) product_C(2^|C|-2), where q is the total number of cycle vertices. This equals the size of the full-profile family realizable from any single root. In particular, every desired color word is realized by some geodesic: choose root bits on each cycle to avoid its two forbidden assignments, then topologically sort the induced precedence graph. This yields a constructive NORI1 proof for all unary-reader colorings but is not a proof for arbitrary nonlinear legal colorings.
