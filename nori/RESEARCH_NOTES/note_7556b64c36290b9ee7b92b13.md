## Research note

**Setup.** Let \(V\) have \(n\ge4\) elements. The ordered-pair overlap graph has states \((a,b)\) for \(a\ne b\), with a directed forward arc \((a,b)\to(b,c)\) whenever \(a,b,c\) are distinct; forget the orientation to obtain a simple graph \(G\). Set \(\lambda(\{(a,b),(b,c)\})=c\). This is well-defined because an overlap edge has a unique forward orientation. Let \(\tau(a,b)=(b,a)\).

**Theorem (rainbow fork decomposition).** Every vertex-simple \(\lambda\)-rainbow path in \(G\), when traversed from one endpoint to the other, has an arc-orientation word of the form \(-^r+^s\), with \(r,s\ge0\). It is thus the reverse of one forward directed path followed by a second forward directed path, both beginning at a common state \((a,b)\); the two arms share no other states. The letters newly appended along these arms are pairwise distinct. Conversely, any two such forward directed arms, meeting only at their initial state and with disjoint and internally nonrepeating appended-letter sets, concatenate to a simple \(\lambda\)-rainbow path.

If in addition the unordered-pair resources \(\rho(a,b)=\{a,b\}\) of the states of the rainbow path form a forest in \(K_V\), then the appended letters avoid \(a,b\). Consequently, the state resources form a tree consisting of the base edge \(ab\) and two internally vertex-disjoint branches emanating from \(b\). In particular, when the path has \(n-2\) edges, the state-resource tree spans \(V\). Such a path encodes an ordered tight path traversing all vertices if and only if one of the two arms is empty.

**Proof.** At any state \((a,b)\), every incoming forward arc has ordinary color \(b\); outgoing forward arcs have pairwise distinct colors \(c\notin\{a,b\}\). A change from forward to backward traversal across the state would use two incoming edges of identical color \(b\), forbidden by rainbow distinctness. Thus the orientation word has no adjacent \(+-\), hence is \(-^r+^s\). Reverse the first segment to obtain two forward paths from the common state. Their appended letters coincide with the edge colors, hence are all distinct; simplicity makes their state intersections consist of the root. The converse follows by reading the concatenation.

Suppose an appended letter on an arm is \(a\) or \(b\). Take its first such occurrence. The projected state resources from the initial edge \(\{a,b\}\) through that occurrence trace a nontrivial closed walk with pairwise distinct intervening vertices (because the appended letters are distinct). Their multiset contains a cycle or a repeated edge, contradicting forest independence. Hence all appended letters are different from both \(a\) and \(b\). The projected state resources are the base edge \(ab\) with two vertex-disjoint edge-path branches from \(b\), so a tree. A length-\(n-2\) path uses \(n-2\) appended letters in \(V\setminus\{a,b\}\), hence all of them. Forward coherence throughout the undirected path holds precisely when \(r=0\), or, reversing the undirected path, when \(s=0\). If both arms are nonempty, its two incident arcs at their common initial state are both outward, precluding coherence in either traversal direction. \(\square\)

**Full-length obstruction to graph-path decoding.** For every \(n\ge4\) choose distinct \(a,b\in V\), partition \(V\setminus\{a,b\}=C\sqcup D\) into two nonempty sets, and order each as \(c_1,\ldots,c_r\) and \(d_1,\ldots,d_s\). Use the two forward paths with state lists
\[
(a,b),(b,c_1),(c_1,c_2),\ldots,(c_{r-1},c_r)
\quad\text{and}\quad
(a,b),(b,d_1),(d_1,d_2),\ldots,(d_{s-1},d_s).
\]
Their union, traversed backward along the first branch and forward along the second, is a simple rainbow undirected path of \(n-2\) edges, with all \(n-1\) projected state-pair resources forming a spanning tree. Its orientation has one change, from backward to forward, so this undirected path cannot be read as one original-vertex tight path in either direction. Further, the used edges meet distinct \(\tau\)-orbits: applying \(\tau\) reverses the underlying ordered triple, whereas both branches list distinct original vertices and share only the initial ordered pair. Thus assign \(\chi=0\) to every used edge, \(\chi=1\) to its \(\tau\)-partner, and arbitrary complementary values on remaining edge orbits. Then \(\chi(\tau e)=1-\chi(e)\), and the spanning-tree rainbow path has zero binary-label changes despite failing forward coherence.

**Local parameters.** The overlap graph is \(2(n-2)\)-regular. At each state \((a,b)\), incoming edges all have color \(b\), while outgoing edges use each color in \(V\setminus\{a,b\}\) once; therefore its color degree is \(n-1\). Its ordinary edge coloring is improper. The original-vertex Hamiltonian tight-path condition requires the forward-coherence part of the theorem alongside resource independence: a zero-switch undirected rainbow spanning path may otherwise be a two-arm fork.
