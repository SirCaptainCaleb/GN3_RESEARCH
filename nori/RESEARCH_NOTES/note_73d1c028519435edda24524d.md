## Research note

For every n>=4 there is a legal antipodally odd edge coloring of Q_n and root 0 with all incident edges red, a red direction-simple path supported on every (n-2)-subset of directions, and no red direction-simple path of length n-1 rooted at 0. Construction: declare all rank 0 and rank 1 edges red, all rank n-2 edges blue. For n>=6, add the increasing-order path from 0 through every (n-2)-subset, declaring its edges red. Each selected edge in direction i<n-1 has all higher bits zero and its antipodal mate all higher bits one, so no selected mates coincide; selected direction n-1 edges have rank n-3 and antipodal rank 2, which differ for n>=6. Rank 0,1 red and rank n-2 blue remain consistent. For n=4 the initial rank prescriptions suffice. For n=5 use two disjoint directed pentagons on two-subsets of [5]: 01,23,04,12,34 and 02,13,24,03,14, with adjacency meaning disjointness. For each oriented arc M->N, declare the rank-two edge from N to N+i red, where i is the unique missing index outside M union N. This chooses one red incoming middle edge for each rank-three vertex and never both antipodal mates, since reverse arcs are absent. Rank-one red edges complete all chosen length-three paths. Extend remaining edge orbits by antipodal opposition. Any geodesic rooted at zero increases Hamming rank and cannot cross rank n-2 to n-1 since every such edge is blue. Also, if a coloring is a NORI1 counterexample, every red path of length n-2 rooted at x omitting i,j must have both incident missing edges at x blue, otherwise one of six endpoint arrangements completes it. Thus at a root x the set of omitted pairs of red near-full paths is contained in the pairs of its blue incident directions and has size at most binomial(blue_degree(x),2). Sharp boundary: n=3 cannot exhibit this behavior with an all-red root star. The six edges between levels one and two form three antipodal pairs, so at least one is red; it extends a red root edge to a two-step red geodesic. Also, every selected length n-2 red path in our n>=4 construction has an explicit full red completion after changing the root by the two omitted bits: start at e_i+e_j, move along i,j to zero using red edges at levels one and zero, then follow the selected path. This distinguishes rooted augmentation failure from unrestricted NORI1.
