## Research note

### Direction-double-occurrence holonomy criterion and the limitation of Hamilton-lift fixed points

Let \(c\) be an antipodally odd coloring of \(Q_m\), \(m\ge2\), and let \(B(c)\) be its standard paired balanced lift on \(Q_{2m}=Q_m\times Q_m\). The red graph is a covering of the base cube \(Q_m\) via \(\pi(x,y)=x\oplus y\); a red lift of base direction \(i\) updates the first fiber state by the red edge-swap involution \(U_i\).

Let \(\mathcal D_m\) be the words of length \(2m\) in which each direction \(i\in[m]\) appears twice. For \(w=(i_1,\ldots,i_{2m})\), write \(U_w=U_{i_{2m}}\cdots U_{i_1}\).

**Theorem (antipodal holonomy criterion).** A legal coloring \(c\) satisfies NORI1 if and only if
\[
\boxed{\exists\,w\in\mathcal D_m,\ \exists\,x\in Q_m:
U_w(x)=\bar x.}
\tag{MH1}
\]
When this occurs, the red lift of the closed base walk \(w\) from every \((x,y)\in Q_{2m}\) is a monochromatic full antipodal geodesic; in particular all \(2^m\) dummy translates are witnesses.

*Proof.* The base projection of a full red antipodal geodesic in \(B(c)\) uses every paired direction set \(\{i,m+i\}\) twice, once via each member, so it gives a word \(w\in\mathcal D_m\). Its old fiber state travels from \(x\) to \(\bar x\) by applying \(U_w\).

Conversely, suppose \(U_w(x)=\bar x\). The unique red lift of \(w\) from \((x,y)\) traverses \(2m\) red edges. Since each base direction \(i\) occurs twice, its base projection returns to \(x\oplus y\). The first fiber state ends at \(\bar x\), so the dummy state ends at \(\bar y\). Moreover the two red steps in base direction \(i\) can only be original-\(i\) or dummy-\((m+i)\) steps. The endpoint flips original bit \(i\), hence an odd number of the two steps was original; it must be one original step and one dummy step. Thus every original and dummy direction was traversed once. The red lift is a full antipodal geodesic. The paired-lift reduction says \(c\) has a monochromatic full geodesic if and only if \(B(c)\) does; by antipodal translation a blue witness gives a red witness. This proves (MH1). The lifted old-bit sequence does not depend on the starting dummy state, so every \(y\) works. \(\square\)

**Theorem (Hamilton-lift fixed-point cycles are antipodal-free).** Let \(H\) be a Hamilton cycle in the base \(Q_m\), and let \(\sigma_H\) be its red return permutation on the \(2^m\) fiber states over a selected base root. If \(\sigma_H(x)=x\), the corresponding lifted red closed cycle, of length \(2^m\), contains no antipodal vertex pair. More generally an orbit of length \(q\) of \(\sigma_H\) produces a simple red lifted cycle of length \(q2^m\). Such a cycle has an antipodal pair precisely when one of the transported fiber orbits contains a complementary pair.

*Proof.* A fixed-point lift traverses the base Hamilton cycle once, visiting each base vertex \(z\) once before closing. Therefore it contains only one point in each fiber \(\pi^{-1}(z)\). But \(\pi(\bar x,\bar y)=\pi(x,y)\), so two antipodal cube vertices share the same base fiber and cannot both lie on that cycle.

For an orbit of length \(q\), concatenate the \(q\) successive lifts of \(H\) from the orbit's fiber states. Over each base vertex, the \(q\) lifted vertices are distinct because distinct starting fiber states remain distinct under the unique path-lifting bijection. The resulting cycle is simple, with \(q\) vertices in each fiber. Over any chosen base vertex, the cycle occupies the image of the return orbit under the fiber transport along the Hamilton path prefix. The cycle has an antipodal pair if one such transported orbit contains two complementary states; the transport permutation need not commute with the antipodal map. \(\square\)

The previously established Gray-Hamilton return theorem supplies many fixed points and long simple monochromatic red cycles. The theorem above shows those particular cycles are automatically antipodal-free. They do not directly provide a red antipodal path, let alone a full geodesic. Progress toward NORI1 through Eulerian red covering monodromy must establish a complementary *orbit displacement* for a direction-double-occurrence loop as in (MH1), rather than rely solely on fixed-point abundance of full base Hamilton tours.
