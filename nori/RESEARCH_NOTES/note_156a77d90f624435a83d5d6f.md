# A nonoptimal 2-opt local minimum in a reversal-odd boundary tournament

**Research obstruction, verified by exhaustive neighborhood inspection.** The nonlocal bounded-cost block reversal theorem of Article XI guarantees that reversing any contiguous segment of an injective vertex word preserves resource feasibility and changes switch count by at most six. It does **not** imply that a nonoptimal Hamiltonian path admits a cost-decreasing block reversal. This note supplies an explicit 14-vertex counterexample.

Let \(n=14\). A reversal-odd triple coloring is specified by assigning one bit \(x_t\) to each canonical reversal orbit of an ordered triple, whose representative is the lexicographically smaller of \((a,b,c)\) and \((c,b,a)\). The color of the reverse orientation is the complement.

Define \(P=(0,1,\ldots,13)\). Let \(\mathcal R(P)\) be all \(91\) words obtained by reversing a contiguous block of length at least two in \(P\). Form the list \(S\) of all reversal-orbits of triples occurring as a consecutive window in \(P\) or in at least one word in \(\mathcal R(P)\), sorted lexicographically. The list has 300 elements. Assign its \(j\)-th orbit the \(j\)-th low-to-high bit of
\[
\boxed{B=\texttt{0x8aaa1f54b89af90b0dfa3030ca59024b71da3b17fc702276c5f915d907985db108e3939f984}.}
\]
Let
\[
W=(11,5,10,7,12,3,1,6,8,4,13,9,2,0).
\]
For reversal-orbits not in \(S\) but appearing as a triple in \(W\), assign the unique canonical bit making that oriented triple have color zero. No conflicts occur with assignments in \(S\), and the twelve additional orbits in \(W\) are all distinct. Assign zero to every remaining orbit.

**Proposition.** The resulting reversal-odd coloring satisfies
\[
\boxed{\operatorname{sw}(P)=4,\quad
\operatorname{sw}(Q)\ge4\ \forall Q\in\mathcal R(P),\quad
\operatorname{sw}(W)=0.}
\]
Thus \(P\) is a nonoptimal local minimum for the full 2-opt block-reversal neighborhood, while the same tournament possesses a monochromatic Hamiltonian tight path.

*Finite proof.* The following complete Python 3 verification constructs the coloring and checks every allowed reversal, not a random sample.

\`\`\`python
from itertools import combinations

n=14
P=tuple(range(n))
W=(11,5,10,7,12,3,1,6,8,4,13,9,2,0)
B=int("8aaa1f54b89af90b0dfa3030ca59024b71da3b17fc702276c5f915d907985db108e3939f984",16)

def canon(t):
    t=tuple(t)
    return min(t,t[::-1])

def words(p):
    return [p[:i]+p[i:j+1][::-1]+p[j+1:]
            for i in range(len(p)) for j in range(i+1,len(p))]

neighbors=words(P)
S=sorted({canon(q[i:i+3]) for q in [P]+neighbors for i in range(n-2)})
assert len(S)==300
bits={t:(B>>j)&1 for j,t in enumerate(S)}

def color(t):
    return bits[canon(t)] ^ (tuple(t)!=canon(t))

for i in range(n-2):
    t=W[i:i+3]; k=canon(t)
    bit=int(tuple(t)!=k)
    if k in bits:
        assert bits[k]==bit
    else:
        bits[k]=bit

def switches(q):
    c=[color(q[i:i+3]) for i in range(n-2)]
    return sum(c[i]!=c[i+1] for i in range(n-3))

assert switches(P)==4
assert all(switches(q)>=4 for q in neighbors)
assert switches(W)==0
\`\`\`

The assertion is an exhaustive certificate for all \(14\cdot13/2=91\) reversals of \(P\); every input bit and permutation is explicitly supplied. The extra assignments required by \(W\) are compatible with the local-neighborhood assignment; the remaining unassigned orbit bits may be chosen arbitrarily.

**Scope.** This is not a counterexample to the existence of a monochromatic boundary-tournament Hamiltonian path: indeed \(W\) is such a path. It refutes a potential proof strategy requiring each nonoptimal Hamiltonian word to admit a strictly improving single contiguous-block reversal. The mathematically relevant next step would need higher-order moves, averaging over all 2-opt exchanges, or a nonlocal combinatorial/topological selection rule that can escape these plateaus without relying on monotonicity of every step.
