# Minimum square-exchange rank and rootwise profile saturation

Let c be any legal antipodally odd coloring on Q_n (n>=2). Set V(c)=span over F2 of v_ij(u)=(partial_j c_i(u))e_i+(partial_i c_j(u))e_j for all i!=j and u. Let W_x be the set of full direction-indexed geodesic profiles from root x, and r=ceil(n/2). The prior notes note_019945e5faa732f94a3e1fce and note_8ea98c5469f2f46a628ea93b prove aff(W_x)=a+x+V, dim V>=r, and a canonical decomposition of V into autonomous even unmarked blocks (one parity relation per block) and fully generated marked blocks.

THEOREM 1 (minimum rank classification). dim V=r if and only if, after relabeling, c consists of m=floor(n/2) disjoint reciprocal reader pairs c_a=x_b+alpha and c_b=x_a+beta, plus, only when n=2m+1 is odd, one remaining direction h with an arbitrary complement-odd rule c_h=f(x_paired) independent of x_h. All pair rules ignore x_h.

PROOF. If t is the number of unmarked even blocks in the canonical decomposition, dim V=n-t. Equality dim V=r requires t=m. Each such block has at least two directions; hence n=2m has m disjoint size-two unmarked blocks, while n=2m+1 has those blocks and a marked singleton. An autonomous size-two legal odd block is a reciprocal signed unary reader pair. In the odd case the remaining rule can be any odd Boolean function of the paired bits. Conversely each pair yields one independent exchange vector e_a+e_b; the odd singleton rule has a nonzero derivative, giving the extra e_h when present. Thus dim V=m in even dimension and m+1 in odd dimension.

THEOREM 2 (saturation and witnesses). At minimum rank, for every root x one has W_x=aff(W_x) and |W_x|=2^r. The roots supporting any monochromatic full geodesic are precisely those obeying x_a+x_b=1+alpha+beta in every reader pair. Their number is 2^(n-m)=2^r and each such root supports both red and blue full geodesics. In even dimension n=2m, there are n! rooted ordered red full geodesics and n! blue ones.

PROOF. The relative order within each reader pair toggles both of its edge colors, independently of the other pairs. The pair-color xor is invariant and equals x_a+x_b+alpha+beta+1. Thus all 2^m pair-profile patterns compatible with these m parity equations occur. If n is odd, choose the pair orders for any desired paired profile. Along the resulting complete traversal of the paired directions, the odd Boolean function f changes from its initial value to its complement. Inserting h before or after a step where f changes gives either h-edge color, without changing pair colors. Thus all 2^(m+1) affine-admissible profiles occur. Both constant words are attainable if and only if the pair parities are all zero. The m constraints are independent; therefore there are 2^(n-m) successful roots. When n=2m, a red path at a successful root imposes one precedence constraint per pair, giving n!/2^m red direction orders. Multiplying by 2^m successful roots gives n! red paths and likewise blue.

THEOREM 3 (unrestricted profile support gap). For every legal odd coloring in every dimension n>=5 and every root x,
|W_x|>=2ceil(n/2)+2.
The bound is attained in n=5 and n=6, where the universal minimum is eight. The universal minima in dimensions n=2,3,4 are 2,4,4.

PROOF. Reversal of the full direction order from a fixed root complements the color profile, so W_x consists of k antipodal profile pairs, |W_x|=2k. Choosing one representative from each pair shows dim aff(W_x)<=k, since the differences are spanned by the all-ones vector and k-1 differences of representatives. The earlier full-class rank theorem yields k>=r. If k=r>=3, Theorem 2 would force |W_x|=2^r>2r, impossible. Hence k>=r+1. The minimum-rank examples attain eight in n=5,6 and the baseline bounds in n=2,3,4.

COROLLARY. A hypothetical unrestricted NORI1 counterexample in dimension n must have dim V>=ceil(n/2)+1.
