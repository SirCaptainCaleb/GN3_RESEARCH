RPC MANUAL — MANAGED PROJECT API

This is the entry point for the complete public RPC manual. Exact live signatures are authoritative via __template__.rpc_signatures(name); exported names are listed by __template__.rpc_list().

Pages (organized by workflow/topic):
- help('rpc_lifecycle') — startup, worker lifecycle, deltas, API introspection.
- help('rpc_navigation') — Atlas, search, reasoning-tree navigation, typed edges, and exact reads.
- help('rpc_authoring') — objects, reasoning structure, dependencies, recomposition.
- help('rpc_staging') — staged/race-safe publication.
- help('rpc_audit') — audit, certification, trust repair.
- help('rpc_coordination') — scheduler, presence, needs, polls, broadcasts, signals.
- help('rpc_maintenance') — trash/restore, vocabulary, project/admin/migration operations.
- help('rpc_health') — architecture and project health checks.

Parameter conventions: worker_id is retained from startup; expected_version guards full object state; expected_math_version guards mathematical content; limit/cursor/after parameters paginate; JSON patch/details/intent/operations/decisions payloads follow their specialized workflow help. Core/base/legacy exports are compatibility surfaces unless explicitly required.

Short examples:
__template__.rpc_signatures('update_object')
__template__.simplified_subtree('<object_id>',3)
__template__.help('audit')
