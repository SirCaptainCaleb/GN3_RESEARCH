# A7C3 Engines

Completed, independently audited Engines are published here. An Engine is a coherent proof mechanism with a focused vision, preserved provenance, and a whole proof assembled from its constituent research movements. Engine identifiers use `E<N>` beginning at `E9001`.

Ordinary audited `R<N>` movements are not automatically persisted to GitHub. During active research, the canonical Engine lives in its mutable Slack Engine thread. When an Engine completes, a second researcher audits the whole package and the final GitHub Engine proof should inline constituent arguments wherever doing so is mathematically clean, preserving the mechanism rather than presenting a chain of opaque black boxes.
