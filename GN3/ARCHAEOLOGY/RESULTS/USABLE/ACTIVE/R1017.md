# R1017 — Four-deletion exactness fails only on a classified P4-free four-cell

## Statement
Let H be a hypothetical smallest Strong Level-(1) counterexample and let D be any four-element vertex set with H-D nonempty. Then exactly one of the following holds. (EXACT) pc(H-D)=2. (CRITICAL-4) pc(H-D)=1, so H-D has a Hamilton tight path, while H[D] has no Hamilton tight P4. In the CRITICAL-4 branch, for every three-subset T of D and every tight trimer orientation C on T, writing y for the fourth vertex, the pair (C,y) lies in the no-P4 branch of R518. Hence D carries one of the four exact R516 terminal-sign alignment signatures relative to C, with the corresponding R517 matching-block quotient type (three transitive types and the uniform cyclic 00 type). Thus the only obstruction to four-deletion exactness is a graph-intrinsic P4-free four-cell with completely explicit local orientation data.

## Hypotheses
H is a hypothetical smallest Strong Level-(1) counterexample; D is an arbitrary four-element vertex set and H-D is nonempty.

## Scope
R24-free replacement interface for the four-vertex case of historical R5. It localizes failure of exactness but does not exclude the critical four-cell.

## Applicability
Whenever a historical R5 invocation deletes four named vertices, first test whether those four vertices support a tight P4. If yes, R4 gives exact two-cover of the complement. If not, retain the exact R516/R517 critical-cell signature and handle that finite residue explicitly.

## Persistence
The deletion set D, the value pc(H-D), any chosen Hamilton path on H-D in the critical branch, P4-freeness of H[D], each chosen tight trimer C on a three-subset of D, its fourth vertex y, and the resulting R516 signature/R517 quotient are graph-intrinsic except the chosen Hamilton path representative on H-D.

## Exclusions / nonclaims
Does not prove pc(H-D)=2 for arbitrary four-sets. Does not rule out any of the four R516 signatures. Does not prove R5 or R24. Different trimer orientations/subsets of D need not yield the same alignment bits, although all are descriptions of the same P4-free four-cell.

## Proof
Let H be a hypothetical smallest Strong Level-(1) counterexample and let D be a four-element vertex set with W=H-D nonempty. Because W is a nonempty proper induced subsystem, accepted smallest-counterexample minimality R4 gives pc(W)<=2. Path-cover number is at least one, so pc(W) is either one or two. If pc(W)=2, the EXACT branch holds.\n\nAssume pc(W)=1. Fix a Hamilton tight path Q on W. We claim H[D] has no Hamilton tight P4. Indeed, if P were a tight Hamilton P4 on D, then P and Q would be two vertex-disjoint tight paths whose supports partition V(H), giving a spanning two-cover of H. This contradicts pc(H)=3 from R4. Hence D is P4-free.\n\nNow fix arbitrarily a three-subset T of D. By accepted R8, T admits a tight trimer orientation C=(a,b,c). Let y be the unique vertex of D-T. Apply accepted R518 to this exact trimer C and fourth vertex y. R518 gives either a Hamilton P4 on D or its explicit no-P4 double-contact branch. The first alternative is impossible because D is P4-free. Therefore (C,y) lies in the no-P4 branch of R518: the two reverse contacts are tight, one of the four exact R516 terminal-sign alignment signatures is realized, and the corresponding R517 matching-block quotient is determined, with the three transitive quotient types and the uniform cyclic 00 type exactly as stated there.\n\nThe choice of T and of its tight trimer orientation C was arbitrary, so this classification is available for every trimer presentation of D. Consequently failure of four-deletion exactness is not an unstructured residue: it is exactly the case that H-D is Hamiltonian while the deleted four-set is a graph-intrinsic P4-free critical cell carrying the full R516/R517 local orientation data. This proves the stated dichotomy. No R5, R24, R168, R169, or singleton-order-floor input is used.
