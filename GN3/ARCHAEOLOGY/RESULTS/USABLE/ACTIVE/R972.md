# R972 — A trimer port forces a depth-two critical-cell component and expels Hamilton endpoints of the opposite rail

## Statement
Retain every conclusion of accepted R969 in the minimum-order R888 trimer-fiber setup G=X disjoint-union B. Then the following additional conclusions hold.

(1) CRITICAL FIVE-CELL DUALITY. For every Hamilton-deletable b in B and every x in X, X+b is non-Hamiltonian, X-x+b is Hamiltonian, and B-b+x is non-Hamiltonian. Thus every Hamilton-deletable b simultaneously gives four small-side Hamilton replacements and four complementary blocked large-side exchanges.

(2) INTERIOR BARRIER CONFINEMENT. Fix any increasing Hamilton order B=(b_0,...,b_m). For every x in X let beta_B(x) be the accepted R895 canonical insertion barrier against this displayed order. Then
  1 <= beta_B(x) <= m-2.
In particular every canonical barrier lies strictly away from both ends of every Hamilton order on B.

(3) OPPOSITE-RAIL FLOOR. Necessarily |B|>=5. Order three is impossible because the interval [1,m-2] is empty. Order four is impossible because, for distinct x,y in X, the blocked four-sets (B-b_0)+x and (B-b_0)+y share the Hamilton triangle B-b_0; accepted R963 Hamiltonizes their five-vertex union, while the complementary three-set is automatically Hamiltonian, yielding a spanning two-cover.

Consequently the accepted R969 long-rail reduction is universal in the trimer-fiber branch: every Hamilton order on B enters the R541 ALIGNED/CROSSED gate state, R582 supplies an endpoint-favorable P5, and R540 yields a one-hole spanning proposal with the exact normalized seam coordinates already retained by R969/D5. The current trimer problem therefore has no |B|=3 or |B|=4 residual.

## Proof
Retain every conclusion of accepted R969.

Let b in B be Hamilton-deletable and fix x in X. Since B-b is Hamiltonian, X+b cannot be Hamiltonian, otherwise (X+b)|(B-b) is a spanning two-cover. Suppose X-x+b were non-Hamiltonian. Then X and X-x+b are two non-Hamiltonian four-sets sharing the triangle X-x, so accepted R963 gives a Hamilton path on X+b. Together with Hamilton B-b this again two-covers G, contradiction. Hence X-x+b is Hamiltonian. Accepted R967 gives the complementary statement that B-b+x is non-Hamiltonian. This proves the critical five-cell duality.

Now fix any Hamilton order B=(b_0,...,b_m), write e_i=b_i b_{i+1}, and fix x in X. Since B+x is non-Hamiltonian, x is noninsertable into every gap of this displayed order, so accepted R895 defines beta_B(x). Endpoint b_0 is Hamilton-deletable, and R967 makes B-b_0+x non-Hamiltonian. If xb_1<e_1 then (x,b_1,...,b_m) is Hamiltonian on B-b_0+x, contradiction. Thus xb_1>e_1, so gap 0 is not right-feasible and beta_B(x) is not 0.

Dually b_m is Hamilton-deletable and R967 makes B-b_m+x non-Hamiltonian. If b_{m-1}x>e_{m-2}, then (b_0,...,b_{m-1},x) is Hamiltonian on B-b_m+x, contradiction. Hence b_{m-1}x<e_{m-2}. If beta_B(x)=m-1, the R895 canonical gap is left-feasible and would require e_{m-2}<b_{m-1}x, contradiction. Therefore beta_B(x) is not m-1. Consequently 1<=beta_B(x)<=m-2 for every x.

This interval is empty when |B|=3, so order three is impossible. If |B|=4, choose distinct x,y in X. The endpoint b_0 is Hamilton-deletable, so R967 makes S_x=(B-b_0)+x and S_y=(B-b_0)+y two non-Hamiltonian four-sets sharing the triangle B-b_0. R963 Hamiltonizes their five-vertex union (B-b_0)+x+y. Its complement is {b_0} union (X-{x,y}), a three-set and hence Hamiltonian in every edge-ordered complete graph. The two Hamilton paths form a spanning two-cover, contradiction. Thus |B|>=5.

Since |B|>=5, the size hypothesis of accepted R969 always holds. Therefore every Hamilton order on B has the retained R969 R541 ALIGNED/CROSSED polarity, R582 endpoint-favorable P5, R540 one-hole proposal, and normalized exact seam coordinates, in addition to the new critical-five-cell and interior-barrier conclusions. This proves R972.
