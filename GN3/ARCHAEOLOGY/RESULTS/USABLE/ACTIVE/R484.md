# R484 — End-Wrap Reverse-Ear Dichotomy

## Statement
Let H be a finite Strong Level-(1) boundary tournament and let P=(v_0,v_1,...,v_n) be a vertex-simple tight path with n>=2. Put w=v_n v_0. (Head-wrap.) If v_n v_0 v_1 is tight, then either the named reverse terminal trimer v_0 v_n v_{n-1} is tight, or V(P) supports the vertex-simple proper tight cycle with cyclic order v_n,v_0,v_1,...,v_{n-1}. (Tail-wrap.) Dually, if v_{n-1} v_n v_0 is tight, then either the named reverse initial trimer v_1 v_0 v_n is tight, or V(P) supports the same proper tight cycle. Thus a one-end rotation that selects the closing state v_n v_0 never yields only an anonymous order change: it certifies either a reverse ear pinned to the opposite endpoint neighbor or a cycle on exactly the old path support.

## Hypotheses
H is a finite Strong Level-(1) boundary tournament; P is a vertex-simple tight path with at least three vertices; accepted R3 and R435.

## Scope
Pure order-free Strong Level-(1) path-interaction lemma. No completion, smallest-counterexample, fixed-fiber, overlap, role-label, or representative-synchronization hypothesis.

## Applicability
Use when a wrap/currentization moves the tail of a named tight path to its head, or the head to its tail, by selecting the closing state. In the R182 fixed-fiber notation P=C_R=(h,x_1,...,x_{r-1},t), a head-wrap t h x_1 yields either h t x_{r-1} tight or a proper tight cycle on V(C_R); the tail-wrap x_{r-1} t h yields either x_1 h t tight or that cycle.

## Persistence
The closing state, the exact opposite endpoint neighbor, the reverse trimer when obtained, and the proper cycle support/order are graph-intrinsic once exhibited. No claim is made that the input path or its rotated path remains selected in later representatives.

## Exclusions / nonclaims
Does not recover the historical Cross-Completion Opposite-Role Collision theorem, does not define head-lost/tail-lost roles, and does not imply the deleted wrap boundary is an old residual boundary. A proper tight cycle is a constructive output, not a contradiction. The reverse trimer is localized to the named closing seam but is not by itself a spanning two-cover or physical sibling clause.

## Proof
For the head-wrap assume v_n v_0 v_1 is tight. Then K=(v_n,v_0,v_1,...,v_{n-1}) is a vertex-simple tight path. Compare K with P using R435 and take the consecutive K-contacts v_i=v_n and v_j=v_0, so i=n>0=j and the ear E is the single state v_n v_0. Since n>=2 this is the nonadjacent one-state case. R435 tests the two seam turns v_{n-1} v_n v_0 and v_n v_0 v_1. The second is tight by hypothesis. If the first is bad, R3 gives its antisymmetric reverse v_0 v_n v_{n-1} tight. If the first is also tight, R435 gives the vertex-simple proper tight cycle obtained by E followed by the old P-segment v_0,v_1,...,v_{n-1}, namely cyclic order v_n,v_0,v_1,...,v_{n-1}. For the tail-wrap assume v_{n-1} v_n v_0 is tight and use K=(v_1,v_2,...,v_n,v_0). Again the consecutive reverse-order ear is E=v_n v_0. Now the first R435 seam v_{n-1} v_n v_0 is tight by hypothesis. If the second seam v_n v_0 v_1 is bad, R3 gives v_1 v_0 v_n tight; if it is tight, the same proper cycle results.
