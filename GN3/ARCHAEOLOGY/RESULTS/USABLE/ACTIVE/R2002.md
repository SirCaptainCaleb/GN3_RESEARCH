# R2002 — Exact cycle criterion for the first-open source closure

**Status:** PASS
**Source:** workspace root `1789410954.532749`

## Statement

Retain the physical first-open detour state of R1061. The final source closure

`b_t->s`

is cyclic if and only if `s` is the source of the spectator-prefix component created by cutting `b_t->b_{t+1}`.

Equivalently, in the original normalized pre-loss forest, cyclicity occurs exactly when the rail contains the directed segment

`s -> ... -> b_t -> b_{t+1} -> ...`.

## Proof

Let `M` be the normalized pre-loss tight three-path forest, with

`d=b_t->b_{t+1}`

selected. Put

`M' = M-{d}+{v->b_{t+1}}`.

By R1061, `M'` is a tight three-path forest with free copies `b_t,out` and `s,in`.

Deleting `d` from its M-rail splits that rail into a prefix `P` ending at `b_t` and a suffix `Q` beginning at `b_{t+1}`. By R1060, `v` was an isolated singleton in M, so adding `v->b_{t+1}` only changes the suffix component, replacing Q by the path obtained by attaching v in front. The prefix P is unchanged.

The source spoke `s` is not incident with either modified edge, so it remains the source of the same component as before. The closure `b_t->s` creates a directed cycle exactly when its terminal endpoint `b_t` and source endpoint `s` lie on the same M'-rail. The M'-rail containing `b_t` is precisely P. Hence the closure is cyclic exactly when s is the source of P.

That condition is equivalent, in the original forest M, to the directed rail segment

`s -> ... -> b_t -> b_{t+1} -> ...`.

Conversely, if M contains this segment, cutting d leaves `P=(s,...,b_t)`, and adding `b_t->s` closes P into a directed cycle.
