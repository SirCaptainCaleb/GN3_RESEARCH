# R1036 — G37 hard-cell first positive pivot has a source/v marked corner when its adjacent switch exists

**Audit state:** PASS_ADJUSTED
**Proof provenance:** Slack `#a7c3-workspace` root `1789312109.292509`, audited against D17.419, D17.421, and corrected D17.433/R1035.

## Statement
Retain the sharp G35/G37 hard cell

`tau(F)=3`, `tau(J)=1`, `w(C_*)=2`,

with the F-normalized prefix closures of D17.421. Write

`W_0=sum_D w(D)`

for the total transition weight of the delta-zero components, let `S_q` be the zipper prefix ledger, and let `r` be the first index with `S_r>0`.

Then:

1. `W_0=0`, and every admissible normalized closure satisfies `T_q = 1 + S_q + (S_q mod 2)`.
2. For every admissible `q<r`, `S_q in {-1,0}` and hence `T_q=1`. At the first positive pivot, `S_r=1`; if `g_r` is admissible, `T_r=3=tau(F)`. Thus `r` is the first admissible numerical threshold index whenever `g_r` exists.
3. A **literal first-loss K_{2,2} rectangle at r** exists only when both adjacent closures `g_{r-1}` and `g_r` are defined. In that case its old same-side diagonal has one `X-X` edge and one `B-B` edge, and the `X-X` edge is incident with the physical X-endpoint `z` of the installed old F-transition `e_r`.
4. When that rectangle exists, exactly the intended root dichotomy holds:
   - if `z` is one of the three source spokes, the rectangle is source-rooted;
   - if it is not source-rooted, then `z=v`, the unique non-spoke X-vertex. This v-rooted case can occur only in the X-MATED SOURCE GATE ancestry class of D17.419. Since `d_F(v)=1`, every other old F transition is source-bearing.
5. If `g_{r-1}` is the unique singleton-defect loop while `g_r` exists, the numerical threshold still occurs at `r`, but there is no literal adjacent switch there. If `g_r` is the loop, the threshold closure itself is interrupted. In either loop case no source/v classification of a nonexistent first-loss rectangle is asserted.

## Adjustment to D17.434
D17.434 correctly proves the sharp-cell arithmetic, the first-positive ledger behavior, and the marked-corner geometry. It overstates the passage from the numerical threshold to a literal zipper rectangle by treating `g_r` as the only relevant loop check.

D17.421 defines the switch at index `r` by comparing the two closures `g_{r-1}` and `g_r`, so **both** must exist. The unique loop may occur at `g_{r-1}`. In that configuration `g_r` can be admissible and already have transition count three, yet the claimed `K_{2,2}` rectangle comparing the previous and current closures is absent.

Accordingly the durable dichotomy is a dichotomy of the literal first-loss rectangle **when the adjacent switch exists**. The numerical staircase itself does not need repair.

## Proof
Transition differences add over the symmetric-difference components. The sharp cell gives

`tau(F)-tau(J)=3-1=2=w(C_*)+W_0`.

Since `w(C_*)=2`, `W_0=0`. Because `w(C_*)` is even, D17.421 gives `gamma_q=S_q mod 2`, and therefore every admissible closure has

`T_q=1+S_q+(S_q mod 2)`.

For `q<r`, minimality of the first positive pivot gives `S_q<=0`. The normalized prefix matching has transition count `1+S_q`, which is a nonnegative integer, so `S_q>=-1`. Thus `S_q in {-1,0}` and the closure formula gives `T_q=1` whenever `g_q` exists. The one-step ledger changes by at most one, so `S_r=1`; if `g_r` exists then `T_r=3`. This proves the numerical threshold statement independently of whether `g_{r-1}` exists.

Now assume both `g_{r-1}` and `g_r` exist. D17.421 identifies their difference as the literal switch

`{f_r,g_{r-1}} <-> {e_r,g_r}`.

The old pair is same-side and the new pair is crossing. Let `z` be the physical X-endpoint of `e_r=a_{r-1}->b_r`. If `z=a_{r-1}`, then `g_{r-1}` is `X-X` and `f_r` is `B-B`; if `z=b_r`, then `f_r` is `X-X` and `g_{r-1}` is `B-B`. Hence the old `X-X` edge is canonically incident with `z`.

The hard-cell X-side is `{v,p,q,s}`, with `p,q,s` the three source spokes and `v` the sole non-spoke. Therefore `z` is either a source spoke or `v`. In the first case the rectangle is source-rooted. Corrected D17.433/R1035 shows that, whenever its adjacent switch exists, the SINGLETON-SPOKE branch lies in this source-rooted case. Consequently a literal non-source-rooted first-loss rectangle must be in the other D17.419 ancestry branch, X-MATED SOURCE GATE, and must have `z=v`. The old-source degree law `d_F(v)=1` then implies that every other old F transition is source-bearing.

Finally, D17.421 allows one unique index with `a_q=b_m`, making `g_q` a forbidden loop. If this index is `r-1`, then the individually admissible closure `g_r` may still realize the numerical threshold `T_r=3`, but the adjacent switch at `r` is undefined. If the loop is at `r`, the threshold closure is itself absent. This is the sole correction needed to D17.434.

## Scope
This result preserves the sharp-cell contraction but distinguishes two objects that D17.434 partially conflated: the first admissible closure at the old transition floor, and the literal adjacent `K_{2,2}` rectangle witnessing the rise. The source/v-rooted dichotomy applies to the latter only when both adjacent closures exist.
