# R1032 — Sharp source-frame counts do not consume the one-vertex obstruction

## Statement
There exists a globally edge-ordered Strong Level-(1) boundary tournament realizing the following data simultaneously:

- `B=(b1,b2,b3,b4)` is a tight Hamilton spectator path;
- `X={v,p,q,r}`;
- the three source turns `(A,p,C),(A,q,C),(A,r,C)` are tight;
- the source five-set `S={A,C,p,q,r}` has a Hamilton P5;
- `S union {v}` has no Hamilton P6;
- `B union {v}` has no Hamilton P5;
- on `G=H-{A,C}`, the literal old source two-cover

      F=(b1,p,q,r,b4) | (v,b2,b3)

  is tight and has `tau(F)=3`;
- the literal three-forest

      J=(p,q,r) | (v,b4,b3) | (b1,b2)

  is tight and has `tau(J)=1`.

Thus the raw source turns, Hamilton spectator, physicality of `F` and `J`, sharp transition counts, internal three-spoke old-source block, and simultaneous nonHamiltonicity of the two contracted one-vertex extensions do not by themselves force the G40/G41 closure. Any successful consumer must use further structure such as canonical D17.421 first-loss/gate ancestry, another genuine synchronization input, or a global minimal-counterexample consequence.

This is a fence on an abstraction, not a smallest counterexample.

## Construction
Use vertices

    {A,C,p,q,r,v,b1,b2,b3,b4}.

Define tight turns by a global strict order on ordinary edges: `(x,m,y)` is tight exactly when edge `xm` precedes edge `my`.

On the six-vertex nucleus `N={A,C,p,q,r,v}`, impose the edge order

    Ap < rv < Aq < Cp < Ar < AC < pr < Cv
       < pq < Av < Cq < pv < qr < qv < Cr.

Then the source turns are immediate:

    Ap < Cp,
    Aq < Cq,
    Ar < Cr.

Also

    Ap < pq < qr < Cr,

so `A,p,q,r,C` is a tight Hamilton P5 on `S`.

Direct enumeration of the `6!` vertex orders shows that no order of all six vertices has monotonically increasing consecutive edge weights. Hence `N=S union {v}` has no tight Hamilton P6.

On `{b1,b2,b3,b4,v}`, impose

    b3v < b2b4 < b2v < b1b3 < b1b4
        < b4v < b1b2 < b2b3 < b1v < b3b4.

Then

    b1b2 < b2b3 < b3b4,

so `B=(b1,b2,b3,b4)` is tight. Direct enumeration of the `5!` vertex orders shows that `B union {v}` has no tight Hamilton P5.

Finally impose the two cross inequalities

    b1p < pq,
    qr < rb4.

The two displayed total-order chains and these two additional inequalities form an acyclic partial order on ordinary edges, so extend it arbitrarily to a total edge order on the full vertex set.

## Verification of F and J
For

    F=(b1,p,q,r,b4) | (v,b2,b3),

we have

    b1p < pq < qr < rb4

and

    b2v < b2b3.

Thus both rails are tight. Relative to `X|B`, the selected crossing edges are `b1p`, `rb4`, and `vb2`, so `tau(F)=3`. The three source spokes occur consecutively and internally on the first rail.

For

    J=(p,q,r) | (v,b4,b3) | (b1,b2),

we have `pq<qr` and `vb4<b4b3`; the last component has order two. Hence `J` is a literal tight three-forest. Its only selected `X|B` edge is `vb4`, so `tau(J)=1`.

All claimed structures therefore coexist in one globally edge-ordered realization.

## Exclusions / nonclaims
The construction is not asserted to satisfy the canonical D17.421 first-loss rectangle, the later gate ancestry, the exact canonical `J` selection procedure, or smallest-counterexample minimality. It proves only that the displayed raw/sharp data are insufficient without some additional canonical or global input.
