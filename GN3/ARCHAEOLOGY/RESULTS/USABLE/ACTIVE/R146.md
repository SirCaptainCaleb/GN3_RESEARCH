# R146 — Three-exterior pair extension for a fixed tight trimer

## Statement
Let P be a three-vertex support carrying a tight trimer in a Strong Level-(1) boundary tournament, and let x,y,z be three distinct vertices outside P. Then at least one of the three five-sets P∪{x,y}, P∪{x,z}, P∪{y,z} supports a tight five-vertex path.

## Hypotheses
Strong Level-(1) boundary antisymmetry; P supports a tight trimer; x,y,z are distinct and outside P.

## Scope
Pure six-vertex local amplification. The proof is entirely human. It uses the repaired five-vertex edge-orderability theorem R902 and the independently human parallel-source P5 lemma S9022.

## Applicability
Use whenever one fixed tight trimer has at least three named exterior vertices. It forbids a complete three-vertex pair-shield around that trimer.

## Persistence
The conclusion is graph-intrinsic on the fixed six vertices.

## Exclusions / nonclaims
Does not identify which exterior pair extends P, and does not assert that every exterior pair extends P.

## Proof
Assume for contradiction that all three five-sets

    P∪{x,y}, P∪{x,z}, P∪{y,z}

are nonHamiltonian.

By R902, each of the three five-sets is edge-orderable. Their restrictions to the common three-set P induce the same comparison orientation on the three ordinary edges of K_P, because those comparisons are exactly the intrinsic tight turns of H[P]. Since an edge order makes that comparison orientation transitive, relabel the three core vertices a,b,c so that the common core-edge order is

    ab < ac < bc.

Hence the three core turns

    bac, abc, acb

are tight.

For an exterior vertex w define its core-match set M(w) subseteq {a,b,c} by

    a in M(w) iff bwc is tight,
    b in M(w) iff awc is tight,
    c in M(w) iff awb is tight.

These are exactly the three comparisons between the w-spokes, measured against the corresponding core comparisons. In any edge-order representation containing P and w, the six possible relative orders of wa,wb,wc give exactly the following six signatures:

| spoke order | M(w) |
| --- | --- |
| wa<wb<wc | {a,b,c} |
| wa<wc<wb | {b,c} |
| wb<wa<wc | {a,b} |
| wb<wc<wa | {a} |
| wc<wa<wb | {c} |
| wc<wb<wa | empty |

Now take two exterior vertices u,v. If M(u) and M(v) shared a coordinate, say a, then

    bac, buc, bvc

would be three parallel tight turns with common ordered endpoints b,c. By S9022 those five vertices would support a Hamilton P5, contradicting the assumed nonHamiltonicity of P∪{u,v}. Therefore

    M(x), M(y), M(z)

are pairwise disjoint.

Two of the match sets cannot both be empty. Indeed, suppose M(u)=M(v)=empty and use the edge order on the nonHamiltonian five-set P∪{u,v}. The table gives

    uc < ub < ua,
    vc < vb < va.

Compare ub and vb. If ub<vb, then

    c,u,b,v,a

is an increasing Hamilton path because cu<ub<vb<va. If vb<ub, then c,v,b,u,a is increasing. Either way P∪{u,v} is Hamiltonian, contradiction.

Thus the three match sets are pairwise disjoint, at most one is empty, and every nonempty match set belongs to

    {a}, {c}, {a,b}, {b,c}, {a,b,c}.

If none were empty, three pairwise disjoint nonempty subsets of {a,b,c} would have to be the three singletons {a},{b},{c}, but {b} is not an allowed signature. Hence exactly one match set is empty. After permuting x,y,z, the other two nonempty disjoint allowed signatures form exactly one of the three unordered pairs

    { {a}, {c} },
    { {a}, {b,c} },
    { {a,b}, {c} }.

Thus, after naming the empty-signature vertex x and ordering y,z appropriately, the only possibilities are

    I.   M(x)=empty, M(y)={a},   M(z)={c};
    II.  M(x)=empty, M(y)={a},   M(z)={b,c};
    III. M(x)=empty, M(y)={a,b}, M(z)={c}.

It remains to exclude these three configurations. We use the same elementary forcing rule as in R902. Under the standing assumption that the relevant five-set is nonHamiltonian, if two turns of a five-vertex word are tight, then the third must be bad and its complete reversal is tight. In the table

    W => rst

means that the other two turns of W are already tight, so rst is forced. Each row is read from left to right. The initial tight turns are determined by bac,abc,acb and the displayed match sets.

| case | successive forced turns | final contradiction |
| --- | --- | --- |
| I | bycxa=>xcy; xcyab=>bay; cxbay=>abx; czbxa=>xbz; acxbz=>xca; xcazb=>zac; yzacb=>azy; cxbya=>ybx; ybxac=>cax; bycax=>acy; bacyz=>zyc; bazyc=>zab; czabx=>xba | abx and xba |
| II | cxbya=>ybx; ybxac=>cax; bycax=>acy; bacyz=>zyc; czbxa=>xbz; acxbz=>xca; xcazb=>zac; zacbx=>xbc; xbcya=>ycb; azycb=>yza; yzacb=>bca | acb and bca |
| III | cxbya=>ybx; ybxac=>cax; bycax=>acy; xbacy=>abx; czbxa=>xbz; acxbz=>xca; xcazb=>zac; yzacb=>azy; bacyz=>zyc; bazyc=>zab; czabx=>xba | abx and xba |

For clarity, the initial exterior-core turns in the three rows are:

    I:   cxb,cxa,bxa;  byc,cya,bya;  czb,cza,azb.
    II:  cxb,cxa,bxa;  byc,cya,bya;  czb,azc,azb.
    III: cxb,cxa,bxa;  byc,ayc,bya;  czb,cza,azb.

Thus every possible signature configuration contradicts boundary antisymmetry. Our assumption that all three exterior pairs fail was impossible. At least one of P∪{x,y}, P∪{x,z}, P∪{y,z} therefore supports a tight Hamilton P5. QED.
