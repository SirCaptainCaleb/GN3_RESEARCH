# R817 — Crossed gates give four canonical 4+4 covers of the order-eight core

## Statement
Retain the accepted crossed R621 frame with X={a,b,c,z}, Q=(q_0,...,q_m), m>=4, L=q_0, u=q_1, s=q_{m-1}, R=q_m, left middle gate {a,c} fully outgoing from L, and right middle gate {b,z} fully incoming to R. Put G_8=H[X union {L,u,s,R}]. Then all four pairs obtained by choosing one left rail from A_1=(u,L,a,c), A_2=(u,L,c,a) and one right rail from B_1=(b,z,R,s), B_2=(z,b,R,s) are literal exact two-covers of G_8. Thus the crossed order-eight core has one fixed support partition {u,L,a,c} sqcup {b,z,R,s} carrying four simultaneous P4-by-P4 representatives. Moreover N=Q[2,m-2] is a nonempty tight path, so each of the four core covers together with N is a literal spanning three-cover of H; in a hypothetical smallest counterexample it is therefore a minimum three-cover.

## Hypotheses
H is in the accepted crossed R621 frame; m>=4; notation X={a,b,c,z}, L=q_0, u=q_1, s=q_{m-1}, R=q_m. Uses only the crossed gate polarities and universal endpoint reverse stars already present in accepted R621.

## Scope
Noncircular crossed-frame bounded-core theorem, valid already for m>=4. It strengthens the generic order-eight-core viewpoint by giving an explicit support partition and four literal P4-by-P4 representatives in the crossed branch.

## Applicability
Use as the preferred crossed bounded-core interface before deeper pair-deletion, capture, or five-cell machinery. The four simultaneous core representatives can be fed independently into block-insertion or rail-rotation arguments against the common middle path Q[2,m-2].

## Persistence
Retain the physical support partition {u,L,a,c}|{b,z,R,s}, the four oriented P4 rails A_1,A_2,B_1,B_2, and the common middle path N=Q[2,m-2]. These are simultaneous graph-intrinsic path facts in the original crossed frame.

## Exclusions / nonclaims
Does not close the crossed phase. Does not assert that the middle path N attaches to either core rail, that one of the four core covers is preferred, or that an analogous fixed 4+4 support partition exists in the aligned phase.

## Proof
In the crossed R621 frame, the left middle gate {a,c} is fully outgoing from L, so (L,a,c) and (L,c,a) are tight. The universal endpoint reverse stars retained in the same frame give (u,L,a) and (u,L,c) tight. Hence A_1=(u,L,a,c) and A_2=(u,L,c,a) are both tight P4s on the same support {u,L,a,c}. Dually, the right middle gate {b,z} is fully incoming to R, so (b,z,R) and (z,b,R) are tight, while the endpoint reverse stars give (b,R,s) and (z,R,s) tight. Hence B_1=(b,z,R,s) and B_2=(z,b,R,s) are both tight P4s on support {b,z,R,s}. The two supports are disjoint and partition V(G_8)=X union {L,u,s,R}. Therefore each of A_1 sqcup B_1, A_1 sqcup B_2, A_2 sqcup B_1, A_2 sqcup B_2 is a literal exact two-cover of G_8. Since m>=4, N=Q[2,m-2] is nonempty (a singleton when m=4 is allowed) and is a tight subpath of Q. Its support is disjoint from G_8 and together they partition V(H), so adjoining N to any of the four core covers gives a literal spanning three-cover of H. In a hypothetical smallest counterexample pc(H)>2, so each displayed three-cover is minimum.
