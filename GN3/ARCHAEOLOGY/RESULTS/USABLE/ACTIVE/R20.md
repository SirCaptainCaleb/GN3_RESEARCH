# R20 — Cover-puncture fragmentation identity

## Statement

Delete any proper set from a historical spanning cover and split what remains into maximal historical runs. In an exact cover of the deletion, the number of selected states joining different runs equals the number of run-color blocks in the current rails minus the number of current rails. It is at least the number of historical runs minus the number of current rails. Equality means each historical run occurs in one contiguous block.

## Scope

## Proof
Delete the prescribed proper vertex set from the historical spanning cover and split every surviving historical component at the deleted vertices into its maximal nonempty historical runs. Give every surviving vertex the color of the unique historical run containing it. Let the current exact cover of the deletion have q nonempty rails. On one current rail, compress consecutive vertices of the same historical-run color into maximal color blocks. If that rail has b color blocks, then exactly b-1 selected adjacent states of the rail join two different historical runs: these are precisely the adjacencies at the boundaries between consecutive color blocks, and no other selected adjacency changes run color. Summing over all q rails, the total number N of selected states joining different historical runs is therefore N=(sum of block counts)-q. This is the asserted identity. If the deletion leaves r nonempty historical runs, every such run contains at least one surviving vertex and hence appears in at least one current color block. Therefore the total number of blocks is at least r, so N>=r-q. Equality holds exactly when the total number of blocks is r. Since all r run colors appear at least once, this occurs exactly when each historical run appears in one and only one contiguous color block across the current rails. Conversely, if every historical run occurs in a single contiguous current block, the total block count is r and equality holds. The argument counts only current selected adjacencies and historical run membership; it determines neither their orientation nor any additional ancestry roles, exactly as fenced in R20.
