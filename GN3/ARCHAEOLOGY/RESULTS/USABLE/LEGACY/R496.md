# R496 — R495 same-end fork mates cannot preserve either source exit under currentization

**Record status:** `USABLE/LEGACY`

## Statement
Retain the head-fork (HF) output of R495. Thus X_H=(b_0,...,b_q,a_0), A^+=(a_1,...,a_p), and P^o=(z_1,...,z_{m-1}) form the displayed spanning three-cover, while the two one-hole candidates have bad seams s_A=(b_q,a_0,a_1) and s_P=(b_q,a_0,z_1) with tight exact mates H_A=(a_1,a_0,b_q) and H_P=(z_1,a_0,b_q). Then no vertex-disjoint path forest can simultaneously select either mate H_A or H_P and either of the two old directed exit states a_0a_1 or a_0z_1. Indeed each mate places a_0 internally with unique successor b_q; selecting a_0a_1 or a_0z_1 in any path component would give a_0 a second successor, while placing that state in another component would reuse a_0. Moreover H_A and H_P cannot be simultaneously selected in one path forest because both use the same internal state a_0b_q with distinct predecessors a_1,z_1. Dually, in the tail-fork (TF) output no path forest selecting either mate T_B=(a_0,b_q,b_{q-1}) or T_P=(a_0,b_q,z_{m-1}) can retain either old incoming state b_{q-1}b_q or z_{m-1}b_q, and the two tail mates cannot be simultaneously selected. Consequently bare R18 currentization, R19 grafting, or any argument that first makes an R495 fork mate current and only afterwards asks to retain the original two-prong ancestry cannot consume the fork. A valid consumer must instead use the literal one-hole proposal/hole certificate before mate currentization, or perform a genuinely cross-arm reroute that recreates the lost source exit/entry on another component.

## Hypotheses
The R495 head-fork HF or tail-fork TF packet is retained, with the displayed physical vertices distinct as inherited from its literal three-cover. A path forest means vertex-disjoint directed paths, so each internal vertex has one predecessor and one successor.

## Scope
Pure path-forest simultaneous-currentness obstruction attached to the R495 HF/TF fork. No smallest-counterexample, antisymmetry, payment, or completion theorem is used beyond the existence of the displayed fork states.

## Applicability
Fence the live R495 HF/TF residue before trying generic prescribed-path currentization or internal grafting. The result identifies exactly which coordinates are structurally incompatible with a current mate and therefore which data must be consumed at candidate level.

## Persistence
Retain the exact R495 mate trimers and old source exit/entry states as physical directed-state coordinates. The conclusion is a simultaneous-currentness incompatibility; the historical truth of all source/fork certificates remains available after representative changes.

## Exclusions / nonclaims
This does not say a fork mate is useless, does not forbid a later surgery from recreating an ancestral state elsewhere, and does not rule out a cross-arm or opposite-end reroute. It is only a simultaneous-currentness obstruction for the displayed physical states.

## Proof
Assume the R495 head fork HF. If a vertex-disjoint path forest selects H_A=(a_1,a_0,b_q), then a_0 occurs internally in one path component with predecessor a_1 and successor b_q. Selecting either old directed exit a_0a_1 or a_0z_1 in that same component would require a_0 to have a successor different from b_q; placing such a state in another component would reuse a_0. Hence neither old exit can coexist with H_A. The identical argument applies to H_P=(z_1,a_0,b_q): again a_0 is internal with unique successor b_q, so neither a_0a_1 nor a_0z_1 can coexist with it. Finally H_A and H_P cannot both be selected in one path forest. If placed in one component, a_0 would have the two distinct predecessors a_1 and z_1; if placed in different components, they reuse a_0 and b_q. Thus the two head mates are mutually incompatible as current states. The tail fork TF is dual. Selecting T_B=(a_0,b_q,b_{q-1}) or T_P=(a_0,b_q,z_{m-1}) makes b_q internal with unique predecessor a_0. Either old incoming state b_{q-1}b_q or z_{m-1}b_q would require a second predecessor if placed in the same component and would reuse b_q if placed elsewhere. The two tail mates cannot coexist because they require distinct successors b_{q-1},z_{m-1} from the same internal b_q (or else reuse vertices across components). Therefore currentizing a fork mate necessarily destroys the displayed same-side source exits/entries; any consumer preserving their ancestry must act at candidate level or recreate the lost state by a separate reroute.
