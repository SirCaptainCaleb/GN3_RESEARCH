# R99 — Minimum-overlap common-triple deletion gateway

**Record status:** `UNUSABLE/QUARANTINED`

## Statement
Let F be the family of supports of global-longest tight five-paths in the standing order-ten smallest counterexample. Choose A,B in F with globally minimum intersection |A∩B|=3, and write S=A∩B, U=A\B, V=B\A, R=V(H)\(A∪B). Then every exact two-cover T of H-S has unordered component profile 4+3. For the physical partition Pi={U,V,R}, t_Pi(T)=1+sigma with sigma>=0. Moreover sigma=0 if and only if one cover component is a tight trimer on R and the other is a tight four-path on U∪V obtained by concatenating a tight dimer on U and a tight dimer on V with exactly one inter-class transition. Otherwise sigma>=1 and hence t_Pi(T)>=2.

## Hypotheses
Standing order-ten smallest-counterexample case; A,B are a globally minimum-overlap pair in F with |A∩B|=3.

## Scope
Pure support/deletion geometry in the minimum-overlap-three butterfly branch.

## Applicability
Applies before choosing transversal versus hub in the R98 dichotomy.

## Persistence
The profile 4+3 conclusion and zero-excess classification depend only on the physical butterfly blocks and therefore are stable across representative changes; sigma itself remains cover-relative.

## Exclusions / nonclaims
Does not classify the positive-excess case beyond t_Pi(T)>=2 and does not by itself produce a spanning two-cover.

## Proof
Let T be any exact two-cover of H-S. By R11, its component orders are 5+2 or 4+3. Suppose they are 5+2, and let D be the support of the order-five rail. By R9 every tight five-path is global-longest, so D belongs to F. But D is contained in H-S=U∪V∪R, while A=S∪U. Thus |D∩A|=|D∩U|≤2. This contradicts the hypothesis that A,B realize the globally minimum intersection size 3 among members of F. Therefore every exact two-cover T of H-S has profile 4+3.

Now use the fixed physical partition Pi={U,V,R}. Each two-vertex wing has intrinsic path-cover number one, and R has intrinsic path-cover number one by R8. Hence the sum of the three intrinsic class path-cover numbers is 3. Since T has two components, R7 gives t_Pi(T)=3-2+sigma=1+sigma with sigma≥0.

If sigma=0, R7 says each class restriction realizes its intrinsic minimum, so each of U,V,R occurs as one unbroken class-restriction path in T. Because t_Pi(T)=1, exactly one inter-class transition joins two of these three class paths, while the third class is the other cover component. The component profile has already been proved to be 4+3. The only union of two classes having size four is U∪V; the unions U∪R and V∪R have size five. Thus the R-class is a tight trimer component, while the other component is a tight four-path obtained by concatenating the U dimer and the V dimer with exactly one U-V transition. Conversely, any exact cover with precisely this structure has each class restriction at its intrinsic minimum and t_Pi(T)=1, so R7 gives sigma=0. If this canonical zero-excess cover does not occur, then sigma is a nonnegative integer different from zero, hence sigma≥1 and t_Pi(T)≥2.
