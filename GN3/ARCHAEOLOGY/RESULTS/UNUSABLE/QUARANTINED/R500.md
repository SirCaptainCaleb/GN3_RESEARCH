## Statement
Let H be a hypothetical smallest Strong Level-(1) counterexample beyond order ten, and suppose the anti-aligned bridge in R495 comes specifically from the R478 P5 currentization. Hence P=(a_0,z_1,z_2,z_3,b_q) has exactly five vertices, so the literal source cover P sqcup A^+ sqcup B^- gives |H|=p+q+5 and therefore p+q>=6. If the R495 output is DR, then H contains a graph-intrinsic balanced opposite-sign pair with a four-deletion cross-state certificate retaining named bridge/ancestral residual classes. If p,q>=2 this is exactly R499. If p=1, then q>=5. Delete E_B={a_0,a_1,b_q,b_{q-2}}. The source cover restricted to H-E_B is the literal three-cover B_L sqcup (b_{q-1}) sqcup P^o, where B_L=(b_0,...,b_{q-3}) and P^o=(z_1,z_2,z_3); all three classes are nonempty. R5 gives an exact two-cover T of H-E_B, R7 forces T to select a state crossing two of these three named classes, and R176 converts that selected cross-state into a balanced opposite-sign pair. Dually, if q=1 then p>=5. Delete E_A={a_0,b_q,b_{q-1},a_2}. The restricted source cover is the literal three-cover (a_1) sqcup A_R sqcup P^o with A_R=(a_3,...,a_p), again all nonempty; R5,R7,R176 give the same conclusion. Thus in the beyond-order-ten R478 P5 application every DR output, including both short-arm cells excluded from R499, immediately births a balanced pair without currentizing the DR path or forgetting the original bridge/ancestral coordinates.

## Proof
Because the R478 bridge has five vertices, the source cover has n=|P|+|A^+|+|B^-|=5+p+q. Since n>10, p+q>=6. If p,q>=2, apply R499. Suppose p=1. Then q>=5. Delete E_B={a_0,a_1,b_q,b_{q-2}}. In the original source cover, P loses a_0,b_q and becomes P^o=(z_1,z_2,z_3); A^+=(a_1) disappears; B^-=(b_0,...,b_{q-1}) punctured at b_{q-2} becomes B_L=(b_0,...,b_{q-3}) plus singleton (b_{q-1}). These three nonempty tight paths cover H-E_B. R5 gives an exact two-cover T. Partition by their supports and apply R7: t=3-2+sigma>=1, so T has a selected state crossing two source components. R176 yields a balanced pair. If q=1, then p>=5. Delete E_A={a_0,b_q,b_{q-1},a_2}. Now B^- disappears, P becomes P^o, and A^+ punctured at a_2 becomes singleton (a_1) plus A_R=(a_3,...,a_p), again three nonempty source components. The same R5/R7/R176 argument applies. Hence every DR case in the P5 application yields the claimed balanced pair.
