# R315 — O4 dichotomy: protected first contact or the unique order-eleven longest-five residue

**Record status:** `UNUSABLE/QUARANTINED`

## Statement
Let H be a hypothetical smallest Strong Level-(1) counterexample in the beyond-order-ten regime. Then one of the following holds. (1) H contains a proper tight path of order at least six, in which case provisional R313 supplies an internal-dimer puncture with a lawful historical capture and, after choosing a protected continuation, a forced first-contact event via old-carrier mirror reentry. (2) Every proper tight path has order at most five. Then provisional R314 gives |H|<=11. Since R191 excludes order ten and the live regime is beyond order ten, necessarily |H|=11. Accepted R193 supplies a tight P5 in every six-set, so the maximum proper tight-path order is exactly five. Hence all contact-free survivors of O4 are confined to the single finite residue n=11, L(H)=5; every order n>=12 survivor is forced into the protected capture/contact frontier.

## Hypotheses
H is a hypothetical smallest Strong Level-(1) counterexample of order greater than ten; accepted R191, R193; provisional R313 and R314.

## Scope
Arbitrary-order parent reduction separating genuine historical-contact progress from one finite residual order.

## Applicability
Use as the new top-level O4 split. For n>=12 work only on the protected first-contact branch; if avoiding that branch, switch entirely to order-eleven longest-five geometry.

## Persistence
The order n, maximum proper-path order L(H), and the existence of the puncture/contact event are graph/history data in their respective branches.

## Exclusions / nonclaims
Does not claim a first-contact event itself closes the conjecture. Does not solve the order-eleven residue. Does not use generic R38 or fixed-trimer packet existence as progress.

## Proof
Let L be the maximum order of a proper tight path in H. If L>=6, choose such a path and apply R313 to obtain the asserted puncture-indexed capture and protected first-contact alternative, unless a spanning two-cover already occurs. Since H is hypothetical counterexample, retain the contact branch. If L<=5, R314 gives n<=2L+1<=11. The live O4 regime is beyond order ten, and R191 independently excludes order-ten smallest counterexamples, so n=11. Finally R193 applied to any six vertices gives a tight P5, so L>=5. Thus L=5. These cases exhaust all possibilities.
