## Repeated hole-preserving cores force transport or synchronized second-layer reversals

Retain the setup of [[four_exposed_endpoints_force_a_repeated_hole_preserving_core]]. Thus
\[
Y\mid P\mid Q
\]
is a spanning three-cover, \(|Y|=5\), the distinguished holes \(x,y\) lie in \(Y\), and for some ordinary label \(r\in Y-\{x,y\}\) the four-core
\[
C=Y-\{r\}
\]
has Hamiltonian endpoint extensions at two exposed tail endpoints.

Let \(T=(t_1,\ldots,t_m)\) be one of the long tails and suppose
\[
C\cup\{t_1\}
\]
is Hamiltonian. If
\[
(T-\{t_1\})\cup\{r\}
\]
is Hamiltonian, replacing \(Y\mid T\) by
\[
(C\cup\{t_1\})\mid((T-\{t_1\})\cup\{r\})
\]
is a neutral pairwise repartition and the new small component still contains both distinguished holes.

If that replacement tail is non-Hamiltonian, the endpoint-replacement/truncation theorem makes \(r\) noninsertable in the inherited truncated path \((t_2,\ldots,t_m)\). Hence
\[
\boxed{h(t_3,t_2,r)=1.}
\]
The terminal endpoint gives the mirror conclusion: either a neutral exchange or
\[
\boxed{h(r,t_{m-1},t_{m-2})=1.}
\]

Consequently, if the repeated four-core accepts both endpoints of one tail, then either a hole-preserving neutral transport is available or the same ordinary label \(r\) reverses both second-layer end edges of that tail.

If instead the repeated core accepts one endpoint of \(P\) and one endpoint of \(Q\), then either one corresponding hole-preserving exchange succeeds, or the same label \(r\) reverses a second-layer edge of each complementary tail.

Thus failure of hole-preserving transport creates one synchronized ordinary reverser across exactly the tails on which the common four-core repeats.
