# Root deletion localizes extension incompatibility to one adjacent two-defect seam

## Composition

Let C be a vertex set and y outside C. Take a Hamiltonian word W on C union {y} and delete y, obtaining an order sigma on C. Every consecutive triple of sigma is inherited from W except at most the two new triples crossing the deleted position. Hence the defect set of sigma is contained in two adjacent status positions. If y was an endpoint, sigma is Hamiltonian. In the full interior case W has local word a,b,y,c,d. If both bridge triples (a,b,c) and (b,c,d) are non-tight, boundary reversal gives (c,b,a) and (d,c,b) tight, so (d,c,b,a) is a tight four-path. Therefore a Hamiltonian one-root extension is either compatible with a Hamiltonian core order, has one marked bridge defect, or exposes a reversed four-vertex seam. This is genuine triple-local information absent from support-only models.
