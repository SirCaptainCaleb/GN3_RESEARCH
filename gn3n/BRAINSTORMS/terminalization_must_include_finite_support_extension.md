# Terminalization must include finite-support extension

The audited finite theorem proves only that each terminal induced support is two-coverable. To close the grand conjecture, terminalization must additionally show that this local two-cover can be inserted into the ambient spanning order, or otherwise converted into a spanning two-cover; induced-support two-coverability alone is insufficient.

The current local-witness finitization is correct as an induced-subtournament theorem: every terminal determining support has order at most ten and path-cover number at most two. This does not by itself solve the terminal branch globally. Reordering the bounded support can change the two status windows crossing each end of the support, and vertices outside the support may still carry farther-out forbidden witnesses. Therefore the global closure theorem must have an extension/replacement clause. A sufficient form would be: from a terminal carrier, either construct a spanning two-cover directly, or replace the bounded contiguous determining interval by an order whose internal status word is two-cover-good and whose new boundary defects lie strictly farther outward, in a way that preserves enough topological balance to continue. Equivalently, terminalization must promote local finite two-coverability to an extendable local surgery, not merely cite the induced support theorem. This is now part of the exact frontier.
