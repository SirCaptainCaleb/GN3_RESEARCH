# Zero-root symmetric holes as the common grand-conjecture frontier

After eliminating the kappa_2=1 nonzero four-block and using the existing kappa_2>=2 zero-root theorem, all deletion-distance regimes funnel to a chamber with exact root p=c. The remaining global problem is to exploit the resulting equal-side canonical partial two-cover with a nonempty symmetric hole.

Let kappa_2(H)>0. Exact-root topology now points to the same object in every regime. For kappa_2>=2, the existing recurrent-face theorem forces a chamber with p=c. For kappa_2=1, the three-role augmented map previously reduced the nonzero branch to one equal-side four-vertex block; [[kappa_one_nonzero_four_block_is_impossible]] eliminates that block, so an augmented zero carrier must contain a zero-root chamber as well. Thus the common frontier is a spanning order pi with p(pi)=c(pi), giving canonical tight paths P_pi and Q_pi of equal order and a nonempty middle hole X_pi. The hole size is delta(pi)=m-2p(pi)>=kappa_2(H). The next targets are: (1) force a zero-root chamber with hole size exactly kappa_2(H); or (2) prove any equal-side zero-root partial cover can be modified to reduce its hole or yield a two-cover. This route is global and does not require minimum-counterexample disturbance arguments. For kappa_2=1 the object is an equal-length deletion cover H-x=P|Q; combine this symmetry with the new complementary-splice machinery and the Ky Fan role-alternation structure. For larger kappa_2, seek an analogous multi-hole splice or a reduction of the symmetric hole.
