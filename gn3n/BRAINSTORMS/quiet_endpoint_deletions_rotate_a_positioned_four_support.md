# Quiet endpoint deletions rotate a positioned four-support

For a positioned Hamiltonian four-support K=(k0,k1,k2,k3) with path-cover-two complement in a minimum counterexample, analyze the case where deletion covers at both displayed endpoints remain quiet one-crossing relative to the three-piece comparison geometry. Quietness appears to force a crossed second Hamilton order, rotating endpoint-root access to the two internal vertices.

Let K=(k0,k1,k2,k3) be a proper Hamiltonian four-support in a minimum counterexample, with H-K having path-cover number two. Apply the generalized endpoint-deletion comparison at k0 and k3. Assume both deletion comparisons avoid a two-cover, order disagreement, split inherited edge, and leave-and-return disturbance, so each is in the unique quiet one-crossing branch.\n\nFor H-k0, the inherited core C0=(k1,k2,k3) cannot occur first in the mixed comparison path: prepending k0 would use the already-tight triple (k0,k1,k2) and would restore a spanning two-cover. Hence C0 occurs last. If the omitted k0 appended to that mixed path, there would again be a two-cover, so the terminal triple (k2,k3,k0) is non-tight. Boundary reversal gives (k0,k3,k2) tight.\n\nFor H-k3, the inherited core C3=(k0,k1,k2) cannot occur last in the mixed comparison path, because appending k3 uses the already-tight triple (k1,k2,k3). Hence C3 occurs first. Prepending k3 to the mixed path must fail, so (k3,k0,k1) is non-tight and boundary reversal gives (k1,k0,k3) tight.\n\nTherefore (k1,k0,k3,k2) is a second Hamiltonian order on K. Its endpoint pair is {k1,k2}, complementary to the original endpoint pair {k0,k3}. Thus two quiet endpoint comparisons rotate endpoint-root access from the original endpoints to both internal vertices.\n\nApplied to the positioned common-carrier support K=(a_r,u,b_s,b_{s-1}) (or its symmetric form), this makes the carrier u itself a displayed endpoint of a Hamilton order unless one of the original endpoint deletions already enters the standard disturbance interface. Hence the v104-v106 branch sharpens to: disturbance/two-cover at an inherited endpoint, or an endpoint-rotated K4 admitting a carrier-rooted deletion comparison. The next target is to combine this carrier-rooted probe with the explicit inherited three-piece complement retained by the positioned support.
