# The five-edge cyclic defect run is impossible in a minimum counterexample

## Statement

Let H be a minimum counterexample to the grand two-cover conjecture and let pi be a minimum-defect-span ordering. Its cyclic defect graph Gamma cannot have proper run multiset {5}. Consequently the 111 branch of the five-type cyclic classification reduces from {3,1},{3,2},{5} to {3,1},{3,2}.

## Body

By mincex01, |V(H)|>10. Suppose Gamma has one defect run of five consecutive cyclic centers. Write the corresponding seven distinct consecutive vertices of the cyclic order as W=(w_0,w_1,...,w_6), so each of the five triples (w_j,w_{j+1},w_{j+2}), 0<=j<=4, is non-tight. Boundary antisymmetry makes every reversed triple (w_{j+2},w_{j+1},w_j) tight, hence W^R=(w_6,w_5,...,w_0) is a tight seven-path. Form a new cyclic vertex order by reversing exactly this seven-vertex block and leaving every exterior vertex in its old cyclic order. Every cyclic triple wholly inside the reversed block is tight, and every cyclic triple wholly outside the block is unchanged and tight because the original five-edge run was the entire defect set. Thus a triple can be defective in the new cyclic order only if its three positions meet one of the two block boundaries. At each boundary only the two centers nearest that boundary can change. Since n>10, the two boundary zones are disjoint and separated on both sides, so the new cyclic defect graph Gamma' is the disjoint union of at most two edge-runs, each of length at most two. Hence nu(Gamma')<=2. If nu(Gamma')<=1, any cut already gives a spanning ordering with contiguous-path number at most two. If nu(Gamma')=2, choose a cut vertex q in one nonempty boundary run that kills that run's matching contribution: for a one-edge run take either endpoint, and for a two-edge run take its middle vertex. Then the other boundary run contributes at most one, so nu(Gamma'-q)<=1. By the defect-line identity ca8dc4ee0bde applied to the rotation cut at q, the resulting spanning ordering has contiguous-path number at most 2, contradicting pc(H)>2. Therefore type {5} is impossible.
