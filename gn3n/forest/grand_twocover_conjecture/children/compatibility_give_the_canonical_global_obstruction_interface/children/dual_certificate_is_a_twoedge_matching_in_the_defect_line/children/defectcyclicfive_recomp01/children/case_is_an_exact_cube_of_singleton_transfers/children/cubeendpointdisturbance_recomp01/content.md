# The {1,1,1} cube reduces to descent, neutral transport, or all-equal endpoint disturbance

## Statement

Let Gamma be a minimum-span cyclic defect certificate of run type {1,1,1}. Then either: (1) some cube state has strictly smaller quadratic potential; (2) the equitable nonuniform antipodes are joined inside the cube by a three-step Phi-neutral singleton-transfer path; or (3) the antipodal base cover is all equal, A|B|C with |A|=|B|=|C|=r, and for each base path X in {A,B,C}, arbitrary two-covers of the two endpoint deletions of X force at least one standard endpoint-transport disturbance: order disagreement, inherited-edge support crossing, or a leave-and-return excursion relative to A|B|C. Moreover, whenever opposite endpoint probes of a displayed path preserve the surviving inherited block intact and in inherited order and have no order disagreement, the common-middle square machinery yields either a Hamiltonian support of order r+2 or a doubled same-side reverse obstruction.

## Body

The cube-size parametrization and transfer classification give the three cases. If the size profile has a gap at least two, transferring one vertex from a largest class to a smallest class strictly decreases Phi. If the profile is equitable but nonuniform, the certified neutral-transfer lemma supplies the three-step Phi-neutral path between antipodes. The only remaining case is the all-equal profile.

In the all-equal case, apply the certified equal-cover endpoint-probe theorem independently to A, B, and C. For any chosen base path X and arbitrary two-covers of its two endpoint deletions, one obtains order disagreement, inherited-edge support crossing, or a leave-and-return excursion relative to the inherited three-cover. Thus the all-equal case is already an endpoint-disturbance source on each of its three base paths.

Separately, suppose opposite endpoint probes of some displayed path satisfy the stronger intact-block hypotheses and have no order disagreement. The opposite-end migration lemma gives the two-for-two support migration; the common-middle closure lemma completes the four-corner square; and the square-amplification theorem yields either a Hamiltonian support of order r+2 or the doubled same-side reverse obstruction. This last implication is conditional and is not obtained by negating the endpoint-disturbance theorem.
