# Support-level deletion-cover cocycles have trivial monodromy

## Statement

Let F_1,...,F_k, k>=4, be deletion covers around distinct omitted labels with a nonempty common surviving core. If consecutive covers around a cycle are support-compatible, then all F_i are pairwise support-compatible. Consequently any deletion-cover cocycle whose transition datum records only the two support classes has trivial monodromy around every support-compatible cycle. Any genuinely nontrivial cocycle obstruction must therefore encode relative order inside a common support class (or information strictly stronger than support membership).

## Body

This is the direct cocycle interpretation of the certified support-cycle closure theorem compatsupportc5close24. Consecutive support compatibility already propagates around the cycle to give one common support partition on every pairwise common domain. Hence there is no nontrivial holonomy at the support-partition level. The cocycle route's intermediate datum, if it exists, must sit above support compatibility and below the full ordered pair-state table; the only remaining room is order-sensitive transport within the common support classes.
