# Use the binary longest-path balance as the secondary coordinate in one-defect reconfiguration

## Statement

Proposal: in the one-defect reconfiguration regime, replace the earlier secondary displacement word by the equivalent binary prefix-balance coordinate. Fix a globally longest path A. For every order-preserving comparison path of deficit one with no reversal witness, record at each surviving A-vertex whether prior omissions from A exceed prior exterior insertions by 0 or 1. Use this binary balance together with the primary support/deletion-side normalization as the state coordinate. A useful move theorem would strictly improve a lexicographic feature of this binary process or expose a reversal/order disagreement.

## Body

One-defect support states are already known to be deletion covers with the omitted label restored, so this is the natural regime in which to use the positional-lag identity. The exact prefix-balance theorem says the discrepancy is confined to {0,1}; this is much stronger than arbitrary local failed-insertion signs. The missing point is not finiteness but monotonicity under legal reconfiguration. Candidate statistics include the first balance-change location, the number of 0-to-1 returns, or the ordered list of change locations, but none is asserted to decrease yet. The immediate task is to compute symbolically how one certified endpoint replacement or deletion-cover swap transforms the balance sequence.
