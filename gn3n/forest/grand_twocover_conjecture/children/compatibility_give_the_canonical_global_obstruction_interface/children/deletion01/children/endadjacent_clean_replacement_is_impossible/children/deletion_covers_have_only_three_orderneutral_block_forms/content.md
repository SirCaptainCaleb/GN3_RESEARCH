# End-adjacent equality-two-crossing deletion covers have only three order-neutral block forms

## Statement

Let H be a minimum counterexample and let H-x=P|Q be a deletion cover with displayed paths P=(p_0,p_1,...,p_m), m>=3, and Q. Put y=p_1 and R=(p_2,...,p_m). Let F be any deletion cover of H-y. Relative to the four-part partition {p_0}|V(R)|V(Q)|{x}, suppose F has exactly two ordinary crossing edges and has no relative-order disagreement with the inherited displayed orders on the common vertices of P and Q. Then F has exactly one of the following three ordered forms: (A) (x,p_0,p_2,...,p_m)|Q; (B1) (x,p_2,...,p_m)|(p_0,Q); (B2) (x,p_2,...,p_m)|(Q,p_0), where Q denotes its displayed order. In particular, the equality-two-crossing, order-neutral branch is a finite block-pattern residue independent of |P| and |Q|.

## Body

Delete the two cross-class ordinary edges of F. The transition identity gives four nonempty monochromatic blocks because F has two path components and exactly two cross-class edges. Equality also implies that each of the four partition classes {p_0}, V(R), V(Q), {x} occurs as exactly one block. Contracting blocks therefore gives a forest on four block-vertices with two edges: either one three-block path plus one isolated block, or two disjoint block-edges. The inherited R- and Q-blocks are traversed in their displayed orders by the no-order-disagreement hypothesis. We eliminate all but the stated forms. First consider a three-block path plus an isolated block. The isolated block cannot be {p_0} or {x}, since replacing that singleton component by the vacuous two-vertex path (y,p_0) or (y,x) would two-cover H. It cannot be R, since m>=3 makes R begin (p_2,p_3), and (y,p_2,p_3) is inherited from P, so y can be prepended to R. Hence Q is isolated. The other component uses the blocks {p_0},{x},R. Any order placing R before p_0 reverses the common P-order and is excluded. If it begins p_0,x, the endpoint hook (y,p_0,x) from c38e8b5c48ee lets us prepend y, giving a two-cover of H. If it begins p_0,R, the inherited triples (p_0,y,p_2) and (y,p_2,p_3) let us insert y between p_0 and R, again two-covering H. Thus the only surviving order is (x,p_0,R), which is (A). Now suppose the contracted forest is two disjoint block-edges. There are three pairings. Pairing p_0 with R is impossible: order p_0,R allows insertion of y between them as above, while order R,p_0 reverses the common P-order. Pairing p_0 with x and R with Q is impossible: if the p_0-x component is ordered p_0,x then (y,p_0,x) prepends y; if it is x,p_0, then that component has order two, contradicting the minimum-counterexample fact that every deletion-cover component has order at least three. Thus the only surviving pairing is x with R and p_0 with Q. The x-R component cannot be ordered R,x because y prepends to R using (y,p_2,p_3). Hence it is (x,R). The p_0-Q component may be (p_0,Q) or (Q,p_0), yielding (B1) and (B2).
