# Neutral gap-two wraps are involutive outside an arithmetic progression and force a common-middle square or order disagreement inside it

## Statement

In a quadratic-potential-maximal trapped three-block state with no double-non-tight block-pair orientation, a neutral wrap is possible only across block orders differing by two and simply swaps those two order values. Repeating it on the same pair is an involution unless a double failure appears. Therefore any nonbacktracking neutral-wrap walk that genuinely uses the third block requires block orders r,r+2,r+4. In that arithmetic-progression residue, six prescribed clean wraps force a full 2-by-2 common-middle square on the original middle core, and if twelve prescribed wraps occur without a double failure then the three supports return with explicit same-support relative-order disagreement.

## Body

The two-sided endpoint-transfer rule combines into one wrap: for a larger block X of order q+2 and smaller Y of order q, the path (last(X),Y,first(X)) is tight whenever neither interface has a double failure, and the complementary interior of X is inherited. The move preserves Phi exactly and swaps the two order values. Applying the same construction to the transformed pair restores the original supports and orders, so same-pair wrapping is an involution unless a double failure appears. Hence a nonbacktracking second wrap must involve the third block; with three distinct invariant order values, two distinct gap-two pairs exist exactly for r,r+2,r+4. Along the unique alternating gap-two circuit, direct substitution after six wraps gives a middle path with the same interior core B_0 and opposite endpoint pair from the original large block. Together with the original middle path, the common-middle rectangle theorem forces the two crossed paths, producing the full 2-by-2 square. Continuing the same six-wrap circuit once more returns all three supports but reverses relative order on explicit pairs in the first two blocks, yielding same-support order disagreement. Thus the AP residue cannot remain neutral: within the prescribed circuit it exposes a double-non-tight interface, a common-middle square after six clean wraps, and by twelve clean wraps explicit order disagreement.
