# Endpoint-incidence Hall route

## Statement

Associate to each deletion label d the admissible endpoint roles it can occupy among normalized two-covers of H-d. Conjecture that either these endpoint-role sets satisfy a Hall-type system of distinct representatives large enough to thread the labels into two coherent endpoint chains, yielding a global two-cover, or some Hall-deficient set forces many labels to share a bounded endpoint neighborhood, creating a rigid concentration that can be compressed by existing compatibility/ordering lemmas.

## Body

This reframes many deletion states as an incidence problem rather than comparing them pairwise. The desired dichotomy is matching versus concentration.
