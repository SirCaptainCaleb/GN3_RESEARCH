# A mandatory triple is Hamilton-order rigid on every cover support that carries it

## Statement

Let H have a mandatory ordered tight triple T: every spanning two-cover of H contains T consecutively in one component. Let A|B be any spanning two-cover in which the displayed component A contains T consecutively. Then every Hamilton tight path on the induced subtournament H[V(A)] contains T consecutively.

## Body

The displayed path on B is already a Hamilton tight path of H[V(B)]. Suppose H[V(A)] had a Hamilton tight path P that did not contain T consecutively. Then P together with the displayed path on B would be a spanning two-cover of H. The B-component contains none of the vertices of T, since T is contained in A, while P avoids T consecutively by assumption. Thus this spanning two-cover contains no component using the mandatory ordered triple T, contradiction. ∎
