# A tight detour replacing one edge gives a reversed-edge path or a bounded wrap extension

## Statement

Let x,y,u_1,...,u_k be distinct vertices, k>=1, such that D=(x,u_1,...,u_k,y) is a tight path. Regard xy as a distinguished old ordinary edge. Then at least one of the following holds: (1) the cyclic order (x,u_1,...,u_k,y) is a tight cycle, and consequently opening it after x gives a tight path (u_1,...,u_k,y,x) in which the distinguished pair occurs as y,x rather than x,y; (2) (x,y,u_k) is tight; (3) (u_1,x,y) is tight. Thus failure of cycle closure produces a tight triple supported on the old edge and one endpoint of the detour.

## Body

All cyclic consecutive triples of the displayed cycle are inherited from the tight path D except possibly the two wrap triples (u_k,y,x) and (y,x,u_1). If both are tight, the cyclic order is a tight cycle and opening the cycle at the ordinary edge x u_1 yields the tight path (u_1,...,u_k,y,x), where y precedes x consecutively. If (u_k,y,x) is not tight, boundary antisymmetry gives its reverse (x,y,u_k), outcome (2). If (y,x,u_1) is not tight, antisymmetry gives (u_1,x,y), outcome (3). If both fail then both bounded wrap extensions hold.
