# The five-set branch simultaneously reverses both chosen endpoint edges

## Statement

In the setting of compatdoubleendpoint43, if the reverse-cross-triple alternative does not occur, then the certified Hamilton path on W={a,u,b,c,v} contains, as consecutive ordered pairs, the reversals of both displayed endpoint edges au of P and cv of Q. Thus the five-set branch is not a bare Hamiltonian-window output: it supplies one bounded Hamilton path simultaneously reversing the chosen endpoint edge of each component.

## Body

Use the four explicit Hamilton paths already established in compatdoubleendpoint43, with no new cyclic rotation or orientation inference.

If a and c are both terminal, P=(...,u,a), Q=(...,v,c), and the Hamiltonian branch gives (a,u,b,c,v). Its consecutive pairs a,u and c,v reverse the displayed terminal endpoint pairs u,a and v,c.

If a and c are both initial, P=(a,u,...), Q=(c,v,...), and the Hamiltonian branch gives (v,c,b,u,a). Its consecutive pairs v,c and u,a reverse the displayed initial endpoint pairs c,v and a,u.

If a is terminal and c is initial, the Hamiltonian branch gives (a,u,b,v,c), containing a,u and v,c, the reversals of u,a and c,v.

If a is initial and c is terminal, the Hamiltonian branch gives (c,v,b,u,a), containing c,v and u,a, the reversals of v,c and a,u.

Hence every Hamiltonian-five branch of the certified four-orientation theorem carries simultaneous reversals of both selected component-end edges. The alternative branch is already an explicit reverse cross triple through b. No triple beyond those certified in compatdoubleendpoint43 is asserted.
