# An internal reversed edge localizes to a Hamiltonian, cyclic, or uniquely ordered matching-block four-kernel

## Statement

Let H be a boundary tournament. Let P be a tight path containing an internal displayed edge uv, so P has both a predecessor a of u and a successor b of v. Suppose a tight triple T reverses the displayed order uv. If T=(x,v,u), put X={x,u,v,b}; if T=(v,u,x), put X={a,u,v,x}. Then the four vertices of X are distinct, and exactly one of the following structural possibilities holds: (1) H[X] is Hamiltonian; (2) H[X] is the exceptional non-edge-orderable cyclic non-Hamiltonian K4; (3) H[X] is edge-orderable and non-Hamiltonian, and its three opposite-edge matchings have one uniquely forced strict block order. In case T=(x,v,u), the block order is {xv,ub} < {xb,uv} < {xu,vb}. In case T=(v,u,x), the block order is {au,vx} < {ax,uv} < {av,ux}.

## Body

First suppose T=(x,v,u). Since (u,v,b) is the inherited successor triple, x cannot equal b: otherwise T=(b,v,u) would be the reversal mate of the tight triple (u,v,b), contradicting boundary antisymmetry. Thus X={x,u,v,b} has four distinct vertices. If H[X] is Hamiltonian, outcome (1) holds. If it is non-Hamiltonian with cyclic comparison digraph, the certified four-vertex classification in smallset01 gives the exceptional cyclic K4, outcome (2). Otherwise H[X] is edge-orderable and non-Hamiltonian, so the matching-block classification applies. Let M0={xv,ub}, M1={xb,uv}, M2={xu,vb}. Tightness of (x,v,u) gives xv<uv, hence M0<M1. Tightness of (u,v,b) gives uv<vb, hence M1<M2. Therefore the unique block order is M0<M1<M2, which is the order stated. Now suppose T=(v,u,x). Use the inherited predecessor triple (a,u,v). Boundary antisymmetry similarly forces x!=a. Put M0={au,vx}, M1={ax,uv}, M2={av,ux}. The inherited triple gives au<uv, so M0<M1; the reversing triple gives uv<ux, so M1<M2. Hence again the unique block order is M0<M1<M2. No path reversal or cyclic permutation of a tight triple is used.
