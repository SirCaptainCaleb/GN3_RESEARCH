# Crossed sparse endpoint near-merges force inherited-order disagreement

## Statement

Let H be a minimum counterexample and let A|B|C be a spanning three-cover with |A|=|B|=|C|=r, where A=(a_1,...,a_r), B=(b_1,...,b_r), and C=(c_1,...,c_r) are displayed tight paths. Suppose H-a_1 has a two-cover B|L in which L is a Hamilton path on (V(A)-{a_1}) union V(C) and has exactly one ordinary edge crossing the partition (V(A)-{a_1})|V(C). Suppose H-a_r has a two-cover R|C in which R is a Hamilton path on (V(A)-{a_r}) union V(B) and has exactly one ordinary edge crossing (V(A)-{a_r})|V(B). Then at least one of L,R has relative-order disagreement with one of its two inherited displayed blocks. Equivalently, the crossed unique-crossing near-merge configuration cannot be simultaneously order-preserving.

## Body

Because H is a minimum counterexample, mincex01 gives |V(H)|>10. Since |V(H)|=3r, we have r>=4. Cutting the unique crossing edge of L gives exactly one A-{a_1} block and one C block; cutting the unique crossing of R gives exactly one A-{a_r} block and one B block. Suppose for contradiction that both L and R preserve the displayed relative order on each inherited block. Thus the two blocks of L are exactly the displayed orders (a_2,...,a_r) and (c_1,...,c_r), in one of the two possible block orders, and the two blocks of R are exactly (a_1,...,a_{r-1}) and (b_1,...,b_r), again in one of the two possible block orders. If L has block order (A-{a_1}),C, then its suffix (a_r,c_1,...,c_r) is a tight Hamilton path on {a_r} union V(C). Together with the Hamilton path R on (A-{a_r}) union B this two-covers H, contradiction. Hence L has block order C,(A-{a_1}). If R has block order B,(A-{a_r}), then its prefix (b_1,...,b_r,a_1) is a tight Hamilton path on V(B) union {a_1}. Together with L this two-covers H, contradiction. Hence R has block order (A-{a_r}),B. Therefore L has displayed order (c_1,...,c_r,a_2,...,a_r) and R has displayed order (a_1,...,a_{r-1},b_1,...,b_r). Since r>=4, the sequence (c_1,...,c_r,a_2,...,a_{r-1},b_1,...,b_r) is a tight path: every triple through the C-to-A junction and the initial A-interior triples is inherited from L, every triple through the A-to-B junction and the final A-interior triples is inherited from R, and all remaining triples lie inside the displayed paths. This path covers every vertex except a_1,a_r. The two-vertex sequence (a_1,a_r) is a tight path, so these two paths form a spanning two-cover of H, contradiction. Hence some inherited block is reordered in L or R.
