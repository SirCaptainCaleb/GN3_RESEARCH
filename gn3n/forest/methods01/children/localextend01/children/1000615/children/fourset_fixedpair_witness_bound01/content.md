# A four-set has at most six same-class fixed-pair witnesses, and six is sharp

## Statement

Let F be any four-vertex set in a boundary tournament. Among the six unordered pairs T subset F, at most six have the property that the complementary two vertices F-T lie in the same fixed-pair orientation class relative to T. This trivial upper bound is sharp: there exists a four-vertex boundary tournament in which all six pairs have the property.

## Body

There are exactly six unordered pairs T contained in a four-set F, so six is an immediate universal upper bound on the number of same-class fixed-pair witnesses. Sharpness is realized by fourset_six_fixedpair_witness_counterexample01, which explicitly constructs a four-vertex boundary tournament for which, for every pair T, the complementary pair F-T lies in one fixed-pair orientation class relative to T. Thus no universal multiplicity bound below six is available from the boundary-tournament axiom alone.
