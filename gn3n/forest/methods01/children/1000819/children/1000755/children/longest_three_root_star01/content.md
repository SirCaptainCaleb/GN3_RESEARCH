# A large longest-path complement yields a Hamiltonian six-set or three Hamiltonian five-sets with a common four-core

## Statement

Let H be a minimum counterexample and let A be a globally longest tight path. Assume |V(H)-V(A)|>=6 and that the internal-reversal K4 alternative of e74b4c4df111 does not occur. Then at least one of the following holds: (1) H contains a proper Hamiltonian six-vertex induced set U such that H-U is non-Hamiltonian with path-cover number two; (2) there is a four-vertex set C and three distinct vertices r_1,r_2,r_3 outside C such that each C union {r_i} is Hamiltonian, and for each i its complement is non-Hamiltonian with path-cover number two.

## Body

Use the notation of e74b4c4df111. Put D={a_1,a_0,a_{lambda-1},a_{lambda-2}} and let G be the set of exterior vertices y for which D union {y} is Hamiltonian with the displayed five-path. Since the K4 alternative is absent, all but at most two exterior vertices are in G. The exterior set has order at least six, so |G|>=4. Choose y in G and put X=D union {y}; X is Hamiltonian. If X union {z} is Hamiltonian for some z in G-{y}, then U=X union {z} is a Hamiltonian six-set. It is proper because every tight path in a minimum counterexample leaves at least four vertices, and if H-U were Hamiltonian then complementary Hamilton paths would two-cover H. Hence H-U is non-Hamiltonian and, by minimality, has path-cover number two, giving (1). Assume instead that X union {z} is non-Hamiltonian for every z in E=G-{y}. Then |E|>=3. Apply fivebadextensioncore01 to the Hamiltonian five-set X and exterior set E. There is x in X such that (X-{x}) union {z} is Hamiltonian for at least ceil(3|E|/5)>=2 distinct vertices z_1,z_2 in E. Put C=X-{x}. Then C union {x}=X, C union {z_1}, and C union {z_2} are three Hamiltonian five-sets on the same four-core C. Each is proper, so the same minimum-counterexample argument shows its complement is non-Hamiltonian with path-cover number two. Taking r_1=x,r_2=z_1,r_3=z_2 gives (2).
