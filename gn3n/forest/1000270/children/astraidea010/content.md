# Edge-orderable tournaments suffice for extremal path-cover number

## Statement

For each n, the maximum path-cover number among n-vertex boundary tournaments equals the maximum among those obtained from a strict total ordering of the edges of K_n, where (a,b,c) is tight exactly when ab<bc.

## Body

Unproved structural reduction. The edge-orderable class is a subclass, so only the inequality from general tournaments to that class needs proof. Try choosing an extremal boundary tournament and changing reversal-pair orientations while preserving its path-cover number, until its comparisons between incident unordered edges admit a common strict edge order. Each nonrealizable orientation contains comparison cycles; a useful local theorem would identify an orientation change on a cycle that does not decrease path-cover number. Main risk: independent local middle-vertex comparisons may support genuinely harder obstructions than a global edge order. Even failure could clarify which cyclic comparison patterns are essential and split the theorem into an edge-orderable core plus a cycle-reduction lemma. This is not an assertion that the present project already has such a reduction.
