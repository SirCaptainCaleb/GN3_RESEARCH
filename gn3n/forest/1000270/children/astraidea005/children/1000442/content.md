# No three vertices are inseparable in every two-cover

## Statement

If a finite boundary tournament H has at least one spanning two-cover, then for every three distinct vertices a,b,c there is a spanning two-cover in which a,b,c do not all lie on the same path. Equivalently, every equivalence class of the relation 'lies on the same path in every spanning two-cover' has size at most two.

## Body

Conjecture, unproved. This weakens prescribed-pair separation while still excluding a mandatory ordered triple. It would close the grand theorem by orientation flips: begin with a boundary tournament having a Hamilton path and change reversal-pair orientations one at a time. If the first change destroyed every two-cover, every two-cover immediately before that change would contain the changed ordered triple, contradicting the conjecture. First attack: assume an inseparable triple and minimize the size of the path containing it, then use the complementary path to split just one of the three labels off. The endpoint-transfer obstructions in the mandatory-triple toolkit are relevant but are not a proof.
