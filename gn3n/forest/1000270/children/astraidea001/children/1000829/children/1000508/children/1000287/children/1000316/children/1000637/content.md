# The fully crossed sharp half-order shell pair branch contains reciprocal direct core crossings

## Statement

Use the setup of 68deffb43319 for two lambda|lambda deletion covers F_a and F_b of H-a and H-b. Let A|B and C|D be their induced support partitions on U=V(H)-{a,b}. If all four intersections A∩C,A∩D,B∩C,B∩D are nonempty, then F_a contains an ordinary path edge with both endpoints in U crossing the partition C|D, and F_b contains an ordinary path edge with both endpoints in U crossing the partition A|B. Thus the fully crossed alternative already supplies reciprocal direct mixed-support edges, without any endpoint or order-preservation hypothesis.

## Body

Exactly one component of F_a contains b. Let P be the other component. After deleting b, P survives unchanged as one of the two support classes A,B; rename so V(P)=B. Because all four intersections are nonempty, B∩C and B∩D are both nonempty.

Read the vertices of the tight path P in their displayed order. Every vertex belongs to exactly one of C,D. Since both classes occur on P, at some consecutive pair of vertices the class changes. That ordinary edge of P has one endpoint in C and the other in D. Both endpoints lie in U because P does not contain b and F_a omits a. Hence F_a contains an ordinary U-edge crossing C|D.

Symmetrically, exactly one component Q of F_b avoids a and survives unchanged on U as one of C,D. The full four-cell hypothesis says Q meets both A and B, so some consecutive ordinary edge of Q crosses A|B, again with both endpoints in U.

This proves the reciprocal direct-crossing assertion. ∎
