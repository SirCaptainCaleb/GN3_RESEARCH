# Successful transferred-label insertion forces an endpoint-edge reversing triple

## Statement

Assume the all-three-successful-insertion branch of 1278e049ce8e. Then the cycle alternative of b2f0a8047d8d cannot occur. Consequently some successful-insertion path and some displayed support path P_i force a tight triple reversing one of the two displayed endpoint edges of P_i. Thus the successful-insertion arm reaches the endpoint-edge-reversal interface directly, strictly sharpening bare relative-order disagreement.

## Body

Choose j and a cyclic pair reversed by R_j relative to a different P_i, as in b2f0a8047d8d. It is enough to choose a reversed pair whose oriented R_j-segment reaches an endpoint of R_j. This is always possible. If t_{j+2} is inserted before t_j, use the reversed pair (t_{j+1},t_{j+2}) relative to P_{j+1}; the R_j segment from t_{j+2} to t_{j+1} is all of R_j. If t_{j+2} is inserted after t_{j+1}, use the reversed pair (t_{j+2},t_j) relative to P_{j+2}; the segment from t_j to t_{j+2} is all of R_j. If the insertion is strictly between t_j and t_{j+1}, write R_j=(t_j,L,t_{j+2},R,t_{j+1}) in block notation and use the reversed pair (t_{j+1},t_{j+2}) relative to P_{j+1}; its reversed R_j-segment E runs from t_{j+2} through R to the terminal vertex t_{j+1}. Apply the reversed-order path-intersection proof from pathcalc01 to P_i and R_j. If it yields an endpoint-edge reversing triple, we are done. Otherwise it closes E together with P_i into a tight cycle C. In the first two endpoint-insertion cases C contains all of R_j. In the internal case, rotate C so that it starts at t_{j+2} and ends at t_{j+1}, then prepend the inherited R_j prefix (t_j,L): the only join triples are already consecutive triples of R_j, so this gives a Hamilton path on U=V(P_i) union V(R_j). In every case U=H-M_k for the remaining petal k. Since M_k is a tight path, Hamiltonicity of U would give a spanning two-cover U|M_k of H, contradiction. Hence the cycle alternative is impossible and the endpoint-edge reversing triple is forced.
