# An endpoint-edge clean detour is bounded by reversal, a Hamiltonian five-window, or a doubled reverse barrier

## Statement

Let H-d=T be an exact deletion two-cover in a minimum counterexample, and suppose one T-component contains an inherited displayed path R=(r_1,...,r_m), m>=3, in preserved relative order but with a clean detour D=(r_1,u_1,...,u_k,r_2), k>=1, replacing the first inherited edge r_1r_2. Then at least one of the following holds: (1) a tight path on the detour support contains the reversed consecutive pair r_2,r_1; (2) for some auxiliary vertex z outside {r_1,r_2,r_3,u_1,...,u_k}, the reversing triple (r_2,r_1,z) is tight; (3) a Hamiltonian five-set is supported on {z,r_1,r_2,r_3,w}, where w is one endpoint of the detour; (4) one side of r_1r_2 carries a doubled reverse barrier. The symmetric statement holds for a detour replacing the last inherited edge.

## Body

Treat the first-edge case. Let z be the immediate predecessor of r_1 in its T-component if such a predecessor exists; if r_1 is initial in that component, set z=d. In either case z is distinct from the detour vertices and r_3. Boundary antisymmetry gives exactly one of (z,r_1,r_2) and (r_2,r_1,z). If the latter is tight, outcome (2) holds. Hence assume (z,r_1,r_2) is tight. The inherited path supplies (r_1,r_2,r_3). Apply 214a634b4fd9 to the detour. Its cycle branch gives outcome (1). Otherwise at least one wrap triple is tight.
