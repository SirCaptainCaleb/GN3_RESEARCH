# Canonical-state graph cannot trap

## Statement

Build a graph whose vertices are canonical deletion-cover states after a fixed normalization, with an edge for one certified bounded local replacement that preserves the normalization. Conjecture that every non-closing state lies in a component containing either a theorem-closing state or a state exhibiting a globally reusable order-disagreement witness; equivalently, there is no closed component consisting entirely of non-closing locally frozen states.

## Body

The point is to promote local exchange failures into global state-graph structure. A trap-free theorem would remove the need for a scalar potential: cycles and plateaus would be harmless as long as every closed class contains a consumable witness.
