# Separated three-label gap transports are locally consistent with boundary antisymmetry

## Statement

There exist boundary tournaments containing an ordered tight core R and three tight paths P_a on R union {b,c}, P_b on R union {a,c}, and P_c on R union {a,b} such that all three restrict to the same order on R, every pair P_a,P_b,P_c is order-incompatible solely because the common omitted-label complement changes insertion gap, and the two insertion gaps used by each of a,b,c may be chosen far apart. Hence boundary antisymmetry and local tightness alone do not force the three transport intervals from compattripletransport13 to overlap, nest, or collapse; any such closure must use additional global counterexample/fixed-complement information.

## Body

Take R=(r_0,...,r_13). Define P_a by inserting b between r_1,r_2 and c between r_7,r_8; define P_b by inserting a between r_3,r_4 and c between r_9,r_10; and define P_c by inserting a between r_5,r_6 and b between r_11,r_12, always preserving the displayed R-order. Declare every consecutive triple required by these three displayed paths tight. These requirements are consistent with the boundary-tournament reversal rule. R-only requirements always use the same R-order. A requirement containing a special label x and two R-vertices is determined by one insertion neighborhood; if the same unordered triple arises from x inserted at another gap, the required orientation has a different middle vertex rather than being the reversal with the same middle. The chosen insertions within each path are separated, so no required consecutive triple contains two special labels. Thus no reversal pair is required tight in both directions. Complete every still-unspecified reversal pair arbitrarily to obtain a boundary tournament. The common label c occupies different gaps in P_a,P_b, b occupies different gaps in P_a,P_c, and a occupies different gaps in P_b,P_c, so all three pairs are order-incompatible while the common core order is fixed. This is only a local-consistency fence: it does not satisfy or refute the global no-two-cover hypotheses of the project.
