# A witness-free one-crossing opposite-donor residue uses the unique inner join-adjacent gaps

## Statement

Continue the opposite-donor one-crossing residue of d4e6e9fba9ed, and assume in addition that no explicit cross triple is allowed. Then any successful insertion that d4e6e9fba9ed confines to the first two gaps is forced into gap 1 rather than the endpoint gap 0, and any successful insertion that it confines to the last two gaps is forced into gap r-1 rather than endpoint gap r. Thus every join-adjacent successful insertion in the one-crossing residue lies exactly one gap inward from the relevant core-core join.

## Body

Suppose d4e6e9fba9ed confines y to the first two gaps of C=(c_1,...,c_r), while the inherited interior path M ends immediately before C in the one-crossing two-cover and (M,y) is tight as inherited from A=(x,M,y). If y used endpoint gap 0, then (y,c_1,c_2) is tight. Consider M,y,C. Every consecutive triple is already tight except possibly (m_last,y,c_1), where m_last is the final vertex of M. If that triple is tight, M,y,C together with the disjoint Hamilton path on B+x gives a spanning two-cover of H. If it is non-tight, boundary antisymmetry gives the explicit reverse cross triple (c_1,y,m_last). Both alternatives are excluded in the witness-free branch, so y cannot use gap 0; hence its confined successful gap is exactly gap 1. The last-gap assertion is symmetric. Namely, whenever d4e6e9fba9ed confines x to the last two gaps of B=(b_1,...,b_r) and the corresponding one-crossing geometry places B immediately before M with (x,M) inherited from A, using endpoint gap r makes B,x tight. The concatenation B,x,M then has only the possibly new join triple (b_r,x,m_1). If it is tight, B,x,M together with the disjoint Hamilton path on C+y gives a spanning two-cover; if it is non-tight, the reverse cross triple (m_1,x,b_r) is tight. Hence gap r is excluded and the confined successful gap is exactly gap r-1. No assertion is made about the successful insertion on an isolated core when d4e6e9fba9ed does not confine its gap.
