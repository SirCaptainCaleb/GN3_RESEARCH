# High migration forces multiple canonical-partition crossings except for one full five-side swap

## Statement

Let C_0|P_0|Q_0 be the original canonical five-bridge cover, with |C_0|=5 and |P_0|,|Q_0|>=7, and let X|P|Q be a reachable minimum-Phi cover with the same component-order multiset, chosen in astra003migrationextremal. Put mu=|X-C_0|. Count ordinary edges of the current three-path forest that cross the old support partition C_0|P_0|Q_0. If mu>=3, then either there are at least two such crossing edges, or mu=5 and the current five-side X lies entirely inside one old outer support. More precisely, in the one-crossing case exactly two old support classes participate: an old outer component A of order m>5 is split into two current monochromatic blocks of orders 5 and m-5, the residual order-five block is X, and the other block is joined by the unique crossing edge to all of C_0 to form the current component of order m; the third old outer support is unchanged as a support.

## Body

Let t be the number of current ordinary path edges crossing the old three-class partition. If t=0, each current path component lies inside one old support class. Since there are three nonempty current components and three nonempty old classes, each old class contains exactly one current component, hence the support partition is unchanged. The unique order-five component is then C_0, so mu=0. Thus mu>=3 implies t>=1. Assume t=1. Cutting the unique crossing edge of the current three-path forest produces four monochromatic blocks across the three old support classes. Hence exactly one old class A is split into two blocks, a second old class B is one block joined across the unique crossing to one A-block, and the third old class C is one unchanged current component. Let k>0 be the order of the A-block transferred into the mixed component. The three current component orders are |A|-k, |B|+k, |C|. Since the current component-order multiset equals the old multiset {|A|,|B|,|C|}, cancelling the unchanged value |C| gives the multiset equality {|A|-k,|B|+k}={|A|,|B|}. Because k>0, the two values must swap, so |A|>|B| and k=|A|-|B|. If neither A nor B is C_0, then C=C_0 and the unique five-side support remains C_0, giving mu=0. If A=C_0, the inequality |A|>|B| is impossible because |A|=5 while every outer side has order at least seven. Therefore B=C_0 and A is an outer component of order m>5. Then k=m-5, the residual A-block has order five and is necessarily the current five-side X, while the mixed component consists of all five vertices of C_0 plus the transferred A-block and has order m. In particular X is disjoint from C_0, so mu=5. This is the stated exceptional one-crossing form. Hence mu=3 or 4 forces t>=2.
