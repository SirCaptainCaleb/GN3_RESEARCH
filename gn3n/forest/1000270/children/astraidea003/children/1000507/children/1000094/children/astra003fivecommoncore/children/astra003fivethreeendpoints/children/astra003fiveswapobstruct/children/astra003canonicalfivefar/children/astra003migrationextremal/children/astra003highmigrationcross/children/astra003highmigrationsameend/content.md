# The exceptional full five-side swap has a same-end common-block normal form

## Statement

Assume the exceptional mu=5, one-crossing case of astra003highmigrationcross. Let A be the old outer component of order m>=7, let X subset V(A) be the current five-side, let Y=V(A)-X have order m-5>=2, and let C_0 be the original five-side. Assume no relative-order disagreement between current monochromatic blocks and the original displayed paths, and assume the old path A crosses the current support partition only once, so X and Y are contiguous intervals of the displayed old path. Then, after orienting the displayed old and current paths as actually given, only the same-end configurations can occur: either A=(X,Y) and the current mixed path is (C_0,Y), or A=(Y,X) and the current mixed path is (Y,C_0), where block notation means concatenation of the inherited tight block orders. The opposite-end configurations A=(X,Y), mixed=(Y,C_0), and A=(Y,X), mixed=(C_0,Y) would splice to a Hamilton tight path on V(A) union C_0 and hence, together with the untouched third component, give a spanning two-cover of H.

## Body

In the exceptional one-crossing form, the current five-side X and transferred block Y partition the old outer support A, while the current component of order m consists of C_0 joined by the unique current crossing edge to Y. Since the old path has only one edge crossing X|Y, the two supports X,Y are contiguous intervals in the old displayed order. Under the no-order-disagreement assumption, the current X- and Y-block orders agree with the inherited old A-order, and similarly the current C_0 block agrees with an original Hamilton order on C_0. There are four attachment-direction possibilities. Suppose A=(X,Y) and the current mixed path is (Y,C_0). Because |Y|>=2, the concatenation (X,Y,C_0) is tight: the X-Y join is inherited from A, the Y-C_0 join from the current mixed path, and the two joins are separated by the whole common block Y, so every consecutive triple is inherited from one of the two tight paths. This gives a Hamilton path on A union C_0; together with the untouched third old/current component it two-covers H, contradiction. The case A=(Y,X) and mixed=(C_0,Y) is symmetric, giving (C_0,Y,X). Therefore only the same-end forms A=(X,Y), mixed=(C_0,Y) or A=(Y,X), mixed=(Y,C_0) remain.
