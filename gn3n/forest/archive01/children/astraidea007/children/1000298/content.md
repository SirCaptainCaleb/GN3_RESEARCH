# Astra 007 alone is inert on a minimum counterexample unless fractional mass reaches two

## Statement

Let H be a minimum-order counterexample to the grand two-cover conjecture. Then pc(H)=3 and tau*(H)<=2n/(n-1)<3. Consequently, assuming Astra idea 007, one can deduce only pc(H)<=3 unless tau*(H)<=2. More precisely, under Astra 007 any minimum counterexample must satisfy 2<tau*(H)<3; conversely the certified sharp half-order shell has tau*(H)=2+1/lambda and is perfectly consistent with the bound pc(H)<=ceil(tau*(H))=3. Thus Astra 007 closes the grand theorem only when combined with an independent mechanism forcing tau*(H)<=2, such as Astra idea 001.

## Body

Minimum-counterexample calculus gives pc(H)=3. The certified deletion-averaging fractional bound gives
tau*(H)<=2n/(n-1).
Since a minimum counterexample has n>10, this upper bound is strictly less than 3.

Assume Astra 007. If tau*(H)<=2, then
pc(H)<=ceil(tau*(H))<=2,
contradicting that H is a counterexample. Hence every minimum counterexample compatible with Astra 007 must have tau*(H)>2. Combining with the preceding upper bound gives
2<tau*(H)<3.
For every value in this interval, ceil(tau*(H))=3, so Astra 007 yields only pc(H)<=3, exactly what is already known.

This is not merely a logical possibility. In the certified sharp half-order shell n=2lambda+1, fractionalsharpshell01 gives
tau*(H)=2+1/lambda.
Therefore ceil(tau*(H))=3, so Astra 007 is fully compatible with the hypothetical counterexample value pc(H)=3 in that shell.

Finally weightedfractionalduality01 identifies Astra 001 with tau*(H)<=2. Hence 001+007 would immediately imply pc(H)<=2, whereas 007 alone supplies no contradiction on the current minimum-counterexample frontier. ∎
