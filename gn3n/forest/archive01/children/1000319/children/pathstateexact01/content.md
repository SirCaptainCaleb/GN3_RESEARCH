# Exact path-state encoding requires the used vertex set

## Statement

A vertex-simple tight path can be encoded exactly by a state consisting of its used set together with its ordered last two vertices: for |S|>=2, a reachable state (S;u,v) means that some tight path uses exactly S and ends ...u,v, and one may append w precisely when w∉S and (u,v,w) is tight, moving to (S∪{w};v,w). Singleton states handle one-vertex paths. Reachability from singleton/pair initial states is equivalent to existence of a vertex-simple tight path with that support and terminal data. Consequently H has a spanning cover by at most two tight paths exactly when two reachable path states have disjoint used sets whose union is V(H) (allowing an empty second component for a Hamilton path). This repairs the used-vertex defect of the ordered-terminal-pair state graph, but the exact state space has exponential size: already the non-singleton states are at most n(n-1)2^(n-2).

## Body

For a displayed tight path (v_1,...,v_t), t>=2, record S={v_1,...,v_t} and the ordered terminal pair (v_{t-1},v_t). Appending a new label w is legal exactly when w is not already used and the new consecutive triple (v_{t-1},v_t,w) is tight. Thus every vertex-simple tight path induces a directed state trajectory in which |S| increases by one at every step. Conversely, induction on |S| reconstructs from every reachable state a tight vertex-simple path using exactly S: the transition explicitly forbids repeated labels and checks the only new consecutive triple. For two components, retaining their two used sets makes disjointness exact; two reachable supports S,T form a path cover precisely when S∩T=∅ and S∪T=V(H), with the usual singleton conventions. The representation is faithful but not low-dimensional. For each S of size at least two there are at most |S|(|S|-1) ordered terminal pairs, so summing crudely over subsets gives at most n(n-1)2^(n-2) non-singleton states, plus n singleton states. Hence any dual/state-compression route that stores only O(n^c) terminal information must prove additional structure; exact path simplicity cannot be obtained from terminal pairs alone.
